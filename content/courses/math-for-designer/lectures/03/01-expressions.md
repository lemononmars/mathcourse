## Algebraic Expressions


:::definition Algebraic Expression

An **algebraic expression** is a mathematical phrase composed of numbers (constants), variables, and arithmetic operations ($+$, $-$, $\times$, $\div$, powers).

:::



:::example

The following are examples of algebraic expressions.


- $3x + 5$

- $2x^2 - 4x + 7$

- $\displaystyle \frac{x + 3}{2x - 1}$

- $4\sqrt{x} - 2y + 8$


:::




## Components of an Algebraic Expression


:::definition Components of an Algebraic Expression



- **Variable:** A symbol representing an unknown value (e.g., $x, y, t$).

- **Constant:** A fixed numeric value with no variable attached (e.g., $4, -7, \frac{2}{3}$).

- **Coefficient:** The numerical factor multiplying a variable (in $5x$, $5$ is the coefficient).


:::




## Example: Identifying Components


:::example

Consider the algebraic expression:
\[ 4x^2 - 7x + 9 \]
Determine the variable, coefficients, and constant term.

:::


:::solution



- **Variable:** $x$

- **Coefficients:** $4$ (for $x^2$) and $-7$ (for $x$)

- **Constant term:** $9$


:::




## Terms and Like Terms


:::definition Terms and Like Terms



- **Term:** A single number, variable, or numbers and variables multiplied together, separated by $+$ or $-$ signs (in $3x^2 - 5x + 7$, terms are $3x^2, -5x, 7$).

- **Like Terms:** Terms sharing identical variable parts with the same exponents (e.g., $4x$ and $-2x$).

- **Unlike Terms:** Terms that have different variables or different powers of the same variable (e.g., $5x^2$ and $5x$).


:::




## Example: Terms and Like/Unlike Terms


:::example



- In $5x^3 - 2x + 8$, the **terms** are $5x^3$, $-2x$, and $8$.

- $3x$ and $-8x$ are **like terms** (same variable $x$).

- $5x^2$ and $5x$ are **unlike terms** (different powers of $x$).


:::




## Fundamental Algebraic Properties (1/5)


:::property Commutative Properties

For all real numbers $a, b$:


- **Commutative Property of Addition:** Changing order does not change the sum.
\[ a + b = b + a \]

- **Commutative Property of Multiplication:** Changing order does not change the product.
\[ a \cdot b = b \cdot a \]


:::




## Fundamental Algebraic Properties (2/5)


:::property Associative Properties

For all real numbers $a, b, c$:


- **Associative Property of Addition:** Changing grouping does not change the sum.
\[ (a + b) + c = a + (b + c) \]

- **Associative Property of Multiplication:** Changing grouping does not change the product.
\[ (a \cdot b) \cdot c = a \cdot (b \cdot c) \]


:::




## Fundamental Algebraic Properties (3/5)


:::property Distributive Property

For all real numbers $a, b, c$:


- **Left Distributive Property:**
\[ a(b + c) = ab + ac \]

- **Right Distributive Property:**
\[ (a + b)c = ac + bc \]

*Description:* Multiplying a number by a sum distributes multiplication to each addend inside the parentheses.

:::




## Fundamental Algebraic Properties (4/5)


:::property Identity Properties

For any real number $a$:


- **Additive Identity:** Adding zero leaves the number unchanged ($0$ is the additive identity).
\[ a + 0 = a \]

- **Multiplicative Identity:** Multiplying by one leaves the number unchanged ($1$ is the multiplicative identity).
\[ a \cdot 1 = a \]


:::




## Fundamental Algebraic Properties (5/5)


:::property Inverse Properties

For any real number $a$:


- **Additive Inverse:** Adding the opposite (negation) yields zero.
\[ a + (-a) = 0 \]

- **Multiplicative Inverse:** Multiplying by the reciprocal yields one (for $a \neq 0$).
\[ a \cdot \frac{1}{a} = 1 \]


:::




## Simplifying Algebraic Expressions


:::example

Simplify the following algebraic expressions by expanding and combining like terms.


- $3x + 5y - 7x + 2y$

- $2(3x - 4) + 4(x + 5)$


:::


:::solution

\begin{eqnarray*}
a) \quad 3x + 5y - 7x + 2y &=& (3x - 7x) + (5y + 2y) 

&=& -4x + 7y 
[6pt]
b) \quad 2(3x - 4) + 4(x + 5) &=& (6x - 8) + (4x + 20) 

&=& (6x + 4x) + (-8 + 20) 

&=& 10x + 12
\end{eqnarray*}

:::
