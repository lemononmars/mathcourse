:::definition

A **linear function** is of the form
\[ f(x) = ax + b \]

:::



:::example

The following are examples of linear functions.


- $f(x) = x-2$

- $f(x) = 3x + 1$

- $\displaystyle f(x) = \frac{2}{3} x - \frac{4}{5}$

- $f(x) = 1$ (in this case, $a=0$)


:::




## Properties that Preserve Equations


:::property Properties of Equality

Let $A, B$ be expressions and $c$ be a real number. If $A = B$, then:


- **Addition Property:** $A + c = B + c$

- **Subtraction Property:** $A - c = B - c$

- **Multiplication Property:** $A \cdot c = B \cdot c$

- **Division Property:** $\frac{A}{c} = \frac{B}{c} \quad (c \neq 0)$


:::





## How to solve a linear equation?

Let $f(x) = ax + b$. The simplest form of linear equation is
\[ f(x) = c.\]
The goal is to find a real number $m$ such that $f(m) = c$. To achieve that, we want to rewrite the equation and derive
\[ x = \cdots\]
This can be achieved by using algebraic manipulation
\begin{eqnarray*}
ax + b &=& c 

ax &=& c - **b**

x &=& \red{\frac{1}{a}}(c-b)
\end{eqnarray*}




:::example

Solve the following linear equations.


- $2x+4=6$

- $-3x-5=4$


:::


:::solution


\begin{eqnarray*}
a) \quad 2x + 4 &=& 6 

2x &=& 6-4 = 2 

x &=& \frac{1}{2}\cdot 2 = 1 

b) \quad -3x -5 &=& 4 

-3x &=& 4+5 = 9 

x &=& \frac{1}{-3} \cdot 9 = -3
\end{eqnarray*}

:::




Another form of linear equation is
\[ f(x) = g(x).\]
Here, we want to find a real number $m$ such that $f(m) = g(m)$. We can still use basic algebraic manipulations.
\begin{eqnarray*}
ax + b &=& cx + d 

ax - **cx** &=& d - **b** 

(a-c)x &=& d-b 

x &=& \frac{d-b}{a-c}
\end{eqnarray*}
Note that we require $a-c\neq0$ or $a \neq c$. 




:::example

Solve the following linear equations.


- $2x+4 =x-6$

- $3x+5=x+7$


:::


:::solution

\begin{eqnarray*}
a) \quad 2x + 4 &=& x - 6 

2x -x &=& -6-4 

x &=& -10 

b) \quad 3x+5 &=& x+7 

3x -x&=& 7-5 

2x &=& 2 

x &=& \frac{1}{2} \cdot 2 = 1
\end{eqnarray*}

:::





:::example

Solve the following linear equations using the distributive property.


- $2(x - 3) = 4(x + 1)$

- $3(2x + 1) - 4 = 2(x - 5) + 3$


:::


:::solution

\begin{eqnarray*}
a) \quad 2(x - 3) &=& 4(x + 1) 

2x - 6 &=& 4x + 4 

2x - 4x &=& 4 + 6 

-2x &=& 10 

x &=& \frac{10}{-2} = -5 
[6pt]
b) \quad 3(2x + 1) - 4 &=& 2(x - 5) + 3 

6x + 3 - 4 &=& 2x - 10 + 3 

6x - 1 &=& 2x - 7 

6x - 2x &=& -7 + 1 

4x &=& -6 

x &=& -\frac{6}{4} = -\frac{3}{2}
\end{eqnarray*}

:::





:::example

Solve the following linear equation.
\[ (2x - 1) + 3(x + 2) = 4x + 15 \]

:::


:::solution

\begin{eqnarray*}
(2x - 1) + 3(x + 2) &=& 4x + 15 

2x - 1 + 3x + 6 &=& 4x + 15 

5x + 5 &=& 4x + 15 

5x - 4x &=& 15 - 5 

x &=& 10
\end{eqnarray*}

:::
