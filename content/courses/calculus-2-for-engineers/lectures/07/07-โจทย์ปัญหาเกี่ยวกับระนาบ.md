## การวาดระนาบในปริภูมิสามมิติ

ในปริภูมิสามมิตินั้น แกน $x$ ประกอบไปด้วยจุดในรุป $(x,0,0)$ (นั่นคือค่า $y=z=0$) 

แปลว่า เราสามารถหาจุดตัดแกน $x$ ของสมการระนาบ ด้วยการแทนค่า $y=z=0$ 

ในทำนองเดียวกัน จุดตัดแกน $y$ ของสมการระนาบ หาได้ด้วยการแทนค่า $x=z=0$ และจุดตัดแกน $z$ หาได้ด้วยการแทนค่า $x=y=0$ 


:::theorem

กำหนดระนาบ $M$ แล้ว


- จุดตัดแกน $x$ คือจุด $(x_0,0,0)$ นั่นคือ $y=z=0$

- จุดตัดแกน $y$ คือจุด $(0,y_0,0)$ นั่นคือ $x=z=0$

- จุดตัดแกน $z$ คือจุด $(0,0,z_0)$ นั่นคือ $x=y=0$


:::

เมื่อเราได้จุดตัดทั้งสามมาแล้ว เราจะสามารถวาดระนาบแบบคร่าวได้






:::example

จงหาจุดตัดแกน $x$, จุดตัดแกน $y$ และจุดตัดแกน $z$ ของระนาบ $2x+3y+4x-12=0$

:::


:::solution

จุดตัดแกน $x$ เกิดขึ้นเมื่อ $y=z=0$ เมื่อแทนค่านี้ลงไปในสมการจะได้
\[2x + 3(0) + 4(0) - 12 = 0 \qquad \longrightarrow \qquad x = 6\]
จุดตัดแกน $y$ เกิดขึ้นเมื่อ $x=z=0$ เมื่อแทนค่านี้ลงไปในสมการจะได้
\[2(0) + 3y + 4(0) - 12 = 0 \qquad \longrightarrow \qquad y =4\]
จุดตัดแกน $z$ เกิดขึ้นเมื่อ $x=y=0$ เมื่อแทนค่านี้ลงไปในสมการจะได้
\[2(0) + 3(0) + 4z - 12 = 0 \qquad \longrightarrow \qquad z = 3\]

:::






## ระยะทางจากจุดไประนาบ


:::theorem

ระยะทางจากจุด $P_0(x_0, y_0, z_0)$ ไปยังระนาบ $M: ax+by+cz+d=0$ คือระยะทางตั้งฉากจากจุดไปยังระนาบ ซึ่งหาได้จากสูตร
\begin{equation} 
D = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}
\end{equation}

:::





:::figure plane_distance_from_point — ระยะทางตั้งฉากจากจุด $P$ ไปยังระนาบ $M$
:::






:::example

จงหาระยะทางระหว่างจุด $P_0 (1, -4, -3)$ กับระนาบ $2x-3y+6z+1=0$

:::


:::solution

ให้ $D$ เป็นระยะทาง จากสมการ \eqref{plane_distance_point_to_plane} จะได้ว่า 

\begin{eqnarray*}
D &=& \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}} 

&=& \frac{|(2)(1) + (-3)(-4) + (6)(-3) + 1|}{\sqrt{2^2 + (-3)^2 + 6^2}} 

&=& \frac{|2+ 12 - 18 + 1|}{\sqrt{4 + 9 + 36}} 

&=& \frac{|-3|}{7} = \frac{3}{7}
\end{eqnarray*}

:::





## ระยะทางระหว่างระนาบที่ขนานกัน

ถ้ากำหนดระนาบ $M_1$ และ $M_2$ ที่ขนานกันมาให้ เราสามารถหาระยะทางได้โดยการหยิบจุด $P_1$ บนระนาบ $M_1$ และหาระยะทางระหว่างจุด $P_1$ และระนาบ $M_2$ หรือเราจะใช้สูตรต่อไปนี้ก็ได้เช่นกัน

:::theorem

ระยะทางระหว่างระนาบ $M_1: ax+by+cz+ d_1=0$ และระนาบ $M_2: ax+by+cz+d_2=0$ หาได้จากสูตร
\begin{equation} 
D = \frac{|d_1 - d_2|}{\sqrt{a^2 + b^2 + c^2}}
\end{equation}

:::

**หมายเหตุ:** สัมประสิทธิ์ในระนาบ $M_1$ และ $M_2$ ต้องเท่ากัน ถ้าไม่เท่ากันให้คูณสมการใดสมการหนึ่งเสียก่อน




:::figure plane_distance_between_planes — ระยะทางระหว่างระนาบ $M_1$ และ $M_2$
:::






:::example

จงหาระยะทางระหว่างระนาบต่อไปนี้ 
\[M_1: x+2y-2z-3=0 \qquad M_2: 2x+4y-4z-7=0\]

:::


:::solution

สังเกตว่าเวกเตอร์แนวฉากของระนาบ $M_1$ คือ $\langle 1,2,-2 \rangle$ และเวกเตอร์แนวฉากของระนาบ $M_2$ คือ $\langle 2,4,-4 \rangle$ ซึ่งขนานกัน (เนื่องจาก $\langle 2,4,-4 \rangle = 2 \langle 1,2,-2 \rangle$) แปลว่าระนาบทั้งสองขนานกัน 


ก่อนอื่น เราแปลงสมการระนาบให้มีสัมประสิทธิ์เท่ากันก่อน โดยการคูณสมการของ $M_1$ ด้วย 2 จะได้สมการใหม่เป็น
\[ M_1: 2x+4y-4z-6=0\]
ฉะนั้น
\[D = \frac{|d_1 - d_2|}{\sqrt{a^2 + b^2 + c^2}} = \frac{|(-6) - (-7)}{\sqrt{2^2 + 4^2 + (-4)^2}} = \frac{1}{6}\]

:::





## มุมระหว่างระนาบ

ถ้าระนาบไม่ขนานกัน แปลว่าระนาบจะทำมุมต่อกัน ข้อสังเกตที่สำคัญคือ มุมระหว่างระนาบจะมีค่าเท่ากับมุมระหว่างเวกเตอร์แนวฉากของระนาบ ฉะนั้นเราจึงสามารถใช้ผลคูณจุดเพื่อหามุมได้ดังนี้

:::theorem

กำหนดสมการระนาบ $M_1: a_1x+b_1y+c_1z+d_1=0$ มีเวกเตอร์แนวฉาก $\vec{N_1} = \langle a_1, b_1, c_1 \rangle$ และระนาบ $M_2: a_2x+b_2y+c_2z+d_2=0$ มีเวกเตอร์แนวฉาก $\vec{N_2} = \langle a_2, b_2, c_2 \rangle$ ให้ $\theta$ เป็นมุมระหว่างระนาบทั้งสองโดยที่ $0 \leq \theta \leq \frac{\pi}{2}$ จะได้

\begin{equation} 
\cos \theta = \frac{|\vec{N_1}\cdot\vec{N_2}|} {\| \vec{N_1}\| \|\vec{N_2}\|} = \frac{|a_1a_2 + b_1b_2 + c_1c_2|}{\sqrt{a_1^2 +b_1^2 + c_1^2}\sqrt{a_2^2 + b_2^2 + c_2^2}}
\end{equation}

:::





:::figure plane_angle — ระนาบ $M_1$ และ $M_2$ ทำมุม $\theta$ ระหว่างกัน
:::






:::example

จงหามุมระหว่างระนาบต่อไปนี้
\begin{eq*}
M_1&:& 3x - 6y - 2x - 15 = 0 

M_2&:& 2x + y -2z -5 = 0 
\end{eq*}

:::


:::solution

นำค่าไปแทนในสูตร \eqref{eq:plane_angle} จะได้ 
\[ \cos \theta = \frac{|(3)(2) + (-6)(1) + (-2)(-2)|}{\sqrt{3^2 + (-6)^2 + (-2)^2}\sqrt{2^2 + 1^2 + (-1)^2}} = \frac{|6-6+4|}{\sqrt{49}\sqrt{9}} =\frac{4}{21} \] 
ฉะนั้น $\theta = \arccos \frac{4}{21} \approx 79^{\circ}$

:::
