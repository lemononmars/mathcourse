## 3. สมการสมมาตรของเส้นตรง

เราสามารถกำจัดตัวแปรเสริม $t$ ออกจากสมการอิงตัวแปรเสริมของเส้นตรงได้ดังนี้ สมมติว่า $a,b \neq 0$ แล้วจะได้
\begin{eq*}
x = x_0 + at \quad &\longrightarrow& \quad t = \frac{x-x_0}{a} 

y = y_0 + bt \quad &\longrightarrow& \quad t = \frac{y-y_0}{b} 

\end{eq*}
ฉะนั้น

:::note

\[\frac{x-x_0}{a} = \frac{y-y_0}{b}\] 

:::

ในทำนองเดียวกัน สำหรับปริภูมิสามมิติจะได้

:::note

\[\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}\] 

:::





## 3. สมการสมมาตรของเส้นตรง


:::theorem

เส้นตรง $L$ ในปริภูมิ 2 มิติที่ผ่านจุด $P_0 = (x_0, y_0)$ และขนานกับเวกเตอร์ $\vec{v} = \left\langle a,b \right\rangle$ โดยที่ $a$ และ $b$ ไม่เท่ากับ 0 อยู่ในรูปของสมการสมมาตร 
\begin{equation} 
\frac{x-x_0}{a} = \frac{y-y_0}{b}
\end{equation}

เส้นตรง $L$ ในปริภูมิ 3 มิติที่ผ่านจุด $P_0 = (x_0, y_0, z_0)$ และขนานกับเวกเตอร์ $\vec{v} = \left\langle a,b,c \right\rangle$ โดยที่ $a,b$ และ $c$ ไม่เท่ากับ 0 อยู่ในรูปของสมการสมมาตร
\begin{equation} 
\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}
\end{equation}

:::






:::example

จงหาสมการสมมาตรของเส้นตรงที่ผ่านจุด $(2,1)$ และขนานกับเวกเตอร์ $ \langle 3, -4 \rangle$ 

:::


:::solution

โจทย์กำหนดให้ $P_0 = (x_0, y_0) = (-2,1)$ และ $\vec{v} =\left\langle a,b \right\rangle = \left\langle 3,-4 \right\rangle$ ฉะนั้นเราสามารถนำค่าทั้งหมดไปใส่ในสมการ \eqref{eq:line_symmetric_2d} ได้ทันที จะได้
\[ \frac{x-2}{3} = \frac{y-3}{-4} \] 

:::






:::example

จงหาสมการสมมาตรของเส้นตรงที่ผ่านจุด $(1,4,7)$ และขนานกับเวกเตอร์ $\langle -2,3,-1 \rangle$ 

:::


:::solution

โจทย์กำหนดให้ $P_0 = (x_0, y_0,z_0) = (1,4,7)$ และ $\vec{v} =\left\langle a,b,c \right\rangle = \left\langle -6,-3,0 \right\rangle$ ฉะนั้นเราสามารถนำค่าทั้งหมดไปใส่ในสมการ \eqref{eq:line_symmetric_3d} ได้ทันที จะได้
\[\frac{x-1}{-2} = \frac{y-4}{3} = \frac{z-7}{-1} \]

:::





## หมายเหตุ


:::remark

ถ้า $a,b$ หรือ $c$ เป็น 0 เราจะไม่นิยมเขียนในรูปแบบสมการสมมาตร แต่ถ้าจำเป็นเราสามารถเขียนได้ดังนี้


- ถ้าตัวใดตัวหนึ่งเป็น 0 เช่น ถ้า $a=0$ และ $b,c \neq 0$ เราสามารถเขียนเป็นสมการสมมาตรได้ดังนี้
\[x = x_0, \quad \frac{y-y_0}{b} = \frac{z-z_0}{c}\]

- ถ้าค่าสองค่าเป็น 0 เช่น ถ้า $a=b=0$ และ $c \neq 0$ เราจะต้องเขียนเป็นสมการอิงตัวแปรเสริม
\[x = x_0, \quad y = y_0, \quad z = z_0 + ct\]


:::
