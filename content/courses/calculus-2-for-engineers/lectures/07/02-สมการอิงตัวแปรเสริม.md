## การแปลงสมการเวกเตอร์เป็นสมการอิงตัวแปรเสริม

จากสมการ \eqref{eq:line_vector_2d} จะได้
\begin{eq*}
\left\langle x,y \right\rangle &=& \left\langle x_0,y_0 \right\rangle + t\left\langle a,b \right\rangle 

&=& \left\langle x_0 + at, y_0 + bt \right\rangle
\end{eq*}
สมการเวกเตอร์นี้จะเป็นจริงก็ต่อเมื่อส่วนประกอบเท่ากัน นั่นคือ
\begin{eq*}
x &=& x_0 + at 

y &=& y_0 + bt
\end{eq*}
ซึ่งเราได้เคยศึกษารูปแบบสมการนี้แล้ว ว่าเป็นสมการอิงตัวแปรเสริม โดยมีตัวแปรอิสระเป็น $t$ และตัวแปรตามเป็น $x$ และ $y$ ในที่นี้เราจะเขียนในรูปแบบ

:::note

\[ L: x = x_0 + at, \quad y = y_0 + bt\]

:::

โดยที่ $L$ เป็นชื่อของเส้นตรง




## 2. สมการอิงตัวแปรเสริมของเส้นตรง


:::theorem

เส้นตรง $L$ ในปริภูมิ 2 มิติที่ผ่านจุด $P_0 = (x_0, y_0)$ และขนานกับเวกเตอร์ $\vec{v} = \left\langle a,b \right\rangle$ โดยที่ $\vec{v} \neq \vec{0}$ อยู่ในรูปของสมการอิงตัวแปรเสริม 
\begin{equation} 
L: x = x_0 + at, \quad y = y_0 + bt
\end{equation}

เส้นตรง $L$ ในปริภูมิ 3 มิติที่ผ่านจุด $P_0 = (x_0, y_0, z_0)$ และขนานกับเวกเตอร์ $\vec{v} = \left\langle a,b,c \right\rangle$ โดยที่ $\vec{v} \neq \vec{0}$ อยู่ในรูปของสมการอิงตัวแปรเสริม
\begin{equation} 
L: x = x_0 + at, \quad y = y_0 + bt, \quad z = z_0 + ct
\end{equation}

:::






:::example

จงหาสมการอิงตัวแปรเสริมของเส้นตรงที่ผ่านจุด $(4,2)$ และขนานกับเวกเตอร์ $\langle -1, 5 \rangle$ 

:::


:::solution

โจทย์กำหนดให้ $P_0 = (x_0, y_0) = (4,2)$ และ $\vec{v} =\left\langle a,b \right\rangle = \left\langle -1,5 \right\rangle$ ฉะนั้นเราสามารถนำค่าทั้งหมดไปใส่ในสมการ \eqref{eq:line_para_2d} ได้ทันที จะได้
\[L: x = 4-t, \quad y = 2 + 5t \] 

:::






:::example

จงหาสมการอิงตัวแปรเสริมของเส้นตรงที่ผ่านจุด $(0,1,2)$ และขนานกับเวกเตอร์ $\langle -6,-3,0 \rangle$ 

:::


:::solution

โจทย์กำหนดให้ $P_0 = (x_0, y_0,z_0) = (0,1,2)$ และ $\vec{v} =\left\langle a,b,c \right\rangle = \left\langle -6,-3,0 \right\rangle$ ฉะนั้นเราสามารถนำค่าทั้งหมดไปใส่ในสมการ \eqref{eq:line_para_3d} ได้ทันที จะได้
\[L: x = -6t, \quad y =1-3t , \quad z = 2\]

:::
