## การหาสมการเส้นตรงเมื่อกำหนดจุดบนเส้นตรง 2 จุด

เราสามารถหาสมการอิงตัวแปรเสริมของเส้นตรงได้ ถ้ากำหนดจุดบนเส้นตรงนั้นมาให้ 2 จุด โดยใช้จุดทั้งสองเพื่อหาเวกเตอร์ที่ขนานกับเส้นตรง ตามทฤษฎีบทดังต่อไปนี้


:::theorem

เวกเตอร์ที่ผ่านจุด $P_0 = (x_0, y_0, z_0)$ และ $P_1 = (x_1, y_1, z_1)$ โดยที่ $P_0 \neq P_1$ คือ 
\begin{equation} 
\overrightarrow{P_0P_1} = \langle x_1 - x_0, y_1 - y_0, z_1 - z_0 \rangle
\end{equation}

:::

แล้วเรานำเวกเตอร์ที่ได้ พร้อมกับจุด $P_0$ ไปใช้ในสมการเวกเตอร์ สมการอิงตัวแปรเสริม หรือสมการสมมาตร เพื่อหาสมการเส้นตรงได้






:::example

จงหาสมการเวกเตอร์เส้นตรงที่ผ่านจุด $P_0 = (1,2,3)$ และ $P_1 = (4,5,6)$ 

:::


:::solution

ใช้สมการ \eqref{eq:line_vect_through_dots} เพื่อหาเวกเตอร์ที่ขนานกับเส้นตรงคือ 
\[\vec{v} = \overrightarrow{P_0P_1} = \left\langle 4,5,6 \right\rangle - \left\langle 1,2,3 \right\rangle = \left\langle 3,3,3 \right\rangle\]
ฉะนั้น เรานำ $\vec{v}$ และจุด $P_0$ ไปใส่ในสมการ \eqref{eq:line_vector_3d} จะได้
\[ \left\langle x,y,z \right\rangle = \left\langle 1,2,3 \right\rangle + t\left\langle 3,3,3 \right\rangle\]

:::






:::example

จงหาสมการอิงตัวแปรเสริมของเส้นตรงที่ผ่านจุด $P_0 = (-1,0,4)$ และ $P_1 = (5,-1,4)$ 

:::


:::solution

ใช้สมการ \eqref{eq:line_vect_through_dots} เพื่อหาเวกเตอร์ที่ขนานกับเส้นตรงคือ 
\[\vec{v} = \overrightarrow{P_0P_1} = \left\langle 5,-1,4 \right\rangle - \left\langle -1,0,4 \right\rangle = \left\langle 6,-1,0 \right\rangle\]
ฉะนั้น เรานำ $\vec{v}$ และจุด $P_0$ ไปใส่ในสมการ \eqref{eq:line_para_3d} จะได้
\[L: x=-1+6t, \quad y=-t, \quad z = 4\]

:::





## การหาข้อมูลจากเส้นตรง

เราได้ศึกษาว่า ถ้ากำหนดข้อมูลมาให้ เราจะสามารถสร้างเส้นตรงได้

ในทำนองกลับกัน ถ้ากำหนดเส้นตรงมาให้ เราสามารถหาข้อมูลต่าง ๆ ได้ดังนี้


- ยกตัวอย่างจุดบนเส้นตรง

- ทดสอบว่าจุดอยู่บนเส้นตรงหรือไม่

- หาเวกเตอร์ที่ขนานกับเส้นตรง






## การยกตัวอย่างจุดบนเส้นตรง

ถ้ากำหนดให้สมการอิงตัวแปรเสริมของเส้นตรงมา เราสามารถแทนค่า $t$ เพื่อหาจุดบนเส้นตรงนั้นได้ 


:::example

ให้เส้นตรง $L$ กำหนดโดยสมการ 
\[x = 1+t, \quad y = 3-2t\] 
จงยกตัวอย่างจุดที่อยู่บนเส้นตรง $L$ ที่แตกต่างกันมา 3 จุด

:::



:::solution

เราสามารถยกตัวอย่างจุดบนเส้นตรงได้ด้วยการแทนค่า $t$ เป็นจำนวนจริงใด ๆ ในที่นี้ถ้าเราให้ $t=**0**$ จะได้ 
\[x = 1+**0** = 1, \quad y = 3-2(**0**) = 3\] 

:::





:::note

\[L: x = 1+t, \quad y = 3-2t\]

:::


:::solution
(ต่อ)
นั่นคือจุด $(x,y) = (0,3)$ อยู่บนเส้นตรง $L$ ถ้าเราให้ $t= **2**$ จะได้ 
\[x = 1+**2** = 3, \quad y = 3-2(**2**) = -1\] 
นั่นคือจุด $(x,y) = (11,-17)$ อยู่บนเส้นตรง $L$ ถ้าเราให้ $t= **10**$ จะได้ 
\[x = 1+**10** = 11, \quad y = 3-2(**10**) = -17\] 
นั่นคือจุด $(x,y) = (11,-17)$ อยู่บนเส้นตรง $L$ ฉะนั้น ตัวอย่างจุดที่อยู่บนเส้นตรง $L$ คือ $(1,3), (3,-1)$ และ $(11,-17)$

:::






## การตรวจสอบว่าจุดอยู่บนเส้นตรงหรือไม่

ในทางกลับกัน จุด $P_0 = (x_0, y_0, z_0)$ จะอยู่บนเส้นตรง $L$ ก็ต่อเมื่อมีค่า $t$ ที่ทำให้สมการทุกสมการเป็นจริง 

:::example

จงหาว่าจุด $P_1 = (1,2,3)$ อยู่บนเส้นตรงต่อไปนี้หรือไม่ 
\[L: x = 3 - 2t, \quad y = t + 1, \quad z = 3\]

:::


:::solution

ถ้าจุด $P_1=(1,2,3)$ อยู่บนเส้นตรง $L$ แล้ว จะมีค่า $t$ ที่ทำให้
\[ 1 = x = 3-2t, \quad 2 = y = t + 1, \quad 3 = z =3 \] 
เมื่อแก้สมการแล้วจะได้ว่า $t=1$ สอดคล้องกับสมการทั้งสาม ฉะนั้นจุด $P_1$ อยู่บนเส้นตรง $L$ 

:::






:::example

จงหาว่าจุด $P_2 =(3,3,3)$ อยู่บนเส้นตรงต่อไปนี้หรือไม่
\[L: x = 3 - 2t, \quad y = t + 1, \quad z = 3\]

:::


:::solution

ถ้าจุด $P_2=(3,3,3)$ อยู่บนเส้นตรง $L$ แล้ว จะมีค่า $t$ ที่ทำให้
\[ 3 = x = 3-2t, \quad 3 = y = t+1, \quad 3 = z = 3\]
เมื่อแก้สมการแรกจะได้ $t=0$ แต่เมื่อแก้สมการที่่สองจะได้ $t=2$ 

แสดงว่าไม่มีค่า $t$ ค่าเดียว ที่ทำให้สมการทุกสมการเป็นจริง ฉะนั้นจุด $P_2(3,3,3)$ **ไม่**อยู่บนเส้นตรง $L$

:::






## การหาเวกเตอร์ที่ขนานกับเส้นตรง

ถ้ากำหนดสมการเส้นตรงมาให้ ในรูปแบบสมการเวกเตอร์ สมการอิงตัวแปรเสริม หรือสมการสมมาตร เราสามารถหาเวกเตอร์สัมผัสได้ ด้วยการพิจารณาสัมประสิทธิ์

:::example

จงหาเวกเตอร์ที่ขนานกับเส้นตรงที่กำหนดโดยสมการเวกเตอร์
\[ \left\langle x,y,z \right\rangle = \left\langle 2+2t, 3-t, 4+t \right\rangle\]

:::


:::solution

เราเขียนสมการเวกเตอร์ใหม่ได้เป็น
\[ \left\langle x,y,z \right\rangle = \left\langle 2+2t, 3-t, 4+t \right\rangle = \left\langle 2,3,4 \right\rangle + t\left\langle 2,-1,1 \right\rangle\]
ฉะนั้น เส้นตรงนี้ขนานกับเวกเตอร์ $\left\langle 2,-1,1 \right\rangle$

:::






:::example

จงหาเวกเตอร์ที่ขนานกับเส้นตรงที่กำหนดโดยสมการอิงตัวแปรเสริม
\[ L: x = 3+t, \quad y = 5t, \quad z = 2\]

:::


:::solution

จากสมการอิงตัวแปรเสริม \eqref{eq:line_para_3d} เราทราบว่าเราหาเวกเตอร์ได้จากสัมประสิทธิ์ของ $t$ นั่นคือ $1, 5, 0$ ตามลำดับ ฉะนั้น เส้นตรงนี้ขนานกับเวกเตอร์ $\left\langle 1,5,0 \right\rangle$

:::
