## 

ในพิกัดฉาก เราแปลงพื้นที่ $dA$ ได้ดังนี้
\[ dA = dx \, dy \]

*การคำนวณพื้นที่สี่เหลี่ยมผืนผ้า $dA = dx dy$*

แต่ในพิกัดเชิงขั้ว พื้นที่ $dA$ แต่ละชิ้นไม่ใช่สี่เหลี่ยมมุมฉาก ทำให้ต้องคำนวณพื้นที่ใหม่

*การคำนวณพื้นที่รูปคล้ายสี่เหลี่ยมผืนผ้า $dA = (dr)(rd \theta)$*





:::theorem

กำหนดให้ $f(r,\theta)$ เป็นฟังก์ชันสองตัวแปรในระบบพิกัดเชิงขั้ว 
\[ \iint\limits_R f(r,\theta) \, dA = \lim_{n \to \infty} \sum_{k=1}^n f(r_k, \theta_k) \Delta A\]

:::





:::slide

เมื่อค่า $\Delta r$ และ $\Delta \theta$ เล็กมาก ฐานจะเข้าใกล้รูปสี่เหลี่ยมผืนผ้า ฉะนั้นเราสามารถประมาณค่าได้โดยใช้พื้นที่สี่เหลี่ยมผืนผ้าแทน 


- ด้านหนึ่ง มีค่าเท่ากับ $\Delta r$ 

- อีกด้านหนึ่ง ขึ้นอยู่กับทั้ง $r$ และ $\theta$ เนื่องจากแม้ว่าจะเป็นมุม $\theta$ เท่ากัน แต่ยิ่งค่า $r$ มากขึ้น ความยาวด้านก็จะมากขึ้น ซึ่งหาได้ด้วยตรีโกณมิติ
\[ r \sin \Delta \theta\]
ซึ่งเมื่อค่า $\Delta \theta$ เล็กมาก เราจะได้ $\sin \Delta \theta \sim \Delta \theta$ นั่นคือเป็น $r \Delta \theta$

ฉะนั้น พื้นที่ของบริเวณคือ
\[ \Delta A \approx ( r \Delta \theta) (\Delta r) = r\Delta r \Delta \theta\]
เมื่อแปลงเป็น $d$ จะได้
\[ dA =** r\, dr** \, d\theta\]

:::





## 


:::theorem

กำหนด $f(r,\theta)$ เป็นฟังก์ชันสองตัวแปรในระบบพิกัดเชิงขั้วที่หาปริพันธ์ได้ 
\begin{equation} 
\iint\limits_R f(r,\theta) \, dA = \iint\limits_{\text{ขอบเขตที่เหมาะสม}} f(r,\theta) **r\,dr**\,d\theta 
\end{equation}

:::






## ปริพันธ์สองชั้นในพิกัดเชิงขั้ว ที่เป็นรูปส่วนของวงแหวน

**ส่วนของวงแหวน** คือ บริเวณที่กำหนดด้วย
\[ \alpha \leq \theta \leq \beta, \qquad a \leq r \leq b \]
เมื่อ $\beta - \alpha < 2\pi$ และ $a > 0$

:::slide




:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.8]
\axes{-0.5}{4}{-0.5}{4};
\draw[red] (0,0) -- (30:4) node[pos = 0.6, below right] {$\theta = \alpha$};
\draw[red] (0,0) -- (60:4) node[pos = 0.6, left] {$\theta = \beta$};
\draw[teal] (20:2) arc [start angle = 20, end angle = 70, radius = 2] node[pos = 0.5, below left] {$r = a$};
\draw[teal] (20:3) arc [start angle = 20, end angle = 70, radius = 3] node[pos = 0.5, above right] {$r = b$};
\fill[teal!20] (30:2) arc[start angle = 30, end angle = 60, radius = 2] -- (60:3) arc[start angle = 60, end angle = 30, radius = 3] -- cycle;
\node at (45:2.5) {$R$};
\end{tikzpicture}
:::


*ส่วนของวงแหวน $\alpha \leq \theta \leq \beta$ และ $a \leq r \leq b$*


:::




เนื่องจากอสมการมีความคล้ายกับกรณีสี่เหลี่ยมมุมฉาก เราจึงสามารถแปลงจากปริพันธ์สองชั้น เป็นปริพันธ์ซ้อนสองชั้นได้เช่นกัน

:::theorem

กำหนดให้ $R$ เป็นบริเวณในระนาบสองมิติ ที่กำหนดด้วย $\alpha \leq \theta \leq \beta$ และ $a < r <b$ 
\begin{equation} 
\iint\limits_R f(r,\theta) \, dA = \int_\alpha^\beta \int_a^b f(r,\theta) **r \, dr** \, d\theta
\end{equation}

:::






:::example

จงหา $\iint\limits_R r^2 \, dA$ เมื่อ $R$ เป็นบริเวณที่กำหนดด้วย $0 \leq \theta \leq \frac{\pi}{2}$ และ $0 \leq r < 2$

:::


:::solution

เนื่องจากเป็นส่วนของวงกลม เราจึงสามารถแปลงเป็นปริพันธ์ซ้อนสองชั้นโดยตรงได้ดังนี้
\begin{eq*}
\iint\limits_R r^2 \, dA &=& \int_0^{\frac{\pi}{2}} \int_0^2 r^2 **r \, dr** \, d\theta = \int_0^{\frac{\pi}{2}} \int_0^2 r^3 \,dr \, d\theta 

&=& \int_0^{\frac{\pi}{2}} \left( \frac{r^4}{4} \right) \Big|_{r=0}^{r=2} \, d\theta = \int_0^{\frac{\pi}{2}} 4 \, d\theta 

&=& \left( 4\theta \right) \Big|_{\theta = 0}^{\theta = \frac{\pi}{2}} = 2\pi
\end{eq*}

:::






:::example

จงหา $\iint\limits_R r \cos\theta \, dA$ เมื่อ $R$ เป็นบริเวณที่กำหนดด้วย $\frac{\pi}{2} \leq \theta \leq \pi$ และ $1 \leq r < 4$

:::


:::solution

เนื่องจากเป็นส่วนของวงกลม เราจึงสามารถแปลงเป็นปริพันธ์ซ้อนสองชั้นโดยตรงได้ดังนี้
\begin{eq*}
\iint\limits_R r\cos\theta \, dA &=& \int_{\frac{\pi}{2}}^\pi \int_1^4 r\cos\theta **r \, dr** \, d\theta = \int_{\frac{\pi}{2}}^\pi \int_1^4 r^2\theta \,dr \, d\theta 

&=& \int_{\frac{\pi}{2}}^\pi \cos\theta \left(\frac{r^3}{3}\right) \Big|_{r=1}^{r=4} \, d\theta = \int_{\frac{\pi}{2}}^\pi 21 \cos\theta \, d\theta 

&=& 21 (\sin\theta)\Big|_{\theta = \pi}^{\theta = \frac{\pi}{2}} = -21 
\end{eq*}

:::





:::exercise

จงหาปริพันธ์ต่อไปนี้


- $\iint\limits_R r^2\cos \theta \, dA$ เมื่อ $R$ เป็นบริเวณที่กำหนดด้วย $0 \leq \theta \leq \pi$ และ $1 \leq r \leq 3$


:::
