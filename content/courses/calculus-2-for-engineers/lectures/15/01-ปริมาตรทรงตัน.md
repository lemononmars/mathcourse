## 1. ปริมาตร


:::theorem

กำหนด $S$ เป็นทรงตันสามมิติ แล้วปริมาตรของ $S$ มีค่าเท่ากับ
\begin{equation} 
V = \iiint\limits_S 1 \, dV
\end{equation}

:::







:::example

จงหาปริมาตรของกรวยฐานวงกลม ความสูง $h$ และรัศมี $h$

:::


:::solution

ขอบเขตของกรวย ในพิกัดทรงกระบอกคือ
\[0 \leq r \leq z, \quad 0 \leq \theta \leq 2\pi, \quad 0 \leq z \leq h\]
ฉะนั้น ปริมาตรของทรงกลมคือ
\begin{eq*}
V = \iiint\limits_S 1 \, dV &=& \int_0^h \int_0^{2\pi} **\int_0^z r \, dr** \, d\theta \, dz 

&=& \int_0^h \blue{ \int_0^{2\pi} \frac{1}{2} z^2 \, d\theta} \, dz 

&=& \int_0^h \pi z^2 \, dz = \frac{1}{3} \pi h^3
\end{eq*}

:::







:::example

จงหาปริมาตรของทรงกลมรัศมี $a$

:::


:::solution

ขอบเขตของทรงกลม ในพิกัดทรงกลมคือ
\[0 \leq \rho \leq a, \quad 0 \leq \phi \leq \pi, \quad 0 \leq \theta \leq 2\pi\]
ฉะนั้น ปริมาตรของทรงกลมคือ
\begin{eq*}
V = \iiint\limits_S 1 \, dV &=& \int_0^{2\pi} \int_0^{\pi} **\int_0^a \rho^2 \sin \phi \, d\rho** \, d\phi \, d\theta 

&=& \int_0^{2\pi}\blue{ \int_0^{\pi} \frac{1}{3} a^3 \sin \phi \, d\phi} \, d\theta 

&=& \int_0^{2\pi} \frac{2}{3} a^3 \, d\theta = \frac{4}{3} \pi a^3
\end{eq*}

:::







:::example

จงหาปริมาตรของกรวยไอศกรีมรัศมี $a$ ที่ทำมุม $0 \leq \phi \leq \tfrac{\pi}{4}$ กับแกน $z$

:::


:::solution

ขอบเขตของกรวยไอศกรีมนี้คือ
\[0 \leq \rho \leq a, \quad 0 \leq \phi \leq \tfrac{\pi}{4}, \quad 0 \leq \theta \leq 2\pi\]
ฉะนั้น ปริมาตรของทรงกลมคือ
\begin{eq*}
V = \iiint\limits_S 1 \, dV &=& \int_0^{2\pi} \int_0^{\pi/4} **\int_0^a \rho^2 \sin \phi \, d\rho** \, d\phi \, d\theta 

&=& \int_0^{2\pi}\blue{ \int_0^{\pi/4} \frac{1}{3} a^3 \sin \phi \, d\phi} \, d\theta 

&=& \int_0^{2\pi} \frac{\sqrt{2}}{6} a^3 \, d\theta = \frac{\sqrt{2}}{3} \pi a^3
\end{eq*}

:::
