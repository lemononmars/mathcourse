## พิกัดทรงกลมในปริภูมิ 3 มิติ

นอกจากพิกัดทรงกระบอกแล้ว เราสามารถใช้พิกัดแบบใหม่ได้ ซึ่งเรียกว่า **พิกัดทรงกลม** 

ถ้า $P$ เป็นจุดในพิกัดทรงกลม ที่เขียนแทนด้วย $(\rho, \theta, \phi)$ เราเรียกเส้นจากจุดกำเนิดไปยังจุด $P$ ว่า **แขน** 


- $\rho$ แทนความยาวของแขน (นั่นคือ ระยะทางจากจุดกำเนิด $(0,0,0)$ ไปยังจุดนั้น)

- $\theta$ แทนมุมระหว่างภาพฉายของแขนบนระนาบ $xy$ กับแกน $x$

- $\phi$ แทนมุมระหว่างแขนกับแกน $z$ ด้านบวก (ด้านที่ชี้ขึ้น)

## วิธีแปลงพิกัดทรงกลม เป็นพิกัดฉาก


:::theorem

กำหนดจุดในพิกัดทรงกลม $(\rho,\theta,\phi)$ ซึ่ง $0 \leq \phi \leq \pi$ เราสามารถแปลงให้เป็นจุดในพิกัดฉาก $(x,y, z)$ ได้ดังนี้
\begin{eq*}
x &=& \rho \sin \phi \cos \theta 

y &=& \rho \sin \phi \sin \theta 

z &=& \rho \cos \phi
\end{eq*}

:::






:::example

จงแปลงจุด $(\rho, \theta, \phi) = \left(2, 0, \frac{\pi}{2}\right)$ ในพิกัดทรงกลม ให้เป็นจุดในพิกัดฉาก

:::


:::solution

จุด $(**\rho**, **\theta**, **\phi**) = \left(2, 0, \frac{\pi}{2}\right)$ ในพิกัดทรงกลม แปลงเป็นพิกัดฉากได้ดังนี้
\begin{eq*}
x &=& **\rho** \sin **\phi** \cos **\theta** = 2\left(\sin \frac{\pi}{2}\right) (\cos 0) = 2(1)(1) = 2 

y &=& **\rho** \sin **\phi** \sin **\theta** = 2\left(\sin \frac{\pi}{2}\right) (\sin 0) = 2(1)(0) = 0

z &=& **\rho** \cos **\phi** = 2\left( \sin \frac{\pi}{2} \right) = 2(0) = 0
\end{eq*}
ฉะนั้น จุด $(\rho, \theta, \phi) = \left(2, 0, \frac{\pi}{2}\right)$ ในพิกัดทรงกลม เท่ากับจุด $(x,y,z) = (2,0,0)$ ในพิกัดฉาก 

:::








## วิธีแปลงพิกัดฉาก เป็นพิกัดทรงกลม


\resizebox{!}{0.8\textheight}{

:::theorem

กำหนดจุดในพิกัดฉาก $(x,y,z)$ ที่ไม่ใช่จุดกำเนิด $(0,0,0)$ เราสามารถแปลงให้เป็นจุดในพิกัดทรงกลม $(\rho,\theta,\phi)$ ได้ดังนี้
\begin{eq*}
\rho &=& \sqrt{x^2 + y^2 + z^2} 

\tan \theta &=& \frac{y}{x} 

\cos \phi &=& \frac{z}{\rho} = \frac{z}{ \sqrt{x^2 + y^2 + z^2}}
\end{eq*}
โดยค่าของ $\theta$ ใช้วิธีเดียวกันกับพิกัดทรงกระบอก และค่าของ $\phi$ จะขึ้นอยู่กับค่า $z$ โดย
\[
\phi = \begin{cases}
\arccos \left( \tfrac{z}{\rho}\right) &, \quad z > 0 

\arccos \left( \tfrac{z}{\rho}\right) + \pi &, \quad z \leq z_0 

\end{cases}
\]

:::

}





:::example

จงแปลงจุด $(x,y,z) = (1,0,1)$ ในพิกัดฉาก ให้เป็นจุด $(\rho, \theta, \phi)$ ในพิกัดทรงกลม

:::


:::solution

จุด $(x,y,z) = (0,1,1)$ ในพิกัดฉาก แปลงเป็นพิกัดทรงกลมได้ดังนี้
\begin{eq*}
\rho &=& \sqrt{x^2 + y^2 + z^2} = \sqrt{1^2 + 0^2 + 1^2} = \sqrt{2} 

\tan \theta &=& \frac{y}{x} = \frac{0}{1} = 0, \qquad \cos \phi = \frac{z}{\rho} = \frac{1}{\sqrt{2}}
\end{eq*}
เนื่องจากจุด $(x,y) = (1,0)$ อยู่บนแกน $x$ ในทิศทางบวก ฉะนั้น $\theta = 0$ และเนื่องจาก $z > 0$ ฉะนั้น $\phi = \arccos \left( \frac{1}{\sqrt{2}}\right) = \frac{\pi}{4}$ ฉะนั้นจุด $(x,y,z) = (1,0,1)$ ในพิกัดฉาก คือจุด $(\rho, \theta, \phi) = \left( \sqrt{2}, 0, \frac{\pi}{4} \right)$ ในพิกัดทรงกลม

:::





:::exercise



- จงแปลงจุด $(\rho, \theta, \phi)$ ในพิกัดทรงกลมต่อไปนี้ ให้เป็นจุด $(x,y,z)$ ในพิกัดฉาก


- $(\rho, \theta, \phi) = \left(1, \frac{\pi}{2}, \frac{\pi}{2}\right)$

- $(\rho, \theta, \phi) = (2, \pi, 0)$

- $(\rho, \theta, \phi) = \left(4, \frac{\pi}{3}, \frac{\pi}{6}\right)$

- $(\rho, \theta, \phi) = \left(\sqrt{3}, -\tfrac{\pi}{4}, \tfrac{3\pi}{4}\right)$


- จงแปลงจุด $(x,y,z)$ ในพิกัดฉากต่อไปนี้ ให้เป็นจุด $(\rho, \theta, \phi)$ ในพิกัดทรงกลม


- $(x,y,z) = (2,2,1)$

- $(x,y,z) = (0,-3,4)$

- $(x,y,z) = (1, \sqrt{3}, -2)$

- $(x,y,z) = (-3,-3,-3)$



:::





## วิธีแปลงพิกัดทรงกระบอกเป็นทรงกลม

โดยส่วนใหญ่เราจะแปลงจากพิกัดฉากไปยังพิกัดอื่น หรือจากพิกัดอื่นกลับไปเป็นพิกัดฉาก แต่เราสามารถแปลงจากพิกัดทรงกลมไปยังพิกัดทรงกระบอก และจากพิกัดทรงกระบอกไปยังทรงกลมได้โดยตรงดังต่อไปนี้

:::theorem

จุดในพิกัดทรงกระบอก $(r, \theta, z)$ แปลงเป็นจุดในพิกัดทรงกลม $(\rho, \theta, z)$ เป็น


- $\rho = \sqrt{r^2 + z^2}$

- $\theta = \theta$

- $\tan \phi = \tfrac{r}{z}$


จุดในพิกัดทรงกลม $(\rho, \theta, \phi)$ แปลงเป็นจุดในพิกัดทรงกระบอก $(r,\theta,z)$ เป็น


- $r = \rho \sin \theta$

- $\theta = \theta$

- $z = \rho \cos\theta$


:::


สังเกตว่า ค่า $\theta$ ในพิกัดทรงกระบอกและพิกัดทรงกลมมีความหมายเหมือนกัน
