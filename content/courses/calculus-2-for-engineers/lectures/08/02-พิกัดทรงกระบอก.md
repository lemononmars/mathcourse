## พิกัดทรงกระบอกในปริภูมิ 3 มิติ

เราสามารถนำพิกัดเชิงขั้วในปริภูมิ 2 มิติ มาขยายเป็น**พิกัดทรงกระบอก**ในปริภูมิ 3 มิติได้


- $r$ แทนระยะทางจากจุดกำเนิด $(0,0,0)$ ไปยังจุดนั้น

- $\theta$ แทนมุมระหว่างแกน $x$ ทิศทางบวก กับรังสี $\overrightarrow{OP}$

- $z$ แทนระยะทางจากจุดกำเนิด $(0,0,0)$ ไปยังจุดนั้นในทิศทางเดียวกันกับแกน $z$

## วิธีแปลงพิกัดทรงกระบอก เป็นพิกัดฉาก

ถ้าเราทราบจุดในพิกัดทรงกระบอก $(r,\theta,z)$ เราสามารถแปลงให้เป็นจุดในพิกัดฉาก $(x,y, z)$ ได้ดังนี้

:::theorem

กำหนดจุด $(r,\theta,z)$ ในพิกัดทรงกระบอก แล้วเราจะสามารถแปลงเป็นจุดในพิกัดฉาก $(x,y,z)$ ได้ดังนี้
\begin{eq*}
x &=&r\cos\theta 

y &=& r\sin\theta 

z &=& z
\end{eq*}

:::






:::example

จงแปลงจุด $(r,\theta,z) = \left(2,\frac{\pi}{3},4\right)$ ในพิกัดทรงกระบอก ให้เป็นจุดในพิกัดฉาก

:::


:::solution

จุด $(r,\theta,z) = \left(2,\frac{\pi}{3},4\right)$ ในพิกัดทรงกระบอก แปลงเป็นพิกัดฉากได้ดังนี้
\begin{eq*}
x &=& r\cos\theta = 2 \cos \frac{\pi}{3} = 2 \frac{1}{2} = 1 

y &=& r\sin\theta = 2\sin \frac{\pi}{3} = 2 \frac{\sqrt{3}}{2} = \sqrt{3} 

z &=& 4
\end{eq*}
ฉะนั้น จุด $(r,\theta,z) = \left(2,\frac{\pi}{3},4\right)$ ในพิกัดทรงกระบอก เท่ากับจุด $(x,y,z) = (1, \sqrt{3}, 4)$ ในพิกัดฉาก

:::






:::example

จงแปลงจุด $(r,\theta,z) = \left(6,\frac{3\pi}{4},-3\right)$ ในพิกัดทรงกระบอก ให้เป็นจุดในพิกัดฉาก

:::


:::solution

จุด $(r,\theta,z) = \left(6,\frac{3\pi}{4},-3\right)$ ในพิกัดทรงกระบอก แปลงเป็นพิกัดฉากได้ดังนี้
\begin{eq*}
x &=& r\cos\theta = 6 \cos \frac{3\pi}{4} = 6 \frac{-\sqrt{2}}{2} = -3\sqrt{2} 

y &=& r\sin\theta = 6\sin \frac{3\pi}{4} = 6 \frac{\sqrt{2}}{2} = 3\sqrt{2} 

z &=& -3
\end{eq*}
ฉะนั้น จุด $(r,\theta,z) = \left(6,\frac{3\pi}{4},-3\right)$ ในพิกัดทรงกระบอก เท่ากับจุด $(x,y,z) = (-3\sqrt{2}, 3\sqrt{2}, -2)$ ในพิกัดฉาก

:::






## วิธีแปลงพิกัดฉาก เป็นพิกัดทรงกระบอก

ในทำนองเดียวกัน ถ้ากำหนดจุดในพิกัดฉาก $(x,y,z)$ มาให้ เราสามารถแปลงเป็นจุดในพิกัดทรงกระบอกได้ โดยใช้หลักการเดียวกันกับพิกัดเชิงขั้ว

:::theorem

กำหนดจุดในพิกัดฉาก $(x,y,z)$ ที่ไม่ใช่จุดกำเนิด $(0,0,0)$ เราสามารถแปลงให้เป็นจุดในพิกัดทรงกระบอก $(r,\theta, z)$ ได้ดังนี้
\begin{eq*}
r &=& \sqrt{x^2 + y^2} 

\tan \theta &=& \frac{y}{x} 

z &=& z
\end{eq*}
โดยค่า $\theta$ จะขึ้นอยู่กับจตุภาคของจุด $(x,y)$ ซึ่งอธิบายเพิ่มเติมในหน้าถัดไป

:::





## การคำนวณหาค่า \theta



:::figure ch1quadrant
:::




- ถ้า $x > 0$ จุด $(x,y)$ จะอยู่ในจตุภาค 1 หรือ 4 (นั่นคือด้านขวาของแกน $y$) จะได้ว่า $\theta = \arctan \tfrac{y}{x}$ 

- ถ้า $x < 0$ จุด $(x,y)$ จะอยู่ในจตุภาค 2 หรือ 3 (นั่นคือด้านซ้ายของแกน $y$) จะได้ว่า $\theta = \arctan \tfrac{y}{x} + \pi$ 

- ถ้า $x=0$ แปลว่าจุดนั้นอยู่บนแกน $y$ นั่นคือมีมุมเท่ากับ $\tfrac{\pi}{2}$ ถ้าค่า $y > 0$ หรือ $\tfrac{-\pi}{2}$ เมื่อค่า $y < 0$







:::example

จงแปลงจุด $(x,y,z) = (1,1,4)$ ในพิกัดฉาก ให้เป็นจุดในพิกัดทรงกระบอก

:::


:::solution

จุด $(x,y,z) = (1,1,4)$ ในพิกัดฉาก แปลงเป็นพิกัดทรงกระบอกได้ดังนี้
\begin{eq*}
r &=& \sqrt{x^2 + y^2} = \sqrt{1^2 + 1^2} = \sqrt{2} 

\tan \theta &=& \frac{y}{x} = 1

z &=& 4
\end{eq*}
เนื่องจาก $(x,y) = (1,1)$ อยู่ในจตุภาคที่ 1 นั่นคือ $0 \leq \theta \leq \frac{\pi}{2}$ ทำให้ได้ว่า $\theta = \arctan 1 = \frac{\pi}{4}$ ฉะนั้น จุด $(x,z,y)=(1,1,4)$ ในพิกัดฉาก เท่ากับจุด $(r,\theta,z) = \left(\sqrt{2}, \frac{\pi}{4}, 4\right)$ ในพิกัดทรงกระบอก

:::






:::example

จงแปลงจุด $(x,y,z) = (0,-3,-2)$ ในพิกัดฉาก ให้เป็นจุดในพิกัดทรงกระบอก

:::


:::solution

จุด $(x,y,z) = (0,-3,-2)$ ในพิกัดฉาก แปลงเป็นพิกัดทรงกระบอกได้ดังนี้
\begin{eq*}
r &=& \sqrt{x^2 + y^2} = \sqrt{0^2 + {-3}^2} = 3 

\tan \theta &=& \frac{-3}{0} \text{ หาค่าไม่ได้}

z &=& -2
\end{eq*}
เนื่องจากจุด $(x,y) = (0,-3)$ อยู่บนแกน $y$ ที่ค่า $y < 0$ ทำให้เราทราบว่า $\theta = -\frac{\pi}{2}$ ฉะนั้น จุด $(x,z,y)=(0,-3,-2)$ ในพิกัดฉาก เท่ากับจุด $(r,\theta,z) = \left(3, -\tfrac{\pi}{2}, -2\right)$ ในพิกัดทรงกระบอก

:::





:::exercise



- จงแปลงจุด $(x,y,z)$ ในพิกัดฉากต่อไปนี้ ให้เป็นจุด $(r, \theta, z)$ ในพิกัดทรงกระบอก


- $(x,y,z) = (2,0,4)$

- $(x,y,z) = (-2,2,-1)$

- $(x,y,z) = (\sqrt{3},-1,0)$

- $(x,y,z) = (-4,-2,-3)$


- จงแปลงจุด $(r, \theta, z)$ ในพิกัดทรงกระบอก ต่อไปนี้ ให้เป็นจุด $(x,y,z)$ ในพิกัดฉาก


- $(r,\theta,z) = (5,0,3)$

- $(r,\theta,z) = \left(6,\tfrac{4\pi}{3},1\right)$

- $(r,\theta,z) = (0,\pi,-2)$

- $(r,\theta,z) = \left(-2,\tfrac{\pi}{2},4\right)$



:::
