## ปริพันธ์บนทรงสี่เหลี่ยมมุมฉาก


:::theorem ทฤษฎีบทของฟูบินี (Fubini's Theorem)

กำหนดให้ $S$ เป็นทรงสี่เหลี่ยมมุมฉากสามมิติที่นิยามด้วยอสมการ
\[a \leq x \leq b, \quad c \leq y \leq d, \quad k \leq z \leq l\] 
หรือในรูปแบบเซต
\[ R = \{ (x,y,z) \mid a \leq x \leq b, \quad c \leq y \leq d , \quad k \leq z \leq l\} = [a,b] \times [c,d] \times [k,l]\] 
ถ้า $f(x,y,z)$ เป็นฟังก์ชันต่อเนื่องบน $S$ แล้ว
\begin{equation} 
\iiint\limits_S f(x,y,z) \, dV = **\int_a^b** **\int_c^d** **\int_k^l** f(x,y,z) \, **dz** \, **dy** \, **dx**
\end{equation}

:::

:::







:::example

จงหาค่าของปริพันธ์สามชั้น
\[ \iiint\limits_S xy^2z^3 \, dV \]
เมื่อ $S$ เป็นทรงสี่เหลี่ยมมุมฉากที่นิยามด้วยอสมการ 
\[-1 \leq x \leq 2, \quad 0 \leq y \leq 3, \quad 0 \leq z \leq 2\]

:::


:::solution
เปลี่ยนรูปปริพันธ์ตามทฤษฏีบทได้ด้งนี้ 
\[ \iiint\limits_S xy^2z^3 \, dV = \red{\int_{-1}^2} **\int_0^3** **\int_0^2** xy^2z^3 \, **dz** \, **dy** \, **dx** \] 
จากนั้นจึงคำนวณเพื่อหาคำตอบ

:::





:::solution
(ต่อ)
\begin{eqnarray*}
\int_{-1}^2 \int_0^3 \int_0^2 xy^2z^3 \, dz \, dy \, dx &=& \int_{-1}^2 \int_0^3 **\left(\int_0^2 xy^2z^3 \, dz\right)** \, dy \, dx 

&=& \int_{-1}^2 \int_0^3 \blue{\left( xy^2\frac{z^4}{4}\right) \Big|_{z=0}^{z=2}} \, dy \, dx 

&=& \int_{-1}^2 \int_0^3 **4xy^2** \, dy \, dx 

&=& \int_{-1}^2 \green{\left( 4x\frac{y^3}{3} \right)\Big|_{y=0}^{y=3}} dx 

&=& \int_{-1}^2 36 x \, dx 

&=& 36 \left(\frac{x^2}{2} \right) \Big|_{x = -1}^{x = 2} = 18 (4 - 1) = 54
\end{eqnarray*}

:::




**หมายเหตุ**: ถ้า $S$ เป็นทรงสี่เหลี่ยมมุมฉาก เราสามารถสลับลำดับการหาปริพันธ์ได้ ตราบเท่าที่เราจับคู่ลิมิต $\int$ กับ $d$ ให้ถูก 
\begin{eqnarray*}
&& \iiint\limits_S f(x,y,z) \, dV 

&=& **\int_a^b** \int_c^d \int_k^l f(x,y,z) \, dz \, dy \, **dx** = **\int_a^b** \int_k^l \int_c^d f(x,y,z) \, dy \, dz \, **dx** 

&=& \int_c^d \textcolor{red}{\int_a^b} \int_k^l f(x,y,z) \, dz \, **dx** \, dy = \int_k^l **\int_a^b** \int_c^d f(x,y,z) \, dy \, **dx** \, dz 

&=& \int_k^l \int_c^d **\int_a^b** f(x,y,z) \, **dx** \, dy \, dz = \int_c^d \int_k^l **\int_a^b** f(x,y,z) \, **dx** \, dz \, dy
\end{eqnarray*}




:::exercise

จงหาค่าของปริพันธ์สามชั้นต่อไปนี้


- $\iiint\limits_S x^2yz \, dV$ เมื่อ $S$ เป็นทรงสี่เหลี่ยมมุมฉากที่นิยามด้วยอสมการ $-1 \leq x \leq 1, \quad 0 \leq y \leq 2, \quad 0 \leq z \leq 1$

- $\iiint\limits_S e^{x+y}\sin z \, dV$ เมื่อ $ S = [0, \ln 2] \times [0, 1] \times \left[0,\frac{\pi}{2} \right]$


:::
