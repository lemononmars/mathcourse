## ค่าต่ำสุดและสูงสุดของฟังก์ชันสองตัวแปร


นึกภาพพื้นผิวของฟังก์ชัน $z = f(x,y)$ เป็นภูเขา ยอดเขาแต่ละยอดจะนับว่าเป็น **ค่าสูงสุดสัมพัทธ์** และจุดต่ำสุดของหุบเขาคือ **ค่าต่ำสุดสัมพัทธ์** ของฟังก์ชัน $f$

ถ้าเราสนใจยอดเขาที่สูงที่สุดในบริเวณที่กำหนด จะนับว่าเป็น **ค่าสูงสุดสัมบูรณ์** และหุบเขาที่ต่ำที่สุดในบริเวณที่กำหนดคือ **ค่าต่ำสุดสัมบูรณ์**

## นิยามของค่าสูงสุดและต่ำสุดสัมพัทธ์


:::definition

ฟังก์ชัน $f(x,y)$ มี**ค่าสูงสุดสัมพัทธ์ (relative maximum)** ที่จุด $P(x_0, y_0)$ ถ้ามีแผ่นดิสค์ $D$ ที่มีจุดศูนย์กลางที่ $P$ ที่ทำให้ $f(x_0, y_0) \geq f(x,y)$ สำหรับทุกจุด $(x,y)$ ใน $D$ 

ฟังก์ชัน $f(x,y)$ มี**ค่าต่ำสุดสัมพัทธ์ (relative maximum)** ที่จุด $P(x_0, y_0)$ ถ้ามีแผ่นดิสค์ $D$ ที่มีจุดศูนย์กลางที่ $P$ ที่ทำให้ $f(x_0, y_0) \leq f(x,y)$ สำหรับทุกจุด $(x,y)$ ใน $D$

:::





## นิยามของค่าสูงสุดและต่ำสุดสัมบูรณ์


:::definition

ฟังก์ชัน $f(x,y)$ มี**ค่าสูงสุดสัมบูรณ์ (absolute maximum)** ที่จุด $P=(x_0, y_0)$ ถ้า $f(x_0, y_0) \geq f(x,y)$ สำหรับทุกจุด $(x,y)$ ในโดเมน

ฟังก์ชัน $f(x,y)$ มี**ค่าต่ำสุดสัมบูรณ์ (absolute maximum)** ที่จุด $P=(x_0, y_0)$ ถ้า $f(x_0, y_0) \leq f(x,y)$ สำหรับทุกจุด $(x,y)$ ในโดเมน

:::





## วิธีการหาค่าสุดขีด

เราจะเรียกค่าต่ำสุดหรือค่าสูงสุด รวมกันว่า **ค่าสุดขีด (extremum)** และนิยามค่าต่ำสุดสัมพัทธ์หรือค่าสูงสุดสัมพัทธ์ว่า **ค่าสุดขีดสัมพัทธ์** และ นิยามค่าต่ำสุดสัมบูรณ์หรือค่าสูงสุดสัมบูรณ์ว่า**ค่าสุดขีดสัมบูรณ์** 


:::definition

ถ้า $f(x,y)$ มีค่าสุดขีดที่จุด $P=(x_0, y_0)$ และ $f$ หาอนุพันธ์ย่อยได้ที่จุด $P$ แล้วจะได้ว่า
\[ f_x(x_0, y_0) = 0 \qquad \text{ และ } \qquad f_y(x_0, y_0) = 0\]

:::




ก่อนที่จะหาค่าสุดขีดได้ เราต้องรู้ก่อนว่าค่านั้นเกิดขึ้นที่จุดไหน ซึ่งจุดดังกล่าวมีนิยามเรียกดังนี้

:::definition

เรียกจุด $(x_0, y_0)$ ว่า **จุดวิกฤต (critical point)** ของฟังก์ชัน $f(x,y)$ ถ้าตรงตามเงื่อนไขใดเงื่อนไขหนึ่งต่อไปนี้


- $f_x(x_0, y_0) = 0$ และ $f_y(x_0, y_0) = 0$

- $f_x(x,y)$ หรือ $f_y(x,y)$ หรือทั้งสองค่า หาค่าไม่ได้ที่จุด $(x_0, y_0)$


:::






:::example

จงหาจุดวิกฤตของฟังก์ชันต่อไปนี้
\[f(x,y) = x^2 + xy +3x\]

:::



:::solution
หาอนุพันธ์ย่อยได้ $f_x(x,y) = 2x+y+3, \quad f_y(x,y) = x$ 
จากนั้นหาค่า $x,y$ ที่ทำให้พจน์ทั้งสองมีค่าเป็น 0 หรือทำให้พจน์ใดพจน์หนึ่งหาค่าไม่ได้ 


- จาก $f_y(x,y) = x = 0$ จะได้ $x=0$ 

- จาก $f_x(x,y) = 2x+y+3 = 0$ จะได้ $y = -2x-3 = -3$ (เพราะเรามี $x=0$) 

เนื่องจากฟังก์ชัน $f_x, f_y$ หาค่าได้ทุกจุด จึงสรุปได้ว่าฟังก์ชันนี้มีจุดวิกฤตที่เดียวคือ $(x,y) = (0,-3)$

:::






:::example

จงหาจุดวิกฤตของฟังก์ชันต่อไปนี้
\[f(x,y) = y\sin x\]

:::



:::solution
หาอนุพันธ์ย่อยได้ $f_x(x,y) = y\cos x, \quad f_y(x,y) = \sin x$ จากนั้นหาค่า $x,y$ ที่ทำให้พจน์ทั้งสองมีค่าเป็น 0 หรือทำให้พจน์ใดพจน์หนึ่งหาค่าไม่ได้


- จาก $f_y(x,y) = \sin x = 0$ จะได้ว่า $ x = n\pi$ เมื่อ $n$ เป็นจำนวนเต็ม 

- จาก $f_x(x,y) = y\cos x = 0$ เมื่อแทนค่า $x = n\pi$ จะได้ $\cos x = \cos (n\pi)$ ซึ่งเป็น 1 หรือ -1 เท่านั้น ทำให้สรุปได้ว่า $y=0$


เนื่องจากฟังก์ชัน $f_x, f_y$ หาค่าได้ทุกจุด จึงสรุปได้ว่าฟังก์ชันนี้มีจุดวิกฤตที่ $(x,y) = (n\pi, 0)$ เมื่อ $n$ เป็นจำนวนเต็มใด ๆ

:::






:::example

จงหาจุดวิกฤตของฟังก์ชันต่อไปนี้
\[f(x,y) = \frac{x}{y}\]

:::



:::solution
หาอนุพันธ์ย่อยได้ $f_x(x,y) = \frac{1}{y}, \quad f_y(x,y) = -\frac{x}{y^2}$ จากนั้นหาค่า $x,y$ ที่ทำให้พจน์ทั้งสองมีค่าเป็น 0 หรือทำให้พจน์ใดพจน์หนึ่งหาค่าไม่ได้ 

เนื่องจาก $f_x(x,y) = \frac{1}{y} = 0$ ไม่มีคำตอบ จึงหาค่า $x,y$ ที่ทำให้พจน์ทั้งสองมีค่าเป็น 0 ไม่ได้ 

แต่ว่าค่า $\frac{1}{y}$ หาค่าไม่ได้เมื่อ $y=0$ เช่นเดียวกันกับ $f_y(x,y) = -\frac{x}{y^2}$ โดยไม่มีเงื่อนไขเกี่ยวกับตัวแปร $x$ ฉะนั้นฟังก์ชันนี้มีจุดวิกฤตที่ $(x,y) = (x,0)$ เมื่อ $x$ เป็นจำนวนจริงใดก็ได้

:::





## การทดสอบค่าสุดขีด


:::definition

กำหนดให้ $f(x,y)$ เป็นฟังก์ชันสองตัวแปร ที่มีอนุพันธ์ย่อยอันดับสองรอบ**จุดวิกฤต** $(x_0, y_0)$ นิยาม
\begin{equation}
D = f_{xx}(x_0, y_0)f_{yy}(x_0, y_0) - {f_{xy}}^2(x_0, y_0)
\end{equation}
แล้วจะได้ว่า


- ถ้า $D > 0$ และ $f_{xx}(x_0, y_0) >0$ แล้ว $f$ มีค่า**ต่ำสุดสัมพัทธ์**ที่จุด $(x_0, y_0)$ 

- ถ้า $D > 0$ และ $f_{xx}(x_0, y_0) <0$ แล้ว $f$ มีค่า**สูงสุดสัมพัทธ์**ที่จุด $(x_0, y_0)$ 

- ถ้า $D <0$ แล้ว $f$ มี**จุดอานม้า (saddle point)** ที่จุด $(x_0, y_0)$ 

- ถ้า $D = 0$ แล้ว เรายังไม่สามารถสรุปอะไรได้


:::

:::





:::figure l08i04.png — ตัวอย่างจุดอานม้า (จุดสีแดง) สังเกตว่าจุดนั้นไม่ใช่ทั้งค่าต่ำสุดและสูงสุดสัมพัทธ์
:::






:::example

จงหาจุดสุดขีดและจุดอานม้าทั้งหมดของฟังก์ชันต่อไปนี้
\[f(x,y) = 3x^2 - 2xy + y^2 - 8y\]

:::



:::solution
ก่อนอื่นเราต้องหาจุดวิกฤตก่อน ด้วยการแก้สมการดังต่อไปนี้
\begin{eqnarray}
f_x(x,y) &=& 6x - 2y = 0 

f_y(x,y) &=& -2x+2y-8 = 0 
\end{eqnarray}
จาก \eqref{eq1} จะได้ $x = \frac{y}{3}$ นำค่านี้ไปแทนในสมการ \eqref{eq2} จะได้ 
\begin{eqnarray*}
-2\frac{y}{3}+2y-8 &=&0 

\frac{4}{3}y-8 &=& 0

y &=& 6
\end{eqnarray*} 


:::





:::solution
(ต่อ) 
ทำให้ได้ $x = \frac{y}{3} = \frac{6}{3} = 2$ ฉะนั้นฟังก์ชันนี้มีจุดวิกฤตจุดเดียวที่ $(x,y) = (2,6)$

จากนั้นเราต้องตรวจสอบต่อว่าเป็นจุดประเภทใด ก่อนอื่นให้คำนวณอนุพันธ์ระดับสองก่อน ได้
\[ f_{xx}(x,y) = 6, \quad f_{yy}(x,y) = 2, \quad f_{xy}(x,y) = -2 \] 
นำไปแทนค่าในสูตร โดยให้ $x=2, y=6$ จะได้ 
\[D = f_{xx}(2,6)f_{yy}(2,6)-{f_{xy}}^2(2,6) = (6)(2) - (-2)^2 = 8 > 0\] 
และ
\[f_{xx}(2,6) = 6 > 0\] 
ซึ่งตรงกับกรณีที่ 1 ในทฤษฏีบทฉะนั้นสรุปว่า $\mathbf{f}$ ** มีค่าต่ำสุดสัมพัทธ์ที่จุด** $(2,6)$ ซึ่งมีค่าเท่ากับ 
\[f(2,6) = 3(2)^2 - 2(2)(6)+(6)^2-8(6) = -24\]

:::






:::example

จงหาจุดสุดขีดและจุดอานม้าทั้งหมดของฟังก์ชันต่อไปนี้
\[f(x,y) = 3xy - 6x - 3y^2 + 7\]

:::


:::solution

ก่อนอื่นต้องหาจุดวิกฤตก่อน ซึ่งได้จากการแก้สมการ
\begin{eqnarray*}
f_x(x,y) &=& 3y-6= 0, \quad y = 2

f_y(x,y) &=& 3x-6y = 0, \quad x = 2 \longrightarrow y = 4 
\end{eqnarray*}
เนื่องจาก $f_x$ และ $f_y$ หาค่าได้ทั้งทุดจุด ฉะนั้นฟังก์ชันนี้มีจุดวิกฤตที่ $(x,y) = (4,2)$ 

:::





:::solution
(ต่อ)
จากนั้นเราต้องตรวจสอบว่าเป็นจุดประเภทใด ก่อนอื่นคำนวณอนุพันธ์ระดับสองก่อน ได้
\[f_{xx} = 0, \quad f_{yy} = -6, \quad f_{xy} = 3\]
นำไปแทนค่าในสูตร โดยให้ $x=2, y=6$ จะได้ 
\[D = f_{xx}(4,2)f_{yy}(4,2)-{f_{xy}}^2(4,2) = (0)(-6) - (3)^2 = -9 < 0 \] 
ซึ่งตรงกับกรณีที่ 3 ในทฤษฏีบท ฉะนั้น **f มีจุดอานม้าที่จุด** $(4,2)$

:::






:::example

จงหาจุดสุดขีดและจุดอานม้าทั้งหมดของฟังก์ชันต่อไปนี้
\[f(x,y) = xy - x^3 - y^2\]

:::


:::solution

ก่อนอื่นต้องหาจุดวิกฤตก่อน ซึ่งได้จากการแก้สมการ
\begin{eqnarray*}
f_x(x,y) &=& y - 3x^2 = 0 \rightarrow y = 3x^2

f_y(x,y) &=& x - 2y = 0 \rightarrow x-2(3x^2)=0 \rightarrow x = 0,\tfrac{1}{6} \rightarrow y = 0, \tfrac{1}{12} 
\end{eqnarray*}
เนื่องจาก $f_x$ และ $f_y$ หาค่าได้ทั้งทุกจุด ฉะนั้นฟังก์ชันนี้มีจุดวิกฤตที่ $(0,0), \left(\frac{1}{6}, \frac{1}{12}\right)$

:::





:::solution
(ต่อ)
คำนวณหา $f_{xx}, f_{yy}, f_{xy}$ ก่อน ได้เป็น
\[f_{xx}(x,y) = -6x, \quad f_{yy}(x,y) = -2, \quad f_{xy}(x,y) = 1 \]

นำจุดวิกฤต $(0,0)$ มาทดสอบ 
\[D = f_{xx}(0,0)f_{yy}(0,0)-{f_{xy}}^2(0,0) = (0)(-2) - (1)^2 = -1 < 0\]
ซึ่งตรงกับกรณีที่ 3 ในทฤษฏีบท ฉะนั้น **f มีจุดอานม้า**ที่จุด $(0,0)$ 

นำจุดวิกฤต $\left(\frac{1}{6}, \frac{1}{12}\right)$ มาทดสอบ 
\[D = f_{xx}(\tfrac{1}{6}, \tfrac{1}{12})f_{yy}(\tfrac{1}{6}, \tfrac{1}{12})-{f_{xy}}^2(\tfrac{1}{6}, \tfrac{1}{12}) = (-1)(-2) - (1)^2 = 1 > 0\] 
โดยที่ $f_{xx}(\tfrac{1}{6}, \tfrac{1}{12}) = -1 < 0$ ซึ่งตรงกับกรณีที่ 2 ในทฤษฏีบท ฉะนั้น **f มีค่าสูงสุดสัมพัทธ์**ที่จุด $(\tfrac{1}{6}, \tfrac{1}{12})$ ซึ่งเท่ากับ $f(\tfrac{1}{6}, \tfrac{1}{12}) = \tfrac{1}{6}\tfrac{1}{12} - \left(\tfrac{1}{6}\right)^3 - \left(\tfrac{1}{12}\right)^2 = \tfrac{1}{432}$

:::





:::exercise

จงหาจุดวิกฤตของฟังก์ชันต่อไปนี้ พร้อมระบุด้วยว่าเป็นจุดประเภทใด


- $f(x,y) = x^2 - 2xy + 3y^2 - 10y$

- $f(x,y) = 3x^2 + y^3 - 6xy$


:::
