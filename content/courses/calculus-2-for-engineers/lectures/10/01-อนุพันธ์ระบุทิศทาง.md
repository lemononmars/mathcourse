## อนุพันธ์ระบุทิศทาง

เราได้เรียนไปแล้วว่า $f_x$ และ $f_y$ คือความชันของเส้นโค้งตามทิศทางของแกน $x$ และแกน $y$ ตามลำดับ

:::figure partial_geometric_interpretation — อนุพันธ์ย่อย $\pd{f
:::
$ และ $\pd{f}{y}$ ตามลำดับ}{}
เราสามารถหาอนุพันธ์ในทิศทางอื่น ๆ ได้ด้วย




## นิยามของอนุพันธ์ระบุทิศทาง


:::definition

1. กำหนดให้ $f(x,y)$ เป็นฟังก์ชันและ $\vec{u} = u_1 \mathbf{i} + u_2 \mathbf{j}$ เป็น**เวกเตอร์หนึ่งหน่วย** จะได้ว่า 
\begin{equation}
D_{\vec{u}} f(x,y) = f_x(x,y)u_1 + f_y(x,y)u_2
\end{equation}

2. กำหนดให้ $f(x,y,z)$ เป็นฟังก์ชันและ $\vec{u} = u_1 \mathbf{i} + u_2 \mathbf{j} + u_3 \mathbf{k}$ เป็น**เวกเตอร์หนึ่งหน่วย** จะได้ว่า 
\begin{equation}
D_{\vec{u}} f(x,y,z) = f_x(x,y,z)u_1 + f_y(x,y,z)u_2 + f_z(x,y,z) u_3 
\end{equation}

:::


**หมายเหตุ:** สังเกตว่าในทฤษฎีบทกำหนดให้ $\vec{u}$ เป็นเวกเตอร์หนึ่งหน่วย ถ้าไม่ใช่ต้องแปลงเป็นเวกเตอร์หนึ่งหน่วยด้วยการหารด้วยขนาดของ $\vec{u}$ นั่นคือใช้ $\frac{\vec{u}}{\| \vec{u} \|}$ แทน

} f$ และ $D_{\vec{v}} f$ ในเชิงเรขาคณิต}{}





:::example

จงหาอนุพันธ์ระบุทิศทางของฟังก์ชัน $f(x,y) = e^{xy}$ ที่จุด $(-2,0)$ ในทิศทางของเวกเตอร์ $\vec{u} = \frac{1}{2}\mathbf{i} + \frac{\sqrt{3}}{2}\mathbf{j}$

:::



:::solution

คำนวณหาอนุพันธ์ย่อยได้
\begin{eqnarray*}
f_x(x,y) &=& ye^{xy}, \quad f_x(-2,0) = (0)e^{(-2)(0)} = 0 

f_y(x,y) &=& xe^{xy}, \quad f_y(-2,0) = (-2)e^{(-2)(0)} = -2 
\end{eqnarray*}
เนื่องจากขนาดของเวกเตอร์ $\vec{u}$ เท่ากับ $\| \vec{u} \| = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = 1$ เราจึงสามารถใช้ทฤษฎีบทเลยได้ทันที ฉะนั้น 
\[D_{\vec{u}} f(x_0, y_0) = f_x(x_0, y_0)u_1 + f_y(x_0,y_0)u_2 = (0)\frac{1}{2} + (-2)\frac{\sqrt{3}}{2} = -\sqrt{3}\]

:::






:::example

จงหาอนุพันธ์ระบุทิศทางของฟังก์ชัน $f(x,y,z) = x^2y - yz^3 + z$ ที่จุด $(1,-2,0)$ ในทิศทางของเวกเตอร์ $\vec{u} = \vvv{2}{+}{-2}$

:::



:::solution

คำนวณหาอนุพันธ์ย่อยได้
\begin{eq*}
f_x(x,y,z) &=& 2xy, \quad f_x(1,-2,0) = 2(1)(-2)= -4 

f_y(x,y,z) &=& x^2 - z^3, \quad f_y(1,-2,0) = 1^2 - 0^3 = 1 

f_z(x,y,z) &=& -3yz^2+1, \quad f_z(1,-2,0) = -3(-2)(0^2) + 1 = 1 
\end{eq*}

:::





:::solution
(ต่อ)
เนื่องจากขนาดของเวกเตอร์ $\vec{u}$ เท่ากับ $\| \vec{u} \| = \sqrt{2^2 + 1^2 + (-2)^2} = \sqrt{9} = 3$ เราจึงต้องแปลงให้เป็นเวกเตอร์หนึ่งหน่วยก่อน ด้วยการหาร $\vec{u}$ ด้วยขนาดของตัวเอง จะได้ 
\[ \frac{\vec{u}}{\|\vec{u}\|} = \frac{ 2\mathbf{i} + 1\mathbf{j} - 2\mathbf{k}}{3} = \frac{2}{3}\mathbf{i} + \frac{1}{3}\mathbf{j} - \frac{2}{3}\mathbf{k} \]

\begin{eqnarray*}
D_{\vec{u}} f(x_0, y_0, z_0) &=& f_x(x_0, y_0, z_0)u_1 + f_y(x_0,y_0,z_0)u_2 + f_z(x_0, y_0, z_0)u_3 

&=& (-4)\frac{2}{3} + (1)\frac{1}{3} + (1)\frac{-2}{3} = -3
\end{eqnarray*}

:::





:::exercise

จงหาอนุพันธ์ระบุทิศทาง $D_{\vec{u}}f(x,y)$ ที่จุด $P = (x_0,y_0)$ ที่กำหนดให้ต่อไปนี้


- $f(x,y) = 2x^3y^4; \vec{u} = \vv{\frac{1}{\sqrt{2}}}{+\frac{1}{\sqrt{2}}}, P = (2,1)$

- $f(x,y) = e^{2xy}; \vec{u} = \vv{-\frac{3}{5}}{+\frac{4}{5}}, P = (4,0)$


:::
