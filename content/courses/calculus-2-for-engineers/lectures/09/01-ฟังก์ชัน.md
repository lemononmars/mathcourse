## นิยามฟังก์ชันค่าจริงของหลายตัวแปร


:::definition

ฟังก์ชันค่าจริงสองตัวแปรจะเขียนอยู่ในรูป

\[ \mathbf{z = f(x,y)} \]

โดยที่ $x,y$ เป็นตัวแปรอิสระที่เป็นจำนวนจริง $(x,y \in \mathbb{R})$ และ $z$ เป็นตัวแปรตาม

จุดที่อยู่บนกราฟของฟังก์ชั่นนี้จะอยู่ในรูป $(x,y,z) = (x,y,f(x,y))$

:::

หมายเหตุ: นิยามโดยทั่วไปคือ $w = f(x_1, x_2, \ldots, x_n)$ ซึ่งเป็นฟังก์ชันค่าจริง $n$ ตัวแปร





:::example

\begin{eqnarray*}
f(x,y) &=& x + y 

f(x,y) &=& x^2 + xy + y^2 

f(x,y) &=& \sin x + \cos y 

f(x,y) &=& x^2 \boxed{\text{ฟังก์ชันนี้ไม่มีพจน์ $y$ แปลว่าค่าของฟังก์ชันไม่ขึ้นอยู่กับค่า $y$}} 

f(x,y) &=& 3 \boxed{\text{ฟังก์ชันนี้ไม่มีพจน์ $x$ และ $y$ เราเรียกว่าเป็นฟังก์ชันค่าคงตัว}}
\end{eqnarray*}

:::






## การหาค่าของฟังก์ชัน

ถ้ากำหนดฟังก์ชัน $f(x,y)$ มาให้ และกำหนดค่า $x$ และ $y$ มาให้แล้ว เราสามารถนำค่านั้นไปแทนในฟังก์ชันได้ทันที โดยจะมีรูปแบบใดรูปแบบหนึ่งต่อไปนี้


- จงหา $f(1,2)$ 

- จงหา $f(x,y)$ เมื่อ $x=1$ และ $y=2$

- จงหา $f(x,y)$ เมื่อ $(x,y) = (1,2)$





:::example

กำหนด $f(x,y) = x+y$ จงหา


- $f(1,1)$

- $f(2,3)$

- $f(-3,1)$


:::


:::solution



- $f(1,1) = 1+1 = 2$

- $f(2,3) = 2 +3 = 5$

- $f(-3, 1) = -3 + 1 = -2$


:::






:::example

กำหนด $f(x,y) = x^2+xy$ จงหาค่าของฟังก์ชันเมื่อ


- $(x,y) = (0,1)$

- $(x,y) = (1,-3)$

- $(x,y) = (-2,5)$


:::


:::solution



- เมื่อ $(x,y) = (0,1)$ จะได้ $f(0,1) = 0^2+0(1) = 0$

- เมื่อ $(x,y) = (1,-3)$ จะได้ $f(1,-3) = 1^2 + 1(-3) = 1 - 3 = -2$

- เมือ $(x,y) = (-2,5)$ จะได้ $f(-2, 5) = (-2)^2 + (-2)(5) = 4 - 10 = -6$


:::






## การหาค่าของฟังก์ชันแบบอื่น ๆ

บางครั้งเราอาจจะต้องการแทนค่าตัวแปรเป็นตัวแปรอื่น หรือต้องการแทนแค่ตัวแปรใดตัวแปรหนึ่ง อยู่ที่ว่าเรากำลังศึกษาเรื่องใดอยู่ ดังตัวอย่างต่อไปนี้

:::example

กำหนด $f(x,y) = x^2y + xy^2$ จงหา


- $f(t,t^2)$

- $f(1,t)$

- $f(x,y)$ เมื่อ $x=y=t$


:::


:::solution



- แทนค่า $x=t$ และ $y=t^2$ ลงไปจะได้ $f(t,t^2) = t^2 (t^2) + t (t^2)^2 = t^4 + t^5$

- แทนค่า $x=1$ และ $y=2t$ ลงไปจะได้ $f(1,t) = 1^2 (2t) + (1) (2t)^2 = 2t + 4t^2$

- แทนค่า $x=t$ และ $y=t$ จะได้ $f(t,t) = t^2(t) + t(t^2) = 2t^3$


:::






## การวาดกราฟฟังก์ชันสองตัวแปร

กำหนดฟังก์ชัน $f(x)$ เราสามารถวาดกราฟ
\[ y = f(x)\]
ได้บนระนาบที่ประกอบด้วยแกน $x$ และแกน $y$ โดยจุด $(x,f(x))$ แทนจุดทั้งหมดที่อยู่บนกราฟ

ในทำนองเดียวกัน กำหนดฟังก์ชัน $f(x,y)$ เราสามารถวาดกราฟ
\[z = f(x,y)\]
ได้ในปริภูมิสามมิติ โดยมีระนาบ $xy$ และแกน $z$ โดยจุด $(x,y,f(x,y))$ แทนจุุดทั้งหมดที่อยู่บนกราฟ
