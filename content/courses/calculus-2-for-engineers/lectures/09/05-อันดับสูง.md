## อนุพันธ์ย่อยอันดับสอง


:::definition

**อนุพันธ์ย่อยอันดับที่สอง** มีอยู่ 4 แบบได้แก่


- $\displaystyle \pd{}{x}\left(\pd{f}{x}\right) = \frac{\partial^2 f}{\partial x^2} = f_{xx}$ 

- $\displaystyle \pd{}{y}\left(\pd{f}{x}\right) = \frac{\partial^2 f}{\partial y \partial x} = f_{yx}$ 

- $\displaystyle \pd{}{x}\left(\pd{f}{y}\right) = \frac{\partial^2 f}{\partial x \partial y} = f_{xy}$ 

- $\displaystyle \pd{}{y}\left(\pd{f}{y}\right) = \frac{\partial^2 f}{\partial y^2} = f_{yy}$ 


:::






:::example

กำหนดให้ $f(x,y) = x^2 + xy^3$ จงหา


- $f_{xx}$

- $f_{yx}$

- $f_{xy}$

- $f_{yy}$


:::


:::solution



\begin{eq*}
f_x &=& \pd{f}{x} = 2x + y^3 

f_{xx} &=& \pd{}{x}(2x+y^3) = 2 

f_{yx} &=& \pd{}{y}(2x+y^3) = 3y^2 
\end{eq*}


\begin{eq*}
f_y &=& \pd{f}{y} = 3xy^2 

f_{xy} &=& \pd{}{x}(3xy^2) = 3y^2 

f_{yy} &=& \pd{}{y}(3xy^2) = 6xy
\end{eq*}



:::






:::example

กำหนดให้ $z = f(x,y) = xe^y + y\ln x $ จงหา


- $f_{xx}$

- $f_{yx}$

- $f_{xy}$

- $f_{yy}$


:::


:::solution



\begin{eq*}
f_x &=& \pd{f}{x} = e^y + \frac{y}{x} 

f_{xx} &=& \pd{}{x}(e^y + \frac{y}{x}) = -\frac{y}{x^2} 

f_{yx} &=& \pd{}{y}(e^y + \frac{y}{x}) = e^y + \frac{1}{x}
\end{eq*}


\begin{eq*}
f_y &=& \pd{f}{y} = xe^y + \ln x 

f_{xy} &=& \pd{}{x}(xe^y + \ln x) = e^y + \frac{1}{x} 

f_{yy} &=& \pd{}{y}(xe^y + \ln x) = xe^y
\end{eq*}



:::






:::example

กำหนดให้ $f(x,y) = \sin 3x \cos 4y$ จงหา


- $f_{xx}$

- $f_{yx}$

- $f_{xy}$

- $f_{yy}$


:::


:::solution

\begin{eq*}
f_x &=& 3\cos 3x \cos 4y 

f_{xx} &=& -9 \sin 3x \cos 4y 

f_{yx} &=& -12 \cos 3x \sin 4y 

f_y &=& -4 \sin 3x \sin 4y 

f_{yx} &=& -12 \cos 3x \sin 4y 

f_{yy} &=& -16 \sin 3x \cos 4y
\end{eq*}

:::






## อนุพันธ์ย่อยอันดับสูง

สำหรับอนุพันธ์ย่อยอันดับที่สูงกว่า เราสามารถใช้สัญลักษณ์เดียวกันได้ ดังตัวอย่างต่อไปนี้

:::example

กำหนดให้ $f(x,y) = e^xy^4$ จงหา $f_{xxx}$ และ $f_{yyy}$

:::


:::solution



\begin{eq*}
f_x &=& \pd{f}{x} = e^xy^4 

f_{xx} &=& \pd{}{x} e^xy^4 = e^xy^4 

f_{xxx} &=& \pd{}{x} e^xy^4 = e^xy^4
\end{eq*}


\begin{eq*}
f_y &=& \pd{f}{y} = 4e^xy^3 

f_{yy} &=& \pd{}{x}(4e^xy^3) = 12e^xy^2 

f_{yyy} &=& \pd{}{y}(12e^xy^2) = 24e^xy
\end{eq*}



:::
