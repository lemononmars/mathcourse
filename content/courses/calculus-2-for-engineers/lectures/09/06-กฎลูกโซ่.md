## ที่มาของกฎลูกโซ่

ถ้ากำหนดให้ $y = f(u), u = g(x)$ แล้วจะได้ว่า

:::note

\[\dx (f\circ g)= \frac{df}{dg} \frac{dg}{dx}\]

:::


:::slide

ในทำนองเดียวกัน เราสามารถพิสูจน์กฎลูกโซ่สำหรับอนุพันธ์ย่อยได้ จากนิยามของอนุพันธ์รวม
\[ \Delta f = \pd{f}{x} \Delta x + \pd{f}{y} \Delta y\]
เมื่อเราต้องการเทียบกับตัวแปร $\Delta t$ จึงนำ $\Delta t$ หาทั้งสองฝั่งของสมการ จะได้
\[ \frac{\Delta f}{\Delta t} = \pd{f}{x} \frac{\Delta x}{\Delta t} + \pd{f}{y}\frac{\Delta y}{\Delta t}\]
เมื่อใช้นิยามอนุพันธ์เพื่อเปลี่ยน $\Delta$ ให้เป็น $\partial$ และพจน์อื่นทั้งหมด จะได้เป็นทฤษฎีบทดังนี้

:::





## กฎลูกโซ่ สำหรับสมการตัวแปรเดียว


:::theorem

กำหนดฟังก์ชัน $f(x,y)$ โดยที่ $x,y$ มีสมการอิงตัวแปรเสริมเป็น $x=x(t), y = y(t)$ แล้วจะอนุพันธ์ย่อยของ $f$ เทียบกับ $t$ คือ
\begin{equation} f_t = \frac{df}{dt} = \pd{f}{x}\frac{dx}{dt} + \pd{f}{y}\frac{dy}{dt} \end{equation} 
กำหนด $f(x,y,z)$ โดยที่ $x,y,z$ มีสมการอิงตัวแปรเสริมเป็น $x=x(t), y = y(t), z = z(t)$ แล้วจะอนุพันธ์ย่อยของ $f$ เทียบกับ $t$ คือ
\begin{equation} f_t = \frac{df}{dt} = \pd{f}{x}\frac{dx}{dt} + \pd{f}{y}\frac{dy}{dt} + \pd{f}{z} \frac{dz}{dt} \end{equation} 

:::

*แผนผังต้นไม้ช่วยจำ กฏลูกโซ่ของ $\pd{z*{t}$}








:::example

กำหนดให้ $f(x,y) =x^2y^2$ โดยที่ $x = 2t, y = t^2$ จงหา $\frac{df}{dt}$

:::


:::solution

\begin{eq*}
\frac{df}{dt} &=& \pd{f}{x}\pd{x}{t} + \pd{f}{y}\pd{y}{t} 

&=& (2xy^2)(2) + (2x^2y)(2t) 

&=& 4xy^2 + 4x^2yt 

&=& 4(2t)(t^2)^2 + 4(2t)^2(t^2)t 

&=& 8t^5 + 16t^5 = 24t^5
\end{eq*}

:::







:::example

กำหนดให้ $f(x,y) = x^3 + y^3$ โดยที่ $x = t^2, y = t^3$ จงหา $\frac{df}{dt}$

:::


:::solution

\begin{eq*}
\frac{df}{dt} &=& \pd{f}{x}\pd{x}{t} + \pd{f}{y}\pd{y}{t} 

&=& (3x^2)(2t) + (3y^2)(3t^2) 

&=& (3(t^2)^2)(2t) + (3(t^3)^2)(3t^2) 

&=& 6t^5 + 9t^8
\end{eq*}

:::






## กฎลูกโซ่สำหรับฟังก์ชันหลายตัวแปร

ถ้าฟังก์ชัน $x$ และ $y$ ขึ้นอยู่กับตัวแปรอื่น เราสามารถสรุปได้เป็นทฤษฎีบทต่อไปนี้

:::theorem

กำหนดฟังก์ชัน $z = f(x,y)$ และ $x = x(u,v)$ และ $y = y(u,v)$ แล้ว
\begin{eq}
f_u = \pd{f}{u} &=& \pd{f}{x}\pd{x}{u} + \pd{f}{y}\pd{y}{u} 

f_v = \pd{f}{v} &=& \pd{f}{x}\pd{x}{v} + \pd{f}{y}\pd{y}{v}
\end{eq}

:::





:::theorem

กำหนดฟังก์ชัน $w = f(x,y,z)$ และ $x = x(u,v), y = y(u,v)$ และ $z = z(u,v)$ แล้ว
\begin{eq}
f_u = \pd{f}{u} &=& \pd{f}{x}\pd{x}{u} + \pd{f}{y}\pd{y}{u} + \pd{f}{z} \pd{z}{u}

f_v = \pd{f}{v} &=& \pd{f}{x}\pd{x}{v} + \pd{f}{y}\pd{y}{v} + \pd{f}{z} \pd{z}{v}
\end{eq}

:::

*แผนภาพช่วยจำ กฏลูกโซ่ของ $\pd{z*{v}$}






:::example

กำหนดให้ $z = f(x,y) = x^3 + y^3$ โดยที่ $x = 3u+v, y = 2u-v$ จงหา $\pd{f}{u}$ และ $\pd{f}{v}$

:::


:::solution

\begin{eqnarray*}
\pd{f}{u} = \pd{f}{x}\pd{x}{u} + \pd{f}{y}\pd{y}{u} &=& (3x^2)(3) + (3y^2)(2) 

&=& 9x^2 + 6y^2 

&=& 9(3u+v)^2 + 6(2u-v)^2 

\pd{f}{v} = \pd{f}{x}\pd{x}{v} + \pd{f}{y}\pd{y}{v} &=& (3x^2)(1) + (3y^2)(-1) 

&=& 3x^2 - 3y^2 

&=& 3(3u+v)^2 - 3(2u-v)^2
\end{eqnarray*}

:::






:::example

กำหนดให้ $z = f(x,y) = xy$ โดยที่ $x = \cos u + \cos v, y = \sin u + \sin v$ จงหา $\pd{f}{u}$ และ $\pd{f}{v}$

:::


:::solution

\begin{eqnarray*}
f_u = \pd{f}{u} &=& \pd{f}{x}\pd{x}{u} + \pd{f}{y}\pd{y}{u} = (y)(-\sin u) + (x)(\cos u) 

&=& (\sin u + \sin v)(-\sin u) + (\cos u + \cos v)(\cos u)

&=& \cos (2u) + \cos (u+v) 

f_v = \pd{f}{v} &=& \pd{f}{x}\pd{x}{v} + \pd{f}{y}\pd{y}{v} = (y)(-\sin v) + (x)(\cos v) 

&=& (\sin u + \sin v)(-\sin v) + (\cos u + \cos v)(\cos v)

&=& \cos (2v) + \cos (u+v)
\end{eqnarray*}

:::






:::example

กำหนดให้ $f(x,y) = x^2 + 3y$ โดยที่ $x = u \cos v, y = v \sin u$ จงหา $\pd{f}{u}$ และ $\pd{f}{v}$

:::


:::solution

\begin{eqnarray*}
f_u = \pd{f}{u} &=& \pd{f}{x}\pd{x}{u} + \pd{f}{y}\pd{y}{u} 

&=& (2x)(\cos v) + (3)(v \cos u) 

&=& (u \cos v)(\cos v) + 3 v \cos u

f_v = \pd{f}{v} &=& \pd{f}{x}\pd{x}{v} + \pd{f}{y}\pd{y}{v} 

&=& (2x)(-u \sin v) + (3)(\sin u) 

&=& (2u \cos v)(-u\sin v) + 3\sin u
\end{eqnarray*}

:::
