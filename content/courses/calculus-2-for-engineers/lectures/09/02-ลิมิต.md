## ลิมิตของฟังก์ชันตัวแปรเดียว

สำหรับฟังก์ชันหนึ่งตัวแปร พิจารณาลิมิตเมื่อ $x \rightarrow x_0$ ของ $f(x)$ คือสามารถเข้าใกล้ได้ 2 ทิศทาง คือ ทางซ้ายและทางขวา เขียนแทนด้วยสัญลักษณ์

\[ \lim_{x \rightarrow x_0^{-}} f(x), \quad \lim_{x \rightarrow x_0^{+}} f(x)\]


:::figure l06i03.png — ลิมิตของฟังก์ชัน 1 ตัวแปร
:::




แต่ฟังก์ชันสองตัวแปรหรือมากกว่านั้น การเข้าใกล้ของจุดหนึ่งจะเข้าใกล้อีกจุดหนึ่งได้ทุกทิศทาง ตามเส้นโค้งที่แตกต่างกัน

:::figure l06i02.png — ลิมิตของฟังก์ชัน 2 ตัวแปร
:::





## ลิมิตของฟังก์ชันหลายตัวแปรตามเส้นโค้ง


:::definition

กำหนดฟังก์ชัน $z = f(x,y)$ เป็นฟังก์ชันค่าจริงสองตัวแปร และ $C$ เป็นเส้นโค้งเรียบในระนาบ $xy$ ที่มีสมการอิงตัวแปรเสริม$x=x(t), y=y(t)$

ถ้า $(x_0, y_0) = (x(t_0), y(t_0))$ เป็นจุดบนเส้นโค้ง $C$ แล้วลิมิตของ $f(x,y)$ เมื่อ $(x,y)$ เข้าใกล้ $(x_0, y_0)$ ตามเส้นโค้ง $C$ นิยามโดย

\begin{equation} 
\lim_{\substack{(x,y) \rightarrow (x_0, y_0) 
\mbox{ตาม } C}} f(x,y) = \lim_{t \rightarrow t_0} f(x(t), y(t))
\end{equation}

:::






:::example

กำหนดให้ $f(x,y) = \frac{2x+y}{2x-y}$ จงหา $\displaystyle \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C}} f(x,y)$ เมื่อกำหนดให้ $C$ มีสมการอิงตัวแปรเสริมเป็น $x = t, y = t$

:::


:::solution
เราต้องการหาลิมิตเข้าใกล้จุด $(x_0,y_0) = (0,0)$ ขั้นแรกต้องคำนวณหา $t_0$ ที่ทำให้ $(x_0, y_0) = (x(t_0), y(t_0)$ นั่นคือ $(0,0) = (t_0, t_0)$ ฉะนั้น $t_0 = 0$ 

\begin{eqnarray*}
\lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C}} f(x,y) &=& \lim_{t \rightarrow 0} f(x(t), y(t)) 

&=& \lim_{t \rightarrow 0} \frac{2x(t) + y(t)}{2x(t) - y(t)} 

&=& \lim_{t \rightarrow 0} \frac{2t+t}{2t-t} = \lim_{t \rightarrow 0} \frac{3t}{t} = \frac{1}{3} \qed
\end{eqnarray*}

:::






:::example

กำหนดให้ $f(x,y) = \frac{2x+y}{2x-y}$ จงหา $\displaystyle \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C}} f(x,y)$ เมื่อกำหนดให้ $C$ มีสมการอิงตัวแปรเสริมเป็น $x = 2t, y = 0$

:::


:::solution

ราต้องการหาลิมิตเข้าใกล้จุด $(x_0,y_0) = (0,0)$ ขั้นแรกต้องคำนวณหา $t_0$ ที่ทำให้ $(x_0, y_0) = (x(t_0), y(t_0)$ นั่นคือ $(0,0) = (2t_0,0)$ ฉะนั้น $t_0 = 0$ 
\begin{eqnarray*}
\lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C}} f(x,y) &=& \lim_{t \rightarrow 0} f(x(t), y(t)) 

&=& \lim_{t \rightarrow 0} \frac{2x(t) + y(t)}{2x(t) - y(t)} 

&=& \lim_{t \rightarrow 0} \frac{2(2t)+0}{2(2t)-0} = \lim_{t \rightarrow 0} \frac{4t}{4t} = 1
\end{eqnarray*}

:::





## การคำนวณหาค่าลิมิต

มีสามกรณีหลัก ๆ ดังนี้


- ลิมิตหาค่าได้

- ไม่ทราบว่าหาค่าได้หรือไม่

- ลิมิตหาค่าไม่ได้



:::remark กรณีที่ 1: หาค่าได้

ในกรณีที่เป็นฟังก์ชันต่อเนื่องและนิยามค่าได้ ลิมิตจะมีค่าเท่ากับฟังก์ชันที่จุดนั้น (นั่นคือ แทนค่า $(x,y)$ ลงไปเลยตรง ๆ ได้) แสดงว่า 
\[ \lim_{(x,y) \rightarrow (0, 0)} f(x,y) = f(x_0, y_0) \] 

:::






:::example

จงหาค่าของ $\displaystyle \lim_{(x,y) \rightarrow (-1,2)} \frac{xy^3}{x+y}$

:::


:::solution

เมื่อแทนค่า $(x,y) = (-1,2)$ ลงในฟังก์ชัน $f(x,y) = \frac{xy^3}{x+y}$ แล้วหาค่าได้ ฉะนั้น $\displaystyle \lim_{(x,y) \rightarrow (-1,2)} \frac{xy^3}{x+y} = \frac{(-1)(2)^3}{(-1)+(2)} = -8$

:::





## การคำนวณหาค่าลิมิต


:::remark กรณีที่ 2: ไม่ทราบว่าหาค่าได้หรือไม่

ในกรณีที่เป็นฟังก์ชันต่อเนื่อง แต่นิยามค่าไม่ได้ (เช่น $\frac{p(x,y)}{q(x,y)}$ ที่ $q(x_0, y_0) = 0$) เราจะตอบว่า ``ไม่รู้'' โดยที่เราจะต้องใช้เทคนิคต่าง ๆ ในการหาค่า เช่น แยกตัวประกอบ สร้างตัวแปรเสริม เพื่อทดสอบว่าหาค่าได้หรือไม่ 

:::






:::example

จงหาค่าของ $\displaystyle \lim_{(x,y) \rightarrow (1,1)} \frac{x^2 - xy}{\sqrt{x} - \sqrt{y}}$

:::


:::solution

เมื่อแทนค่า $(x,y) = (1,1)$ ลงในฟังก์ชัน $f(x,y) = \frac{x^2 - xy}{\sqrt{x} - \sqrt{y}}$ แล้วได้ค่า $\frac{1-1}{1-1} = \frac{0}{0}$ ฉะนั้นเราจึงต้องทดสอบต่อว่าจัดรูปได้หรือไม่ ซึ่งในกรณีนี้เราคูณด้วยสังยุค (conjugate) ของ $\sqrt{x} - \sqrt{y}$ ได้เป็น
\begin{eqnarray*}
\frac{x^2 - xy}{\sqrt{x} - \sqrt{y}} = \frac{x(x-y)}{\sqrt{x} - \sqrt{y}} &=& \frac{x(\sqrt{x}-\sqrt{y})(\sqrt{x} + \sqrt{y})}{\sqrt{x}-\sqrt{y}} = x(\sqrt{x}+\sqrt{y})
\end{eqnarray*}
ฉะนั้น
\[\lim_{(x,y) \rightarrow (1,1)} \frac{x^2 - xy}{\sqrt{x} - \sqrt{y}} = \lim_{(x,y) \rightarrow (1,1)} x(\sqrt{x} + \sqrt{y}) = 1(\sqrt{1} + \sqrt{1}) = 2 \]

:::





:::remark กรณีที่ 3: หาค่าไม่ได้

ถ้าเราสามารถหาเส้นโค้ง $C_1, C_2$ ที่ทำให้ 
\[ \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_1}} f(x,y) \neq \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_2}} f(x,y) \] 
เราจะสรุปได้ว่าฟังก์ชันนี้ไม่มีลิมิตที่จุด $(x_0, y_0)$

:::






:::example

จหาค่าของ $\displaystyle \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_1}} \frac{x^2y}{x^4 + y^2}$ เมื่อ $C_1$ มีสมการอิงตัวแปรเสริมเป็น $x = t, y = t^2$

:::


:::solution

หาค่า $t_0$ ที่ทำให้ $(0,0) = (t_0, t_0^2)$ นั่นคือ $t_0 = 0$ จากนั้นแทนค่า $x=t, y=t^2$ ในฟังก์ชันเลยจะได้ $\frac{x^2y}{x^4 + y^2} = \frac{t^2t^2}{t^4 + (t^2)^2} = \frac{t^4}{2t^4} = \frac{1}{2}$ ดังนั้น 
\[ \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_1}} \frac{x^2y}{x^4 + y^2} = \lim_{t \rightarrow t_0} \frac{1}{2} = \frac{1}{2} \]

:::






:::example

จหาค่าของ $\displaystyle \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_2}} \frac{x^2y}{x^4 + y^2}$ เมื่อ $C_2$ มีสมการอิงตัวแปรเสริมเป็น $x = t, y = 0$

:::


:::solution

หาค่า $t_0$ ที่ทำให้ $(0,0) = (t_0, 0)$ นั่นคือ $t_0 = 0$ จากนั้นแทนค่า $x=t, y=0$ ในฟังก์ชันเลยจะได้ $\frac{x^2y}{x^4 + y^2} = \frac{t^2 \cdot 0}{t^4 + (0)^2} = 0$ ดังนั้น 
\[ \lim_{\substack{(x,y) \rightarrow (0, 0) 
\mbox{ตาม } C_2}} \frac{x^2y}{x^4 + y^2} = \lim_{t \rightarrow t_0} 0 = 0 \]

นอกจากนั้น เนื่องลิมิตในตัวอย่างนี้ (ตามเส้นโค้ง $C_2$) กับตัวอย่างก่อนหน้านี้ (ตามเส้นโค้ง $C_1$) มีค่าไม่เท่ากัน ฉะนั้นเราจะสรุปได้ว่า $\displaystyle \lim_{(x,y) \rightarrow (0, 0)} \frac{x^2y}{x^4 + y^2}$ หาค่าไม่ได้

:::
