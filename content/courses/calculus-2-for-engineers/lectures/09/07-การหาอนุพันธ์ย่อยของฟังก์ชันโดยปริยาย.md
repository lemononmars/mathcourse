## ฟังก์ชันโดยปริยาย

ฟังก์ชันในรูปแบบ $z = f(x,y)$ เรียกว่าเป็น**ฟังก์ชันเด่นชัด** (Explicit function) ซึ่งเราคำนวณค่า $z$ ซึ่งเป็นตัวแปรตามที่อยู่ฝั่งซ้ายของสมการได้จากตัวแปรอิสระ $x,y$ ที่อยู่ฝั่งขวาของสมการ


\par ส่วนฟังก์ชั่น $F(x,y,z) = 0$ เรียกว่าเป็น**ฟังก์ชันโดยปริยาย** (Implicit function) เนื่องจากเราไม่ได้กำหนดตัวแปรตามกับตัวแปรอิสระ และในบางครั้งเราไม่สามารถเขียนให้อยู่ในรูปฟังก์ชันเด่นชัดได้ (เช่น $x^2 + y^2 + z^2 - 4 = 0)$ 



:::slide

เราสามารถหาอนุพันธ์ย่อยของฟังก์ชันโดยปริยาย $F(x,y,z) = 0$ ได้ด้วยการ หาอนุพันธ์ย่อยทั้งสองข้างของสมการ $F(x,y,z) = 0$ เทียบกับตัวแปร $x$ โดยให้ $y$ เป็นค่าคงตัวชั่วขณะ และ $x,z$ เป็นตัวแปรอิสระ แล้วจัดรูปจนได้ค่า $\pd{z}{x}$ 

:::






:::example

กำหนดสมการ $3xz + yz^2 + xy = 1$ จงหา $\pd{z}{x}$ 

:::


:::solution

หาอนุพันธ์ย่อยทั้งสองข้างของสมการ เทียบกับตัวแปร $x$ โดยให้ $y$ เป็นค่าคงตัวชั่วขณะ จะได้
\begin{eqnarray*}
\pd{F}{x} = \pd{}{x}(3xz + yz^2 + xy) &=& 0 

3\left(x \pd{z}{x} + z\right) + 2yz \pd{z}{x} + y &=& 0 

\pd{z}{x}(3x + 2yz) + 3z + y &=& 0 

\pd{z}{x} &=& \frac{-3z-y}{3x+2yz} 
\end{eqnarray*}

:::






:::example

กำหนดให้ $3xz + yz^2 + xy = 1$ จงหา $\pd{z}{y}$ 

:::


:::solution

หาอนุพันธ์ย่อยทั้งสองข้างของสมการ เทียบกับตัวแปร $y$ โดยให้ $x$ เป็นค่าคงตัวชั่วขณะ จะได้
\begin{eqnarray*}
\pd{F}{y} = \pd{}{y}(3xz + yz^2 + xy) &=& 0 

3x\pd{z}{y} + (2yz \pd{z}{y} + z^2) + x &=& 0 

\pd{z}{y}(3x + 2yz) + z^2 + x &=& 0 

\pd{z}{y} &=& \frac{-z^2-x}{3x+2yz} 
\end{eqnarray*}

:::





## ที่มาของการหาอนุพันธ์ย่อยของฟังก์ชันโดยปริยายโดยใช้สูตร

อย่างไรก็ตาม เราสามารถหาอนุพันธ์ย่อยของฟังก์ชันโดยปริยาย $w = F(x,y,z) = 0$ ได้ สมมติว่าเราต้องการหา $\pd{z}{x}$ 
:::slide
เราสามารถใช้กฎลูกโซ่
\[ \pd{w}{x} = \pd{F}{x} \pd{x}{x} + \pd{F}{y} \pd{y}{x} + \pd{F}{z} \pd{z}{x} = 0\]
เนื่องจากเราสนใจเทียบตัวแปร $z$ กับ $x$ เราจึงให้ $y$ เป็นค่าคงตัวชั่วขณะ ทำให้ $\pd{y}{x} = 0$ ทำให้เราได้
\[ \pd{F}{x} + \pd{F}{z} \pd {z}{x} = 0\]
เมื่อเขียน $\pd{F}{x} = F_x$ และ $\pd{F}{z} = F_z$ พร้อมทั้งจัดรูปสมการใหม่ จะได้
\[ \pd{z}{x} = -\frac{F_x}{F_z} \]

:::





## สูตรอนุพันธ์ย่อยโดยปริยาย


:::theorem

กำหนดฟังก์ชันโดยปริยาย $F(x,y,z)=0$ โดยเขียน $F_x = \pd{F}{x}, F_y = \pd{F}{y}$ และ $F_z = \pd{F}{z}$ แล้ว
\begin{eq*}
\pd{x}{y} = -\frac{F_y}{F_x} &\quad& \pd{x}{z} = -\frac{F_z}{F_x}

\pd{y}{x} = -\frac{F_x}{F_y} &\quad& \pd{y}{z} = -\frac{F_z}{F_y}

\pd{z}{x} = -\frac{F_x}{F_z} &\quad& \pd{z}{y} = -\frac{F_y}{F_z}
\end{eq*}

:::






:::example

กำหนดให้ $3xz + yz^2 + xy = 1$ จงหา $\pd{z}{x}$ และ $\pd{z}{y}$

:::


:::solution

กำหนดให้ $F(x,y,z) = 3xz + yz^2 + xy$ จะได้
\[F_x = 3z + y, \qquad F_y = z^2+x, \qquad F_z = 3x+2yz\] 
ฉะนั้น เมื่อแทนค่าในสูตรจะได้
\[ \pd{z}{x} = -\frac{F_x}{F_z} = -\frac{3z + y}{3x + 2yz}\]
\[ \pd{z}{y} = -\frac{F_y}{F_z} = -\frac{z^2+x}{3x + 2yz}\]

:::






:::example

กำหนดสมการ $ z \sin x + y \cos z = 0 $ จงหา $\pd{z}{x}$ และ $\pd{z}{y}$ 

:::


:::solution

ให้ $F(x,y,z) = z \sin x + y \cos z = 0$ หาค่า $\pd{z}{x}, \pd{z}{y}$ โดยใช้สูตรดังนี้
\begin{eqnarray*}
F_x &=& z \cos x 

F_y &=& \cos z 

F_z &=& \sin x - y \sin z 

\pd{z}{x} &=& -\frac{F_x}{F_z} = -\frac{z \cos x}{\sin x - y \sin z} 

\pd{z}{y} &=& -\frac{F_y}{F_z} = -\frac{\cos z}{\sin x - y \sin z}

\end{eqnarray*}

:::
