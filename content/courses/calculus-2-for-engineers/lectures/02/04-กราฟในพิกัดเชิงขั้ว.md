## กราฟในพิกัดเชิงขั้ว

กราฟของสมการเชิงขั้วจะอยู่ในรูป $r = r(\theta)$ ตัวอย่างเช่น 
\[r = \theta, \quad r = \sin \theta, \quad r = 3\theta^2\] 
เราสามารถใช้การลงจุดเพื่อคาดเดารูปแบบของกราฟได้ โดยทั่วไปจะลองใช้ค่า 
\[\theta = -\frac{\pi}{2}, -\frac{\pi}{4}, 0, \frac{\pi}{4}, \frac{\pi}{2}\] 
หรือ
\[\theta = 0, \frac{\pi}{6}, \frac{\pi}{3}, \frac{\pi}{2}, \frac{4\pi}{3}, \frac{5\pi}{6}, \pi\] 
หรือค่าอื่นก็ได้ แล้วแต่สมควร


แต่ถ้าเราต้องการวาดกราฟ $r=r(\theta)$ แบบครบถ้วน จำเป็นจะต้องใช้ซอฟต์แวร์ช่วย





:::example

จงลงจุดกราฟของ $r = \sin \theta$ อย่างน้อย 5 จุด พร้อมทั้งเดาว่าเป็นกราฟประเภทใด

:::


:::solution
โจทย์ไม่ได้กำหนดค่าของ $\theta$ มา เราจึงเลือกอะไรก็ได้ ในที่นี้เราเลือก $\theta = -\frac{\pi}{2}, \frac{\pi}{4},0,\frac{\pi}{4},\frac{\pi}{2}$


- แทนค่า $\theta = -\tfrac{\pi}{2}$ จะได้ $r = \sin \left(-\tfrac{\pi}{2}\right) = -1$ นั่นคือจะได้จุด $(-1, -\tfrac{\pi}{2})$ 

- แทนค่า $\theta = -\tfrac{\pi}{4}$ จะได้ $r = \sin \left(-\tfrac{\pi}{4}\right) = -\tfrac{\sqrt{2}}{2}$ นั่นคือจะได้จุด $\left(-\tfrac{\sqrt{2}}{2}, -\tfrac{\pi}{4}\right)$ 

- แทนค่า $\theta = 0$ จะได้ $r = \sin 0 = 0$ นั่นคือจะได้จุด $(0, 0)$

- แทนค่า $\theta = \tfrac{\pi}{2}$ จะได้ $r = \sin \left(\tfrac{\pi}{4}\right) = \tfrac{\sqrt{2}}{2}$ นั่นคือจะได้จุด $\left(\tfrac{\sqrt{2}}{2}, \tfrac{\pi}{4}\right)$ 

- แทนค่า $\theta = \tfrac{\pi}{4}$ จะได้ $r = \sin \left(\tfrac{\pi}{2}\right) = 1$ นั่นคือจะได้จุด $\left(1, \tfrac{\pi}{2}\right)$


:::




และเมื่อนำจุด $(r,\theta)$ มาลงในระนาบในพิกัดเชิงขั้ว จะได้กราฟนี้ สังเกตว่าจุด $\left(-1, -\frac{\pi}{2}\right)$ และ $\left(1, \frac{\pi}{2} \right)$ ซ้อนกัน 



:::tikz TikZ diagram
\begin{tikzpicture}[scale=4]
\draw[<->, thick] (-0.6,0) -- (0.6,0) ;
\draw[->, thick] (0,-0.2) -- (0,1.2);
\foreach \t / \ttext / \r / \rtext  in {-45/-\frac{\pi}{4}/-0.707/-\frac{\sqrt{2}}{2},0/0/0/0,45/\frac{\pi}{4}/0.707/\frac{\sqrt{2}}{2},90/\frac{\pi}{2}/1/1}
\fill[blue] (\t:\r) circle (0.5pt) node[scale = 0.8, above] {$\left(\rtext, \ttext\right)$};
\fill[blue] (90:1) circle (0.5pt) node[scale = 0.8, below] {$\left(-1, -\frac{\pi}{2} \right)$}; 
\end{tikzpicture}
:::


*จุดบนเส้นโค้ง $r = \sin\theta$*




ซึ่งถ้าเราใช้ซอฟต์แวร์ในการวาดกราฟ จะทราบว่ากราฟของสมการ $r = \sin \theta$ เป็นกราฟวงกลมดังภาพด้านล่าง



:::tikz TikZ diagram
\begin{tikzpicture}[scale=4]
\draw[<->, thick] (-0.6,0) -- (0.6,0) ;
\draw[->, thick] (0,-0.2) -- (0,1.2);
\draw (0,0.5) circle (0.5);
\foreach \t / \ttext / \r / \rtext  in {-45/-\frac{\pi}{4}/-0.707/-\frac{\sqrt{2}}{2},0/0/0/0,45/\frac{\pi}{4}/0.707/\frac{\sqrt{2}}{2},90/\frac{\pi}{2}/1/1}
\fill[blue] (\t:\r) circle (0.5pt);
\end{tikzpicture}
:::


*กราฟ $r = \sin\theta$ ที่วาดโดยซอฟต์แวร์*
