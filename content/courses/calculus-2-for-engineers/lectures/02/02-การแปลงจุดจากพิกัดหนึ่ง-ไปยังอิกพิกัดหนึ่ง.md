## การเปลี่ยนระบบพิกัดเชิงขั้วไปพิกัดฉาก

จากรูปจะเห็นว่าเราสามารถใช้ฟังก์ชั่นตรีโกณมิติเพื่อหาความสัมพันธ์ระหว่างจุดในพิกัดเชิงขั้ว $(r, \theta)$ และจุดในพิกัดฉาก $(x,y)$ ได้ดังนี้ 

\minipage{0.5\textwidth}
\[ \cos \theta = \frac{x}{r} \Rightarrow x = r \cos \theta \] 
\[ \sin \theta = \frac{y}{r} \Rightarrow y = r \sin \theta \] 
\endminipage
\minipage{0.5\textwidth}

## การเปลี่ยนระบบพิกัดเชิงขั้วไปพิกัดฉาก


:::theorem

กำหนดให้ $(r,\theta)$ เป็นพิกัดเชิงขั้ว ซึ่งมีพิกัดฉากเป็น $(x,y)$ จะได้ว่า 
\begin{eqnarray*}
x &=& r \cos \theta 

y &=& r \sin \theta 
\end{eqnarray*}

:::






:::example

จงแปลงจุด $P\left(4, \frac{\pi}{3}\right)$ ในพิกัดเชิงขั้ว ให้เป็นพิกัดฉาก

:::


:::solution


\minipage{0.6\textwidth}
จาก $P\left(4, \frac{\pi}{3}\right)$ จะได้ $r = 4$ และ $\theta = \frac{\pi}{3}$ ดังนั้น
\begin{eqnarray*}
x &=& r \cos \theta = 4 \cos \frac{\pi}{3} = 4 \left(\frac{1}{2}\right) = 2 

y&=& r\sin \theta = 4 \sin \frac{\pi}{3} = 4 \left( \frac{\sqrt{3}}{2}\right) = 2\sqrt{3} 
\end{eqnarray*}
ฉะนั้นจุด $P$ ในพิกัดฉากคือ $(2,2\sqrt{3})$
\endminipage
\minipage{0.35\textwidth}


:::tikz TikZ diagram

\draw[-, blue, thick] (0,0) -- (2,3.464) node[pos=0.5, above left] {$4$};

\endminipage

:::






:::example

จงแปลงจุด $Q\left(-2, \frac{\pi}{2}\right)$ ในพิกัดเชิงขั้ว ให้เป็นพิกัดฉาก

:::


:::solution
จาก $Q\left(-2, \frac{\pi}{2}\right)$ จะได้ $r = -2$ และ $\theta = \frac{\pi}{2}$ ดังนั้น
\minipage{0.6\textwidth}
\begin{eqnarray*}
x &=& r \cos \theta = -2 \cos \frac{\pi}{2} = -2 \times 0 = 0 

y&=& r\sin \theta = -2 \sin \frac{\pi}{2} = -2 \times 1 = -2
\end{eqnarray*}
ฉะนั้นจุด $Q$ ในพิกัดฉากคือ $(0, -2)$
\endminipage
\minipage{0.35\textwidth}

## การเปลี่ยนระบบพิกัดฉากไปพิกัดเชิงขั้ว

ในทำนองเดียวกัน จะได้ว่า 
\begin{eqnarray*}
r^2 = x^2 + y^2 &\Rightarrow& r = \sqrt{x^2 + y^2} 

\tan \theta = \frac{y}{x} &\Rightarrow& \theta = \arctan \frac{y}{x} + n \pi \text{, เมื่อ } n \text{ เป็นจำนวนเต็มใด ๆ} 
\end{eqnarray*}
เนื่องจากมีค่า $\theta$ ที่เป็นไปได้หลายค่า นั่นคือเราต้องพิจารณาต่อจากกราฟว่ามุม $\theta$ มีค่าเท่าใด โดยให้ดูว่าจุด $(x,y)$ อยู่ในจตุภาคใด






:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.6]
\fill[fill = teal!40] (0,0) rectangle (2,2) node[pos = 0.5] {จตุภาคที่ 1};
\fill[fill = red!40] (0,0) rectangle (-2,2) node[pos = 0.5] {จตุภาคที่ 2};
\fill[fill = red!40] (0,0) rectangle (-2,-2) node[pos = 0.5] {จตุภาคที่ 3};
\fill[fill = teal!40] (0,0) rectangle (2,-2) node[pos = 0.5] {จตุภาคที่ 4};
\node[teal, draw] at (4,0) {$\tan x > 0$};
\node[red, draw] at (-4,0) {$\tan x < 0$};
\axes{-2.2}{2.2}{-2.2}{2.2}
\draw[line width = 0.1cm, <->] (0, 2.2) -- (0, -2.2) node[below = 0.5 cm, draw] {$\tan x = 0$};
\end{tikzpicture}
:::


*ค่าของ $\tan x$ ในแต่ละจตุภาค*




- ถ้า $x > 0$ จุด $(x,y)$ จะอยู่ในจตุภาค 1 หรือ 4 (นั่นคือด้านขวาของแกน $y$) จะได้ว่า $\theta = \arctan \tfrac{y}{x}$ 

- ถ้า $x < 0$ จุด $(x,y)$ จะอยู่ในจตุภาค 2 หรือ 3 (นั่นคือด้านซ้ายของแกน $y$) จะได้ว่า $\theta = \arctan \tfrac{y}{x} + \pi$ 

- ถ้า $x=0$ แปลว่าจุดนั้นอยู่บนแกน $y$ นั่นคือมีมุมเท่ากับ $\tfrac{\pi}{2}$ ถ้าค่า $y > 0$ หรือ $\tfrac{-\pi}{2}$ เมื่อค่า $y < 0$





## การเปลี่ยนระบบพิกัดฉากไปพิกัดเชิงขั้ว


:::theorem

กำหนดให้ $(x, y)$ เป็นพิกัดเชิงขั้ว ซึ่งมีพิกัดฉากเป็น $(r, \theta)$ จะได้ว่า
\begin{eqnarray*}
r &=& \sqrt{x^2 + y^2} 

\theta &=& 
\begin{cases}
\arctan \frac{y}{x} & ,\text{ เมื่อ } x > 0 

\arctan \frac{y}{x} + \pi & ,\text{ เมื่อ } x < 0

\frac{\pi}{2} & ,\text{ เมื่อ } x = 0, y > 0 

\frac{-\pi}{2} & ,\text{ เมื่อ } x = 0, y < 0 

\end{cases} 
\end{eqnarray*}

:::






:::example

จงแปลงจุด $P(2,2)$ ในพิกัดฉากต่อไปนี้ ให้เป็นจุดในพิกัดเชิงขั้ว

:::


:::solution
กำหนดจุด $P(2,2)$ เป็นพิกัดฉาก จะแปลงเป็นพิกัดเชิงขั้วได้ดังนี้
\minipage{0.6\textwidth}
\[r=\sqrt{2^2+2^2} = \sqrt{8} = 2\sqrt{2}\]
เนื่องจาก $x>0$ และ $y>0$ ฉะนั้น $\theta$ อยู่ในจตุภาคที่ 1 นั่นคือ
\[\theta= \arctan \left(\frac{2}{2}\right) = \arctan 1 = \frac{\pi}{4}\] 
จึงสรุปได้ว่าพิกัดเชิงขั้วของจุด $P$ คือ $(r,\theta)= \left(2\sqrt{2}, \frac{\pi}{4}\right) $
\endminipage
\minipage{0.35\textwidth}


:::tikz TikZ diagram
\begin{tikzpicture}

\draw[->, thick] (0,-0.2) -- (0,2.2);

\draw[dashed] (2,0) -- (2,2) node[pos=0.5, right] {$2$};
\draw[-, blue, thick] (0,0) -- (2,2) node[pos=0.5, above left] {$2\sqrt{2}$}; 
\fill[blue] (2,2) circle (3pt)

:::


\captionof{figure}{พิกัดเชิงขั้วของจุด $P(2,2)$ }
\endminipage

:::






:::example

จงแปลงจุด $Q(-4,4\sqrt{3})$ ในพิกัดฉากต่อไปนี้ ให้เป็นจุดในพิกัดเชิงขั้ว

:::


:::solution

กำหนดจุด $Q(-4,4\sqrt{3})$ เป็นพิกัดฉาก จะแปลงเป็นพิกัดเชิงขั้วได้ดังนี้
\[r=\sqrt{(-4)^2+(4\sqrt{3})^2} = \sqrt{16+48} = \sqrt{64} = 8\]
เนื่องจาก $x<0$ และ $y > 0$ ฉะนั้น $\theta$ อยู่ในจตุภาคที่ 2 นั่นคือต้องบวกด้วย $\pi$ จะได้ 
\[\theta = \arctan \left( \frac{4\sqrt{3}}{-4}\right) + \pi = \arctan (-\sqrt{3}) + \pi = -\frac{\pi}{3} + \pi = \frac{2\pi}{3}\]
จึงสรุปได้ว่าพิกัดเชิงขั้วของจุด $Q$ คือ $(r,\theta)= \left(8, \frac{2\pi}{3}\right) $

:::
