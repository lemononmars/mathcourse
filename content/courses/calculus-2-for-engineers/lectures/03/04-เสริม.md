## เปรียบเทียบ

ปิดท้ายด้วยสูตรเปรียบการระหว่างระบบพิกัดฉาก (ที่ได้ศึกษาแล้วในวิชาแคลคูลัส 1 สำหรับวิศวกร) และระบบพิกัดเชิงขั้ว (ที่ศึกษาในคาบเรียนนี้)

\renewcommand*{\arraystretch}{2}

| | ระบบพิกัดฉาก $(x,y)$ | ระบบพิกัดเชิงขั้ว $(r,\theta)$ |
| --- | --- | --- |
| ฟังก์ชัน | $y = f(x)$ | $r = f(\theta)$ |
| ความชัน | $\frac{dy}{dx}$ | $\frac{r'\sin \theta + r \cos \theta}{r' \cos \theta - r \sin \theta}$ |
| พื้นที่ | $\int y dx$ | $\int \frac{1}{2} r^2 d\theta$ |
| ความยาวเส้นโค้ง | $\int \sqrt{ 1 + (y')^2 } dx $ | $\int \sqrt{r^2 + (r')^2 } d\theta$ |






## บทพิสูจน์สูตรของความยาวส่วนโค้ง

เราทราบว่า
\[\frac{dx}{d\theta} = r' \cos \theta - r \sin \theta \qquad \qquad \frac{dy}{d\theta} = r' \sin \theta + r \cos \theta\]
และต้องการจะพิสูจน์ว่า
\[\left( \frac{dx}{d\theta}\right)^2 + \left( \frac{dy}{d\theta}\right)^2 = r^2 + (r')^2\]




## บทพิสูจน์ (1/2)

เรานำ $\frac{dx}{d\theta}$ มายกกำลังสองทั้งสองข้างของสมการ

:::slide

\begin{eq}
\left(\frac{dx}{d\theta}\right)^2 &=&(r'\cos\theta - r\sin\theta)^2 \nonumber 

&=&(r'^2)\cos^2\theta - 2rr'\cos\theta\sin\theta + r^2\sin^2\theta 
\end{eq}
\noindent ในทำนองเดียวกัน นำ $\frac{dy}{d\theta}$ มายกกำลังสองทั้งสองข้างของสมการ จะได้
\begin{eq}
\left(\frac{dy}{d\theta}\right)^2 &=&(r'\sin\theta + r\cos\theta)^2 \nonumber 

&=&(r')^2\sin^2\theta + 2rr'\cos\theta\sin\theta + r^2\cos^2\theta 
\end{eq}

:::





## บทพิสูจน์ (2/2)

เมื่อนำ \eqref{curvelengthdx2} และ \eqref{curvelengthdy2} มาบวกกัน จะสังเกตว่าพจน์ $2rr'\cos\theta\sin\theta$ จะตัดกันพอดี จึงได้

:::slide

\begin{eq*}
\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 &=& (r'^2)\cos^2\theta + r^2\sin^2\theta + (r'^2)\sin^2\theta + r^2\cos^2\theta 

&=&(r')^2(\cos^2\theta + \sin^2\theta) + r^2(\sin^2\theta + \cos^2\theta)

&=&(r')^2 + r^2

\end{eq*}
ซึ่งเราสามารถจัดรูปต่อให้มี $d\theta$ ด้านขวาดังนี้
\[(dx)^2 + (dy)^2 =\big((r')^2 + r^2\big)(d\theta)^2 \] \qed

:::
