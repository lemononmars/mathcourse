## ที่มา

กำหนดเส้นโค้ง $r = f(\theta)$ และมุม $\alpha < \beta$ เราสามารถหาความยาวส่วนโค้งระหว่างมุม $\alpha$ และ $\beta$ ได้


:::figure polar_arclength — $L$ คือความยาวส่วนโค้งของเส้นโค้ง ระหว่างมุม $\theta=\alpha$ และ $\theta=\beta$ ในพิกัดเชิงขั้ว
:::





## การหาความยาวส่วนโค้งในระบบพิกัดเชิงขั้ว

สูตรหาความยาวส่วนโค้งในระบบพิกัดฉากคือ

\[ L = \int \sqrt{ 1 + \left( \frac{dy}{dx} \right)^2 } \, dx = \int \sqrt{ (dx)^2+ (dy)^2} \] 

:::slide

แทนค่า 
\[\frac{dx}{d\theta} = r' \cos \theta - r \sin \theta \qquad \qquad \frac{dy}{d\theta} = r' \sin \theta + r \cos \theta\]
และจัดรูป (ยาวมาก อ่านต่อได้ใน (ส่วนเสริม \ref{sec:extra})) จะได้
\[\left( \frac{dx}{d\theta}\right)^2 + \left( \frac{dy}{d\theta}\right)^2 = r^2 + (r')^2\]
ซึ่งมีการตัดพจน์กันโดยใช้เอกลักษณ์ $(\sin \theta)^2 + (\cos \theta)^2 = 1$

:::





## สูตรความยาวส่วนโค้งในระบบพิกัดเชิงขั้ว


:::theorem ความยาวส่วนโค้งในระบบพิกัดเชิงขั้ว

กำหนดสมการเชิงขั้ว $r = f(\theta)$ โดยให้ $r' = \frac{df}{d\theta}$ เป็นอนุพันธ์ของฟังก์ชัน $f$ เทียบกับ $\theta$ ถ้าให้ $L$ เป็นความยาวส่วนโค้งของกราฟ $r=f(\theta)$ ระหว่างมุม $\theta = \alpha$ ถึง $\beta$ แล้ว
\begin{equation} 
L = \int_\alpha^\beta \sqrt{r^2 + (r')^2 } \, d\theta
\end{equation}

:::

ถ้าโจทย์กำหนดฟังก์ชัน $r = f(\theta)$ และเส้นตรง $\theta = \alpha$ กับ $\theta = \beta$ มาให้แล้ว เราสามารถนำค่าทั้งหมดไปใส่ในสูตรได้ทันที แต่ถ้าไม่กำหนดมาให้เราต้องวาดรูปและหามุมก่อน





:::example

จงหาความยาวส่วนโค้ง $r = \sin \theta$ จากมุม $\theta = 0$ ถึงมุม $\theta = \pi$

:::


:::solution

เนื่องจากโจทย์กำหนดข้อมูลทั้งหมดมาให้แล้ว เราสามารถหาคำตอบได้เลยทันที ในสูตร \eqref{eq:polar_curve} ดังนี้
\begin{eq*}
L = \int_{\alpha}^{\beta} \sqrt{r^2 + r\,'^2} \, d\theta &=& \int_0^{\pi} \sqrt{ (\sin \theta)^2 + (\cos\theta)^2} \, d\theta 

&=& \int_0^{\pi} 1 \, d\theta 

&=& (\theta)\Big|_{\theta = 0}^{\theta = \pi} = \pi - 0 = \pi
\end{eq*}

:::





## ขั้นตอนการหาความยาวส่วนโค้ง

แต่ถ้าโจทย์กำหนดรูปอย่างเดียว เราจำเป็นจะต้องวิเคราะห์จากสมการเพื่อหาเส้นตรง $\theta = \alpha$ และ $\theta = \beta$ ที่เป็นขอบเขต ซึ่งมีขั้นตอนโดยสังเขปดังนี้

:::remark



- วาดรูป 

- หาเส้นเริ่ม $\theta = \alpha$ และเส้นจบ $\theta = \beta$ ที่ทำให้ $r(\alpha) = r(\beta)$ (นั่นคือ จุดบนกราฟวนกลับมาบรรจบกับจุดแรก) 

- แทนค่าในสูตรแล้วคำนวณ 


:::






:::example

จงหาความยาวของเส้นโค้ง $r = 1- \cos \theta$

:::




:::figure l02i06.png — เส้นโค้ง $r = 1 - \cos\theta$
:::




:::slide



- วาดรูป 

- หาจุดเริ่ม $\theta = \alpha$ และจุดจบ $\theta = \beta$ จากการวาดกราฟ 
\[\alpha = 0, \beta = 2\pi\]

- แทนค่าในสูตรแล้วคำนวณ

\begin{eq*}
r &=& 1 - \cos\theta 

r' &=& \frac{d}{d\theta} (1 - \cos\theta) = \sin\theta
\end{eq*}

:::







:::solution
(ต่อ)
จากนั้นนำค่า $r, r', \alpha$ และ $\beta$ ไปใส่ในสูตร \eqref{eq:polar_curve} ดังนี้
\begin{eq*}
L &=& \int_\alpha^\beta \sqrt{r^2 + (r')^2 } \, d\theta 

&=& \int_0^{2\pi} \sqrt{ (1 - \cos \theta)^2 + (\sin \theta)^2} \, d\theta 

&=& \int_0^{2\pi} \sqrt{ 1-2\cos \theta + (\cos \theta)^2 + (\sin \theta)^2} \, d\theta \boxed{\text{กำลังสองสัมบูรณ์}} 

&=& \int_0^{2\pi} \sqrt{ 2 - 2\cos \theta} \, d\theta 

&=& \int_0^{2\pi} \sqrt{ 4 \left( \sin \frac{\theta}{2} \right)^2 } \, d\theta \boxed{\text{สูตรมุมครึ่ง}}

\end{eq*}

:::





:::solution
(ต่อ)
\begin{eq*}
L &=& \int_0^{2\pi} \sqrt{ 4 \left( \sin \frac{\theta}{2} \right)^2 } \, d\theta \boxed{\text{สูตรมุมครึ่ง}}

&=& 2 \int_0^{2\pi} \sin \frac{\theta}{2} \, d\theta 

&=& 2 \int_0^{2\pi} \sin \frac{\theta}{2} \, \left( 2 d \frac{\theta}{2}\right) \mathnote{แทนค่า $u = \frac{\theta}{2}$}

&=& -4 \cos \frac{\theta}{2} \Big|_{\theta = 0}^{\theta = 2\pi} 

&=& (-4\cos \pi) - (-4\cos 0) 

&=& 4 - (-4) = 8
\end{eq*}

:::





:::exercise

จงหาความยาวส่วนโค้งของเส้นโค้งต่อไปนี้


- $r = 4$ ระหว่างมุม $\theta = 0$ และ $\theta = \frac{\pi}{2}$

- $r = 2\sin\theta$ ระหว่างมุม $\theta = 0$ และ $\theta = \pi$


:::
