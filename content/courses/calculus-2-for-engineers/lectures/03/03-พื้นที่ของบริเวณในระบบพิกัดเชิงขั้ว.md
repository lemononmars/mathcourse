## การหาพื้นที่ของบริเวณในระบบพิกัดเชิงขั้ว

กำหนดให้ $R$ เป็นบริเวณที่ปิดล้อมด้วยเส้นตรง $\theta = \alpha$, $\theta = \beta$, และเส้นโค้ง $r = f(\theta)$

ถ้าเราแบ่งบริเวณ $R$ ออกเป็นบริเวณย่อย ด้วยเส้นตรง $\theta = \theta_1, \theta_2, \theta_3, \ldots, \theta_n$ ที่แต่ละมุมระหว่างเส้นแต่ละคู่มีค่าเท่ากับ $\theta$ จะทำให้เกิดรูปดังต่อไปนี้

พื้นที่วงกลมที่คิดเป็นมุม $2\pi$ มีค่าเท่ากับ $\pi r^2$ เราสามารถใช้บัญญัติไตรยางค์เพื่อหาพื้นที่วงกลมที่คิดเป็นมุม $\theta$ ได้เท่ากับ
\[ \theta \frac{\pi r^2}{2 \pi} = \frac{1}{2}r^2 \theta\]

## ที่มา

กำหนดเส้นโค้ง $r = f(\theta)$ และมุม $\alpha < \beta$ เราสามารถหาความยาวส่วนโค้งระหว่างมุม $\alpha$ และ $\beta$ ได้


:::figure polar_region — $R$ คือบริเวณที่ปิดล้อมด้วยเส้นโค้ง $r = r(\theta)$ ระหว่างมุม$\theta = \alpha$ และ $\theta = \beta$
:::






## สูตรพื้นที่ของบริเวณในระบบพิกัดเชิงขั้ว

เมื่อเรารวมพื้นที่เสี้ยวของวงกลมทั้งหมดเข้าด้วยกัน จะได้พื้นที่ประมาณบริเวณ $R$ ซึ่งพื้นที่รวมกันได้เท่ากับ

:::slide

\[\sum_{k=1}^{n} \frac{1}{2} (r(\theta_k))^2 d\theta\]
และเมื่อเราให้ค่า $n$ เข้าใกล้อนันต์ (นั่นคือ เมื่อให้จำนวนบริเวณย่อยมากขึ้น) จะได้
\[R = \lim_{n \to \infty} \sum_{k=1}^{n} \frac{1}{2} (r(\theta_k))^2 d\theta\]
สุดท้าย ลิมิตด้านขวาสามารถเขียนใหม่ให้อยู่ในรูปของ
\[ \int_{\alpha}^{\beta} \frac{1}{2} r^2 \, d\theta\]

:::





:::theorem พื้นที่ของบริเวณในพิกัดเชิงขั้ว

กำหนดสมการเชิงขั้ว $r = f(\theta)$ และ $R$ เป็นบริเวณที่ปิดล้อมด้วยเส้นตรง $\theta = \alpha$, $\theta = \beta$, และเส้นโค้ง $r = f(\theta)$
\begin{equation} 
R = \int_\alpha^\beta \frac{1}{2} r^2 d\theta
\end{equation}

:::


ถ้าโจทย์กำหนดฟังก์ชัน $r = f(\theta)$ และเส้นตรง $\theta = \alpha$ กับ $\theta = \beta$ มาให้แล้ว เราสามารถนำค่าทั้งหมดไปใส่ในสูตรได้ทันที

แต่ถ้าโจทย์ไม่กำหนดมาให้ เราต้องใช้เครื่องมือในการวาดกราฟ เพื่อหาค่า $\alpha$ และ $\beta$ ที่ทำให้เส้นโค้งมาบรรจบพอดี





:::example

จงหาพื้นที่ของบริเวณที่ปิดล้อมด้วยเส้นโค้ง $r = \theta$ เส้นตรง $\theta = 0$ และเส้นตรง $\theta = \frac{\pi}{2}$

:::


:::solution

เนื่องจากโจทย์กำหนดข้อมูลทั้งหมดมาให้แล้ว เราสามารถหาคำตอบได้เลยทันทีดังนี้
\begin{eq*}
R = \int_{\alpha}^{\beta} \frac{1}{2} r^2 \, d\theta &=& \int_0^{\pi/2} \frac{1}{2} (\theta)^2 \, d\theta 

&=& \left( \frac{1}{6} \theta^3 \right) \Big|_{\theta = 0}^{\theta = \pi/2} 

&=& \frac{1}{6} \left( \frac{\pi}{2} \right)^3 - \frac{1}{6} (0)^3 = \frac{\pi^3}{48}
\end{eq*}

:::





## ขั้นตอนการหาพื้นที่

แต่ถ้าโจทย์กำหนดรูปอย่างเดียว เราจำเป็นจะต้องวิเคราะห์จากสมการเพื่อหาเส้นตรง $\theta = \alpha$ และ $\theta = \beta$ ที่เป็นขอบเขต ซึ่งมีขั้นตอนเหมือนการหาความยาวส่วนโค้ง ดังนี้

:::remark



- วาดรูป 

- หาเส้นเริ่ม $\theta = \alpha$ และเส้นจบ $\theta = \beta$ ที่ทำให้ $r(\alpha) = r(\beta)$ (นั่นคือ จุดบนกราฟวนกลับมาบรรจบกับจุดแรก) 

- แทนค่าในสูตรแล้วคำนวณ 


:::







:::example

จงหาพื้นที่ของบริเวณที่ปิดล้อมด้วยเส้นโค้ง $r = 2 + 2 \cos \theta$ 

:::

:::solution



- วาดรูป

- หาเส้นเริ่ม $\theta = \alpha$ และเส้นจบ $\theta = \beta$ ในที่นี้เราสามารถให้
\[\alpha = 0, \beta = 2\pi\] 

- แทนค่าในสูตรแล้วคำนวณ

:::solution
(ต่อ)
\begin{eq*}
R = \int_0^{2\pi} \frac{1}{2} r^2 \,d\theta &=& \int_0^{2\pi} \frac{1}{2} (2 + 2 \cos \theta)^2 \,d\theta 

&=& \int_0^{2\pi} 2 + 4\cos\theta + 2\cos^2\theta \, d\theta \boxed{\text{กระจายกำลังสองสมบูรณ์}} 

&=& \int_0^{2\pi} 4\cos\theta + 3 + (2\cos^2\theta -1) \,d\theta \boxed{\text{จัดรูป}}

&=& \int_0^{2\pi} 4\cos\theta + 3 + \cos 2\theta \,d\theta \boxed{\text{สูตรมุมสองเท่า}}

&=& \left(4\sin\theta + 3\theta + \frac{1}{2}\sin 2\theta \right)\Big|_{\theta = 0}^{2\pi} 

&=& \left(4 \sin 2\pi + 6 \pi + \frac{1}{2} \sin 4\pi \right) - \left(4 \sin 0 + 0 + \frac{1}{2} \sin 0\right) 

&=& (0 + 6\pi + 0) - (0 + 0 + 0) = 6\pi
\end{eq*}

:::





:::exercise

จงหาพื้นที่ของบริเวณที่ปิดล้อมด้วยเส้นโค้งต่อไปนี้


- $r = \theta$ ระหว่างมุม $\theta = 0$ และ $\theta = \pi$

- $r = \cos (3\theta)$ ระหว่างมุม $\theta = 0$ และ $\theta = \frac{2\pi}{3}$


:::
