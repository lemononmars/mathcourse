## การหาอนุพันธ์ของสมการเชิงขั้ว

กำหนดให้สมการในพิกัดเชิงขั้วคือ $r = f(\theta)$ เราสามารถแปลงเป็นสมการอิงตัวแปรเสริมในพิกัดฉากได้ดังนี้
\begin{eq*}
x &=& r \cos \theta = f(\theta)\cos \theta 

y &=& r \sin \theta = f(\theta) \sin \theta
\end{eq*}
โดยที่ $\theta$ เป็นตัวแปรเสริมตัวแปรเดียว ซึ่งเราศึกษาแล้วว่า
\begin{equation} 
\frac{dy}{dx} = \frac{\Big( \frac{dy}{d\theta}\Big)}{\Big(\frac{dx}{d\theta}\Big)}
\end{equation}
นั่นคือ เราต้องการหา $\frac{dy}{d\theta}$ และ $\frac{dx}{d\theta}$



เราสามารถคำนวณหาอนุพันธ์ของ $x,y$ เมื่อเทียบกับ $\theta$ โดยใช้กฎผลคูณของอนุพันธ์ที่ว่า
\[\frac{d}{dx} ( **u(x)** **v(x)**) = **u(x)** \frac{d}{dx}**v(x)** + **v(x)** \frac{d}{dx} **u(x)**\] 

:::slide

ได้มีค่าดังนี้
\begin{eq*}
\frac{dx}{d\theta} &=& \frac{d}{d\theta} (f(\theta)\cos\theta) = f(\theta) (-\sin \theta) + f\,'(\theta) \cos\theta 

\frac{dy}{d\theta} &=& \frac{d}{d\theta} (f(\theta)\sin\theta) =f(\theta) (\cos \theta) + f\,'(\theta) \sin\theta 
\end{eq*}
เมื่อนำไปแทนที่ในสูตรการหาอนุพันธ์ของสมการอิงตัวแปรเสริม \eqref{eq:parametric_diff} จะได้ผลลัพธ์ดังนี้ 

:::





:::theorem อนุพันธ์ของฟังก์ชันเชิงขั้ว

กำหนดสมการเชิงขั้ว $r = f(\theta)$ ซึ่ง $r' = \frac{df}{d\theta}$ แล้วอนุพันธ์ของ $r$ มีค่าเท่ากับ 
\begin{equation} 
\frac{dy}{dx} = \frac{ r \cos \theta + r' \sin\theta}{-r\sin \theta + r' \cos\theta}
\end{equation}
อุนพันธ์ของ $r$ เมื่อกำหนด $\theta = \theta_0$ มาให้ มีค่าเท่ากับ 
\[\frac{dy}{dx}\Big|_{\theta = \theta_0} = \frac{ r(\theta_0) \cos \theta_0 + r'(\theta_0) \sin\theta_0}{-r(\theta_0)\sin \theta_0 + r'(\theta_0) \cos\theta_0}\]

:::






:::example

จงหาอนุพันธ์ของสมการเชิงขั้ว $r = 1$ เมื่อ $\theta = \frac{\pi}{4}$ 

:::


:::solution

จาก $r = 1$ ซึ่งเป็นฟังก์ชันค่าคงตัว จะได้ $r' = 0$ ฉะนั้นจากสมการ \eqref{eq:diff_polar} จะได้ 
\begin{eq*}
\frac{dy}{dx} &=& \frac{ r \cos \theta + r' \sin\theta}{-r\sin \theta + r' \cos\theta} 

&=& \frac{ (1)(\cos \theta) + (0)(\sin\theta)}{- (1)(\sin \theta) + (0)(\cos\theta)} \boxed{\text{แทนค่า $r, r'$}} 

&=& \frac{\cos\theta}{-\sin\theta} = -\cot\theta
\end{eq*} 
เมื่อแทนค่า $\theta = \frac{\pi}{4}$ จะได้
\[ \frac{dy}{dx} \Big|_{\theta - \frac{\pi}{4}} = -\cot\frac{\pi}{4} = -1 \]

:::







:::example

จงหาอนุพันธ์ของสมการเชิงขั้ว $r = \sin \theta$ เมื่อ $\theta = \frac{\pi}{2}$ 

:::


:::solution

จาก $r = \sin \theta$ จะได้ $r' = \cos \theta$ ฉะนั้นจากสมการ \eqref{eq:diff_polar} จะได้ 
\begin{eq*}
\frac{dy}{dx} &=& \frac{ r \cos \theta + r' \sin\theta}{-r\sin \theta + r' \cos\theta} 

&=& \frac{ \sin \theta \cos \theta + \cos \theta \sin\theta}{- \sin\theta \sin \theta + \cos \cos\theta} \boxed{\text{แทนค่า $r$ และ $r'$}} 

&=& \frac{2 \sin\theta\cos\theta}{-\sin^2\theta + \cos^2\theta}
\end{eq*} 
เมื่อแทนค่า $\theta = \frac{\pi}{3}$ จะได้ $\sin \frac{\pi}{3} = \frac{\sqrt{3}}{2} , \cos \frac{\pi}{3} = \frac{1}{2}$ ฉะนั้น
\[ \textstyle \frac{dy}{dx} \Big|_{\theta - \frac{\pi}{3}} = \frac{2\left(\frac{\sqrt{3}}{2}\right)\left(\frac{1}{2}\right) }{- \left(\frac{\sqrt{3}}{2}\right)^2 + \left(\frac{1}{2}\right)^2 } = \frac{\frac{\sqrt{3}}{2}}{ -\frac{3}{4} + \frac{1}{4}} = -\sqrt{3} \]

:::





:::exercise

จงหาอนุพันธ์ของสมการเชิงขั้วต่อไปนี้ ที่ค่า $\theta$ ที่กำหนด


- $r = 2\cos\theta$ ที่ $\theta = \frac{\pi}{4}$

- $r = \theta$ ที่ $\theta = \pi$


:::
