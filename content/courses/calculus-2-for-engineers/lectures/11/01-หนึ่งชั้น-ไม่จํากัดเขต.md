## ปริพันธ์หนึ่งชั้น ของฟังก์ชันสองตัวแปร

เรานิยามปริพันธ์ไว้ว่า ถ้า 
\[\frac{d}{dx} F(x) = f(x) \]
แล้ว 
\[ F(x) + C = \int f(x) \, dx\]
ในทำนองเดียวกัน เราจะนิยามปริพันธ์หนึ่งชั้น สำหรับฟังก์ชันหลายตัวแปรว่า ถ้า
\[\pd{}{x} F(x,y) = f(x,y)\]
แล้ว 
\[ F(x,y) + C = \int f(x,y) \, dx\]





:::example



- เนื่องจาก $\pd{}{x} xy = y$ ฉะนั้น $xy + C = \int y \, dx$ 

- เนื่องจาก $\pd{}{x} x^2y^4 = 2xy^4$ ฉะนั้น $x^2y^4 + C = \int 2xy^4 \, dx$ 

- เนื่องจาก $\pd{}{y} x^7y^3 =3x^7y^2$ ฉะนั้น $x^7y^3 = \int 3x^7y^2 \, dy$ 

- เนื่องจาก $\pd{}{y} \sin x \sin y = \sin x \cos y$ ฉะนั้น $\sin x \sin y + C = \int \sin x \cos y \, dy$


:::





## การหาปริพันธ์หนึ่งชั้นของฟังก์ชันสองตัวแปร แบบไม่จำกัดเขต

การหาอนุพันธ์ไม่จำกัดเขตเทียบกับตัวแปร $**x**$ อยู่ในรูป
\[ \int f(x,y) \, **dx**\]
ทำได้ด้วยการให้ตัวแปร $y$ เป็นค่าคงตัวชั่วขณะ ในทำนองเดียวกัน อนุพันธ์ไม่จำกัดเขตเทียบกับตัวแปร $**y**$ อยู่ในรูป
\[ \int f(x,y) \, **dy**\]
ทำได้ด้วยการให้ตัวแปร $x$ เป็นค่าคงตัวชั่วขณะ 





:::example

จงหาค่าของ $\int xy \, dx$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $x$ เราจึงมอง $y$ เป็นค่าคงตัวชั่วขณะ ดังนั้น
\begin{eqnarray*}
\int xy \, dx &=& y \int x \, dx 

&=& y \left( \frac{x^2}{2} + C\right)
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int x \sin y \, dy$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $y$ เราจึงมอง $x$ เป็นค่าคงตัวชั่วขณะ ดังนั้น
\begin{eqnarray*}
\int x \sin y\, dy &=& x \int \sin y \, dy 

&=& x \left( -\cos y + C\right)
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int y^5 \cos x \, dx$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $x$ เราจึงมอง $y$ เป็นค่าคงตัวชั่วขณะ ซึ่งทำให้ $y^5$ เป็นค่าคงตัวชั่วขณะเช่นกัน ดังนั้น
\begin{eqnarray*}
\int y^5 \cos x\, dx &=& y^5 \int \cos x \, dx 

&=& y^5 \left( \sin x + C\right)
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int y^4 \, dx$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $x$ เราจึงมอง $y$ เป็นค่าคงตัวชั่วขณะ ซึ่งทำให้ $y^4$ เป็นค่าคงตัวชั่วขณะเช่นกัน ดังนั้น
\begin{eqnarray*}
\int y^4 \, dx &=& y^4 \int 1 \, dx 

&=& y^4 \left(x + C\right)
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int e^{x^2} \, dy$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $y$ เราจึงมอง $x$ เป็นค่าคงตัวชั่วขณะ ซึ่งทำให้ $e^{x^2}$ เป็นค่าคงตัวชั่วขณะเช่นกัน ดังนั้น
\begin{eqnarray*}
\int e^{x^2} \, dy &=& e^{x^2} \int 1 \, dy 

&=& e^{x^2} \left(y + C\right)
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int \frac{1}{x+y} \, dx$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $x$ เราจึงมอง $y$ เป็นค่าคงตัวชั่วขณะ แต่ในข้อนี้เราไม่สามารถดึง $y$ ออกมานอกปริพันธ์ในทันทีได้ จึงต้องใช้เทคนิคการแทนค่า $u$ ดังนี้
\begin{eq*}
u &=& x+y 

du &=& d(x+y) = dx
\end{eq*}
ฉะนั้น
\begin{eqnarray*}
\int \frac{1}{x+y} \, dx &=& \int \frac{1}{x+y} \, d(x+y) 

&=& \ln |x+y| + C
\end{eqnarray*}

:::






:::example

จงหาค่าของ $\int e^{xy+1} \, dy$

:::


:::solution

เนื่องจากเป็นการหาปริพันธ์เทียบกับ $y$ เราจึงมอง $x$ เป็นค่าคงตัวชั่วขณะ แต่ในข้อนี้เราไม่สามารถดึง $x$ ออกมานอกปริพันธ์ในทันทีได้ จึงต้องใช้เทคนิคการแทนค่า $u$ ดังนี้
\begin{eq*}
u &=& xy+1 

du &=& d(xy+1) = xdy
\end{eq*}
ฉะนั้น
\begin{eqnarray*}
\int e^{xy+1} \, dy = \int e^{xy+1} \, \frac{d(xy+1)}{x} &=& \frac{1}{x} \int e^{xy+1} \, d(xy+1)

&=& \frac{1}{x} e^{xy+1}
\end{eqnarray*}

:::
