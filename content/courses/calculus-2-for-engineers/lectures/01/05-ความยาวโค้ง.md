## ที่มาของสูตรหาความยาวส่วนโค้งของสมการอิงตัวแปรเสริม

เราสามารถหาความยาวส่วนโค้งได้ ด้วยการแบ่งเส้นโค้งออกเป็นช่วงย่อย และประมาณค่าของเส้นโค้งย่อยด้วยเส้นตรง ซึ่งหาได้ด้วยทฤษฎีบทปิทากอรัส

*ความสัมพันธ์ระหว่างส่วนของเส้นตรงระหว่างสองจุด และค่า $\Delta x$ และ $\Delta y$*





จากภาพ จะได้ความยาวเส้นตรงข้ามมุมฉากเป็น
\[ \sqrt{ (\Delta y)^2 + (\Delta x)^2 } \]
เมื่อแปลงให้อยู่ในรูปของ $dy$ และ $dx$ จะได้
\[\sqrt{(dy)^2 + (dx)^2}\] 
ซึ่งไม่มีความหมายในตัวเอง แต่เราสามารถคูณสมการหลัง $\frac{dt}{dt}$ จะได้ 
\[ \sqrt{(dy)^2 + (dx)^2}\, \frac{dt}{dt} = \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt = \sqrt{(y'(t))^2 + (x'(t))^2} \dt \] 
สุดท้าย เมื่อแบ่งความกว้างของช่วงย่อยให้ถี่ขึ้น โดยให้ค่า $dt$ เข้าใกล้ศูนย์ จะได้ผลลัพธ์เป็น
\[\int_a^b \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt\]




:::theorem สูตรหาความยาวส่วนโค้ง

ความยาวส่วนโค้งของสมการอิงตัวแปรเสริม $x = x(t)$ และ $y = y(t)$ เมื่อ $a \leq t \leq b$ 
\begin{equation}
\int_a^b \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt
\end{equation}

:::






:::example

จงหาความยาวส่วนโค้งของสมการอิงตัวแปรเสริม $x = 2t+1, y = 4-3t$ เมื่อ $-1 \leq t \leq 1$

:::


:::solution

จากสมการจะได้ $\frac{dx}{dt} = 2$ และ $\frac{dy}{dt} = -3$ เมื่อแทนค่านี้ในสูตรจะได้ 
\begin{eqnarray*}
\int_a^b \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt 
&=& \int_{-1}^1 \sqrt{ (2)^2 + (-3)^2} \, dt 

&=& \int_{-1}^1 \sqrt{13} \, dt 

&=& \sqrt{13} (t) \Big|_{t = -1}^{t = 1} 

&=& \sqrt{13}(1 - (-1)) = 2\sqrt{13}
\end{eqnarray*}

:::





:::example

จงหาความยาวส่วนโค้งของสมการอิงตัวแปรเสริม $x = \sin t, y = \cos t$ เมื่อ $0 \leq t \leq \pi$

:::


:::solution

จากสมการจะได้ $\frac{dx}{dt} = \cos t$ และ $\frac{dy}{dt} = -\sin t$ เมื่อแทนค่านี้ในสูตรจะได้ 
\begin{eqnarray*}
\int_a^b \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt &=& \int_0^\pi \sqrt{ (- \sin t)^2 + (\cos t)^2} \, dt 

&=& \int_0^\pi 1 \, dt 

&=& t \Big|_{t = 0}^{t = \pi} 

&=& \pi - 0 = \pi
\end{eqnarray*}

:::




\[ \int_a^b \sqrt{\left( \frac{dy}{dt}\right)^2 + \left( \frac{dx}{dt}\right)^2} \, dt \]

:::exercise

จงหาความยาวส่วนโค้งของสมการอิงตัวแปรเสริมต่อไปนี้


- $x = 3t, \quad y = 4t$ เมื่อ $0 \leq t \leq 2$

- $x = \cos t, y = \sin t$ เมื่อ $0 \leq t \leq 2\pi$


:::
