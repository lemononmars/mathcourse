## การหาอนุพันธ์ของสมการอิงตัวแปรเสริม

เราสามารถหาอนุพันธ์จากนิยามโดยตรงได้ ถ้าต้องการหาอนุพันธ์ที่ $t = t_0$ ให้เลือกจุด $t=t_1$ ที่เข้าใกล้ค่า $t_0$ จากภาพจะหาความชันได้เป็น

\[ \frac{\Delta y}{\Delta x} = \frac{y(t_1) - y(t_0)}{x(t_1)-x(t_0)} \]

ถ้าเขียน $t_1 = t_0 + h$ จะได้

\[ \frac{y(t_1) - y(t_0)}{x(t_1)-x(t_0)} = \frac{y(t_0+h) - y(t_0)}{x(t_0+h) - x(t_0)} = \frac{\left(y(t_0+h) - y(t_0)\right)/h}{\left(x(t_0+h) - x(t_0)\right)/h} \]

สุดท้าย เมื่อหาลิมิตเมื่อ $h$ เข้าใกล้ 0 ทั้งสองฝั่งของสมการจะได้

\[ \dyx = \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} \]



## การหาอนุพันธ์ของสมการอิงตัวแปรเสริม (ต่อ)

ในอีกมุมหนึ่ง กำหนดให้สมการอิงตัวแปรเสริมของเส้นโค้ง $C$ คือ 
\[x = x(t), \quad y = y(t)\] 

เราสามารถหาอนุพันธ์ที่จุด $t=t_0$ ได้โดยใช้กฎลูกโซ่ กล่าวคือ
\begin{eqnarray*}
\frac{dy}{dt} &=& \frac{dy}{dx}\frac{dx}{dt} 

\frac{dy}{dx} &=& \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} 
\end{eqnarray*}





## สูตรอนุพันธ์ของสมการอิงตัวแปรเสริม


:::theorem อนุพันธ์ของสมการอิงตัวแปรเสริม

กำหนดสมการอิงตัวแปรเสริม $x = x(t)$ และ $y = y(t)$ ที่อนุพันธ์ $\frac{dy}{dt}$ และ $\frac{dx}{dt}$ หาค่าได้ แล้วอนุพันธ์ $\dyx$ หาได้จาก
\begin{equation}
\dyx = \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} = \frac{y'(t)}{x'(t)}
\end{equation}
ซึ่งมีค่าเท่ากับความชันของเส้นสัมผัสเส้นโค้ง ณ จุด $(x(t), y(t))$

:::






:::example

จงหาอนุพันธ์ของสมการอิงตัวแปรเสริม $x = t^2, y = 2t^3$ 

:::


:::solution

จากสมการที่ให้มา จะได้ว่า 
\[ \frac{dx}{dt} = 2t , \quad \frac{dy}{dt} = 6t^2\] 
ฉะนั้น
\[\frac{dy}{dx} = \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} = \frac{6t^2}{2t} = 3t\]

:::






:::example

จงหาอนุพันธ์ของสมการอิงตัวแปรเสริม $x = \ln t, y = \frac{1}{t^2}$ 

:::


:::solution

จากสมการที่ให้มา จะได้ว่า 
\[ \frac{dx}{dt} = \frac{1}{t} , \quad \frac{dy}{dt} = -\frac{1}{t^3}\] 
ฉะนั้น
\[\frac{dy}{dx} = \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} = \frac{1/t}{-1/t^3} = -t^2\]

:::






:::example

จงหาอนุพันธ์ของสมการอิงตัวแปรเสริม $x = \sin (2t), y = \cos (2t)$ ณ จุด $t = \frac{\pi}{8}$

:::


:::solution

จากสมการที่ให้มา จะได้ว่า 
\[ \frac{dx}{dt} = 2\cos(2t) , \quad \frac{dy}{dt} = -2\sin(2t)\] 
ฉะนั้น
\[\frac{dy}{dx} = \frac{\left(\frac{dy}{dt}\right)}{\left(\frac{dx}{dt}\right)} = \frac{-2\sin(2t)}{2\cos(2t)} = -\tan(2t)\]
เราสามารถหาอนุพันธ์ที่จุด $t = \frac{\pi}{8}$ ได้โดยการแทนค่าลงไปโดยตรง จะได้ 
\[ \dyx \Big|_{t = \frac{\pi}{8}} = - \tan\left(2 \frac{\pi}{8}\right) = - \tan\left( \frac{\pi}{4} \right) = -1\]

:::




\[ \frac{dy}{dx} = \frac{\left(\frac{dy}{dt}\right)}{\Big(\frac{dx}{dt}\Big)}\]

:::exercise

จงหา $\dps \frac{dy}{dx}$ ของสมการอิงตัวแปรเสริมต่อไปนี้


- $x=t, \quad y = 4t$

- $x=\cos t, \quad y = \sin t$


:::
