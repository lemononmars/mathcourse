## นิยามเวกเตอร์ปกติหนึ่งหน่วย

นอกจากเวกเตอร์สัมผัสหน่วยแล้ว เรายังสนใจเวกเตอร์ที่บอกถึงการเปลี่ยนแปลงของเวกเตอร์สัมผัสหน่วย $\vec{T}(t)$ โดยเราจะเรียกเวกเตอร์นั้นว่าเวกเตอร์ปกติ 

:::definition เวกเตอร์ปกติหนึ่งหน่วย (Unit normal vector)

เราจะเรียกเวกเตอร์ที่มีขนาดหนึ่งหน่วยและมีทิศทางเดียวกันกับ $\vec{T}'(t)$ ที่จุด $\vec{R}(t)$ ใด ๆ ว่าเป็น**เวกเตอร์ปกติหนึ่งหน่วย** เขียนแทนด้วย $\vec{N}(t)$ นั่นคือ

\begin{equation} 
\vec{N}(t) = \frac{\vec{T}'(t)}{\|\vec{T}'(t)\|}, \|\vec{T}'(t)\| \neq 0
\end{equation}

:::

*เวกเตอร์ $\vec{N*(t)$ อนุภาค ณ จุดต่าง ๆ}






:::example

กำหนดให้ $\vrt = \vvv{\sin t}{+\cos t}{-t}$ จงหาเวกเตอร์สัมผัสหน่วย $\vec{T}(t)$ และเวกเตอร์ปกติหน่วย $\vec{N}(t)$

:::


:::solution

ก่อนอื่นเราหา $\vec{T}(t)$ จากสมการ \eqref{vecfun_unit_tangent} ได้เป็น
\begin{eq*}
\dvrt &=& \vvv{\cos t}{-\sin t}{-} 

\| \dvrt \| &=& \sqrt{(\cos t)^2 + (-\sin t)^2 + (-1)^2} 

&=& \sqrt{1 + 1} = \sqrt{2} 

\vec{T}(t) &=& \frac{\dvrt}{\| \dvrt\|} 

&=& \frac{\vvv{\cos t}{-\sin t}{-1}}{\sqrt{2}} 

&=& \vvv{\frac{\cos t}{\sqrt{2}}}{-\frac{\sin t}{\sqrt{2}}}{-\frac{1}{\sqrt{2}}} 

\end{eq*}

:::





:::solution
(ต่อ)
จากนั้น หา $\vec{N}(t)$ จากสมการ \eqref{eq:vecfun_unit_normal} ได้
\begin{eq*}
\vec{T}\,'(t) &=& \vvv{-\frac{\sin t}{\sqrt{2}}}{-\frac{\cos t}{\sqrt{2}}}{-0} = \vv{-\frac{\sin t}{\sqrt{2}}}{-\frac{\cos t}{\sqrt{2}}}

\| \vec{T}\,'(t) \| &=& \sqrt{\left( -\frac{\sin t}{\sqrt{2}}\right)^2 + \left( -\frac{\cos t}{\sqrt{2}}\right)^2 + 0^2} 

&=& \sqrt{ \frac{\sin^2 t}{2} + \frac{\cos^2 t}{2} } = \sqrt{\frac{1}{2}} = \frac{1}{\sqrt{2}} 

\vec{N}(t) &=& \frac{\vec{T}\,'(t)}{\| \vec{T}\,'(t)\|} 

&=& \frac{1}{\left(\frac{1}{\sqrt{2}}\right)}\left(\vv{-\frac{\sin t}{\sqrt{2}}}{-\frac{\cos t}{\sqrt{2}}}\right) 

&=& \sqrt{2}\left(\vv{-\frac{\sin t}{\sqrt{2}}}{-\frac{\cos t}{\sqrt{2}}}\right) 

&=& \leftlangle -\sin t, -\cos t \rightangle
\end{eq*}

:::







:::example

กำหนดให้ $\vrt = a \cos^3 t \mathbf{i} + b \sin^3 t \mathbf{j}$ จงหาเวกเตอร์สัมผัสหน่วย $\vec{T}(t)$ และเวกเตอร์ปกติหน่วย $\vec{N}(t)$

:::


:::solution

ก่อนอื่น หา $\dvrt$ และ $\| \dvrt\|$ ได้ดังนี้
\begin{eqnarray*}
\vrt &=& a \cos^3 t \mathbf{i} + b \sin^3 t \mathbf{j} 

\dvrt &=& -3a \cos^2 t \sin t \mathbf{i} + 3a \sin^2 t \cos t \mathbf{j} 

\| \dvrt \| &=& \sqrt{(3a \cos^2 t \sin t)^2 + (3a \sin^2 t \cos t)^2} 

&=& \sqrt{9a^2 \cos^4 t \sin^2 t + 9a^2 \sin^4 t \cos^2 t} 

&=& \sqrt{(9a^2\sin^2 t \cos^2 t)(\cos^2 t + \sin^2 t)} 

&=& 3a\sin t \cos t 
\end{eqnarray*}

:::





:::solution
(ต่อ) 
จากนั้นหา $\vec{T}(t)$ จากสมการ \eqref{vecfun_unit_tangent} จะได้
\begin{eq*}
\vec{T}(t) &=& \frac{\vec{R}'(t)}{\|\vec{R}'(t)\|} 

&=& \frac{-3a \cos^2 t \sin t \mathbf{i} + 3a \sin^2 t \cos t \mathbf{j}}{3a\sin t \cos t} 

&=& -\cos t \mathbf{i} + \sin t \mathbf{j} 

\vec{T}'(t) &=& \leftlangle \dt(-\cos t), +\dt (\sin t) \rightangle 

&=& \leftlangle \sin t, +\cos t \rightangle 

\| \vec{T}'(t) \| &=& \sqrt{(\sin t)^2 + (\cos t)^2} 

&=& 1 
\end{eq*}

:::





:::solution
(ต่อ) สุดท้าย หาเวกเตอร์หน่วยปกติ $\vec{N}(t)$ จะได้
\begin{eq*}
\vec{N}(t) &=& \frac{\vec{T}'(t)}{\| \vec{T}'(t) \| } 

&=& \frac{\sin t \mathbf{i} + \cos t \mathbf{j}}{1} 

&=& \sin t \mathbf{i} + \cos t \mathbf{j}
\end{eq*}

:::





:::exercise

จงหาเวกเตอร์สัมผัสหน่วย $\vec{T}(t)$ และเวกเตอร์ปกติหน่วย $\vec{N}(t)$ ของฟังก์ชันค่าเวกเตอร์ $\vrt$ ต่อไปนี้


- $\vrt = \leftlangle t^2, +t \rightangle$

- $\vrt = \leftlangle 3\sin t, +3\cos t \rightangle$

- $\vrt = \vvv{2\cos t}{-2\sin t}{+t}$


:::
