## ความหมายทางเรขาคณิตของอนุพันธ์ฟังก์ชันค่าเวกเตอร์

เราสามารถพิสูจน์ได้ว่า $\dt \vrt = \dvrt$ เป็นเวกเตอร์ที่สัมผัสกับเส้นโค้ง $C$ ที่จุด $t$ ใด ๆ (ละบทพิสูจน์ไว้ในที่นี้) 



:::tikz TikZ diagram
\begin{tikzpicture}[scale = 3]
\draw[<->, thick] (-0.2,0) -- (1.2,0) node[right] {$x$};
\draw[<->, thick] (0,-0.2) -- (0,1.2) node[above] {$y$};
\draw (1,0) arc (0:90:1cm);
\draw[->, red, very thick] (0,0) -- (30:1) node[right, fill=white,fill opacity = 0.8] {$\vec{r}(t)$};
\draw[->, red, very thick] (0,0) -- (40:1) node[left, fill=white,fill opacity = 0.8] {$\vec{r}(t+\Delta t)$};
\draw[->, blue, very thick] (30:1) -- (40:1) node[above right, fill=white,fill opacity = 0.8] {$\vec{r}(t+\Delta t) - \vec{r}(t)$};
\draw[->, blue, very thick] (30:1) -- +(120:0.8) node[right, fill=white,fill opacity = 0.8] {$\frac{\vec{r}(t+\Delta t) - \vec{r}(t)}{\Delta t} = \dvrt$};
\end{tikzpicture}
:::


*เปรียบเทียบเวกเตอร์ $\vrt$ และ $\dvrt$*




ถ้าเรามองเส้นโค้งของกราฟของ $\vrt$ เป็นเส้นทางของอนุภาค แล้วอนุพันธ์ $\dvrt$ จะหมายถึงความเร็วของอนุภาค ณ ขณะใด ๆ



:::tikz TikZ diagram
\begin{tikzpicture}[domain=-5:5, scale = 1, samples = 100]
\draw[-] plot (\x, {sin (\x r)});
\foreach \x in {-4,...,4}
\draw[->, blue, very thick] (\x, {sin (\x r)}) -- +(1,{cos (\x r)});
\draw[blue] (-4, {sin (-4 r)}) ++ (1,{cos (-4 r)})  node[ right = 5pt] {$\dvrt$};
\end{tikzpicture}
:::


*เวกเตอร์ $\dvrt$ ที่แสดงควาเร็วของอนุภาค ณ จุดต่าง ๆ*






## นิยามเวกเตอร์สัมผัสหน่วย

ในการคำนวณทางฟิสิกส์นั้นเราจะสนใจทิศทางของเวกเตอร์สัมผัส ไม่สนใจขนาด ฉะนั้นเราจึงนิยามเวกเตอร์ที่มีทิศทางเดียวกันกับเวกเตอร์สัมผัส และมีขนาดหนึ่งหน่วยดังนี้



:::tikz TikZ diagram
\begin{tikzpicture}[scale = 3]
\draw[<->, thick] (-1.2,0) -- (1.2,0) node[right] {$x$};
\draw[<->, thick] (0,-0.2) -- (0,1.2) node[above] {$y$};
\draw (0.5,0) arc (0:180:0.5);
\foreach \t  in {0, 45, ..., 135}
{
\draw[->, thick, red] (0,0) -- (\t:0.5);
\draw[->, thick, blue] (\t:0.5) -- +({\t + 90}:1);
\draw[->, very thick, violet] (\t:0.5) -- +({\t + 90}:0.7);
}
\draw (0:0.5) node[below, fill=white,fill opacity = 0.8] {$\vec{r}(t)$};
\draw (0:0.5)++(90:1) node[left, fill=white,fill opacity = 0.8] {$\vec{r'}(t)$};
\draw (0:0.5)++(90:0.7) node[right, fill=white,fill opacity = 0.8] {$\vec{T}(t)$};
\end{tikzpicture}
:::


*เปรียบเทียบเวกเตอร์ $\vrt,\dvrt$ และเวกเตอร์สัมผัสหน่วย $\vec{T*(t)$}






## นิยามเวกเตอร์สัมผัสหน่วย


:::slide
เนื่องจากเราสามารถแปลงเวกเตอร์ใด ๆ ให้เป็นเวกเตอร์หน่วยได้ ด้วยการหารด้วยขนาดของตัวเอง เราสรุปเป็นนิยามได้ดังนี้
:::


:::definition เวกเตอร์หนึ่งหน่วยสัมผัสของเส้นโค้ง (Unit tangent vector)

ให้ $C$ เป็นเส้นโค้งของฟังก์ชันค่าเวกเตอร์ในปริภูมิ 3 มิติ $\vrt = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}$ โดยที่ $\vec{r}'(t)$ จะเป็น **เวกเตอร์แนวสัมผัสของเส้นโค้ง** $C$ ที่จุด $\dvrt$ และจะเรียก $\vec{T}(t)$ ว่าเป็น**เวกเตอร์หนึ่งหน่วยสัมผัสของเส้นโค้ง** $C$ ที่จุดเดียวกัน เขียนแทนด้วยสัญลักษณ์

\begin{equation} 
\vec{T}(t) = \frac{\vec{r}'(t)}{\|\vec{r}'(t)\|}, \|\vec{r}'(t)\| \neq 0
\end{equation}

:::







:::example

กำหนดให้ $\vrt = \vvv{t}{+t^2}{+\frac{2}{3}t^3}$ แล้วจงหา $\dvrt$ และเวกเตอร์สัมผัสหน่วย $\vec{T}(t)$

:::


:::solution

จากสมการ \eqref{vecfun_unit_tangent} จะได้
\begin{eq*}
\dvrt &=& \vvv{}{+2t}{+2t^2} 

\| \dvrt \| &=& \sqrt{1^2 + (2t)^2 + (2t^2)^2} 

&=& \sqrt{1+ 4t^2 + 4t^4} = \sqrt{(1 +2t^2)^2} = 1+2t^2 

\vec{T}(t) &=& \frac{\dvrt}{\| \dvrt \|} 

&=& \frac{\vvv{}{+2t}{+2t^2}}{1+2t^2} 

&=& \vvv{\frac{1}{1+2t^2}}{+\frac{2t}{1+2t^2}}{+\frac{2t^2}{1+2t^2}} 
\end{eq*}

:::
