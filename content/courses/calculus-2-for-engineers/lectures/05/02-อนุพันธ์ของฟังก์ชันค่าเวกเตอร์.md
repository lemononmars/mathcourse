## นิยามอนุพันธ์ของฟังก์ชันค่าเวกเตอร์


:::definition

**อนุพันธ์ของฟังก์ชันค่าเวกเตอร์** $\vec{r}(t)$ ที่ $t = t_0$ เขียนแทนด้วย $\dps \frac{d}{dt} \vec{r}(t) $ (เขียนย่อเป็น $\vec{r}\,'(t)$) เท่ากับ
\begin{equation}
\frac{d}{dt} \vec{r}(t) = \lim_{h \rightarrow 0} \frac{\vec{r}(t+h) - \vec{r}(t)}{h}
\end{equation}

:::

สังเกตว่า อนุพันธ์ของฟังก์ชันค่าเวกเตอร์ เป็นเวกเตอร์เช่นกัน โดยจะเป็นเวกเตอร์ที่**สัมผัส**กับเส้นโค้งที่จุด $t = t_0$ 





:::example

กำหนดให้ $\vec{r}(t) = \leftlangle 2t, +3 \rightangle$ แล้วจงหา $\frac{d}{dt} \vec{r}(t)$

:::


:::solution

\begin{eq*}
\frac{d}{dt} \vec{r}(t) &=& \lim_{h \rightarrow 0} \frac{\vec{r}(t+h) - \vec{r}(t)}{h} 

&=& \lim_{h \rightarrow 0} \frac{\left(\leftlangle (2t+2h), +3 \rightangle\right) - \left(\leftlangle 2t, +3 \rightangle\right)}{h} 

&=& \lim_{h \to 0} \frac{2h\mathbf{i}}{h} = 2\mathbf{i} 
\end{eq*}

:::





## อนุพันธ์ของฟังก์ชันค่าเวกเตอร์


\resizebox{!}{0.8\textheight}
{

:::definition

กำหนดให้ $\vec{r}(t) = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}$ โดยที่ $f,g,h$ เป็นฟังก์ชันที่มีอนุพันธ์ที่ $t$ จะได้ว่า $\vec{r}(t)$ มีอนุพันธ์ที่ $t$ และ
\begin{equation}
\frac{d}{dt} \vec{r}(t) = \vvv{\frac{d}{dt} f(t)}{+\frac{d}{dt} g(t)}{+\frac{d}{dt} h(t)}
\end{equation}
หรือเขียนได้ในอีกรูปแบบหนึ่งเป็น
\[\vec{r}\,'(t) = \vvv{f\,'(t)}{+g\,'(t)}{+h\,'(t)} \]
อนุพันธ์ของ $\vec{r}(t)$ ที่ $t=t_0$ มีค่าเท่ากับ
\[ \vec{r}\,'(t_0) = \vvv{f\,'(t_0)}{+g\,'(t_0)}{+h\,'(t_0)} \]

:::

}





:::example

จงหา


- $\frac{d}{dt} (\leftlangle t^4, +2t^5 \rightangle)$

- $\frac{d}{dt} (\vvv{t^3}{+e^t}{+\cos t}) $


:::


:::solution

\begin{eqnarray*}
\frac{d}{dt} \leftlangle t^4, +2t^5 \rightangle &=& \vv{\frac{d}{dt}(t^4)}{+\frac{d}{dt}(2t^5)} 

&=& \leftlangle 4t^3, +10t^4 \rightangle 

\frac{d}{dt} \vvv{t^3}{+e^t}{+\cos t} &=& \vvv{\frac{d}{dt}(t^3)}{+\frac{d}{dt}(e^t)}{+ \frac{d}{dt} (\cos t)} 

&=& \vvv{3t^2}{e^t}{-\sin t}
\end{eqnarray*}

:::





## อนุพันธ์อันดับสูง

เรานิยามอนุพันธ์อันดับสูงของฟังก์ชันค่าเวกเตอร์ได้ดังนี้

:::definition

กำหนดให้ $\vec{r}(t) = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}$ โดยที่ $f,g,h$ เป็นฟังก์ชันที่มีอนุพันธ์อันดับที่ $n$ ที่ $t$ (นั่นคือ $f\,^{(n)}, g^{(n)}, h^{(n)}$ หาค่าได้) 

จะได้ว่า $\vec{r}(t)$ มีอนุพันธ์อันดับที่ $n$ ที่ $t$ และ
\begin{equation}
\frac{d^n}{(dt)^n} \vec{r}(t) = \vvv{\frac{d^n}{(dt)^n} f(t)}{+\frac{d^n}{(dt)^n} g(t)}{+\frac{d^n}{(dt)^n} h(t)} 
\end{equation}
หรือเขียนได้ในอีกรูปแบบหนึ่งเป็น
\[\vec{r}^{(n)} (t) = \vvv{f\,^{(n)}(t)}{+g^{(n)}(t)}{+h^{(n)}(t)} \]

:::





:::example

กำหนดให้ $\vrt = \leftlangle t^2, -t^4 \rightangle$ จงหา $\frac{d^2}{dt^2} \vrt$

:::


:::solution

เราหาอนุพันธ์ทีละขั้นได้ดังนี้
\begin{eq*}
**\dvrt** &=& \frac{d}{dt} \vrt = \frac{d}{dt} (\leftlangle t^2, -t^4 \rightangle) = \leftlangle 2t, -4t^3 \rightangle 

\blue{\vec{r}\,''(t)} &=& \frac{d^2}{dt^2} \vec{r} = \frac{d}{dt} **\dvrt** = \leftlangle 2, - 12t \rightangle 
\end{eq*}
ฉะนั้น $\frac{d^2}{dt^2} \vrt= \leftlangle 2, - 12t \rightangle$

:::





:::example

กำหนดให้ $\vrt = \leftlangle t^3, +\sin t \rightangle$ จงหา $\frac{d^3}{dt^3} \vrt$

:::


:::solution

เราหาอนุพันธ์ทีละขั้นได้ดังนี้
\begin{eq*}
**\dvrt** &=& \frac{d}{dt} \vrt = \frac{d}{dt} (\leftlangle t^3, +\sin t \rightangle) = \leftlangle 3t^2, +\cos t \rightangle 

\blue{\vec{r}\,''(t)} &=& \frac{d^2}{dt^2} \vec{r} = \frac{d}{dt} **\dvrt** = \leftlangle 6t, - \sin t \rightangle 

\vec{r}\,'''(t) &=& \frac{d^3}{dt^3} \vec{r} = \frac{d}{dt} \blue{\vec{r}\,''(t)} = \leftlangle 6, - \cos t \rightangle 
\end{eq*}
ฉะนั้น $\frac{d^3}{dt^3} \vrt= \leftlangle 6, - \cos t \rightangle$

:::





:::exercise

จงหาอนุพันธ์ของฟังก์ชันค่าเวกเตอร์ต่อไปนี้


- $\dt \left( \vv{t^2}{+\frac{1}{t^2}} \right)$

- $\dt \left( \vvv{\frac{1}{t+1}}{+e^{3t}}{+\sin(2t)}\right)$


:::
