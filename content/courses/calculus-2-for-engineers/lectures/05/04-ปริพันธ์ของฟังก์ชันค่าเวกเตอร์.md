เรานิยามปริพันธ์ของฟังก์ชันค่าเวกเตอร์ ในทำนองเดียวกันกับฟังก์ชัน $y=f(x)$ 

## ปริพันธ์ของฟังก์ชันค่าเวกเตอร์


:::definition

กำหนดให้ $\vec{r}(t)$ และ $\vec{R}(t)$ เป็นฟังก์ชันค่าเวกเตอร์ ซึ่ง $\vec{R}\,'(t) = \vec{r}(t)$ **ปริพันธ์ไม่จำกัดเขตของ** $\vec{r}(t)$ โดยเทียบกับ $t$ เขียนแทนด้วย 
\begin{equation}
\int \vec{r}(t) \, dt = \vec{R}(t) + \vec{c}
\end{equation}
เมื่อ $\vec{c}$ เป็นเวกเตอร์ค่าคงตัวใด ๆ ในปริภูมิเดียวกันกับ $\vec{r}(t)$

:::




เช่นเดียวกับอนุพันธ์ เราสามารถหาปริพันธ์ของฟังก์ชันค่าเวกเตอร์แยกของส่วนประกอบแต่ละส่วนได้ 

## ปริพันธ์ของฟังก์ชันค่าเวกเตอร์


:::theorem

กำหนดให้ $\vec{r}(t) = \vvv{f(t)}{+g(t)}{+h(t)}$ เป็นฟังก์ชันค่าเวกเตอร์ โดยที่ $f(t), g(t)$ และ $h(t)$ หาปริพันธ์ได้ แล้ว
\begin{equation}
\int \vec{r}(t) dt = \vvv{\left(\int f(t) \, dt \right)}{+\left(\int g(t) \, dt \right)}{+\left(\int h(t)\, dt \right)}
\end{equation}

:::






:::example

จงหา


- $ \int (\leftlangle , +2t \rightangle) \, dt$

- $ \int (\leftlangle 2t, +3t^2 \rightangle) \, dt$


:::


:::solution

\begin{eq*}
\int (\leftlangle 2t, +3t^2 \rightangle) \, dt &=& \leftlangle \left(\int 2t\, dt\right), +\left(\int 3t^2\, dt\right) \rightangle 

&=& \leftlangle t^2, +t^3 \rightangle + \vec{c} 

\int (\leftlangle , +2t \rightangle) \, dt &=& \leftlangle \left( \int \, dt\right), +\left( \int 2t \, dt \right) \rightangle 

&=& \leftlangle t, +t^2 \rightangle + \vec{c}
\end{eq*}

:::






:::example

จงหา $\int \left(\vvv{\cos t}{+\frac{1}{t}}{+e^t}\right) \, dt$

:::


:::solution

\begin{eq*}
&&\int \left(\vvv{\cos t}{+\frac{1}{t}}{+e^t}\right) \, dt 

&=& \vvv{\left(\int \cos t \,dt\right)}{+\left(\int\frac{1}{t}\,dt\right)}{+\left(\int e^t\,dt\right)} 

&=& \vvv{\sin t}{+\ln t}{+e^t} + \vec{c}
\end{eq*}

:::





:::example

จงหา $ \int \left(\vvv{\frac{1}{t}}{+\cos t}{+e^{-t}}\right) \, dt$

:::


:::solution

\begin{eq*}
&&\int \left(\vvv{\frac{1}{t}}{+\cos t}{+e^{-t}}\right) \, dt 

&=& \vvv{\left(\int \frac{1}{t}\, dt\right)}{+\left(\int \cos t\, dt\right)}{+\left(\int e^{-t}\, dt\right)}, 

&=& \vvv{\ln t}{+\sin t}{-e^{-t}} + \vec{c}
\end{eq*}

:::





:::exercise

จงหาปริพันธ์ไม่จำกัดเขตของฟังก์ชันค่าเวกเตอร์ต่อไปนี้


- $\int (\leftlangle 2, +t^3 \rightangle) \, dt$

- $\int (\vvv{e^{2t}}{+\sin (3t)}{+\sqrt{t}}) \, dt$


:::





## ปริพันธ์จำกัดเขตของฟังก์ชันค่าเวกเตอร์


:::definition

กำหนดให้ $\vec{r}(t) = \vvv{f(t)}{+g(t)}{+h(t)}$ โดยที่ $f,g,h$ เป็นฟังก์ชันที่หาค่าปริพันธ์จำกัดเขตในช่วง $[a,b]$ ได้ จะได้ว่า 
\begin{equation}
\int_a^b \vec{r}(t) dt = \left(\int_a^b f(t) dt \right)\mathbf{i} + \left(\int_a^b g(t) dt \right) \mathbf{j} + \left(\int_a^b h(t)dt \right) \mathbf{k}
\end{equation}

:::







:::example

จงหา
\[ \int_0^\pi (\leftlangle \sin t, + t^2 \rightangle) \, dt \]

:::


:::solution

\begin{eq*}
\int_0^\pi (\leftlangle \sin t, + t^2 \rightangle) \, dt &=& \left( \int_0^\pi \sin t dt \right) \mathbf{i} + \left( \int_0^\pi t^2 dt \right) \mathbf{j} 

&=& \left( -\cos t \Big|_0^\pi\right) \mathbf{i} + \left( \frac{1}{+3}t^3 \Big|_0^\pi\right) \mathbf{j} 

&=& \vv{\left( (-\cos \pi) - (- \cos 0) \right)}{+ \left( \frac{1}{3} \pi^3 - \frac{1}{3} 0^3 \right)} 

&=& 2 \mathbf{i} + \frac{1}{3}\pi^3 \mathbf{j}
\end{eq*}

:::





:::exercise

จงหาปริพันธ์จำกัดเขตของฟังก์ชันค่าเวกเตอร์ต่อไปนี้


- $\int_0^{\pi} (\leftlangle \sin t, -\cos t \rightangle) \, dt$

- $\int_{-1}^1 (\vvv{1}{+t}{+t^2}) \, dt$


:::





## ความยาวส่วนโค้ง


:::theorem

กำหนดให้ $\vec{r}(t) = \vvv{f(t)}{+g(t)}{+h(t)}$ แล้วให้ $L$ คือความยาวส่วนโค้งระหว่าง $a \leq t \leq b$ แล้ว
\begin{equation}
L = \int_a^b \sqrt{\left(\frac{df}{dt}\right)^2 + \left(\frac{dg}{dt}\right)^2 + \left(\frac{dh}{dt}\right)^2} \, dt
\end{equation}
หรืออาจเขียนในรูป
\[L = \int_a^b \| \vec{r}\,'(t) \| dt \]

:::






:::example

กำหนดให้ $\vec{r}(t) = \leftlangle 2 \cos t, + 2 \sin t \rightangle$ จงหาความยาวส่วนโค้งระหว่าง $0 \leq t \leq \pi$

:::


:::solution

จากฟังก์ชันค่าเวกเตอร์ที่กำหนดให้ จะได้ 
\[f(t) = 2\cos t \qquad g(t) = 2\sin t\]
แล้วจะได้ว่า
\[\frac{df}{dt} = \frac{d}{dt} 2\cos t = -2\sin t \qquad \frac{dg}{dt} = \frac{d}{dt} 2\sin t = 2\cos t\]
ฉะนั้น
\begin{eqnarray*}
L &=& \int_0^\pi \sqrt{\left(\frac{df}{dt}\right)^2 + \left(\frac{dg}{dt}\right)^2} = \int_0^\pi \sqrt{(2\cos t)^2 + (2\sin t)^2} \, dt 

&=& \int_0^\pi 4 dt = (4t) \Big|_{0}{\pi} = 4\pi
\end{eqnarray*}

:::
