## นิยามลิมิตของฟังก์ชันค่าเวกเตอร์

เราสามารถหาลิมิตของฟังก์ชันค่าเวกเตอร์ได้ เช่นเดียวกันกับฟังก์ชันในรูป $y = f(x)$ โดยการหาลิมิตของฟังก์ชันหน้าเวกเตอร์ $\mathbf{i}, \mathbf{j}, \mathbf{k}$ แยกกัน

:::definition

ถ้า $\vec{r}(t) = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}$ เป็นฟังก์ชันค่าเวกเตอร์บนช่วง $[a,b]$ และ ลิมิตของ $\vec{r}(t)$ เมื่อ $t$ เข้าใกล้ $t_0$ ของ $\displaystyle \lim_{t \rightarrow t_0} f(t), \lim_{t \rightarrow t_0} g(t), \lim_{t \rightarrow t_0} h(t)$ หาค่าได้ จะได้ว่า

\begin{equation}
\lim_{t \rightarrow t_0} \vec{r}(t) = \left(\lim_{t \rightarrow t_0} f(t)\right)\mathbf{i} + \left(\lim_{t \rightarrow t_0} g(t)\right)\mathbf{j} + \left(\lim_{t \rightarrow t_0} h(t)\right)\mathbf{k}
\end{equation}

:::






:::example

กำหนดให้ $\vec{r}(t) = \leftlangle t^2, +e^t \rightangle$ จงหา


- $\lim_{t \rightarrow 0} \vec{r}(t)$

- $\lim_{t \rightarrow 1} \vec{r}(t)$


:::


:::solution

\begin{eqnarray*}
\lim_{t \rightarrow 0} \vec{r}(t) &=& \vv{\left( \lim_{t \to 0} t^2\right)}{+\left( \lim_{t \to 0} e^t\right)} 

&=& \vv{**0**^2 }{+e^{**0**}} 

&=& \leftlangle 0, +1 \rightangle = \mathbf{j} 

\lim_{t \rightarrow 1} \vec{r}(t) &=& \vv{\left( \lim_{t \to 1} t^2\right)}{+\left( \lim_{t \to 1} e^t\right)} 

&=& \vv{**1**^2 }{+e^{**1**}} 

&=& \leftlangle 1, +e \rightangle = \vv{1}\mathbf{e}
\end{eqnarray*}

:::






:::example

กำหนดให้ $\vec{r}(t) = \vv{t^3}{+ \frac{t^2-4}{t-2}}$ จงหา 


- $\limt{3} \vec{r}(t) $

- $\limt{2} \vec{r}(t) $


:::


:::solution

\begin{eqnarray*}
\lim_{t \rightarrow 3} \vec{r}(t) &=& \left(\limt{3} t^3\right) \mathbf{i} + \left(\limt{3} \frac{t^2-4}{t-2} \right) \mathbf{j} 

&=& \vv{**3**^3}{+\frac{**3**^2-4}{**3**-2}} = \leftlangle 27, +5 \rightangle 

\lim_{t \rightarrow 2} \vec{r}(t) &=& (\limt{2} (t^3)) \mathbf{i} + \left(\limt{2} \frac{t^2-4}{t-2} \right) \mathbf{j} 

&=& \vv{**2**^3}{+\left(\limt{2} **t+2**\right)} \mathnote{ $\frac{t^2-4}{t-2} = \frac{(t+2)(t-2)}{t-2} = t+2, t\neq 2$ } 

&=& 8 \mathbf{i} + 4 \mathbf{j}
\end{eqnarray*}

:::




เราใช้นิยามของลิมิตมานิยามความต่อเนื่องของฟังก์ชันค่าเวกเตอร์ โดยเงื่อนไขความต่อเนื่องของฟังก์ชันค่าเวกเตอร์เหมือนกับเงื่อนไขความต่อเนื่องของฟังก์ชันในรูป $y = f(x)$ ทุกประการ

## ความต่อเนื่องของฟังก์ชันค่าเวกเตอร์


:::definition

ฟังก์ชันค่าเวกเตอร์ $\vec{r}(t)$ ต่อเนื่องที่ $t = t_0$ ก็ต่อเมื่อเงื่อนไข 3 ข้อต่อไปนี้เป็นจริง


- หาค่า $\vec{r}(t_0)$ ได้

- หาค่า $\displaystyle \lim_{t \rightarrow t_0} \vec{r}(t)$ได้

- $\displaystyle \lim_{t \rightarrow t_0} \vec{r}(t) = \vec{r}(t_0)$


:::






:::example

กำหนดให้ $\vec{r}(t) = \vvv{t^2}{+ e^t}{+\sin 3t}$ จงพิสูจน์ว่า $\vec{r}(t)$ มีความต่อเนื่องที่ $t=\pi$

:::


:::solution
ตรวจสอบเงื่อนไขทั้งสามข้อ ดังนี้ 


- $\vec{r}(\pi)$ หาค่าได้ เนื่องจากฟังก์ชัน $t^2, e^t$ และ $\sin 3t$ มี $\pi$ อยู่ในโดเมน ฉะนั้น
\[ \vec{r}(\pi) = \pi^2 \mathbf{i} + e^\pi \mathbf{j} + \sin (3\pi) \mathbf{k} = \pi^2 \mathbf{i} + e^\pi \mathbf{j}\]


:::





:::solution
(ต่อ)
\setcounter{enumi}{1}

- $\dps \lim_{t \to \pi} \vec{r}(t)$ หาค่าได้ เนื่องจาก $\dps \lim_{t \to \pi} t^2 = \pi^2, \quad \lim_{t \to \pi} e^t = e^\pi, \quad \lim_{t \to \pi} \sin 3t = \sin 3\pi = 0$ 
ทำให้ได้ว่า 
\begin{eq*}
\lim_{t \to \pi} \vec{r}(t) &=& \left( \lim_{t \to \pi} t^2 \right) \mathbf{i} + \left( \lim_{t \to \pi} e^t \right) \mathbf{j} + \left( \lim_{t \to \pi} \sin 3t \right) \mathbf{ki} 

&=& \vvv{\pi^2}{+e^\pi\mathbf{j}}{3\pi}
\end{eq*}

- $\dps \lim_{t \to \pi} \vec{r}(t) = \vvv{\pi^2}{+e^\pi\mathbf{j}}{3\pi}$ ตามที่ได้แสดงไว้แล้วใน 1. และ 2.

ฉะนั้น $\vec{r}(t)$ มีความต่อเนื่องที่ $t = \pi$

:::





:::exercise

จงหาลิมิตของฟังก์ชันค่าเวกเตอร์ต่อไปนี้


- $\lim_{t \to 1} \vv{\left(\frac{t^2-1}{t-1}\right)}{+\left(\frac{t+3}{t+1}\right)}$

- $\lim_{t \to 2} \vvv{t^3}{+\left(\frac{1}{t+1}\right)}{+\left(\frac{t-2}{t^2-4}\right)}$


:::
