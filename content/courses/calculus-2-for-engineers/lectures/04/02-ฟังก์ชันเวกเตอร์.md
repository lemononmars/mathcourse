## การเขียนเวกเตอร์

โดยทั่วไป เราสามารถเขียนเวกเตอร์ได้ 3 รูปแบบหลัก ได้แก่

\[ \left\langle v_1, v_2 \right\rangle = \leftlangle v_1, +v_2 \rightangle = \begin{pmatrix} v_1 
v_2 \end{pmatrix} \]

แต่ในบทนี้ เราจะใช้เพียงรูปแบบ

:::note

\[ \leftlangle v_1, +v_2 \rightangle \]

:::

เนื่องจากพจน์ $\mathbf{i}$ และ $\mathbf{j}$ มีความสำคัญต่อการทำความเข้าใจการดำเนินการต่าง ๆ




## นิยามฟังก์ชันค่าเวกเตอร์ของตัวแปรเชิงเดี่ยว


:::definition

ฟังก์ชันค่าเวกเตอร์ของตัวแปรเชิงเดี่ยว คือ ฟังก์ชันที่มีโดเมนเป็นซับเซตของจำนวนจริง และมีเรนจ์เป็นเวกเตอร์

\[\vec{r}: \mathbb{R} \to \mathbb{V}\] 
ในปริภูมิสองมิติ
\[\vec{r}(t) = f(t) \mathbf{i} + g(t) \mathbf{j}\] 
ในปริภูมิสามมิติ
\[\vec{r}(t) = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}\]
โดยที่ $t$ เป็นตัวแปรอิสระ และ $\vrt$ เป็นตัวแปรตาม

:::






:::example

ตัวอย่างต่อไปนี้ เป็นฟังก์ชันค่าเวกเตอร์
\begin{eqnarray*}
\vrt &=& \leftlangle t, +t^2 \rightangle 

\vrt &=& \leftlangle \sin t, +\cos t \rightangle 

\vrt &=& \leftlangle , +2t \rightangle 

\vrt &=& \leftlangle 2, -3 \rightangle 

&& 
:::slide
\boxed{\text{เนื่องจากผลลัพธ์ไม่ขึ้นอยู่กับตัวแปร $t$ จึงนับว่าเป็นฟังก์ชันค่าคงตัว}}
:::


\vrt &=& t^4 \mathbf{j} 
:::slide
\mathnote{ในที่นี้ เรามองเป็น $\leftlangle 0, +t^4 \rightangle$}
:::


\end{eqnarray*}

:::






## การแทนค่าฟังก์ชันค่าเวกเตอร์

เราสามารถแทนค่าของฟังก์ชันค่าเวกเตอร์ได้ เช่นเดียวกันกับการแทนค่าฟังก์ชันทั่วไป

:::example

กำหนด $\vrt = \leftlangle 2t, +t^2 \rightangle$ จงหา


- $\vec{r}(2)$

- $\vec{r}(-1)$

- $\vec{r}(t^3)$


:::


:::solution



- $\vec{r}(**2**) = \vv{2(**2**)}{+(**2**)^2} = \leftlangle 4, +4 \rightangle$

- $\vec{r}(**-1**) = \vv{2(**-1**)}{+(**-1**)^2} = \leftlangle -2, + \rightangle$ \mathnote{$1\vec{j} = \vec{j}$}

- $\vec{r}(**t^3**) = \vv{2(**t^3**)}{+(**t^3**)^2} = \leftlangle 2t^3, +t^6 \rightangle$


:::





:::exercise

กำหนดให้ $\vec{r_1} =\vvv{t^2}{+\sin t}{+\cos t}$ และ $\vec{r_2} = \vvv{t}{-\sin t}{+\cos t}$ จงหา


- $\vec{r_1}(0)$

- $\vec{r_1}(2t)$

- $\vec{r_2}(\pi)$

- $\vec{r_2}(t^2)$


:::
