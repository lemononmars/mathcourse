## การวาดกราฟของฟังก์ชันค่าเวกเตอร์

เราสามารถเขียนกราฟของฟังก์ชันค่าเวกเตอร์เสมือนกราฟของเส้นโค้งได้ เนื่องจากเราสามารถแทนเวกเตอร์ $\leftlangle a, +b \rightangle$ ในปริภูมิ 2 มิติด้วยจุด $(a,b)$ บนระนาบได้ และแทนเวกเตอร์ $\vvv{a}{+b}{+c}$ ในปริภูมิ 3 มิติด้วยจุด $(a,b,c)$ บนปริภูมิสามมิติได้ 


ข้อแตกต่างของจุด $(a,b)$ และเวกเตอร์ $\leftlangle a, +b \rightangle$ คือการนำไปใช้คำนวณต่อ เช่น เราสามารถหาผลคูณจุดของเวกเตอร์สองตัวได้ แต่ไม่สามารถหาผลคูณจุดของจุดสองจุดได้





:::example

จงวาดกราฟของฟังก์ชันค่าเวกเตอร์ $\vrt = \leftlangle t^2, +2t \rightangle$

:::


:::solution

เราสามารถวาดกราฟของเส้นโค้งที่เกิดจาก $\vec{r}$ ได้เช่นเดียวกันกับสมการอิงตัวแปรเสริม
\[ x = t^2,\quad y = 2t\]
ซึ่งจะออกมาเป็นกราฟพาราโบลา เพื่อไม่ให้สับสนกับกราฟธรรมดา เราจะวาดเวกเตอร์หนึ่งลงบนกราฟเพื่อเป็นตัวอย่าง

:::






:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.5]
\draw[very thin,color=gray] (0,-5) grid (5,5);
\draw[<->, thick] (-1,0) -- (5.5,0) node[right] {$x$};
\draw[<->, thick] (0,-5.5) -- (0,5.5) node[above] {$y$};
\foreach \x/ \y/ \t in {4/-4/-2,1/-2/-1,0/0/0,1/2/1,4/4/2}
	\draw[->, blue, very thick] (0,0) -- (\x,\y) node[left=10pt, fill=white,fill opacity = 0.8] {$\vec{r}(\t)$};
\end{tikzpicture}
:::


*ค่าของ $\vrt = \leftlangle t^2, +2t \rightangle$ เมื่อ $t=-2,-1,0,1,2$*






:::tikz TikZ diagram
\begin{tikzpicture}[domain=-3:3, scale = 0.4]
\draw[very thin,color=gray] (0,-6) grid (10,6);
\draw[<->, thick] (-1,0) -- (10.2,0) node[right] {$x$};
\draw[<->, thick] (0,-6.2) -- (0,6.2) node[above] {$y$};
\draw[color=green, variable = \t, very thick] plot ({\t*\t},{\t*2});
\draw[->, blue, very thick] (0,0) -- (4,4) node[right, scale = 1.5, fill=white,fill opacity = 0.8] {$\vec{r}(t)$};
\end{tikzpicture}
:::


*กราฟของฟังก์ชัน $\vrt = \leftlangle t^2, +2t \rightangle$*






:::exercise

จงวาดเวกเตอร์ของฟังก์ชันต่อไปนี้ลงในกราฟ โดยใช้ค่า $t = -2, -1, 0, 1, 2$


- $\vec{r}(t) = \leftlangle t^2, + t \rightangle$

- $\vec{r}(t) = \leftlangle (2+t), - (t^2-1) \rightangle$
