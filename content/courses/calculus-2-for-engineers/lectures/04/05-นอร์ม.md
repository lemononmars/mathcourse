## นิยามนอร์มของฟังก์ชันค่าเวกเตอร์

เรานิยามนอร์มของฟังก์ชันค่าเวกเตอร์ ได้ในทำนองเดียวกันกับนอร์มของเวกเตอร์

:::definition

กำหนดให้ $\vrt = f(t) \mathbf{i} + g(t) \mathbf{j}$ แล้วนอร์มของฟังก์ชัน $\vrt$ คือ 
\begin{equation} 
\|\vrt\| = \sqrt{(f(t))^2 + (g(t))^2}
\end{equation}
กำหนดให้ $\vrt = f(t) \mathbf{i} + g(t) \mathbf{j} + h(t) \mathbf{k}$ แล้วนอร์มของฟังก์ชัน $\vrt$ คือ 
\begin{equation}
\|\vrt\| = \sqrt{(f(t))^2 + (g(t))^2 + (h(t))^2}
\end{equation}

:::






:::example

กำหนดให้ $\vrt = (t-1) \mathbf{i} + (t+1) \mathbf{j}$ จงหา $\| \vrt \|$

:::


:::solution

หานอร์มโดยใช้สมการ \eqref{eq:vector_function_norm_2d} ได้เป็น
\begin{eq*}
\| \vrt \| &=& \sqrt{(t-1)^2 + (t+1)^2} 

&=& \sqrt{(t^2-2t+1) + (t^2+2t+1)} 

&=& \sqrt{2t^2 + 2}
\end{eq*}

:::






:::example

กำหนดให้ $\vrt = \vvv{3 \sin t}{ -3 \cos t}{+ 4}$ จงหา $\| \vrt \|$

:::


:::solution

หานอร์มโดยใช้สมการ \eqref{eq:vector_function_norm_2d} ได้เป็น
\begin{eq*}
\| \vrt \| &=& \sqrt{(3\sin t)^2 + (-3\cos t)^2 + 4^2} 

&=& \sqrt{9\sin^2 t + 9\cos^2 t + 16} 

&=& \sqrt{9 + 16} = 5
\end{eq*}
สังเกตว่าผลลัพธ์เป็นค่าคงตัว แสดงว่านอร์มของฟังก์ชันนี้ไม่ขึ้นอยู่กับตัวแปร $t$

:::






:::example

กำหนดให้ $\vrt = \leftlangle , +t^2 \rightangle$ จงหา 


- $\| \vrt \|$

- $\| 3\vrt \|$

- $\| t^2 \vrt \|$


:::


:::solution

\begin{eq*}
\| \vrt \| &=& \sqrt{1^2 + (t^2)^2} = \sqrt{1 + t^4} 

\| 3\vrt\| &=& \| \leftlangle 3, +3t^2 \rightangle \| = \sqrt{3^2 + (3t^2)^2} 

&=& \sqrt{9 + 9t^4} = 3\sqrt{1+t^4}

\| t^2 \vrt \| &=& \| \leftlangle t^2, +t^4 \rightangle \| = \sqrt{(t^2)^2 + (t^4)^2} 

&=& \sqrt{t^4 + t^8} 

&=& \sqrt{t^4(1 + t^4)} 

&=& |t^2| \sqrt{1 + t^4} = t^2 \sqrt{1+t^4}
\end{eq*}

:::





## สมบัติของนอร์มฟังก์ชันค่าเวกเตอร์

จากตัวอย่างก่อนหน้านี้ ทำให้เราสามารถตั้งข้อสังเกต และสรุปเป็นสมบัติได้ดังต่อไปนี้

:::property

กำหนดให้ $\vec{r_1}(t)$ เป็นฟังก์ชันค่าเวกเตอร์ใด ๆ ให้ $f(t): \mathbb{R} \to \mathbb{R}$ เป็นฟังก์ชนค่าจริง และให้ $k$ เป็นค่าคงตัว จะได้ว่า


- $\| k \vrt \| = |k| \| \vrt \|$

- $\| f(t) \vrt \| = | f(t) | \| \vrt \|$

- $\| \vrt \|^2 = \vrt \cdot \vrt$


:::





:::exercise

จงหานอร์มของฟังก์ชันค่าเวกเตอร์ต่อไปนี้


- $\vec{r}(t) = \leftlangle , +t \rightangle$

- $\vec{r}(t) = \vvv{t}{+t^2}{-t^2}$

- $\vec{r}(t) = \vec{r_1}(t) + \vec{r_2}(t)$ เมื่อ $\vec{r_1}(t) = \leftlangle \sin t, -\cos t \rightangle$ และ $\vec{r_2}(t) = \leftlangle \cos t, +\sin t \rightangle$


:::
