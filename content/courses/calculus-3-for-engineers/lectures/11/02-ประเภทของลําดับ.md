## ลำดับเลขคณิต


:::definition

**ลำดับเลขคณิต** (Arithmetic sequence) คือลำดับที่อยู่ในรูป 
\[\seq{a_1 + (n-1)d} = a_1, a_1+d, a_1+2d, a_1+3d, \ldots\] 
เมื่อ $a_1$ และ $d$ เป็นจำนวนจริง โดยลำดับเลขคณิตมีสมบัติว่า ผลต่างของพจน์สองพจน์ที่อยู่ติดกันเป็นค่าคงตัว นั่นคือ $a_{k+1} - a_k = d$ โดยเรียกค่าคงตัว $d$ นั้นว่า **ผลต่างร่วม** 

:::





:::example

จากลำดับเลขคณิตต่อไปนี้ จงหา $a_1$ และ $d$


- $5,10,15,20, \ldots$ 
:::slide
มีผลต่างร่วม $d=5$
:::


- $10, 6, 2, -2, \ldots$ 
:::slide
มีผลต่างร่วม $d=-4$
:::


- $7,7,7,7, \ldots$ 
:::slide
มีผลต่างร่วม $d=0$
:::



:::


:::solution



- $5,10,15,20, \ldots$ มีค่า $a_1 = 5$ และ $d=5$

- $10, 6, 2, -2, \ldots$ มีค่า $a_1 = 10$ และ $d=-4$

- $7,7,7,7, \ldots$ มีค่า $a_1 = 7$ และ $d=0$


:::








## ลำดับเรขาคณิต


:::definition

**ลำดับเรขาคณิต** (Geometric sequence) คือลำดับที่อยู่ในรูป 
\[\seq{a_1r^{n-1}} = a_1, a_1r, a_1r^2, a_1r^3, \ldots\] 
เมื่อ $a_1$ และ $r$ เป็นจำนวนจริง โดยลำดับเรขาคณิตมีสมบัติว่า อัตราส่วนของพจน์สองพจน์ที่อยู่ติดกันเป็นค่าคงตัว นั่นคือ $\tfrac{a_{k+1}}{a_k} = r$ โดยเรียกค่าคงตัว $r$ นั้นว่า **อัตราส่วนร่วม** 

:::






:::example

จากลำดับเรขาคณิตต่อไปนี้ จงหา $a_1$ และ $r$


- $2,6,18,54, \ldots, 2(3^{n-1}), \ldots$ 
:::slide
มีอัตราส่วนร่วม $r = 3$
:::


- $12, 4, \frac{4}{3}, \frac{4}{9}, \ldots, \frac{12}{3^{n-1}}, \ldots$ 
:::slide
มีอัตราส่วนร่วม $r = \frac{1}{3}$
:::


- $8, -8, 8, -8, \ldots, 8(-1)^{n-1},\ldots$ 
:::slide
มีอัตราส่วนร่วม $r = -1$
:::



:::


:::solution



- $2,6,18,54, \ldots$ มีค่า $a_1 = 2$ และ $r=3$

- $12, 4, \frac{4}{3}, \frac{4}{9}, \ldots$ มีค่า $a_1 = 12$ และ $r=\frac{1}{3}$

- $8, -8, 8, -8, \ldots$ มีค่า $a_1 = 8$ และ $r=-1$


:::





## ลำดับเวียนซ้ำ


:::definition

**ลำดับเวียนซ้ำ** (Recurrence sequence) คือลำดับที่นิยามด้วยสมการที่ขึ้นอยู่กับพจน์ก่อนหน้า 

:::


เช่น ถ้าเรานิยามลำดับเวียนซ้ำ $a_1 = 1, \quad a_n = a_{n-1} + n$ แล้วเราอาจจะแปลงลำดับเวียนซ้ำนี้ให้เป็นลำดับธรรมดาได้ 
:::slide
เช่น
\begin{eq*}
a_2 &=& a_1 + 2 = 1+2 = 3 

a_3 &=& a_2 + 3 = 3+3 = 6 

a_4 &=& a_3 + 4 = 6 + 4 = 10 
\end{eq*}
ทำให้เราทราบว่าที่จริงแล้วลำดับดังกล่าวคือ $a_n = \tfrac{n(n+1)}{2}$

:::




หรือเช่น
\[ F_1 = 1, \quad F_2 = 1, \quad F_{n+2} = F_{n+1} + F_n\] 
เราสังเกตว่า

:::slide

\begin{eq*}
F_3 &=& F_2 + F_1 = 1+1 = 2

F_4 &=& F_3 + F_2 = 2 + 1 = 3

F_5 &=&F_4 + F_3 = 3+2 = 5

&\vdots 
\end{eq*}

:::

ซึ่งไม่สามารถเขียนในรูปปิดแบบง่ายได้ ลำดับนี้คือลำดับฟิโบนัชชี (Fibonacci sequence)
