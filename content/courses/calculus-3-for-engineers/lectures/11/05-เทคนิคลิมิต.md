เมื่อทราบว่าลำดับลู่เข้าแล้ว เราจึงจะทำการหาลิมิต ซึ่งต้องใช้เทคนิคหลากหลาย ในหนังสือเล่มนี้เราจะแนะนำเทคนิคที่ใช้งานได้บ่อย 


:::theorem ทฤษฎีบทของโลปิตาลสำหรับลำดับของจำนวน

กำหนดลำดับ $\{a_n\}$ และ $\{b_n\}$ ซึ่งมีฟังก์ชัน $f,g$ ที่หาอนุพันธ์อันดับหนึ่งได้สำหรับทุกค่า $x \geq 1$ และ $f(n) = a_n$ และ $g_n = b_n$ สำหรับทุกจำนวนเต็ม $n$ ถ้าเงื่อนไขข้อใดข้อหนึ่งต่อไปนี้เป็นจริง


- $\limseq a_n$ และ $\limseq b_n$ เท่ากับ $\infty$ หรือ $-\infty$ 

- $\limseq a_n = \limseq b_n = 0$

แล้วจะได้ว่า
\begin{equation} 
\limseq \frac{a_n}{b_n} = \lim_{x \to +\infty} \frac{f(n)}{g(n)} = \lim_{x \to +\infty} \frac{f\,'(x)}{g\,'(x)}
\end{equation}

:::






:::example

จงหาลิมิตของลำดับ $\{ ne^{-n} \}$

:::


:::solution

กำหนดให้ $f(x) = x$ และ $g(x) = e^{x}$ เนื่องจาก $f$ และ $g$ หาอนุพันธ์ได้และ $\lim_{x \to +\infty} x = \lim_{x \to +\infty} e^x = \infty$ ดังนั้นเราจึงสามารถใช้สมการ \eqref{eq:limit_sequence_lhospital} จะได้
\[ \limseq ne^{-n} = \lim_{x \to +\infty} \frac{x}{e^x} = \lim_{x \to +\infty} \frac{1}{e^x} = 0\] 
ฉะนั้นลำดับ $\{ ne^{-n} \}$ ลู่เข้าและมีลิมิตเท่ากับ $0$

:::






:::example

จงหาลิมิตของลำดับ $\left\{ \frac{(\ln n) + 1}{\ln (n+1)} \right\}$

:::


:::solution

เนื่องจาก $f(x) = (\ln x) + 1$ และ $g(x) = \ln (x+1)$ หาอนุพันธ์ได้เมื่อ $x \geq 1$ และ $\lim_{x \to +\infty} (\ln x) + 1 = \lim_{x \to +\infty} \ln (x+1) = \infty$ ฉะนั้นเราจึงสามารถใช้ทฤษฎีบท จะได้
\begin{eq*} 
\limseq \frac{(\ln n) + 1}{\ln (x+1)} = \lim_{x \to +\infty} \frac{(\ln x) + 1}{\ln (x+1)} &=& \lim_{x \to +\infty} \frac{(1/x) + 0}{1/(x+1)} 

&=& \lim_{x \to +\infty} \frac{x+1}{x} = 1 
\end{eq*}
ฉะนั้นลำดับ $\left\{ \frac{(\ln n) + 1}{\ln (n+1)} \right\}$ ลู่เข้าและมีลิมิตเท่ากับ $1$

:::





## พีชคณิตของลำดับ (1/2)

สำหรับลำดับที่เป็นผลบวก ผลลบ ผลคูณ หรือผลหารของลำดับอื่น ที่เราทราบว่าลู่เข้าหาลิมิตอยู่แล้ว เราสามารถหาลิมิตได้ทันทีดังสมบัติต่อไปนี้ 

:::property

กำหนดลำดับ $\{a_n\}$ และ $\{b_n\}$ ที่ลู่เข้าหาลิมิต $L$ และ $M$ ตามลำดับ และ $c$ เป็นค่าคงตัว 


- $\limseq c = c$ 

- $\limseq ca_n = cL$ 

- $\limseq a_n + b_n = L+M$ 

- $\limseq a_n - b_n = L-M$ 


:::





## พีชคณิตของลำดับ (2/2)


:::property

กำหนดลำดับ $\{a_n\}$ และ $\{b_n\}$ ที่ลู่เข้าหาลิมิต $L$ และ $M$ ตามลำดับ และ $c$ เป็นค่าคงตัว 


- $\limseq a_nb_n = LM$ 

- $\limseq \frac{a_n}{b_n} = \frac{L}{M}$ ถ้า $M \neq 0$ 

- $\limseq \ln a_n = \ln L$ ถ้า $L > 0$ และ $\limseq e^{a_n} = e^L$


:::






:::example

จงหาลิมิตของลำดับ $\left\{ \frac{2n^3+1}{(n+1)^3} \right\}$

:::


:::solution

ถ้าเราแทนค่าลิมิตของแต่ละพจน์จะได้ $\tfrac{\infty}{\infty}$ ซึ่งเป็นรูปแบบไม่กำหนด ฉะนั้นเราจึงต้องใช้เทคนิคในการจัดรูป ในที่นี้พจน์เศษและส่วนเป็นพหุนามทั้งคู่ เราจึงหารทุกพจน์ด้วย $x^3$ ซึ่งมีเลขชี้กำลังเป็นดีกรีของพหุนาม จึงได้ 
\begin{eq*}
\limseq \frac{2n^3+1}{(n+1)^3} &=& \limseq \frac{2n^3+1}{n^3+3n^2+3n+1} 

&=& \limseq \frac{2+\frac{1}{n^3}}{1+3\frac{1}{n}+3\frac{1}{n^3}+\frac{1}{n^3}} \mathnote{คูณเศษและส่วนด้วย $\tfrac{1}{n^3}$}

&=& \tfrac{2+0}{1+(3)(0) + (3)(0) + 0} = \tfrac{2}{1} = 2 
\end{eq*}
ฉะนั้นลำดับ $\left\{ \tfrac{2n^3+1}{(n+1)^3} \right\}$ ลู่เข้าและมีลิมิตเท่ากับ $2$

:::





## ทฤษฎีบทสควีซสำหรับลำดับ

สุดท้ายนี้ เราใช้ทฤษฎีบทของลิมิต มาเป็นเครื่องมือในการพิสูจน์การลู่เข้าของลำดับสลับ หรือลำดับที่มีพจน์ที่ไม่สามารถหาอนุพันธ์ได้ (เช่น $n!$) ดังต่อไปนี้

:::theorem ทฤษฎีบทสควีซสำหรับลำดับของจำนวน

\index{ทฤษฎีบทบีบคั้น} กำหนดลำดับ $\{a_n\}, \{b_n\}$ และ $\{c_n\}$ ที่มีสมบัติว่า $a_k \leq b_k \leq c_k$ สำหรับทุกจำนวนเต็มบวก $k$ ถ้า $\lim_{n \to +\infty} a_n = L$ และ $\lim_{n \to +\infty} c_n = L$ แล้วจะได้ว่า $\lim_{n \to +\infty} b_n = L$ เช่นกัน

:::







:::example

จงพิจารณาว่าลำดับ $\left\{ \frac{\sin n}{\ln n} \right\}$ ลู่เข้าหรือลู่ออก ถ้าลู่เข้าให้หาลิมิตด้วย

:::


:::solution

เราทราบว่า $-1 \leq \sin n \leq 1$ สำหรับทุกจำนวนเต็มบวก $n$ และเนื่องจาก $\ln n \geq 0$ เมื่อ $n \geq 1$ ดังนั้นจึงได้ว่า
\begin{eq*}
-\frac{1}{\ln n} \leq \frac{\sin n}{\ln n} \leq \frac{1}{\ln n}

-\frac{1}{\ln n} \leq a_n \leq \frac{1}{\ln n} 
\end{eq*}
แต่เนื่องจาก $\limseq -\frac{1}{\ln n}$ = 0 และ $\limseq \frac{1}{\ln n} = 0$ ฉะนั้นเราจึงสรุปโดยทฤษฎีบท ได้ว่า $\limseq a_n = 0$ เช่นกัน

:::
