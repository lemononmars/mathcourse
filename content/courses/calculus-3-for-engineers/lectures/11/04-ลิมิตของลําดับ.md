## นิยามของลิมิตของลำดับ

การสังเกตรูปแบบของลำดับในจำนวนจำกัด ไม่อาจสรุปถึงแนวโน้มของลำดับในระยะยาวได้ เราจึงต้องมีนิยามและวิธีการพิสูจน์มารองรับ

\resizebox{!}{0.7\textheight}
{

:::definition

เรากล่าวว่า ลำดับ $\{a_n\}$ **ลู่เข้าหาลิมิต $L$** ถ้าประพจน์ต่อไปนี้เป็นจริง: 

*
สำหรับจำนวนจริง $\epsilon > 0$ ใด ๆ จะมีจำนวนเต็มบวก $N$ ที่มีสมบัติว่า สำหรับทุกค่า $n \geq N$ นั้น $|a_n - L| < \epsilon$
*

ถ้าเป็นอย่างนั้นแล้ว เราจะเขียนว่า
\[ \lim_{n \to +\infty} a_n = L\]
ถ้าลำดับไม่ลู่เข้าหาลิมิตใด ๆ เลย จะกล่าวว่าลำดับนั้น **ลู่ออก**

:::

}





การจะใช้นิยามนี้เพื่อพิสูจน์ว่าลำดับลู่เข้านั้นใช้ความรู้เกินเนื้อหาในวิชานี้ จึงขอยกตัวอย่างสั้น ๆ ให้พอเห็นภาพ ส่วนการจะพิสูจน์การลู่เข้าของลิมิตนั้นเราจะใช้ทฤษฎีบทอื่น ๆ เข้ามาช่วย ซึ่งจะอธิบายเพิ่มเติมในหน่วยนี้

:::example

จงพิสูจน์ว่าลำดับ $\left\{ \frac{1}{n} \right\}$ ลู่เข้าหาลิมิต 0

:::


:::solution

เราจะพิสูจน์ว่าประพจน์ในนิยามเป็นจริง สำหรับจำนวนจริง $\epsilon > 0$ ใด ๆ เราสามารถเลือกจำนวนเต็มบวก $N = \left\lceil\frac{1}{\epsilon} \right\rceil$ ที่มีสมบัติว่า สำหรับทุกจำนวนเต็มบวก $n \geq N$ จะได้ 
\[ |a_n - L| = \left| \frac{1}{n} \right| < \left| \frac{1}{N} \right| < \epsilon \] 
ฉะนั้น $\lim_{n \to +\infty} \frac{1}{n} = 0$

:::






## ลิมิตของลำดับพื้นฐาน

สำหรับลิมิตของฟังก์ชันมูลฐานที่ใช้บ่อยมีดังนี้ 

:::theorem

$\limseq n^k = \begin{cases} + \infty &\text{ถ้า } k > 0 
0, &\text{ถ้า } k < 0 
1, & \text{ถ้า } k = 0\end{cases}$ 

:::






:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0.3:2, yscale = 0.8]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,0.0) -- (0, 3.5);
\draw[blue, ->] plot (\x, {\x^(-1)});
\node at (1,-1) {$k < 0$};
\node at (1,-2) {$\{a_n\} = n^{-1} = \frac{1}{n}$};
\begin{scope}[xshift = 3cm]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,0.0) -- (0, 3.5);
\draw[blue, ->] plot (\x, {\x^0});
\node at (1,-1) {$k = 0$};
\node at (1,-2) {$\{a_n\} = n^0 = 1$};
\end{scope}
\begin{scope}[xshift = 6cm]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,0.0) -- (0, 3.5);
\draw[blue, ->] plot (\x, {\x^2});
\node at (1,-1) {$k > 0$};
\node at (1,-2) {$\{a_n\} = n^2$};
\end{scope}
\end{tikzpicture}
:::


*กราฟแสดงลำดับ $\{n^k\*$ สำหรับค่า $k=-1,0$ และ $2$}






## ลิมิตของลำดับพื้นฐาน


:::theorem

$\limseq r^n = \begin{cases} \text{ลู่ออก}, &\text{ ถ้า } |r| > 1 \text{ หรือ } r = -1
0, &\text{ ถ้า } |r| < 1 
1, &\text{ ถ้า } r = 1\end{cases}$ 

:::






:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0.3:2, yscale = 0.8]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,0) -- (0, 4);
\draw[blue, ->] plot (\x, {2^(\x)});
\node at (1,-1) {$|r| > 1$};
\node at (1,-2) {$\{a_n\} = 2^n$};
\begin{scope}[xshift = 3cm]
\draw[->] (0,1) -- (2.5,1);
\draw[<->] (0,0) -- (0, 2);
\foreach \x in {1, 2, ..., 8}
{
	\filldraw[blue] ({\x/4}, {(-1)^(\x)+1}) circle[radius = 0.05cm, yscale = 1.25];
}
\node at (1,-1) {$r = -1$};
\node at (1,-2) {$\{a_n\} = (-1)^n$};
\end{scope}
\begin{scope}[xshift = 6cm]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,0) -- (0, 4);
\draw[blue, ->] plot (\x, 1);
\node at (1,-1) {$r = 1$};
\node at (1,-2) {$\{a_n\} = 1^n = 1$};
\end{scope}
\begin{scope}[xshift = 9cm]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0, 0) -- (0, 4);
\draw[blue, ->] plot (\x, {(0.5)^(\x)});
\node at (1,-1) {$|r| < 1$};
\node at (1,-2) {$\{a_n\} = \left(\frac{1}{2}\right)^n$};
\end{scope}
\end{tikzpicture}
:::


*กราฟแสดงลำดับ $\{r^n\*$ สำหรับค่า $r=2,-1, 1$ และ $\frac{1}{2}$}






## การหาลิมิต \left\{ \frac{1
{a_n} \right\}$ เมื่อทราบ $\left\{ a_n\right\}$}
ถ้าเราทราบลิมิตของ $\{a_n\}$ แล้วเราจะหาลิมิตของส่วนกลับ $\left\{ \frac{1}{a_n} \right\}$ ได้ดังนี้

:::theorem



- ถ้า $\limseq a_n$ ลู่เข้าและมีค่าเท่ากับ $L$ แล้ว $\limseq \frac{1}{a_n}$ จะลู่เข้าเช่นกัน และมีค่าเท่ากับ $\frac{1}{L}$

- ถ้า $\limseq a_n = +\infty$ หรือ $-\infty$ แล้ว $\limseq \frac{1}{a_n} = 0$

- ถ้า $\limseq a_n = 0$ แล้ว $\limseq \frac{1}{a_n}$ จะลู่ออก


:::





## ลิมิตของลำดับพื้นฐาน


:::theorem



- $\limseq \ln n = +\infty$

- $\limseq e^n = +\infty$

- $\limseq \sin n$ และ $\limseq \cos n$ ลู่ออก


:::






:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0:2, yscale = 0.8]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,-2) -- (0, 2);
\draw[blue, ->, domain = 0.2:2] plot (\x, {ln(\x)});
\node at (1,-3) {$\{a_n\} = \ln(n) $};
\begin{scope}[xshift = 3cm]
\draw[->] (0,0) -- (2.5,0);
\draw[->] (0,-2) -- (0, 2);
\draw[blue, ->, domain = 0.2:2] plot (\x, {exp(\x)/4});
\node at (1,-3) {$\{a_n\} = e^n $};
\end{scope}
\begin{scope}[xshift = 6cm]
\draw[->] (0,0) -- (2.5,0);
\draw[<->] (0,-2) -- (0, 2);
\draw[blue, ->] plot (\x, {cos(3*\x r)});
\node at (1,-3) {$\{a_n\} = \cos(n)$};
\end{scope}
\begin{scope}[xshift = 9cm]
\draw[->] (0,0) -- (2.5,0);
\draw[<->] (0,-2) -- (0, 2);
\draw[blue, ->] plot (\x, {sin(3*\x r)});
\node at (1,-3) {$\{a_n\} = \sin(n)$};
\end{scope}
\end{tikzpicture}
:::


*กราฟแสดงลำดับ $\{\ln n\*, \{e^n\}, \{\cos (n)\}$ และ $\{\sin (n)\}$}







:::example

จงหาลิมิตของลำดับต่อไปนี้


- $\{n^3\}$

- $\{\sqrt{n}\}$

- $\left\{ \frac{1}{n^2} \right\}$


:::


:::solution



- เนื่องจากลำดับอยู่ในรูป $n^k$ โดยที่ $k=3 > 0$ ฉะนั้น $\limseq n^3 = +\infty$ 

- เนื่องจากลำดับอยู่ในรูป $n^k$ โดยที่ $k=\frac{1}{2} > 0$ ฉะนั้น $\limseq \sqrt{n} = +\infty$ 

- เขียน $\frac{1}{n^2} = n^{-2}$ แล้วลำดับจะอยู่ในรูป $n^k$ โดยที่ $k=-2 < 0$ ฉะนั้น $\limseq n^{-2} = 0$


:::






:::example

จงหาลิมิตของลำดับต่อไปนี้


- $\{3^n\}$

- $\left\{ \left(\frac{3}{4}\right)^n \right\}$

- $\left\{ \left(-\frac{3}{2}\right)^n \right\}$


:::


:::solution



- เนื่องจากลำดับอยู่ในรูป $r^n$ โดยที่ $r=3 > 0$ ฉะนั้น $\limseq r^n$ ลู่ออก

- เนื่องจากลำดับอยู่ในรูป $r^n$ โดยที่ $r=\frac{3}{4}$ อยู่ระหว่าง 1 และ $-1$ ฉะนั้น $\limseq \left(\frac{3}{4}\right)^n = 0$

- เนื่องจากลำดับอยู่ในรูป $r^n$ โดยที่ $r=-\frac{3}{2} < -1$ ฉะนั้น $\limseq \left(-\frac{3}{2}\right)^n$ ลู่ออก


:::
