## ค่าคลาดเคลื่อนของหลักเกณฑ์ซิมป์สัน


:::theorem

กำหนดฟังก์ชันต่อเนื่อง $f(x)$ ที่หาอนุพันธ์อันดับที่สองบนช่วง $[a,b]$ ได้ กำหนดให้ $x_0, x_1, \ldots, x_{2n}$ เป็นจุดแบ่งบนช่วง $[a,b]$ ที่มีระยะห่างของจุดแต่ละคู่เท่ากับ $h$ กำหนดให้ $S_{2n}$ เป็นค่าประมาณของ $S = \int_a^b f(x) \, dx$ โดยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู กำหนดให้ $M_4$ เป็นค่ามากสุดของ $|f\,^{(4)}(x)|$ บนช่วง $[a,b]$ และนิยาม $\varepsilon$ เป็นค่าขอบเขตความคลาดเคลื่อนระหว่างค่าจริง $S$ และค่าประมาณ $S_{2n}$ จะได้ว่า 
\begin{equation} 
\varepsilon = \frac{(b-a)^5}{180(2n)^4} M_4
\end{equation}

:::





:::slide

ในทำนองเดียวกัน ถ้ากำหนดค่าขอบเขตความคลาดเคลื่อนที่รับได้ไว้ก่อนแล้ว เราสามารถหาจำนวนช่วงย่อยที่ต้องการได้จากอสมการนี้

:::

\begin{cor}{}{}
กำหนดฟังก์ชัน $f(x)$ และตัวแปรอื่นตามทฤษฎีบท ถ้าเราต้องการให้ค่าคลาดเคลื่อนสัมบูรณ์ $|E_S| < \varepsilon$ สำหรับจำนวนจริงบวก $\varepsilon$ ใด ๆ แล้วเราต้องแบ่งออกเป็นอย่างน้อย $2n$ ช่วงย่อย เมื่อ $n$ คือค่าที่ทำให้
\begin{equation} 
(2n)^4 = \frac{(b-a)^5}{2880\varepsilon}M_4 
\end{equation}
\end{cor}




:::remark หมายเหตุ

ถ้า $f(x)$ เป็นฟังก์ชันพหุนามที่มีดีกรีไม่เกิน $3$ (นั่นคือ $f(x) = a_3x^3 + a_2x^2+a_1x+a_0$) แล้ว 
\[f\,^{(4)}(x) = 0\]
ฉะนั้นจากอสมการ ทำให้ $\varepsilon = 0$ แสดงว่า $ \int_a^b f(x)\, dx=S_{2n}$ นั่นคือค่าประมาณที่คำนวณมาได้จะมีค่าเท่ากับค่าจริงพอดี

:::






:::example

ถ้าเราต้องการประมาณค่าของ $\int_0^1 \frac{1}{1+x} \, dx$ ด้วยหลักเกณฑ์ซิมป์สัน


- จงหาค่าขอบเขตความคลาดเคลื่อน เมื่อแบ่งเป็น 4 ช่วงย่อย

- ถ้าต้องการให้ค่าคลาดเคลื่อนสัมบูรณ์ไม่เกิน 0.0005 จะต้องแบ่งออกเป็นอย่างน้อยกี่ช่วงย่อย


:::


:::solution

ก่อนอื่น ให้หาค่า $M_4$ ก่อน ซึ่งจากการหาอนุพันธ์ของ $f(x) = \tfrac{1}{1+x}$ จะได้
\begin{eq*}
f\,'(x) = -\frac{1}{(1+x)^2} &,& f\,''(x) = \frac{2}{(1+x)^3} 

f\,'''(x) = -\frac{6}{(1+x)^4} &,& f^{(4)}(x) = \frac{24}{(1+x)^5}
\end{eq*}

:::





:::solution
(ต่อ)
เราหาจุดวิกฤตของ $f^{(4)}(x)$ ได้จากการแก้สมการ $f^{(5)}(x) = -\tfrac{120}{(1+x)^6}$ และหาค่า $x$ ที่ทำให้ $f^{(5)}(x) = 0$ หรือหาค่าไม่ได้ ซึ่งได้ $x=0$ ฉะนั้นจุดวิกฤตทั้งหมดคือ $x=0$ และจุดขอบ $x = 1$ ซึ่งเมื่อแทนค่าจะได้
\[ f^{(4)}(0) = 24, \quad f^{(4)}(1) = \frac{24}{32} = 0.75\]
ฉะนั้น $M_4 = 24$

เมื่อเราแทนค่า $a,b,n$ และ $M_4$ ลงไปในสมการจะได้
\[ \varepsilon = \frac{(b-a)^5}{180(2n)^4} M_4 = \frac{(1-0)^5}{(180)(4^2)} (24) = 0.008\dot{3} \]

:::





:::solution
(ต่อ)
ฉะนั้น ค่าขอบเขตความคลาดเคลื่อนจากการการประมาณค่าด้วยหลักเกณฑ์ซิมป์สัน
\[ S_4 - 0.008\dot{3} \leq S \leq S_4 + 0.008\dot{3} \]

จากอสมการจะได้
\[(2n)^4 = \frac{(b-a)^5}{180\varepsilon}M_4 = \frac{(1-0)^5}{(180)(0.00005)} (24) = 2666.\dot{6} \]
ฉะนั้น $2n = \sqrt[4]{2666.\dot{6}} \approx 7.18$ เนื่องจาก $2n$ ต้องเป็นจำนวนเต็มคู่ ดังนั้นเราต้องแบ่งออกเป็นช่วงย่อยอย่างน้อย 8 ช่วง

:::
