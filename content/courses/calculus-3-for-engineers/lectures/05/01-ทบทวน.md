## สูตรการการประมาณค่าด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู


:::note การประมาณค่าด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู

กำหนดฟังก์ชันต่อเนื่อง $f(x)$ และช่วง $[a,b]$ โดยที่ $f(x) \geq 0$ สำหรับทุกค่า $a,b$ กำหนดจำนวนเต็ม $n$ เป็นจำนวนของช่วงย่อยและ $h_n = \frac{b-a}{n}$ แล้ว
\begin{eq}
\int_a^b f(x)\, dx &\approx& \frac{h_n}{2} \Big( f(x_0) + 2f(x_1) + 2f(x_2) + \ldots + 2f(x_{n-1}) + f(x_n) \Big) 

&\approx& \frac{h_n}{2} \left(f(x_0) + f(x_n) + 2\sum_{k = 1}^{n-1} f(x_k) \right) 
\end{eq}

:::

## สูตรการการประมาณค่าด้วยหลักเกณฑ์ซิมป์สัน


:::note การประมาณค่าด้วยหลักเกณฑ์ของซิมป์สัน

กำหนดฟังก์ชันต่อเนื่อง $f(x)$ และช่วง $[a,b]$ โดยที่ $f(x) \geq 0$ สำหรับทุกค่า $a,b$ กำหนดจำนวนเต็ม $2n$ เป็นจำนวนของช่วงย่อยและ $h_{2n} = \frac{b-a}{2n}$ แล้ว
\begin{eq}
\int_a^b f(x)\, dx &\approx& \frac{h_{2n}}{3} \Big( f(x_0) + 4f(x_1) + 2f(x_2) \nonumber 

&\qquad& + \ldots + 2f(x_{2n-2}) + 4f(x_{2n-1}) + f(x_{2n})\Big) 

&\approx& \frac{h_{2n}}{3} \left( f(x_0) + f(x_{2n}) + 4\sum_{k=0}^{n-1} f(x_{2n+1}) + 2\sum_{k=1}^{n-1} f(x_{2k}) \right)
\end{eq}

:::
