## ที่มาของการหาคลาดเคลื่อน


:::slide



- เมื่อเราได้ค่าประมาณมาแล้ว เราจำเป็นจะต้องตรวจสอบว่าค่าที่หามาได้นั้นห่างจากค่าจริงเท่าใด เพื่อที่จะได้เปรียบเทียบว่าหลักเกณฑ์การประมาณค่าแบบใดมีประสิทธิภาพมากกว่ากัน

- คำถามคือในเมื่อเราหาค่าจริงจากปริพันธ์ไม่ได้แล้วเราจะตรวจสอบได้อย่างไร? เช่น ถ้าหลักเกณฑ์แรกให้ค่า $3.55$ และหลักเกณฑ์ที่สองให้ค่า $3.43$ แล้วเราจะทราบได้อย่างไรว่าค่าใดใกล้ค่าจริงมากกว่ากัน

- ข่าวดีก็คือ เราไม่จำเป็นต้องใช้ปริพันธ์ (ซึ่งเราหาไม่ได้ตั้งแต่ในตอนแรก) แต่เราสามารถใช้อนุพันธ์มากำหนดขอบเขตของค่าคาดเคลื่อนได้


:::





:::definition

กำหนดให้ $X$ เป็นค่าจริง และ $X_a$ เป็นค่าประมาณของ $X$ 



- **ค่าคลาดเคลื่อน** (error): $E = X - X_a$

- **ค่าคลาดเคลื่อนสัมบูรณ์** (absolute error): $|E| = |X - X_a|$

- **ค่าขอบเขตความคลาดเคลื่อน** (error bound): $\varepsilon$ โดยที่ $|E| \leq \varepsilon$


:::





:::theorem

กำหนดฟังก์ชันต่อเนื่อง $f(x)$ ที่หาอนุพันธ์อันดับที่สองบนช่วง $[a,b]$ ได้ กำหนดให้ $x_0, x_1, \ldots, x_n$ เป็นจุดแบ่งบนช่วง $[a,b]$ ที่มีระยะห่างเท่ากัน

กำหนดให้ $T_n$ เป็นค่าประมาณของ $T = \int_a^b f(x) \, dx$ โดยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู กำหนดให้ $M_2$ เป็นค่ามากสุดของ $|f\,''(x)|$ บนช่วง $[a,b]$ และนิยาม $\varepsilon$ เป็นค่าขอบเขตความคลาดเคลื่อนระหว่างค่าจริง $T$ และค่าประมาณ $T_n$ จะได้ว่า 
\begin{equation} 
\varepsilon = \frac{(b-a)^3}{12n^2} M_2
\end{equation}

:::






:::tikz TikZ diagram
\begin{tikzpicture}[xscale = 4]
\draw[<->] (0,0) -- (2,0);
\draw (1,0) --+ (0,-0.1) node[below] {$T_n$};
\foreach \x in {0.5, 1}

	\draw[<->, blue] (\x, 0.5) --+ (0.5,0) node[pos = 0.5, above] {$\varepsilon$};
}
\draw[|-|, teal, very thick] (0.5, 0) -- (1.5, 0);
\draw[teal] (1.3, 0) --+ (0, -0.1) node[below] {$T$};
\draw[|-|, red] (1, -1) --+ (0.3, 0) node[pos = 0.5, below] {$|E|$};
\end{tikzpicture}
:::


*ความสัมพันธ์ระหว่างค่าประมาณ $T_n$, ค่าคลาดเคลื่อน $E$, ค่าขอบเขตความคลาดเคลื่อน $\varepsilon$, และค่าจริง $T$*






:::remark ข้อสังเกต (1/2)



- ถ้าค่า $n$ ยิ่งมาก พจน์ $\tfrac{(b-a)^3}{12n^2}M_2$ ก็จะยิ่งน้อยลง 

- ฉะนั้นถ้าเราต้องการให้ค่าขอบเขตความคลาดเคลื่อน $\varepsilon$ น้อย เราจำเป็นจะต้องเลือกค่า $n$ ที่มาก

- ค่า $M_2$ หาได้จากการคำนวณค่าสูงสุดสัมบูรณ์และต่ำสุดสัมบูรณ์ของ $f\,''(x)$ ในช่วง $[a,b]$ ซึ่งเราได้ทำการศึกษาไว้แล้วในวิชาแคลคูลัส 2 สำหรับวิศวกร


:::






:::remark ข้อสังเกต (2/2)



- ถ้าหาค่า $M_2$ ได้ยาก เราสามารถใช้อสมการเพื่อหาค่า $M$ ที่ค่ามากกว่า (นั่นคือ $M_2 < M$) ที่สมบัติว่า $M \geq |f\,''(x)|$ สำหรับทุกค่า $x$ บนช่วง $[a,b]$ ได้ และจากสมบัติของอสมการ
\[ \varepsilon = \frac{(b-a)^3}{12n^2} M_2 \leq \frac{(b-a)^3}{12n^2} M\]
ทำให้เราสามารถหาค่าขอบเขตความคลาดเคลื่อน $\varepsilon$ โดยใช้ $M$ แทน $M_2$ ได้


:::






:::example

จงหาค่าขอบเขตความคลาดเคลื่อนของการประมาณค่า $\int_0^2 x^2 \, dx$ ด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู เมื่อแบ่งเป็น $4$ ช่วงย่อย 

:::


:::solution

โจทย์กำหนดช่วง $a=0, b=2$ และ $n=4$ มาให้แล้ว เหลือค่า $M_2$ ที่เราต้องหาเพิ่มเติม โดยหาอนุพันธ์ดังนี้
\[ f\,'(x) = 2x, \qquad f\,''(x) = 2\]
เนื่องจาก $f\,''(x)$ เป็นฟังก์ชันคงตัว ฉะนั้น $M_2=2$ เราจึงได้จะได้ค่าขอบเขตความคลาดเคลื่อนเท่ากับ
\[\varepsilon = \frac{(b-a)^3}{12n^2} M_2 = \frac{(2-0)^3}{(12)(4^2)} (2) = 0.08\dot{3} \]

:::





## หมายเหตุ

เราสามารถคำนวณได้ว่า
\[ \int_0^2 x^2 \, dx = T_n = 2.75\] 
ฉะนั้นเราสามารถสรุปได้ว่าค่าจริงอยู่ในช่วง
\begin{eq*}
2.75 - 0.08\dot{3} &\leq& T \leq 2.75 + 0.08\dot{3} 

2.\dot{6} &\leq& T \leq 2.8\dot{3}
\end{eq*}
ซึ่งค่าจริง $ T =2.8\dot{3}$ อยู่ในช่วงดังกล่าวจริง

\begin{tikzpicture}[xscale = 5, yscale = 1.5]

}

\draw[<-, teal] (1.5,0) --+ (0, -0.2) node[below] {$T = 2.8\dot{3}$};
\end{tikzpicture}
:::


*ความสัมพันธ์ระหว่างค่าประมาณ ค่าขอบเขตความคลาดเคลื่อน และค่าจริง*







:::example

จงหาค่าขอบเขตความคลาดเคลื่อนของการประมาณค่า $\int_1^2 \frac{1}{x} \, dx$ ด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู เมื่อแบ่งเป็น $5$ ช่วงย่อย 

:::


:::solution

โจทย์กำหนดช่วง $[a,b] = [1,2]$ และกำหนด $n=5$ มาให้แล้ว 
\[ f\,'(x) = -\tfrac{1}{x^2}, \qquad f\,''(x) = \tfrac{2}{x^3}\]
เราสามารถหาค่าสูงสุดสัมบูรณ์ของ $f\,''(x) = \tfrac{2}{x^3}$ ได้ด้วยการหาจุดวิกฤต $f\,'''(x) = -\tfrac{6}{x^4}$ ซึ่งมีค่าเท่ากับ 0 หรือหาค่าไม่ได้เมื่อ $x=0$ แต่ $x=0$ ไม่อยู่ในช่วง $[1,2]$ แสดงว่าค่าสุดขีดจะต้องอยู่ที่ขอบ นั่นคือ $x=1$ หรือ $x=2$ ซึ่ง $f\,''(1) = 2$ และ $f\,''(2) = \tfrac{1}{4}$ ฉะนั้นค่าที่มากที่สุดในช่วง $[1,2]$ คือ $M_2 = 2$ จะได้ขอบเขตค่าคาดเคลื่อนเท่ากับ
\[ \varepsilon \leq \tfrac{(b-a)^3}{12n^2} M_2 = \tfrac{(2-1)^3}{(12)(5^2)} (2) = 0.00\dot{6} \]

:::

\[\int_1^2 \frac{1}{x} \, dx = T_n = 0.6956\]

0.6810 &\leq& T \leq 0.7022
\end{eq*}

## การหาจำนวนช่วงย่อยที่จำเป็น เมื่อกำหนดค่าคลาดเคลื่อน


:::slide



- ทฤษฎีบทให้ค่าคลาดเคลื่อนเมื่อกำหนดจำนวนช่วงย่อยมาให้ 

- ในทางกลับกันถ้าเรากำหนดค่าคลาดเคลื่อนที่รับได้ไว้ตั้งแต่แรก เช่น เราต้องการให้ค่าคลาดเคลื่อนน้อยกว่า 0.0001 เราสามารถใช้อสมการ 
ในการหาว่าเราจำเป็นจะแบ่งช่วงย่อยออกเป็นจำนวนอย่างน้อยกี่ช่วง เพื่อให้ค่าคลาดเคลื่อนไม่เกินค่าที่เราตั้งไว้ ดังนี้


:::

\begin{cor}{}{}
กำหนดฟังก์ชัน $f(x)$ และตัวแปรอื่นตามทฤษฎีบท ถ้าเราต้องการให้ค่าคลาดเคลื่อนสัมบูรณ์ $|E_T| < \varepsilon$ สำหรับจำนวนจริงบวก $\varepsilon$ ใด ๆ แล้วเราต้องแบ่งออกเป็นอย่างน้อย $n$ ช่วงย่อย เมื่อ $n$ คือค่าที่ทำให้
\begin{equation} 
n^2 = \frac{(b-a)^3}{12\varepsilon}M_2 
\end{equation}
\end{cor}





:::example

ถ้าเราต้องการประมาณค่าของปริพันธ์ $\int_{-2}^2 x^2 \, dx$ ให้ค่าคลาดเคลื่อนสัมบูรณ์น้อยกว่าหรือเท่ากับ $0.01$ จงหาว่าเราต้องแบ่งเป็นช่วงย่อยอย่างน้อยกี่ช่วง

:::


:::solution

กำหนดให้ค่าขอบเขตความคลาดเคลื่อนเป็น $\varepsilon = 0.01$ จากสมการ \eqref{eq:trapezoid_error} 
\[ \varepsilon = \tfrac{(b-a)^3}{12n^2} M_2 = 0.01\]
เราสามารถหา $M_2$ ได้ด้วยการพิจารณา $f\,''(x) = 2$ ซึ่งเป็นค่าคงตัว ฉะนั้น $M_2$ = 2 ซึ่งเมื่อจัดรูปอสมการและแทนค่า $a,b$ และ $M_2$ ลงไปจะได้
\[ n^2 = \frac{(b-a)^3}{12 \varepsilon} M_2 = \frac{(2-(-2))^3}{(12)(0.01)} 2 = 1066.\dot{6}\]
นั่นคือ $n = \sqrt{1066.\dot{6}} \approx 32.64$ เนื่องจาก $n$ ต้องเป็นจำนวนเต็ม เราจึงต้องแบ่งเป็นช่วงย่อยอย่างน้อย 33 ช่วง

:::







:::example

ถ้าเราต้องการประมาณค่าของปริพันธ์ $\int_0^1 \sin (x^2) \, dx$ ให้ค่าคลาดเคลื่อนสัมบูรณ์น้อยกว่าหรือเท่ากับ $0.0001$ จงหาว่าเราต้องแบ่งเป็นช่วงย่อยอย่างน้อยกี่ช่วง

:::


:::solution

กำหนดให้ค่าขอบเขตความคลาดเคลื่อนเป็น $\varepsilon = 0.0001$ จากสมการ \eqref{eq:trapezoid_error} 
\[ \varepsilon = \frac{(b-a)^3}{12n^2} M_2 < 0.0001\]
เราสามารถหา $M_2$ ได้ด้วยการพิจารณา $f\,''(x)$ ซึ่งจากกฎลูกโซ่และกฎผลคูณของปริพันธ์จะได้
\begin{eq*}
f\,'(x) &=& \cos (x^2) \dx x^2 = 2x\cos(x^2) 

f\,''(x) &=& (2x) \dx \cos (x^2) + \cos(x^2) (2x) 

&=& -4x\sin(x^2) + 2\cos(x^2)
\end{eq*}

:::





:::solution
(ต่อ)
เราพบว่าเราหาจุดวิกฤตจากการแก้สมการ $f^{(3)}(x)= 0$ เพื่อหาค่า $M_2$ ได้อย่างยากลำบาก จึงต้องใช้อสมการเพื่อหาค่า $M > M_2$ แทน 

เนื่องจากเราทราบว่า $x$ อยู่ในช่วง $[0,1]$ และ $|\sin(x^2)| \leq 1$ และ $|\cos(x^2)| \leq 1$ สำหรับทุกค่า $x$ ฉะนั้นจากอสมการสามเหลี่ยมจะได้
\begin{eq*}
|f\,''(x)| &\leq& |-4x\sin(x^2) + 2\cos(x^2) | 

&\leq& |-4x\sin(x^2)| + |2\cos(x^2)| 

&\leq& (4)(1)(1) + (2)(1) = 6
\end{eq*}
ฉะนั้น $M_2 = 6$ เมื่อจัดรูปอสมการและแทนค่า $a,b$ และ $M_2$ ลงไปจะได้
\[ n^2 = \frac{(b-a)^3}{12 \varepsilon} M_2 = \frac{(1-0)^3}{(12)(0.0001)} 6 = 5000\]
นั่นคือ $n = \sqrt{5000} \approx 70.71$ เนื่องจาก $n$ ต้องเป็นจำนวนเต็ม แสดงว่าเราต้องแบ่งเป็นช่วงย่อยอย่างน้อย 71 ช่วง จึงจะรับประกันได้ว่าค่าคลาดเคลื่อนจะน้อยกว่าหรือเท่ากับ $0.0001$

:::
