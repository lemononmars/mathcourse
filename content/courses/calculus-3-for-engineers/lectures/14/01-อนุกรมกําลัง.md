## ที่มา

พิจารณาอนุกรมเรขาคณิต
\[1 + r + r^2 + r^3 + \ldots = \frac{1}{1-r}\] 
เราทราบว่าอนุกรมนี้ลู่เข้าเมื่อ $|r| < 1$ นั่นคือเราสามารถแปลงเป็นฟังก์ชันต่อไปนี้ได้ 
\[1 + x + x^2 + x^3 + \ldots = \frac{1}{1-x}\]


:::slide

โดยกำหนดโดเมนเป็น $-1 < x < 1$ สังเกตว่าฝั่งขวาคือฟังก์ชันเศษส่วนธรรมดา ส่วนฝั่งซ้ายมีหน้าตาคล้ายพหุนาม 


คำถามคือ ถ้ากำหนดฟังก์ชันใด ๆ มา (เช่น $f(x) = \sin x$ หรือ $f(x) = e^{-x}$) แล้วเราจะสามารถเขียนเป็นพหุนามด้านซ้ายได้เสมอไปหรือไม่ และถ้าเขียนได้แล้วจะหาค่าได้สำหรับทุกจำนวนจริง $x$ หรือสำหรับค่า $x$ ในบางช่วง

:::





## อนุกรมกำลัง


:::definition

**อนุกรมกำลังในกำลังของ $x$** คืออนุกรมที่เขียนในรูป
\[ \sum_{n=0}^{\infty} c_nx^n = c_0 + c_1x + c_2x^2 + c_3x^3 + \ldots\]
เมื่อ $x$ เป็นตัวแปรของค่าจริงใด ๆ, $c_0, c_1, c_2, \ldots$ เป็นค่าคงตัว ซึ่งเราเรียกว่า **สัมประสิทธิ์ของอนุกรมกำลัง**

:::






:::example
จงหารูปทั่วไปของสัมประสิทธิ์ $c_n$ ของอนุกรมต่อไปนี้


- $1+x+x^2+x^3+x^4 + \cdots$ 

- $-2x^2 + 4x^4 - 6x^6 - \cdots$


:::


:::solution



- $c_n = 1$ สำหรับทุกค่า $n \geq 0$

- $c_n = 0$ เมื่อ $n$ เป็นเลขคี่ และ $c_n = (-1)^{n/2} n$ เมื่อ $n$ เป็นเลขคู่

เราสามารถเขียนได้อีกรูปแบบนึงได้ นั่นคือ

$c_{2n+1} = 0$ และ $c_{2n} = (-1)^n 2n$ สำหรับทุกจำนวน $n \geq 0$


:::






:::example
จงหารูปทั่วไปของสัมประสิทธิ์ $c_n$ ของอนุกรมต่อไปนี้


- $1 + \frac{1}{3!}x^3 + \frac{1}{6!}x^6 + \frac{1}{9!}x^9 + \cdots$

- $x+x^3$


:::


:::solution



- $c_n = 0$ เมื่อ $n$ หารด้วย 3 ไม่ลงตัว และ $c_n = \frac{1}{n!}$ เมื่อ $n$ หารด้วย 3 ลงตัว

เราสามารถเขียนได้อีกรูปแบบนึงได้ นั่นคือ

$c_{3n} = \frac{1}{(3n)!}$ และ $c_{3n+1} = c_{3n+2} = 0$ สำหรับทุกจำนวน $n \geq 0$


- $c_1 = 1, c_3 = 1$ และ $c_n = 0$ สำหรับทุกจำนวน $k \neq 1, 3$


:::






## อนุกรมกำลังในกำลังของ x-a


:::definition

**อนุกรมกำลังในกำลังของ $x-a$** คืออนุกรมที่เขียนในรูป
\[ \sum_{n=0}^{\infty} c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + c_3(x-a)^3 + \ldots\]
เมื่อ $x$ เป็นตัวแปรของค่าจริงใด ๆ, $c_0, c_1, c_2, \ldots$ เป็นค่าคงตัว ซึ่งเราเรียกว่า **สัมประสิทธิ์ของอนุกรมกำลัง** \index{อนุกรมกำลัง!สัมประสิทธิ์} และ $a$ เป็นค่าคงตัวที่เรียกว่า **จุดศูนย์กลางของอนุกรมกำลัง** 

:::

ข้อสังเกต: อนุกรมกำลังในกำลังของ $x$ ก็คืออนุกรมกำลังในกำลังของ $x-a$ เมื่อ $a = 0$





:::example
จงหาจุดศูนย์กลางของอนุกรมกำลังต่อไปนี้ พร้อมหารูปทั่วไปของสัมประสิทธิ์ $c_n$ 


- $1 + (x-1) + (x-1)^2 + (x-1)^3 + \cdots$ 

- $1+ \frac{x-4}{2} + \frac{(x-4)^2}{3} + \frac{(x-4)^3}{4} + \ldots$ 

- $ 2!(x+2)^4 + 3!(x+2)^6 + 4!(x+2)^8 + \cdots$


:::





:::solution



- $\sum_{n=0}^{\infty} (x-1)^n = 1 + (x-1) + (x-1)^2 + (x-1)^3 + \cdots$ เป็นอนุกรมกำลังในกำลังของ $x-1$ มีจุดศูนย์กลางของอนุกรมกำลังเป็น $a=1$ และมีสัมประสิทธิ์ของอนุกรมกำลังเป็น $1, 1, 1, \ldots$

- $\sum_{n=0}^{\infty} \frac{(x-4)^n}{n+1} = 1 + \frac{x-4}{2} + \frac{(x-4)^2}{3} + \frac{(x-4)^3}{4} + \ldots$ เป็นอนุกรมกำลังในกำลังของ $(x-4)$ มีจุดศูนย์กลางของอนุกรมกำลังเป็น $a=4$ และมีสัมประสิทธิ์ของอนุกรมกำลังเป็น $1, \frac{1}{2}, \frac{1}{3}, \ldots$

- $\sum_{n=2}^{\infty} n!(x+2)^{2n} = 2!(x+2)^4 + 3!(x+2)^6 + 4!(x+2)^8 + \cdots$ เป็นอนุกรมกำลังในกำลังของ $x+1$ มีจุดศูนย์กลางของอนุกรมกำลังเป็น $a=-1$ และมีสัมประสิทธิ์ของอนุกรมกำลังเป็น $0,0,0,0,2!,0,3!,0,4!, \ldots$


:::
