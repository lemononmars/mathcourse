## ทบทวนปริพันธ์

ในวิชาแคลคูลัส 1 สำหรับวิศวกร เราได้ศึกษาวิธีการคำนวณปริพันธ์จำกัดเขต

:::note

\[ \int_a^b f(x) \, dx\]

:::

โดยใช้เทคนิคต่าง ๆ มากมาย เพื่อให้ได้คำตอบที่เป็นรูปปิด (closed form) นั่นคือ สามารถเขียนออกมาเป็นฟังก์ชันได้ และเป็นค่าจริง แต่ถึงกระนั้น ยังมีปริพันธ์ที่ไม่สามารถเขียนเป็นรูปปิดได้ เช่น

:::note

\[ \int_0^1 e^{-x^2} \, dx \]

:::

แม้ว่าเราจะเขียนเป็นรูปปิดไม่ได้ แต่เราสามารถพิสูจน์ได้ว่ามีคำตอบเป็นจำนวนจริง




## การคำนวณปริพันธ์ด้วยผลบวกรีมัน


เราได้ศึกษาการคำนวณปริพันธ์ด้วยผลบวกรีมันว่า

:::note

\[\int_a^b f(x) \, dx = \lim_{n \to \infty} \sum_{i=0}^n f(x_n) \, \Delta x \]

:::

โดยที่ $\Delta x$ คือความยาวของฐาน และ $f(x_n)$ คือความสูงของสี่เหลี่ยม ทำให้ได้ว่าผลบวกทางฝั่งขวาคือผลรวมของพื้นที่สี่เหลี่ยมผืนผ้า 





:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0:4]
\draw[<->] (-0.5,0) -- (4.5,0) node [right] {$x$};
\draw[<->] (0,-0.5) -- (0,5.5) node [above] {$y$};
\filldraw[fill = blue!40!white] (0,0) -- plot (\x, {5-(\x-2)^2}) -- (4,0) -- cycle;
\node at (4, 4) {$y=f(x)$};
\begin{scope}[xshift = 6cm]
\draw[<->] (-0.5,0) -- (4.5,0) node [right] {$x$};
\draw[<->] (0,-0.5) -- (0,5.5) node [above] {$y$};
\filldraw[fill = blue!40!white] (0,0) -- plot (\x, {5-(\x-2)^2}) -- (4,0) -- cycle;
\foreach \x in {0,1,2,3}
{
	\filldraw[fill = red!40!white, fill opacity = 0.5] (\x, 0) rectangle (\x+1, {5-(\x-2)^2});
}
\end{scope}
\end{tikzpicture}
:::


*การประมาณพื้นที่ใต้เส้นโค้งด้วยผลบวกรีมัน*





ข้อดีของวิธีการนี้คือเข้าใจง่ายและคำนวณง่าย แต่ข้อเสียคือสามารถเกิดค่าคลาดเคลื่อนได้สูง ทำให้ค่าประมาณที่ได้แตกต่างกับค่าจริงอย่างมาก

เราจึงต้องหาวิธีการอื่นที่ทำให้ได้ค่าประมาณที่ใกล้เคียงค่าจริงมากขึ้น ซึ่งเราจะทำการศึกษาวิธีที่ได้รับความนิยม 2 วิธีด้วยกัน ได้แก่

:::note



- หลักเกณฑ์เชิงสี่เหลี่ยมคางหมู (Trapezoid Rule)

- หลักเกณฑ์ซิมป์สัน (Simpson's Rule)


:::
