## ที่มา

*การประมาณค่าปริพันธ์ด้วยหลักเกณฑ์สี่เหลี่ยมคางหมู*





หลักการประมาณค่าปริพันธ์โดย **หลักเกณฑ์เชิงสี่เหลี่ยมคางหมู** มีดังนี้

:::slide


:::remark 1) แบ่งออกเป็นช่วงย่อยที่มีขนาดเท่ากัน

เลือกจำนวนเต็ม $n$ เพื่อแบ่งช่วง $[a,b]$ ออกเป็น $n$ ช่วงย่อยเท่า ๆ กัน โดยช่วงย่อยแต่ละช่วงจะมีขนาดเท่ากับ $h_n = \frac{b-a}{n}$

:::



:::remark 2) กำหนดจุดเพื่อบอกขอบเขตของช่วงย่อย

กำหนดจุด $x_0, x_1, x_2, \ldots, x_n$ โดยที่ $x_0 = a, x_n = b$ และระยะห่างจุดที่อยู่ติดกันมีค่าเท่ากัน นั่นคือ
\[x_k = a + kh_n \]

:::


:::






:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0:4, scale = 1.5]

	\draw[blue, <->] (\x, 0.5) -- (\x+1, 0.5) node[pos = 0.5, above, black, scale = 2] {$h_n$}; 
}
\draw (4, 0) -- (4, -0.1) node [below] {$x_4$};
\end{tikzpicture}
:::


*การแบ่งช่วงย่อยของหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู*






:::slide


:::remark 3) คำนวณพื้นที่สี่เหลี่ยมคางหมูแต่ละรูป

เนื่องจากสี่เหลี่ยมคางหมูที่อยู่ระหว่าง $x_k$ และ $x_{k+1}$ มีความสูงเท่ากับ $x_{k+1} - x_k = h_n$ และมีด้านคู่ขนานยาว $f(x_k)$ และ $f(x_{k+1})$ ดังนั้นสี่เหลี่ยมนั้นจะมีพื้นที่เท่ากับ
\[ \frac{1}{2} \times \text{ สูง } \times \text{ ผลรวมด้านคู่ขนาน } = \frac{1}{2} h_n (f(x_k) + f(x_{k+1})) \]

:::


:::

:::


*การสร้างและคำนวณพื้นที่สี่เหลี่ยมคางหมู*






:::slide

ฉะนั้น พื้นที่รวมทั้งหมดมีค่าเท่ากับ
\begin{eq*}
\int_a^b f(x)\, dx &=& \int_{x_0}^{x_1} f(x) \, dx + \int_{x_1}^{x_2} f(x) \, dx + \ldots \int_{x_{n-1}}^{x_n} f(x) \, dx 

&\approx& \frac{1}{2} h_n (f(x_0) + f(x_1)) + \frac{1}{2} h_n (f(x_1) + f(x_2)) 

&\qquad& + \cdots + \frac{1}{2} h_n (f(x_{n-1}) + f(x_n)) 

&=& \frac{h_n}{2} \Big( (f(x_0) + f(x+1)) + (f(x_1) + f(x_2)) 

&\qquad& + \cdots + (f(x_{n-1}) + f(x_n)) \Big) 

\int_a^b f(x)\, dx&\approx&\frac{h_n}{2} \Big( f(x_0) + 2f(x_1) + 2f(x_2) + \cdots + 2f(x_{n-1}) + f(x_n) \Big) 

\end{eq*}

:::





## สูตรการการประมาณค่าด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู


:::theorem การประมาณค่าด้วยหลักเกณฑ์เชิงสี่เหลี่ยมคางหมู

กำหนดฟังก์ชันต่อเนื่อง $f(x)$ และช่วง $[a,b]$ โดยที่ $f(x) \geq 0$ สำหรับทุกค่า $a,b$ กำหนดจำนวนเต็ม $n$ เป็นจำนวนของช่วงย่อยและ $h_n = \frac{b-a}{n}$ แล้ว

\begin{eq}
\int_a^b f(x)\, dx &\approx& \frac{h_n}{2} \Big( f(x_0) + 2f(x_1) + 2f(x_2) + \ldots + 2f(x_{n-1}) + f(x_n) \Big) 

&\approx& \frac{h_n}{2} \left(f(x_0) + f(x_n) + 2\sum_{k = 1}^{n-1} f(x_k) \right) 
\end{eq}


:::

โดยที่สมการ \eqref{eq:trapezoid_2} ได้มาจากการจัดรูปสมการ \eqref{eq:trapezoid_1} ใหม่ 






:::example

จงใช้หลักเกณฑ์เชิงสี่เหลี่ยมคางหมูประมาณค่าปริพันธ์ $\int_0^2 x^2\, dx$ เมื่อ $n=4$

:::


:::solution

ขอบเขตของปริพันธ์จากโจทย์คือ $[a,b] = [0,2]$ ซึ่งถ้าเราแบ่งออกเป็น $4$ ช่วงย่อยแล้วจะได้ $h_4 = \frac{b-a}{4} = \frac{2-0}{4} = 0.5$ จากนั้น เราจึงทราบว่าเราต้องกำหนดจุดเพื่อแบ่งช่วงย่อยเป็น
\begin{eq*}
x_0 &=& a = 0 

x_1 &=& x_0 + 0.5 = 0.5 

x_2 &=& x_1 + 0.5 = 1 

x_3 &=& x_2 + 0.5 = 1.5 

x_4 &=& x_3 + 0.5 = 2 
\end{eq*}

:::






:::tikz TikZ diagram
\begin{tikzpicture}[domain = 0:4]

\draw[->] (0,0) -- (0,4.5) node [above] {$y$};
\filldraw[fill = blue!40!white] (0,0) -- plot (\x, {(\x^2)/4}) -- (4,0) -- cycle;

\node at (1, 2) {$y=x^2$};

	\draw ({\x}, 0) -- ({\x}, -0.2) node [below] {$\xp$};
	\filldraw[fill = red!40!white, fill opacity = 0.5] (\x, 0) -- (\x, \x^2/4) -- ({\x+1}, {(\x+1)^2/4}) -- ({\x+1}, 0) -- cycle;
}
\draw (4, 0) -- (4, -0.2) node [below] {$2$};
\end{scope}
\end{tikzpicture}
:::


*ปริพันธ์หลักเกณฑ์สี่เหลี่ยมคางหมูของฟังก์ชัน $y = x^2$*





สร้างตารางหาค่า $f(x_k)$ ได้ดังนี้



| k | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| x_k | 0 | 0.5 | 1 | 1.5 | 2 |
| f(x_k) = x_k^2 | 0 | 0.25 | 1 | 2.25 | 4 |



:::slide

ดังนั้น เราสามารถนำค่านี้ไปใส่ในสูตรเพื่อประมาณค่าได้เป็น
\begin{eq*}
\int_0^2 x^2 \, dx &\approx& \frac{h_n}{2}\Big(f(x_0) + 2f(x_1) + 2f(x_2) + 2f(x_3) + f(x_4) \Big) 

&=& \frac{1}{2} (0.5)\Big(0 + (2)(0.25) + (2)(1) + (2)(2.25) + 4 \Big)

&=& 2.75
\end{eq*}
นั่นคือ ค่าประมาณของปริพันธ์ $\int_0^2 x^2\, dx$ มีค่าเท่ากับ $2.75$

:::






:::example

จงใช้หลักเกณฑ์เชิงสี่เหลี่ยมคางหมูประมาณค่าปริพันธ์ $\int_1^2 \frac{1}{x} \, dx$ เมื่อ $n=5$ โดยใช้ทศนิยม 5 ตำแหน่ง

:::


:::solution

ขอบเขตของปริพันธ์จากโจทย์คือ $[a,b] = [1,2]$ ซึ่งถ้าเราแบ่งออกเป็น $5$ ช่วงย่อยแล้วจะได้ $h_5 = \tfrac{b-a}{5} = \tfrac{2-1}{5} = 0.2$ จากนั้น เราจึงทราบว่าเราต้องกำหนดจุดเพื่อแบ่งช่วงย่อยเป็น
\begin{eq*}
x_0 &=& a = 1 

x_1 &=& x_0 + 0.2 = 1.2 

x_2 &=& x_1 + 0.2 = 1.4 

x_3 &=& x_2 + 0.2 = 1.6 

x_4 &=& x_3 + 0.2 = 1.8 

x_5 &=& x_4 + 0.2 = 2 

\end{eq*}

:::

*ปริพันธ์หลักเกณฑ์สี่เหลี่ยมคางหมูของฟังก์ชัน $y = \frac{1*{x}$}





สร้างตารางหาค่า $f(x_k) = \tfrac{1}{x_k}$ ได้ดังนี้



| k | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| x_k | 1 | 1.2 | 1.4 | 1.6 | 1.8 | 2 |
| f(x_k) = \tfrac{1}{x_k} | 1 | 0.8333\ldots | 0.7143\ldots | 0.6250 | 0.5555\ldots | 0.5 |



:::slide

ดังนั้น เราสามารถนำค่านี้ไปใส่ในสูตรเพื่อประมาณค่าได้เป็น

\begin{eq*}
\int_1^2 \frac{1}{x} \, dx &\approx& \frac{h_n}{2} \Big(f(x_0) + 2f(x_1) + 2f(x_2) + 2f(x_3) + 2f(x_4) + f(x_5) \Big) 

&=& \frac{1}{2} (0.2)\Big(1 + (2)(0.8333) + (2)(0.7143) 

&\qquad& + (2)(0.6250) + (2)(0.5556) + 0.5 \Big)

&=& 0.6956
\end{eq*}

นั่นคือ ค่าประมาณของปริพันธ์ $\int_1^2 \tfrac{1}{x} \, dx$ มีค่าเท่ากับ $0.6956$

:::
