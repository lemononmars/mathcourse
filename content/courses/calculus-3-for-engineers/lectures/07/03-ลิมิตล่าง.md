*ปริพันธ์ $\int_{0*^{1} \frac{1}{\sqrt{x}} \, dx$}





เมื่อเกิดปัญหาขึ้นที่ $x=0$ เราจึงลองหาปริพันธ์ที่เข้าใกล้ค่า $x=0$ แทน นั่นคือพิจารณา
\[ \int_t^1 \frac{1}{\sqrt{x}} \, dx\] 
และให้ค่า $t$ เข้าใกล้ $0$ จากด้านบวก ดัง\figref{fig:improper_integral_discon_lower_limit}

*ปริพันธ์ $\int_{t*^{1} \frac{1}{\sqrt{x}} \, dx$}



:::



ในทำนองเดียวกัน ถ้าลิมิตด้านล่าง (นั่นคือค่า $a$) มีค่าเป็นอนันต์ เราสามารถนิยามปริพันธ์ได้ดังนี้

:::definition

กำหนดให้ $f(x)$ เป็นฟังก์ชันที่มีความต่อเนื่องบนช่วง $[a,b]$ ยกเว้นที่จุด $a$ ซึ่งเป็นจุดไม่ต่อเนื่องอนันต์ แล้วค่าปริพันธ์ไม่ตรงแบบ $\int_a^b f(x) \,dx$ นิยามโดย
\begin{equation}
\int_a^b f(x)\, dx = \lim_{t \to a^+} \int_t^b f(x)\, dx
\end{equation}
ถ้าลิมิตหาค่าได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่เข้า** และถ้าลิมิตหาค่าไม่ได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่ออก**

:::






:::example

จงพิจารณาว่า $\int_0^1 \frac{1}{\sqrt{x}} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เนื่องจากฟังก์ชัน $f(x) = \frac{1}{\sqrt{x}} $ มีค่าอนันต์เมื่อ $x=0$ ซึ่งเป็นลิมิตล่าง เราจึงเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น
\begin{eq*}
\int_0^1 \frac{1}{\sqrt{x}} \,dx &=& \limt{0^+} \int_t^1 \frac{1}{\sqrt{x}} \,dx 

&=& \limt{0^+} 2\sqrt{x} \, \Big|_t^1 

&=& \limt{0^+} 2\sqrt{1} - 2\sqrt{t} = 2
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_0^1 \frac{1}{\sqrt{x}} \,dx = 2$

:::






:::example

จงพิจารณาว่า $\int_{-4}^4 \frac{1}{(x+4)^{\frac{2}{3}}} \, dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราสามารถใช้เทคนิคการแทนค่า $u=x+4$ ซึ่งทำให้ $du = dx$ เพื่อหาปริพันธ์ได้เป็น
\begin{eq*}
\int \frac{1}{(x+4)^{\frac{2}{3}}}\, dx &=& \int \frac{1}{u^{\frac{2}{3}}} \, du

&=& 3u^{\frac{1}{3}} +C 

&=& 3(x+4)^{\frac{1}{3}} + C
\end{eq*}

:::





:::solution
(ต่อ)
เนื่องจากฟังก์ชัน $f(x) = \frac{1}{(x+4)^{\frac{2}{3}}} \, dx$ มีค่าอนันต์เมื่อ $x=-4$ ซึ่งเป็นลิมิตล่าง เราจึงเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น
\begin{eq*}
\int_{-4}^4 \frac{1}{(x+4)^{\frac{2}{3}}} \,dx &=& \limt{-4^+} \int_t^4 \frac{1}{(x+4)^{\frac{2}{3}}} \,dx 

&=& \limt{-4^+} 3(x+4)^{\frac{1}{3}} \, \Big|_t^4 

&=& \limt{-4^+} 3(4+4)^{\frac{1}{3}} - 3(t+4)^{\frac{1}{3}} 

&=& 6-0 = 6
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_{-4}^4 \frac{1}{(x+4)^{\frac{2}{3}}} \, dx = 6$

:::
