## นิยามปริพันธ์ที่มีค่าอนันต์ที่ลิมิตบน

ถ้าเกิดค่าอนันต์ขึ้นที่ลิมิตบน เราสามารถหาค่าของปริพันธ์ได้ด้วยการแปลงเป็นลิมิตตามนิยามดังต่อไปนี้

:::definition

กำหนดให้ $f(x)$ เป็นฟังก์ชันที่มีความต่อเนื่องบนช่วง $[a,b]$ ยกเว้นที่จุด $b$ ซึ่งเป็นจุดไม่ต่อเนื่องอนันต์ แล้วค่าปริพันธ์ไม่ตรงแบบนิยามโดย
\begin{equation}
\int_a^b f(x)\, dx = \lim_{t \to b^-} \int_a^t f(x)\, dx
\end{equation}
ถ้าลิมิตหาค่าได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่เข้า** และถ้าลิมิตหาค่าไม่ได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่ออก**

:::







:::example

จงพิจารณาว่า $\int_0^8 \frac{1}{\sqrt[3]{8-x}} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เนื่องจากฟังก์ชัน $f(x) = \frac{1}{\sqrt[3]{8-x}} $ มีค่าอนันต์เมื่อ $x=8$ ซึ่งเป็นลิมิตบน เราจึงเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยาม โดยเราใช้เทคนิคการแทนค่า $u = 8-x$ เพื่อคำนวณปริพันธ์ได้เป็น
\begin{eq*}
\int \frac{1}{\sqrt[3]{8-x}} \, dx &=& \int u^{-\frac{1}{3}} \, (-du) 

&=& - \frac{3}{2}u^{\frac{2}{3}} + C

&=& -\frac{3}{2} (8-x)^{\frac{2}{3}} + C
\end{eq*}

:::





:::solution
(ต่อ)
และคำนวณค่าของปริพันธ์ได้เป็น
\begin{eq*}
\int_0^8 \frac{1}{\sqrt[3]{8-x}} \,dx &=& \limt{8^-} \int_0^t \frac{1}{\sqrt[3]{8-x}} \,dx 

&=& \limt{8^-} \left( -\frac{3}{2}(8-t)^{\frac{2}{3}} \right) \Big|_0^t 

&=& \limt{8^-} \left( -\frac{3}{2}(8-t)^{\frac{2}{3}} \right) - \left( -\frac{3}{2}(8-0)^{\frac{2}{3}} \right) 

&=& \frac{3}{2}(8^{\frac{2}{3}}) = \frac{3}{2} (4) = 6
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_0^8 \frac{1}{\sqrt[3]{8-x}} \,dx = 6$

:::






:::example

จงพิจารณาว่า $\int_0^3 \frac{1}{\sqrt{9-x^2}} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เนื่องจากฟังก์ชัน $f(x) = \tfrac{1}{\sqrt{9-x^2}} $ มีค่าอนันต์เมื่อ $9-x^2 = 0$ นั่นคือ $x = -3,3$ ซึ่ง $x=3$ เป็นลิมิตบน เราจึงเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณค่าของปริพันธ์ได้เป็น
\begin{eq*}
\int_0^3 \tfrac{1}{\sqrt{9-x^2}} \,dx &=& \limt{3^-} \int_0^t \tfrac{1}{\sqrt{9-x^2}} \,dx 

&=& \limt{3^-} \arcsin \tfrac{x}{3} \, \Big|_0^t \mathnote{$\int \tfrac{1}{\sqrt{a^2 - x^2}} \, dx = \arcsin \tfrac{x}{a} + C$} 

&=& \limt{3^-} \arcsin \tfrac{t}{3} - \arcsin \tfrac{0}{3} = \arcsin 1 - \arcsin 0 = \tfrac{\pi}{2}
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\textstyle \int_0^3 \tfrac{1}{\sqrt{9-x^2}} \,dx = \tfrac{\pi}{2}$

:::
