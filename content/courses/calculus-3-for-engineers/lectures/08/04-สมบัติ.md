## สมบัติของปริพันธ์ตามเส้น


:::property

กำหนดเส้นโค้ง $C$ ที่มีทิศทาง และ $f(x,y)$ และ $g(x,y)$ ที่หาค่าได้สำหรับทุกจุด $(x,y)$ บน $C$ นิยาม $-C$ เป็นเส้นโค้งที่มีจุดเดียวกันกับ $C$ แต่มีทิศทางตรงกันข้าม


- $\int_{-C} f(x,y) \, dx = - \int_C f(x,y) \, dx$ (สมบัติเป็นจริงสำหรับ $dy$ และ $dz$ เช่นกัน)

- $\int_C f(x,y) \, dx + g(x,y) \, dy = \int_C f(x,y) \, dx + \int_C g(x,y) \, dy$ 


:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C 3y\,dx + 3x\,dy$ เมื่อเส้นโค้ง $C$ กำหนดด้วยสมการอิงตัวแปรเสริม
\[ x = t, \quad y = t^2, \quad 0 \leq t \leq 2\]

:::


:::solution

เราเปลี่ยน $dx$ และ $dy$ ให้เป็น $dt$ ได้ดังนี้
\begin{eq*}
x = t &\longrightarrow &dx = dt 

y = t^2 &\longrightarrow &dy = 2t\,dt
\end{eq*}
ฉะนั้นเราแทนค่า $x,y,dx$ และ $dy$ ลงไปได้ดังนี้
\begin{eq*}
\int_C 3y \, dx + 3x \, dy = \int_0^2 3t^2 \, dt + 3t (2t \, dt) &=& \int_0^2 9t^2 \, dt 

&=& 3t^3 \Big|_0^2 =24
\end{eq*}

:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C 2xy \, dx + (x^2+y^2) \, dy$ เมื่อเส้นโค้ง $C$ กำหนดด้วยสมการอิงตัวแปรเสริม
\[ x = \cos t, \quad y = \sin t, \quad 0 \leq t \leq \frac{\pi}{2}\]

:::


:::solution

เราเปลี่ยน $dx$ และ $dy$ ให้เป็น $dt$ ได้ดังนี้
\begin{eq*}
x = \cos t &\longrightarrow &dx = -\sin t\,dt 

y = \sin t &\longrightarrow &dy = \cos t\,dt
\end{eq*}
ฉะนั้นเราแทนค่า $x,y,dx$ และ $dy$ ลงไปได้ดังนี้

:::





:::solution
(ต่อ)
\begin{eq*}
&&\int_C 2xy \, dx + (x^2+y^2) \, dy 

&=& \int_0^{\pi/2} 2(\cos t)(\sin t) (-\sin t \, dt) + (\cos^2 t + \sin^2 t) (\cos t \, dt ) 

&=& \int_0^{\pi/2} -2\sin^2 t \cos t \, dt + \cos t \, dt 

&=& \int_0^{\pi/2} -2\sin^2 t \, d \sin t + \cos t \, dt 

&=& \left( -\frac{2}{3} \sin^3 t \, + \sin t \right) \Big|_{0}^{\pi/2} 

&=& \left( -\frac{2}{3} \sin^3 \frac{\pi}{2} + \sin \frac{\pi}{2} \right) - \left( -\frac{2}{3} \sin^3 0 \, + \sin 0 \right) 

&=& -\frac{2}{3} + 1 = \frac{1}{3}
\end{eq*}

:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C y\,dx + xy\,dy$ เมื่อเส้นโค้ง $C$ เป็นเส้นตรงจากจุด $(2,0)$ ไปจุด $(0,2)$

:::


:::solution

สมการเวกเตอร์ของเส้นโค้ง $C$ คือ
\begin{eq*}
\vrt &=& (1-t)\vec{P_1} + t \vec{P_2} 

&=& (1-t) \langle 2,0\rangle + t \langle 0,2\rangle 

&=& \langle 2(1-t), 0 \rangle + \langle 0, 2t \rangle 

&=& \langle 2-2t, 2t \rangle
\end{eq*}
ฉะนั้น สมการอิงตัวแปรเสริมของเส้นตรง $C$ คือ
\[ x = 2-2t, \quad y = 2t, \quad 0 \leq t \leq 1\]

:::





:::solution
(ต่อ)
และเราเปลี่ยน $dx$ และ $dy$ ให้เป็น $dt$ ได้ดังนี้
\begin{eq*}
x = 2-2t &\longrightarrow& dx = -2\,dt 

y = 2t &\longrightarrow& dy = 2\, dt
\end{eq*}
เมื่อเราแทนค่า $x,y,dx$ และ $dy$ ลงไปจะได้
\begin{eq*}
\int_C y\,dx + xy\,dy &=& \int_0^1 (2t)(-2 \,dt) + (2-2t)(2t) (2\, dt) 

&=& \int_0^1 -4t \,dt + 8t-8t^2\, dt 

&=& \int_0^1 -8t^2+4t \, dt 

&=& \left( -\frac{8}{3} t^3 + 2t^2 \right)\Big|_0^1 

&=& \frac{8}{3} - 2 = -\frac{2}{3}
\end{eq*}

:::
