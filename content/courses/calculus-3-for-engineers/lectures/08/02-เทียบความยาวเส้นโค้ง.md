## ที่มา


:::slide

เนื่องจากค่า $ds$ ขึ้นอยู่กับรูปร่างของเส้นโค้ง $C$ เราจึงไม่สามารถใช้นิยามเพื่อคำนวณปริพันธ์ได้โดยตรง อย่างไรก็ตาม ถ้า $C$ เป็นเส้นโค้งที่มีสมการอิงตัวแปรเสริม เราจะสามารถแปลงปริพันธ์ตามเส้นให้เป็นปริพันธ์ตัวแปรเดียวได้ดังนี้


\noindent สมมติว่าเส้นโค้ง $C$ สามารถเขียนในรูปของสมการอิงตัวแปรเสริมในรูปเวกเตอร์ได้เป็น
\[ \vrt = \leftlangle x(t), +y(t) \rightangle \quad (a \leq t \leq b)\]
โดยที่ $\vrt$ เป็นเวกเตอร์ที่หาปริพันธ์ได้ เราทราบจากปริพันธ์ของเวกเตอร์ว่า
\[ \frac{ds}{dt} = \left\| \frac{dr}{dt} \right\| \qquad \longrightarrow \qquad ds = \| \dvrt \| \, dt\]

:::





:::slide

ฉะนั้น
\[ \int_C f(x,y)\, ds = \int_a^b f(x(t), y(t)) \| \dvrt \| \, dt\]
ซึ่งเป็นปริพันธ์ในปริภูมิหนึ่งมิติของตัวแปร $t$ ที่เราสามารถคำนวณได้ โดยเราจัดรูป $\| \dvrt \|$ ได้ดังนี้
\begin{eq*}
\vrt &=& \leftlangle x(t), +y(t) \rightangle 

\dvrt &=& \leftlangle x'(t), +y'(t) \rightangle 

&=& \vv{\frac{dx}{dt}}{+\frac{dy}{dt}} 

\| \dvrt \| &=& \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}
\end{eq*}

:::





## การหาปริพันธ์ตามเส้นเทียบความยาวเส้นโค้ง ในสองมิติ


:::theorem

กำหนดเส้นโค้ง $C$ ที่มีสมการอิงตัวแปรเสริมในรูปเวกเตอร์เป็น $\vrt = \leftlangle x(t), +y(t) \rightangle$ เมื่อ $a \leq t \leq b$ และฟังก์ชัน $f(x,y)$ ที่ต่อเนื่องบนเส้นโค้ง $C$ แล้ว
\begin{eq}
\int_C f(x,y)\, ds &=& \int_a^b f(x(t), y(t)) \| \dvrt \| \, dt 

&=& \int_a^b f(x(t), y(t)) \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 }\, dt 
\end{eq}

:::





## การหาปริพันธ์ตามเส้นเทียบความยาวเส้นโค้ง ในสามมิติ


:::theorem

กำหนดเส้นโค้ง $C$ ที่มีสมการอิงตัวแปรเสริมในรูปเวกเตอร์เป็น $\vrt = \vvv{x(t)}{+y(t)}{+z(t)}$ เมื่อ $a \leq t \leq b$ และฟังก์ชัน $f(x,y,z)$ ที่ต่อเนื่องบนเส้นโค้ง $C$ แล้ว
\begin{eq}
\int_C f(x,y,z)\, ds &=& \int_a^b f(x(t), y(t),z(t)) \| \dvrt \| \, dt 

&=& \textstyle \int_a^b f(x(t), y(t),z(t)) \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 + \left(\frac{dz}{dt}\right)^2 }\, dt 
\end{eq}

:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C xy \, ds$ เมื่อ $C: \vrt = \leftlangle t, +3t \rightangle \quad (0 \leq t \leq 1)$

:::


:::solution

จาก $\vrt = \leftlangle t, +3t \rightangle$ จะได้ $\dvrt = \leftlangle , +3 \rightangle$ แล้ว $\| \dvrt \| = \sqrt{1^2 + 3^2} = \sqrt{10}$ ฉะนั้น
\begin{eq*}
\int_C xy \, ds &=& \int_0^1 (t)(3t) \| \dvrt \| \, dt 

&=& \int_0^1 3\sqrt{10} t^2 \, dt 

&=& ( \sqrt{10}t^3 ) \Big|_0^1 = \sqrt{10}
\end{eq*}

:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C (x + y) \, ds$ เมื่อ $C$ เป็นเส้นโค้งที่มีสมการเวกเตอร์เป็น $\vrt = \leftlangle \cos t, +\sin t \rightangle \quad (0 \leq t \leq \pi)$

:::


:::solution

จาก $\vrt = \leftlangle \cos t, +\sin t \rightangle$ จะได้ $\dvrt = \leftlangle -\sin t, +\cos t \rightangle$ แล้ว $\| \dvrt \| = \sqrt{(-\sin t)^2 + (\cos t)^2} = 1$ ฉะนั้น
\begin{eq*} 
\int_C x+y \, ds &=& \int_0^1 (\cos t + \sin t) \| \dvrt \| \, dt 

&=& \int_0^{\pi} \cos t + \sin t \, dt 

&=&(\sin t - \cos t) \Big|_0^{\pi} 

&=& (\sin \pi - \cos \pi) - (\sin 0 - \cos 0) 

&=& 1 - (-1) = 2
\end{eq*}

:::
