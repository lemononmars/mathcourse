## สมการเวกเตอร์ของส่วนของเส้นตรง


\resizebox{!}{0.8\textheight}{

:::theorem

กำหนดจุด $P_0 (x_0, y_0)$ และจุด $P_1 (x_1, y_1)$ ซึ่งแปลงเป็นเวกเตอร์ $\vec{P_0}$ และ $\vec{P_1}$ ตามลำดับ แล้วส่วนของเส้นตรงจากจุด $P_0$ ไปยังจุด $P_1$ มีสมการเวกเตอร์เป็น

\begin{eq}
\vrt &=& (1-t)\vec{P_0} + t\vec{P_1} \nonumber 

&=& \langle (1-t)x_0 + tx_1, (1-t)y_0 + ty_1 \rangle 
\end{eq}

สำหรับค่า $0 \leq t \leq 1$ และเขียนเป็นสมการอิงตัวแปรเสริมได้เป็น
\[x = (1-t)x_0 + tx_1, \qquad y = (1-t)y_0 + ty_1, \qquad 0 \leq t \leq 1\]


:::

}




:::remark ข้อสังเกต



- สังเกตว่าถ้าแทนค่า $t=0$ ลงไป จะได้
\[ \vec{r}(0) = \langle (1-0)x_0 + (0)(x_1), (1-0)y_0 + (0)y_1 \rangle = \langle x_0, y_0 \rangle\]
ซึ่งเป็นเวกเตอร์ที่แทนจุด $P_0$ พอดี และถ้าแทน $t=1$ ลงไป จะได้
\[ \vec{r}(1) = \langle (1-1)x_0 + (1)(x_1), (1-1)y_0 + (1)y_1 \rangle = \langle x_1, y_1 \rangle\]
ซึ่งเป็นเวกเตอร์ที่แทนจุด $P_1$ พอดี

- ลำดับของจุดมีผล ถ้าเราสลับจุด $P_0$ และ $P_1$ จะได้ส่วนของเส้นตรงที่มีทิศทางตรงกันข้าม


:::







:::tikz TikZ diagram
\begin{tikzpicture}[scale = 2]
\draw [<->] (-0.5,0) -- (3,0) node[right] {$x$};
\draw [<->] (0,-0.5) -- (0,2) node[above] {$y$};
\filldraw[blue] (2.5, 0.5) circle (0.2mm) node[below] {$P_1$};
\filldraw[blue] (0.5, 1.5) circle (0.2mm) node[below] {$P_2$};
\draw[red, very thick, ->] (2.5,0.5) -- (0.5,1.5) node[below, pos = 0.5] {$C$};
\node[draw, double] at (1, -1) {$\vrt = (1-t)P_0 + tP_1, \quad 0 \leq t \leq 1$};
\end{tikzpicture}
:::


*ภาพแสดงสมการเวกเตอร์ของส่วนของเส้นตรงจากจุด $P_0$ ไปจุด $P_1$*






:::example

จงหาสมการเวกเตอร์ของส่วนของเส้นตรงจากจุด $P_0(0,0)$ ไปยังจุด $P_1(2,3)$

:::


:::solution

แทนค่า $(x_0, y_0) = (0,0)$ และ $(x_1,y_1) = (2,3)$ ลงไปในสูตร \ref{eq:vector_eq_line_segment} จะได้
\begin{eq*}
\vrt &=& \langle (1-t)x_0 + tx_1, (1-t)y_0 + ty_1 \rangle

&=& \langle (1-t)(0) + t(2), (1-t)(0) + t(3) \rangle 

&=& \langle 2t, 3t \rangle
\end{eq*}

:::





:::example

จงหาสมการเวกเตอร์ของส่วนของเส้นตรง $C$ จากจุดในรูป ต่อไปนี้


:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.2]
\axes{-1.5}{4.5}{-3.5}{2.5}
\draw (-1,2) circle [radius = 0.1cm, fill = blue] node[left] {$P_0(-1,2)$};
\draw (4,-3) circle [radius = 0.1cm, fill = blue] node[below] {$P_1(4,-3)$};
\draw[->, red] (-1,2) -- (4,-3) node[pos=0.5, above] {$C$};
\end{tikzpicture}
:::





:::


:::solution

แทนค่า $(x_0, y_0) = (-1,2)$ และ $(x_1,y_1) = (4,-3)$ ลงไปในสูตร \ref{eq:vector_eq_line_segment} จะได้
\begin{eq*}
\vrt &=& \langle (1-t)x_0 + tx_1, (1-t)y_0 + ty_1 \rangle

&=& \langle (1-t)(-1) + t(4), (1-t)(2) + t(-3) \rangle 

&=& \langle -1+t+4t, 2-2t-3t \rangle 

&=& \langle 5t-1, 2-5t \rangle
\end{eq*}

:::





## สมการเวกเตอร์ส่วนของวงกลม



:::theorem

กำหนดวงกลมรัศมี $a$ แล้วส่วนของวงกลมจากมุม $\theta_1$ ไปยังมุม $\theta_2$ เขียนเป็นสมการเวกเตอร์ได้ดังนี้

\[\vrt = \langle a \cos t, a \sin t \rangle, \quad \theta_1 \leq t \leq \theta_2\]

และเขียนเป็นสมการอิงตัวแปรเสริมได้เป็น
\[x = a\cos t, \qquad y = a \sin t, \qquad \theta_1 \leq t \leq \theta_2 \]


:::







:::tikz TikZ diagram
\begin{tikzpicture}[scale = 2]
\draw [<->] (-1.2,0) -- (1.2,0) node[right] {$x$};
\draw [<->] (0,-1.2) -- (0,1.2) node[above] {$y$};
\draw[dashed] (0,0) circle [radius = 1cm];
\draw[red, very thick, ->] (30:1cm) arc [start angle = 30, end angle =120, radius = 1cm] node[pos = 0.5, above] {$C$}; 
\node[draw, double] at (0, -1.5) {$\vrt = \langle a \cos t, a \sin t \rangle, \quad \theta_1 \leq t \leq \theta_2$};
\draw[dotted] (0,0) -- (30: 1cm) node [below, pos = 0.5] {$\theta_1$};
\draw[dotted] (0,0) -- (120: 1cm) node [below, right, pos = 0.5] {$\theta_2$};
\draw[|-|] (0,-0.1) --+ (1,-0) node[below, pos = 0.5] {$a$};
\end{tikzpicture}
:::


*ภาพแสดงส่วนของวงกลม จากมุม $\theta_1$ ไปมุม $\theta_2$*






:::example

จงหาสมการเวกเตอร์ของเส้นโค้ง $C$ ที่เป็นส่วนของวงกลมในรูปต่อไปนี้


:::tikz TikZ diagram
\begin{tikzpicture}
\axes{-0.5}{1.5}{-0.5}{1.5};
\draw[red, ->] (1,0) arc [radius = 1, start angle = 0, end angle = 90] node[pos = 0.5, above] {$C$};
\draw (1,0) --+ (0, -0.1) node[below] {$3$};
\end{tikzpicture}
:::





:::


:::solution

ในภาพนี้ $C$ เป็นเส้นโค้งในวงกลมรัศมี 3 หน่วย โดยเริ่มจากมุม $0$ ไปยังมุม $\frac{\pi}{2}$ ฉะนั้นสมการเวกเตอร์ของเส้นโค้ง $C$ คือ
\[\vrt = \langle 3\cos t, 3 \sin t \rangle, \quad 0 \leq t \leq \frac{\pi}{2}\]

:::






:::example

จงหาปริพันธ์ตามเส้น $\int_C xy\,dx + x^2\,dy$ เมื่อเส้นโค้ง $C$ เป็นเส้นโค้ง $x=y^2$ จากจุด $(0,0)$ ไปยังจุด $(2,4)$

:::


:::solution

เราเปลี่ยนสมการเส้นโค้งให้เป็นสมการอิงตัวเสริมได้ด้วยการกำหนดตัวแปรใดตัวแปรหนึ่งให้เท่ากับตัวแปรเสริมก่อน ในที่นี้คือกำหนดให้ 
\[y=t \qquad \text{แล้วจะได้} \qquad x=t^2, \qquad 0 \leq t \leq 2\]
เราเปลี่ยน $dx$ และ $dy$ ให้เป็น $dt$ ได้ดังนี้
\begin{eq*}
x = t^2 &\longrightarrow &dx = 2t\,dt 

y = t &\longrightarrow &dy = dt
\end{eq*}

:::





:::solution

เมื่อเราแทนค่า $x,y,dx$ และ $dy$ ลงไปจะได้
\begin{eq*}
\int_C xy\,dx + x^2\,dy &=& \int_0^2 (t^2)(t)(2t)\, dt + (t^2)^2 (dt) 

&=& \int_0^2 3t^4 \, dt 

&=& \left( \frac{3}{5} t^5 \right)\Big|_0^2 = \frac{96}{5}
\end{eq*}

:::
