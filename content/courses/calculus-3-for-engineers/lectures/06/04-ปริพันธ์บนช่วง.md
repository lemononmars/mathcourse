สุดท้าย เมื่อกำหนดขอบเขตปริพันธ์ในช่วง $(-\infty, \infty)$ มาให้ เราอาจจะคิดว่าเราต้องสร้างบทนิยามขึ้นมาใหม่ แต่ที่จริงแล้วเราสามารถใช้สมบัติการบวกของปริพันธ์ 
:::slide

\[\int_{-\infty}^{+\infty} f(x) \, dx = \int_{-\infty}^c f(x)\,dx + \int_c^{+\infty} f(x)\,dx\]
เมื่อ $c$ เป็นจำนวนจริงใด ๆ และผลบวกทางขวาของสมการ คือปริพันธ์บนช่วง $(-\infty, c]$ และช่วง $[c, \infty)$ ที่เราได้ศึกษามาแล้ว

:::

*การแบ่งปริพันธ์เป็น $\int_{-\infty*^{c} \frac{1}{1+x^2} \, dx$ และ $\int_c^{+\infty} \frac{1}{1+x^2} \, dx$}








\resizebox{!}{\textheight}{

:::definition

กำหนดให้ $f(x)$ เป็นฟังก์ชันที่มีความต่อเนื่องบนช่วง $(-\infty, +\infty)$ (นั่นคือ ต่อเนื่องสำหรับทุกจำนวนจริง $x$) และเลือกจำนวนจริง $c$ ใด ๆ 


- ถ้า $ \int_{-\infty}^c f(x)\,dx$ **และ** $ \int_c^{+\infty} f(x)\,dx$ เป็นปริพันธ์ไม่ตรงแบบที่**ลู่เข้า**ทั้งคู่ แล้ว $\int_{-\infty}^{+\infty} f(x) \, dx$ จะเป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้าเช่นกัน โดยที่
\begin{equation}
\int_{-\infty}^{+\infty} f(x) \, dx = \int_{-\infty}^c f(x)\,dx + \int_c^{+\infty} f(x)\,dx
\end{equation}

- ถ้า $ \int_{-\infty}^c f(x)\,dx$ **หรือ** $ \int_c^{+\infty} f(x)\,dx$ อันใดอันหนึ่ง เป็นปริพันธ์ไม่ตรงแบบที่**ลู่ออก** แล้ว $\int_{-\infty}^{+\infty} f(x) \, dx$ จะเป็นปริพันธ์ไม่ตรงแบบที่ลู่ออก


:::

}






:::example

จงพิจารณาว่า $\int_{-\infty}^{\infty} \frac{2x}{(1+x^2)^2} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราใช้เทคนิคการแทนค่า $u = 1+x^2$ ซึ่งจะได้ $du = 2x\,dx$ เพื่อหาปริพันธ์ได้เป็น
\[ \int \frac{2x}{(1+x^2)^2} \, dx = \int \frac{2x}{u^2} \left( \frac{du}{2x} \right)= \int \frac{1}{u^2} \, du = -\frac{1}{u} + C = -\frac{1}{1+x^2} + C\]
เนื่องจากเป็นปริพันธ์บนช่วง $(-\infty, \infty)$ เราจึงเลือกค่า $c$ ใด ๆ ก็ได้ ในที่นี้เราเลือก $c=0$ จากนั้นจึงหาปริพันธ์ดังนี้

:::





:::solution
(ต่อ)
\begin{eq*}
\int_{-\infty}^{0} \frac{2x}{(1+x^2)^2} \,dx &=& \limt{-\infty} \int_{t}^0 \frac{2x}{(1+x^2)^2} \,dx

&=& \limt{-\infty} \left( - \frac{1}{1+x^2} \right) \Big|_t^{0} 

&=& \limt{-\infty} \left( -\frac{1}{1+0^2} \right) - \left( -\frac{1}{1+t^2} \right) = -1 

\end{eq*}

:::





:::solution
(ต่อ)
\begin{eq*}
\int_{0}^{\infty} \frac{2x}{(1+x^2)^2} \,dx &=& \limt{\infty} \int_0^t \frac{2x}{(1+x^2)^2} \,dx

&=& \limt{\infty} \left( - \frac{1}{1+x^2} \right) \Big|_0^t 

&=& \limt{\infty} \left( -\frac{1}{1+t^2} \right) - \left( -\frac{1}{1+0^2} \right) = 1
\end{eq*}
เนื่องจากปริพันธ์ทั้งสองลู่เข้าทั้งคู่ ฉะนั้น $\int_{-\infty}^{\infty} \frac{2x}{(1+x^2)^2} \,dx$ เป็นปริพันธ์ที่ลู่เข้าเช่นกัน โดยมีค่าเท่ากับ 
\begin{eq*} 
\int_{-\infty}^{\infty} \frac{2x}{(1+x^2)^2} \,dx &=& \int_{-\infty}^{0} \frac{2x}{(1+x^2)^2} \,dx + \int_{0}^{\infty} \frac{2x}{(1+x^2)^2} \,dx 

&=& -1+1 = 0
\end{eq*}

:::






:::example

จงพิจารณาว่า $\int_{-\infty}^{\infty} \frac{1}{x^2-4x+8} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราอาจลองใช้เทคนิคการแยกเป็นเศษส่วนย่อย แต่เนื่องจากรากของ $x^2-4x+8$ คือ $x = 2+2i, 2-2i$ ซึ่งไม่ใช่จำนวนจริง เราจึงต้องลองวิธีอื่น ในที่นี้เราสามารถเขียนเป็น 
\[ x^2-4x+8 = (x^2-4x+4)+4 = (x-2)^2 + 2^2\]
ซึ่งอยู่ในรูป $u^2 + a^2$ แสดงว่าเราสามารถใช้สูตรปริพันธ์ของ $\arctan$ ได้โดยตรงดังนี้
\[ \int \frac{1}{x^2-4x+8} \, dx = \int \frac{1}{(x-2)^2 + 2^2} \, dx = \frac{1}{2} \arctan \frac{x-2}{2} + C\]

:::





:::solution
(ต่อ)
เนื่องจากเป็นปริพันธ์บนช่วง $(-\infty, \infty)$ เราจึงเลือกค่า $c$ ใด ๆ ก็ได้ ในที่นี้เราเลือก $c=0$ จากนั้นจึงหาปริพันธ์ดังนี้
\begin{eq*}
\int_{-\infty}^{0} \frac{1}{x^2-4x+8} \,dx &=& \limt{-\infty} \int_{t}^0 \frac{1}{x^2-4x+8} \,dx

&=& \limt{-\infty} \left( \frac{1}{2} \arctan \frac{x-2}{2} \right) \Big|_t^{0} 

&=& \limt{-\infty} \left(\frac{1}{2} \arctan \frac{0-2}{2}\right) - \left( \frac{1}{2} \arctan \frac{t-2}{2} \right) 

&=& \frac{1}{2}\arctan (-1) - \frac{1}{2}\left( - \frac{\pi}{2} \right) 

&=& \frac{\pi}{8} + \frac{\pi}{4} = \frac{3\pi}{8}
\end{eq*}

:::





:::solution

\begin{eq*}
\int_{0}^{\infty} \frac{1}{x^2-4x+8} \,dx &=& \limt{\infty} \int_0^t \frac{1}{x^2-4x+8} \,dx

&=& \limt{\infty} \left( \frac{1}{2} \arctan \frac{x-2}{2} \right) \Big|_0^{t} 

&=& \limt{\infty} \left(\frac{1}{2} \arctan \frac{t-2}{2}\right) - \left( \frac{1}{2} \arctan \frac{0-2}{2} \right) 

&=& \frac{1}{2}\left( \frac{\pi}{2} \right) - \frac{1}{2}\arctan (-1) 

&=& \frac{\pi}{4} - \frac{\pi}{8} = \frac{\pi}{8}
\end{eq*}

:::





:::solution
(ต่อ)
เนื่องจากปริพันธ์ทั้งสองลู่เข้าทั้งคู่ ฉะนั้น $\int_{-\infty}^{\infty} \frac{1}{x^2-4x+8} \,dx$ เป็นปริพันธ์ที่ลู่เข้าเช่นกัน โดยมีค่าเท่ากับ 
\begin{eq*}
\int_{-\infty}^{\infty} \frac{1}{x^2-4x+8} \,dx&=& \int_{-\infty}^{0} \frac{1}{x^2-4x+8} \,dx + \int_{0}^{\infty} \frac{1}{x^2-4x+8} \,dx

&=& \frac{3\pi}{8} + \frac{\pi}{8} = \frac{\pi}{2}
\end{eq*}

:::
