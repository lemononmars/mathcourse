*ปริพันธ์ $\int_{t*^{0} e^{x} \, dx$}






:::definition

กำหนดให้ $f(x)$ เป็นฟังก์ชันที่มีความต่อเนื่องบนช่วง $x \leq b$ และให้ $\int_t^b f(x) \, dx$
หาค่าได้สำหรับทุกค่า $t \in (-\infty,b]$ แล้วค่าปริพันธ์ไม่ตรงแบบ $\int_{-\infty}^{b} f(x) \,dx$ นิยามโดย
\begin{equation}
\int_{-\infty}^{b}f(x)\, dx = \lim_{t \to -\infty} \int_t^b f(x)\, dx
\end{equation}
ถ้าลิมิตหาค่าได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่เข้า** และถ้าลิมิตหาค่าไม่ได้ จะกล่าวว่าปริพันธ์ไม่ตรงแบบนั้น **ลู่ออก**

:::






:::example

จงพิจารณาว่า $\int_{-\infty}^{0} e^{2x} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราใช้เทคนิคการแทนค่า $u = 2x$ ซึ่งจะได้ $du = 2\,dx$ เพื่อหาปริพันธ์ได้เป็น
\[ \int e^{2x} \, dx = \int e^u \, \frac{1}{2} \, du = \frac{1}{2} e^u + C = \frac{1}{2}e^{2x} + C\]
ฉะนั้น เราเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น

:::





:::solution
(ต่อ)
\begin{eq*}
\int_{-\infty}^{0} e^{2x} \,dx &=& \limt{-\infty} \int_{t}^{0} e^{2x} \,dx

&=& \limt{-\infty} \frac{1}{2}e^{2x} \Big|_t^{0} 

&=& \limt{-\infty} \frac{1}{2}e^0 - \frac{1}{2}e^t = \frac{1}{2}
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_{-\infty}^{0} e^{2x} \,dx = \frac{1}{2}$

:::






:::example

จงพิจารณาว่า $\int_{-\infty}^{1} xe^{-x^2} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราใช้เทคนิคการแทนค่า $u = -x^2$ ซึ่งจะได้ $du = -2x\,dx$ เพื่อหาปริพันธ์ได้เป็น
\[ \int xe^{-x^2} \, dx = \int xe^{u} \frac{du}{-2x} = -\frac{1}{2} \int e^u \, du= -\frac{1}{2}e^u + C = -\frac{1}{2} e^{-x^2} + C\]
ฉะนั้น เราเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น

:::





:::solution
(ต่อ)
\begin{eq*}
\int_{-\infty}^{1}xe^{-x^2} \,dx &=& \limt{-\infty} \int_{t}^1 xe^{-x^2} \,dx

&=& \limt{-\infty} \left( -\frac{1}{2} e^{-x^2} \right) \Big|_t^{1} 

&=& \limt{-\infty} \left( - \frac{1}{2}e^{-1}\right) - \left(- \frac{1}{2}e^{-t^2} \right) = -\frac{1}{2e}
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_{-\infty}^{1} xe^{-x^2} \,dx = -\frac{1}{2e}$

:::






:::example

จงพิจารณาว่า $\int_{-\infty}^{0} \frac{1}{(4-x)^2} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เราใช้เทคนิคการแทนค่า $u = 4-x$ ซึ่งจะได้ $du = -\,dx$ เพื่อหาปริพันธ์ได้เป็น
\[ \int \frac{1}{(4-x)^2} \, dx = \int \frac{1}{u^2} (-du) = \frac{1}{u} + C = \frac{1}{4-x} + C\]
ฉะนั้น เราเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น

:::





:::solution
(ต่อ)
\begin{eq*}
\int_{-\infty}^{0} \frac{1}{(4-x)^2} \,dx &=& \limt{-\infty} \int_{t}^0 \frac{1}{(4-x)^2} \,dx

&=& \limt{-\infty} \left( \frac{1}{4-x} \right) \Big|_t^{0} 

&=& \limt{-\infty} \left( \frac{1}{4-0} \right) - \left( \frac{1}{4-t} \right) = \frac{1}{4}
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_{-\infty}^{0} \frac{1}{(4-x)^2} \,dx = \frac{1}{4}$

:::







:::example

จงพิจารณาว่า $\int_{-\infty}^{0} \frac{1}{x^2-3x+2} \,dx$ ลู่เข้าหรือลู่ออก พร้อมหาค่าของปริพันธ์ถ้าลู่เข้า

:::


:::solution

เนื่องจากเราแยกตัวประกอบตัวส่วนได้เป็น 
\[x^2 - 3x + 2 = (x-1)(x-2)\]
เราจึงสามารถใช้เทคนิคการแยกเศษส่วนย่อย โดยกำหนดให้
\[ \frac{1}{x^2-3x+2} = \frac{A}{x-1} + \frac{B}{x-2} \qquad \longrightarrow \qquad 1 = A(x-2 ) + B(x-1) \]
เมื่อแก้สมการแล้วจะได้ $A = -1, B = 1$ ฉะนั้น เราเปลี่ยนปริพันธ์ไม่ตรงแบบให้เป็นลิมิตตามนิยามและคำนวณออกมาได้เป็น

:::





:::solution
(ต่อ)
\begin{eq*}
&&\int_{-\infty}^{0} \frac{1}{x^2-3x+2} \,dx 

&=& \limt{-\infty} \int_{t}^0 \left( \frac{-1}{x-1} + \frac{1}{x-2}\right) \,dx

&=& \limt{-\infty} \left( -\ln|x-1| + \ln|x-2| \right) \Big|_t^{0} 

&=& \limt{-\infty} \left( -\ln (1-x) + \ln(2-x) \right) \Big|_t^{0} \boxed{\text{ถ้า $y < 0$ แล้ว $|y| = -y$}}

&=& \limt{-\infty} \left( \ln \frac{2-x}{1-x} \right) \Big|_t^{0} \mathnote{สมบัติการลบ $\ln x - \ln y = \ln \frac{x}{y}$}
\end{eq*}

:::





:::solution
(ต่อ)
\begin{eq*}
&& \limt{-\infty} \left( \ln \frac{2-x}{1-x} \right) \Big|_t^{0} 

&=& \limt{-\infty} \left(\ln \frac{2-0}{1-0} \right) - \left( \ln \frac{2-t}{1-t} \right) 

&=& \ln 2 - \limt{-\infty}\ln \left( 1 + \frac{1}{1-t} \right) 

&=& \ln 2 - \ln (1+0) = \ln 2
\end{eq*}
ฉะนั้น เป็นปริพันธ์ไม่ตรงแบบที่ลู่เข้า โดยที่ $\int_{-\infty}^{0} \frac{1}{x^2-3x+2} \,dx = \frac{1}{4}$

:::
