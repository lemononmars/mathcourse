## สมการอนุพันธ์เชิงเส้น

สมการอนุพันธ์รูปแบบต่อมาที่เราจะศึกษา คือสมการที่ค่าอนุพันธ์ $y^{(n)}$ หรือ $\dyx[n]$ ที่ไม่ซับซ้อนมากนัก นั่นคือมีเลขชี้กำลังเป็น 1 เท่านั้น 

:::definition

**สมการเชิงอนุพันธ์เชิงเส้น** คือสมการที่สามารถเขียนอยู่ในรูป 
\begin{eq}
a_n(x) \dyx[n] + a_{n-1}(x) \dyx[n-1] + \cdots + a_1(x) \dyx + a_0(x) y &=& q(x) 

\text{หรือ } a_n(x) y^{(n)} + a_{n-1}(x) y^{(n-1)} + \cdots + a_1(x) y' + a_0(x) y &=& q(x)
\end{eq}

:::






:::example

สมการต่อไปนี้เป็นสมการอนุพันธ์เชิงเส้น 
\begin{eq*}
\dyx[2] + \dyx + y &=& e^{2x} 

\dyx[10] - x^3\dyx[5] + x^2\dyx &=& 0 

y^{(5)} - x^2 y' &=& \sin 4x 

y' - y &=& 1
\end{eq*}

:::






:::example

สมการต่อไปนี้**ไม่**เป็นสมการอนุพันธ์เชิงเส้น 
\begin{eq*}
\left(\dyx\right)^3 &=& x^3 

\dyx + y^4 &=& \ln x 

\dyx[4] - \dyx[3] \dyx[2] + y &=& 0 

y^{(5)} - \frac{x}{y} &=& \sin 4x
\end{eq*}

:::






## สมการอนุพันธ์เชิงเส้นอันดับหนึ่ง


:::definition

**สมการเชิงอนุพันธ์เชิงเส้นอันดับหนึ่ง** คือสมการที่อยู่ในรูป
\begin{equation}
\dyx + p(x)y = q(x) 
\end{equation}

:::



:::example



- $\dyx + 4y = x^2$

- $\dyx - x^2 y = e^x$

- $y' - e^x y= e^{2x}$

- $y' + \frac{1}{x^2+1} y = \tan x$


:::
