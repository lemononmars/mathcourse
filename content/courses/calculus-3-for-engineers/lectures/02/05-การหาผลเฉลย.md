## การหาผลเฉลยของสมการแม่นตรง (1/2)


:::slide


:::remark



- หาปริพันธ์ของ $M(x,y)$ เทียบกับ $x$ ได้เป็น
\begin{equation}
u(x,y) = \int M(x,y) \, dx + g(y)
\end{equation}
โดยที่ $g(y)$ เป็นฟังก์ชันที่มีแต่ตัวแปร $y$ ที่เรายังไม่ทราบค่าในขณะนี้ 

- นำ \eqref{eq:exact1} มาหาอนุพันธ์เทียบกับ $y$ จะได้
\begin{eq}
\pd{u}{y} (x,y) &=& \pd{}{y} \int M(x,y) \, dx + g'(y) \nonumber 

g'(y) &=& \pd{u}{y} - \pd{}{y} \int M(x,y) \, dx \nonumber 

&=& N(x,y) - \pd{u}{y} \int M(x,y) \, dx 
\end{eq}


:::


:::





## การหาผลเฉลยของสมการแม่นตรง (2/2)


:::slide


:::remark


\setcounter{enumi}{2}

- นำ \eqref{eq:exact2} มาหาปริพันธ์เทียบกับ $y$ จะได้ 
\begin{equation} 
g(y) = \int \left( N(x,y) - \pd{}{y} \int M(x,y) \, dx \right) \, dy
\end{equation}

- นำ $g(y)$ ที่ได้จาก \eqref{eq:exact3} มาแทนค่าใน \eqref{eq:exact1} เพื่อหา $u(x,y)$ และทำให้ได้ผลเฉลยเป็น 
\[ u(x,y) = C\]
โดยที่ $C$ เป็นค่าคงตัว ซึ่งเราอาจจัดรูปต่อให้เป็น $y = f(x)$ ได้


:::


:::






:::example

จงหาผลเฉลยของสมการ 
\[(2x+3y) \, dx + (3x+2)\, dy = 0\]

:::


:::slide


:::solution

ก่อนอื่นต้องทดสอบก่อนว่าเป็นสมการแม่นตรงหรือไม่ ถ้าให้ $M(x,y) = 2x+3y$ และ $N(x,y) = 3x+2$ แล้ว 
\[ \pd{M}{y} = \pd{}{y}(2x+3y) = 3 \quad \text{ และ }\quad \pd{N}{x} =\pd{}{x} (3x+2) = 3\] 
เนื่องจาก $\pd{M}{y} = \pd{N}{x}$ เราจึงสามารถหาผลเฉลยด้วยวิธีการของสมการแม่นตรงได้

:::


:::





:::slide


:::solution
(ต่อ)


- เริ่มจากหาปริพันธ์ของ $M(x,y)$ เทียบกับ $x$ ได้เป็น
\begin{eq}
u(x,y) &=& \int M(x,y) \, dx + g(y) 

&=& \int (2x+3y) \, dx + g(y) \nonumber 

&=& x^2 + 3yx + g(y) + C_1 
\end{eq} 

- หาอนุพันธ์ย่อยของ $u(x,y)$ จาก \eqref{eq:exactexample2} เทียบกับ $y$ จะได้
\begin{eq*} 
\pd{u}{y} &=& \pd{}{y} x^2 + 3yx + g(y) + C_1 

3x+2 &=& 3x + g'(y)

g'(y)&=& = 2
\end{eq*}


:::


:::





:::slide


:::solution
(ต่อ)

\setcounter{enumi}{2}

- หาปริพันธ์จาก $g'(y) = 2$ ได้
\[g(y) = 2y + C_2\]

- นำ $g(y)$ ที่ได้กลับไปแทนในสมการ \eqref{eq:exactexample1} จะได้
\[ u(x,y) = x^2 + 3yx + 2y + C_1 + C_2\] 

- สรุปว่า ผลเฉลยของสมการคือ $u(x,y) = C$ นั่นคือ
\[ x^2+3yx + 2y + C_1 + C_2 = C\] 
ซึงเราสามารถรวมค่าคงตัวให้เป็น $C-C_1-C_2 = C_3$ และจัดรูปต่อ ได้เป็น
\[ y = \frac{- x^2 + C_3}{3x+2} \] 


:::


:::




**หมายเหตุ 1**: ถ้าเราเข้าใจขั้นตอนการหาผลเฉลยของสมการแม่นตรงแล้ว เราสามารถข้ามไปใช้สูตรได้ทันที ซึ่งสูตรคือ
\[ u(x,y) = \int M(x,y) \, dx + \int N(x,y)\, dy - \int \left( \pd{}{y} \int M(x,y) \, dx \right) \, dy \] 
และผลเฉลยของสมการอนุพันธ์ $M(x,y)\, dx + N(x,y) \, dy = 0$ คือ 
\[ u(x,y) = C\] 



**หมายเหตุ 2**: การหาผลเฉลยด้วยสมการแม่นตรงมีข้อจำกัดมาก เช่น สมการอนุพันธ์
\[ x^2 y \, dx + xy^2 \, dy = 0\]

:::slide

เป็นสมการแม่นตรง และมีผลเฉลยเป็น $x^2y^2 = C$ แต่ถ้าเราหารทั้งสองฝั่งของสมการด้วย $x$ จะได้สมการอนุพันธ์
\[ xy \, dx + y^2 \,dy = 0\]
ที่แม้ว่าจะมีผลเฉลยเดียวกัน แต่ก็ไม่ใช่สมการแม่นตรงอีกต่อไป เนื่องจาก $\pd{}{y} xy = x$ แต่ $\pd{}{x} x^2 = 2x$ ฉะนั้น จึงต้องศึกษาว่าใช้ตัวคูณใดเพื่อแปลงจากสมการใด ๆ ให้เป็นสมการแม่นตรง ซึ่งมีชื่อเรียกว่า ``ตัวประกอบปริพันธ์'' (Integrating Factor) ซึ่งอยู่นอกเหนือจากขอบเขตของวิชานี้

:::
