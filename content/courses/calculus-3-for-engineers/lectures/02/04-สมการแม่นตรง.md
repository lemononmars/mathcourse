## ที่มาของสมการแม่นตรง


:::slide

ถ้ากำหนดสมการอนุพันธ์ในรูป
\[ M(x,y) dx + N(x,y) dy = 0\] 
สังเกตได้ว่า สมการนี้คล้ายกับอนุพันธ์รวม (total differential) เมื่อกำหนดฟังก์ชัน $u(x,y)$ มาให้ จะได้ว่า 
\[ du = \pd{u}{x} \, dx + \pd{u}{y} \, dy\] 
เราจึงตั้งข้อสังเกตได้ว่า ถ้าเราสามารถหาฟังก์ชัน $u(x,y)$ ที่ทำให้
\[ M(x,y) = \pd{u}{x} \quad \text{ และ } \quad N(x,y) = \pd{u}{y}\] 
เราก็จะสามารถแก้สมการอนุพันธ์ได้เช่นกัน

:::





## สมการอนุพันธ์แม่นตรง


:::definition

สมการอนุพันธ์แม่นตรง คือสมการที่สามารถเขียนอยู่ในรูป
\begin{equation}
M(x,y)\, dx + N(x,y) \, dy = 0
\end{equation} 
โดยที่ $M(x,y)$ และ $N(x,y)$ เป็นฟังก์ชันสองตัวแปรที่มีสมบัติว่า มีฟังก์ชันสองตัวแปร $u(x,y)$ ที่ทำให้
\begin{equation}
M(x,y) = \pd{u}{x} (x,y) \quad \text{ และ } \quad N(x,y) = \pd{u}{y} (x,y)
\end{equation}

:::






:::example

จงหาว่าสมการต่อไปนี้เป็นสมการแม่นตรงหรือไม่


- $y \, dx + x\,dy = 0$

- $2x\, dx + 2y\,dy = 0$


:::


:::solution



- เป็นสมการแม่นตรง เนื่องจากมีฟังก์ชัน $u(x,y) = xy$ ที่ทำให้
\[ M(x,y) = y = \pd{u}{x} \quad \text{ และ } \quad N(x,y) = x = \pd{u}{y}\]

- เป็นสมการแม่นตรง เนื่องจากมีฟังก์ชัน $u(x,y) = x^2+y^2$ ที่ทำให้
\[ M(x,y) = 2x = \pd{u}{x} \quad \text{ และ } \quad N(x,y) = 2y = \pd{u}{y}\]


:::






:::example

จงหาว่าสมการต่อไปนี้เป็นสมการแม่นตรงหรือไม่


- $\cos y\, dx + (-x\sin y) \,dy = 0$ 

- $e^{x-y}\, dx - e^{x-y}\,dy = 0$


:::


:::solution



- เป็นสมการแม่นตรง เนื่องจากมีฟังก์ชัน $u(x,y) = x \cos y$ ที่ทำให้
\[ M(x,y) = \cos y = \pd{u}{x} \quad \text{ และ } \quad N(x,y) = -x\sin y = \pd{u}{y}\] 

- เป็นสมการแม่นตรง เนื่องจากมีฟังก์ชัน $u(x,y) = e^{x-y}$ ที่ทำให้
\[ M(x,y) = e^{x-y} = \pd{u}{x} \quad \text{ และ } \quad N(x,y) = e^{x-y} = -\pd{u}{y}\] 


:::




เนื่องจากเราไม่ทราบแน่ชัดว่าจะสามารถหาฟังก์ชัน $u(x,y)$ ที่ต้องการได้หรือไม่ จึงต้องหาวิธีตรวจสอบก่อน

:::theorem

ถ้า $\pd{M}{y}$ และ $\pd{N}{x}$ เป็นฟังก์ชันต่อเนื่องแล้ว สมการเชิงอนุพันธ์ $M(x,y) \, dx + N(x,y) \, dy = 0$ เป็นสมการแม่นตรงก็ต่อเมื่อ 
\begin{equation}
\pd{M}{y} = \pd{N}{x}
\end{equation}
สำหรับทุกค่า $(x,y)$ ใน $\mathbb{R} \times \mathbb{R}$

:::

ถ้าตรวจสอบว่าเป็นสมการแม่นตรงเรียบร้อยแล้ว เราสามารถดำเนินการหาผลเฉลย (ที่จะกล่าวถึงต่อไปนี้) ได้





:::example

จงตรวจสอบว่าสมการอนุพันธ์ต่อไปนี้ เป็นสมการแม่นตรงหรือไม่


- $y \, dx + x\,dy = 0$

- $y^3 \, dx + x^3 \,dy = 0$


:::


:::solution



- เราคำนวณได้ว่า $\pd{M}{y} = \pd{y}{y} = 1$ และ $ \pd{N}{x} = \pd{x}{x} = 1$

เนื่องจาก $\pd{M}{y} = \pd{N}{x}$ เราจึงสรุปได้ว่าสมการนี้เป็นสมการแม่นตรง 

- เราคำนวณได้ว่า $\pd{M}{y} = \pd{y^3}{y} = 3y^2 $ และ $\pd{N}{x} = \pd{x^3}{x} = 3x^2$ 

เนื่องจาก $\pd{M}{y} \neq \pd{N}{x}$ เราจึงสรุปได้ว่าสมการนี้**ไม่เป็น**สมการแม่นตรง 


:::
