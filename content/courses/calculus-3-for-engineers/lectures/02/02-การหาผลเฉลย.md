## หลักการหาผลเฉลยสมการเชิงอนุพันธ์เชิงเส้นอันดับหนึ่ง

ก่อนอื่น เราสามารถสังเกตว่าจากสมการ
\[ \dyx + p(x)y = q(x)\] 

:::slide

พจน์ด้านซ้ายของสมการ มีรูปแบบคล้ายกับสูตรอนุพันธ์ของผลคูณฟังก์ชัน
\[\dx (\, f(x) \mu(x) ) = f\,'(x) \mu(x) + f(x)\mu'(x)\]
ซึ่งถ้าให้ $y=f(x)$ จะได้
\[\dx (\, y \mu(x) ) = \dyx \mu(x) + y \mu'(x)\]
ฉะนั้น เป้าหมายของเราคือ หาฟังก์ชัน $\mu(x)$ มาคูณ $\dyx + p(x)y$ เพื่อให้ได้ 
\[\mu(x) \left( \dyx + p(x)y \right)= \dyx g(x) + y g'(x)\]

:::





## วิธีหาผลเฉลยสมการเชิงอนุพันธ์เชิงเส้นอันดับหนึ่ง (1/2)


:::slide


:::remark



- หาตัวประกอบปริพันธ์ 
\[ \mu(x) = e^{\int p(x)\, dx}\] 
โดยละค่า $C$ ที่ได้จาก $\int p(x) \, dx$ ไว้ 

- คูณสมการในโจทย์ด้วยตัวประกอบปริพันธ์ จะได้
\[ \mu(x) \dyx + \mu(x) p(x) y = \mu(x) q(x)\] 

- จัดรูปใหม่ด้วยสูตรอนุพันธ์ของผลคูณฟังก์ชัน ได้เป็น 
\[\dx (y\mu(x)) = \mu(x) q(x)\]


:::


:::





## วิธีหาผลเฉลยสมการเชิงอนุพันธ์เชิงเส้นอันดับหนึ่ง (2/2)


:::slide


:::remark


\setcounter{enumi}{3}

- หาปริพันธ์ทั้งสองข้างของสมการ จะได้
\[ y\mu(x) = \int \mu(x)q(x) \, dx\] 
นั่นคือ \[y=\frac{Q(x) + C}{\mu(x)}\] คือผลเฉลยทั่วไปของสมการ เมื่อ $Q(x)$ คือปริพันธ์ของฟังก์ชัน $\int \mu(x)q(x) \, dx$


:::


:::






:::example

จงหาผลเฉลยของสมการอนุพันธ์ 
\[ \dyx + 2y = 3e^x\]

:::


:::slide


:::solution

ก่อนอื่นเราต้องตรวจสอบก่อนว่าสมการนี้เป็นสมการอนุพันธ์เชิงเส้นอันดับหนึ่ง ซึ่งเป็นจริง โดยที่
\[ p(x) = 2\, \quad q(x) = 3e^x\]


- หาตัวประกอบปริพันธ์จากสูตร \mathnote{ $\mu(x) = e^{\int p(x)\, dx}$} โดยละค่า $C$ ที่จะได้จากปริพันธ์ไว้ นั่นคือ 
\[ \mu(x) = e^{\int 2 \, dx} = e^{2x}\] 


:::


:::





:::slide


:::solution
(ต่อ)

\setcounter{enumi}{1}

- คูณสมการในโจทย์ด้วยตัวประกอบปริพันธ์ $\mu(x) = e^{2x}$ จะได้
\begin{eq*}
\mu(x) \dyx + \mu(x) p(x) y &=& \mu(x) q(x) 

e^{2x} \dyx + 2 e^{2x} y &=& e^{2x} 3 e^{x}
\end{eq*}

- จัดรูปใหม่ด้วยสูตรอนพันธ์ของผลคูณฟังก์ชัน ได้เป็น 
\[ \dx \left(y e^{2x} \right) = 3e^{3x}\] 


:::


:::





:::slide


:::solution
(ต่อ)

\setcounter{enumi}{3}

- หาปริพันธ์ทั้งสองข้างของสมการ จะได้
\begin{eq*}
\int \left( \dx (ye^{2x})\right)\, dx &=& \int 3e^{3x} \, dx 

ye^{2x} &=& e^{3x} + C 

y &=& e^{-2x} \left( e^{3x} + C \right) 

&=& e^x + C e^{-2x} 
\end{eq*} 
นั่นคือ ผลเฉลยของสมการอนุพันธ์ $\dyx + 2y = 3e^x$ คือฟังก์ชัน $y = e^x + Ce^{-2x}$ เมื่อ $C$ เป็นค่าคงตัวใด ๆ


:::


:::






:::example

จงหาผลเฉลยของสมการอนุพันธ์ 
\[ \dyx - \frac{y}{x} = 3x^3\]

:::


:::slide


:::solution

ตรวจสอบก่อนว่าเป็นสมการอนุพันธ์เชิงเส้นอันดับหนึ่งหรือไม่ ซึ่งเป็นจริง โดยที่
\[ p(x) = -\frac{1}{x}\, \quad q(x) = 3x^3\]


- หาตัวประกอบปริพันธ์จากสูตร \mathnote{ $\mu(x) = e^{\int p(x)\, dx}$} โดยละค่า $C$ ไว้ นั่นคือ
\[ \mu(x) = e^{\int -\frac{1}{x} \, dx} = e^{-\ln x} = \frac{1}{x}\]


:::


:::





:::slide


:::solution
(ต่อ)

\setcounter{enumi}{1}

- คูณสมการในโจทย์ด้วยตัวประกอบปริพันธ์ $\mu(x) = \frac{1}{x}$ จะได้
\begin{eq*}
\mu(x) \dyx + \mu(x) p(x) y &=& \mu(x) q(x) 

\frac{1}{x} \dyx - \frac{1}{x^2} y &=& \frac{1}{x} (3x^3)
\end{eq*} 

- จัดรูปใหม่ด้วยสูตรอนพันธ์ของผลคูณฟังก์ชัน ได้เป็น 
\[ \dx \left(\, y \frac{1}{x} \right) = 3x^2\]


:::


:::





:::slide


:::solution
(ต่อ)

\setcounter{enumi}{3}

- หาปริพันธ์ทั้งสองข้างของสมการ จะได้
\begin{eq*}
\int \left( \dx \left(y \frac{1}{x} \right)\right)\, dx &=& \int 3x^2 \, dx 

y \frac{1}{x} &=& x^3 + C 

y &=& x \left( x^3 + C \right) 

&=& x^4+ C x
\end{eq*} 
นั่นคือ ผลเฉลยของสมการอนุพันธ์ $\dyx - \frac{y}{x} = 3x^3$ คือฟังก์ชัน $y = x^4 + Cx$ เมื่อ $C$ เป็นค่าคงตัวใด ๆ


:::


:::
