## นิยามสนามเวกเตอร์


:::definition สนามเวกเตอร์

กำหนดฟังก์ชัน $f(x,y)$ และ $g(x,y)$ เป็นฟังก์ชันสองตัวแปร แล้วสนามเวกเตอร์ (vector field) ในปริภูมิสองมิติจะอยู่ในรูป
\begin{equation}
\vec{F}(x,y) = \leftlangle f(x,y), +g(x,y) \rightangle
\end{equation}

:::

สังเกตว่า สนามเวกเตอร์ก็คือฟังก์ชันค่าเวกเตอร์ ที่เราได้ศึกษามาแล้วในวิชาแคลคูลัส 2 สำหรับวิศวกรที่อยู่ในรูป
\[ \vrt = \leftlangle f(t), +g(t) \rightangle \]
โดยเปลี่ยนจากฟังก์ชันตัวแปรเดียว $t$ เป็นฟังก์ชันสองตัวแปร $x$ และ $y$




:::example

กำหนดสนามเวกเตอร์ $\vec{F}(x,y) = \leftlangle xy, +(x+y) \rightangle$ จงหา


- $\vec{F}(2,3)$

- $\vec{F}(x, 0)$

- $\vec{F}(t,t^2)$


:::


:::solution

แทนค่า $x$ และ $y$ ตามที่โจทย์กำหนดมาให้ได้ทันที ดังต่อไปนี้


- $\vec{F}(2,3) = \leftlangle (2)(3), +(2+3) \rightangle = \leftlangle 6, +5 \rightangle$

- $\vec{F}(x,0) = \leftlangle (x)(0), +(x+0) \rightangle = x\mathbf{j}$

- $\vec{F}(t,t^2) = \leftlangle (t)(t^2), +(t+t^2) \rightangle = \leftlangle t^3, +(t+t^2) \rightangle$


:::





## การวาดกราฟของสนามเวกเตอร์

เราสามารถวาดกราฟของสนามเวกเตอร์ได้ โดยการวาดเวกเตอร์ $F(x,y)$ ที่จุด $(x,y)$ ดัง\figref{fig:vector_field_graph}



:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.5]
\begin{scope}[xshift = -8cm]
\axes{-3}{3}{-3}{3}
\draw[blue, ->] (2,2) -- (3,3) node[right, pos = 0.5] {$\vec{F}(x,y)$};
\filldraw[red] (2,2) circle[radius = 0.05cm] node[below] {$(x,y)$};
\end{scope}
\axes{-3}{3}{-3}{3}
\foreach \x in {-2,-1.5,...,2}
{
	\foreach \y in {-2,-1.5,...,2}
	{
		\draw[blue, ->] (\x, \y) --+ (0.25*\x, 0.25*\y);
		\filldraw[fill = red] (\x,\y) circle[radius = 0.02cm];
	}
}
\end{tikzpicture}
:::
