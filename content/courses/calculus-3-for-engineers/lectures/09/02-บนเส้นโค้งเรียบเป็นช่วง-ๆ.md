## ที่มา

ในบางครั้งเส้นโค้ง $C$ ไม่ใช่เส้นโค้งเรียบที่หาปริพันธ์ได้ทุกจุด แต่สามารถแบ่งออกเป็นเส้นโค้งย่อย ที่แต่ละเส้นโค้งหาปริพันธ์ได้ 


:::definition

ถ้าเส้นโค้ง $C$ ประกอบด้วยเส้นโค้งย่อย $C_1, C_2, C_3, \ldots, C_n$ ต่อเนื่องกัน จะเรียกเส้นโค้ง $C$ ว่า **เส้นโค้งเรียบเป็นช่วง ๆ** (piecewise smooth curve) โดยจะเขียนด้วย $C = C_1 \cup C_2 \cup \cdots \cup C_n$ และ
\[ \int_C f(x,y) \, ds = \int_{C_1} f(x,y) \, ds + \int_{C_2} f(x,y) \, ds + \cdots + \int_{C_n} f(x,y) \, ds\]

:::

นิยามนี้ถูกใช้เมื่อเราหาความสัมพันธ์ระหว่างปริพันธ์บนพื้นผิว (เช่น สี่เหลี่ยมผืนผ้า) และปริพันธ์บนเส้นรอบรูปปิด ที่จะได้ศึกษาในวิชาต่อ ๆ ไป






:::example

จงหาปริพันธ์ตามเส้น $\int_C x^2 - y^2 \, ds$ เมื่อ $C$ คือเส้นตรงจากจุด $(0,0)$ ไปยังจุด $(1,0)$ แล้วเคลื่อนที่เป็นวงกลมไปยังจุด $(0,1)$

:::



:::tikz TikZ diagram
\begin{tikzpicture}[scale = 2]
\draw[<->] (-0.2,0) -- (1.2,0) node[right] {$x$};
\draw[<->] (0,-0.2) -- (0,1.2) node[above] {$y$};
\draw[->, red, very thick] (0,0) -- (1,0) node[pos = 0.5, below] {$C_1$};
\draw[->, blue, very thick] (1,0) arc [start angle = 0, end angle = 90, radius = 1cm] node[pos = 0.5, above] {$C_2$};
\draw (1,0) -- (1,-0.1) node[below] {$1$};
\end{tikzpicture}
:::


*เส้นโค้ง $C$ สำหรับตัวอย่าง \theexample*





:::solution

แบ่งเส้นโค้ง $C$ ออกเป็นเส้นโค้ง 2 เส้น ซึ่งมีสมการเชิงเวกเตอร์ดังนี้
\[**C_1**: (0,0) \text{ ถึง } (1,0) \qquad **C_2**: (1,0) \text{ ถึง } (0,1) \text{ บนโค้งวงกลม } \]


เส้นโค้ง $**C_1**$ มีสมการพารามิเตอร์เป็น $ \vrt = (1-t)\langle 0,0 \rangle + t \langle 1, 0 \rangle = \langle t, 0 \rangle$ นั่นคือ
\[x(t) = t, \qquad y(t) = 0\]
จะได้
\[dx = \, dt, \qquad dy = 0 \, dt\]
\[\| \dvrt \| = \sqrt{\left( \frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} = \sqrt{1^2 + 0^2} = 1\]
ฉะนั้น
\begin{eq*}
\int_{**C_1**} (x^2-y^2)\, ds = \int_0^1 (t^2 - 0^2) (1) \, dt = \int_0^1 t^2 \, dt = \frac{1}{3}
\end{eq*}

:::





:::solution
(ต่อ)
เส้นโค้ง $**C_2**$ เป็นเส้นโค้งวงกลม จึงมีสมการพารามิเตอร์เป็น $ \vrt = \langle \cos t, \sin t \rangle$ โดยจุดเริ่มคือ $(1,0)$ เมื่อ $t=0$ และจุดสิ้นสุด $(0,1)$ เมื่อ $t = \frac{\pi}{2}$ นั่นคือ
\[x(t) = \cos t, \qquad y(t) = \sin t\]
\[dx = -\sin t \, dt, \qquad dy = \cos t \, dt\]
\[ \| \dvrt \| = \sqrt{\left( \frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} = \sqrt{(-\sin t)^2 + (\cos t)^2} = 1\]
ฉะนั้น
\begin{eq*}
\int_{**C_2**} (x^2 - y^2) \, ds &=& \int_0^{\pi/2} \Big((\cos t)^2 - (\sin t)^2\Big) (1) (dt) 

&=& \int_0^{\pi/2} \cos 2t \, dt \boxed{\text{เอกลักษณ์ตรีโกณมิติ}}

&=& \frac{1}{2} \sin (2t) \Big|_{0}^{\pi/2} = \frac{1}{2}(\sin \pi - \sin 0) = 0
\end{eq*}

:::





:::solution
(ต่อ)
ฉะนั้น
\begin{eq*}
\int_C x^2 - y^2 \, ds &=& \int_{**C_1**} x^2-y^2 \, ds + \int_{**C_2**} x^2-y^2 \, ds 

&=& \frac{1}{3} + 0 

&=& \frac{1}{3}
\end{eq*}

:::







:::example

จงหาปริพันธ์ตามเส้น $\int_C xy \, dx + x^2 \,dy$ เมื่อ $C$ คือเส้นรอบรูปสามเหลี่ยมที่มีจุดยอดเป็นจุด $(0,0), (3,0)$ และ $(3,2)$ ที่หมุนทวนเข็มนาฬิกา

:::



:::tikz TikZ diagram
\begin{tikzpicture}
\draw[<->] (-0.2,0) -- (4.2,0) node[right] {$x$};
\draw[<->] (0,-0.2) -- (0,2.2) node[above] {$y$};
\draw[->, red, very thick] (0,0) -- (3,0) node[pos = 0.5, below] {$C_1$};
\draw[->, blue, very thick] (3,0) -- (3,2) node[pos = 0.5, right] {$C_2$};
\draw[->, teal, very thick] (3,2) -- (0,0) node[pos = 0.5, above left] {$C_3$};
\draw (3,0) --+ (0,-0.1) node[below] {$3$};
\draw (0,2) --+ (-0.1,0) node[left] {$2$};
\end{tikzpicture}
:::


*เส้นโค้ง $C$ สำหรับตัวอย่าง \theexample*





:::solution

แบ่งเส้นโค้ง $C$ ออกเป็นเส้นตรง 3 เส้น ซึ่งมีสมการเชิงเวกเตอร์ดังนี้
\[**C_1**: (0,0) \text{ ถึง } (3,0) \qquad **C_2**: (3,0) \text{ ถึง } (3,2) \qquad **C_3**: (3,2) \text{ ถึง } (0,0) \qquad \]


เส้นโค้ง $**C_1**$ มีสมการพารามิเตอร์เป็น $ \vrt = (1-t)\langle 0,0 \rangle + t \langle 3, 0 \rangle = \langle 3t, 0 \rangle$ นั่นคือ
\[x(t) = 3t, \qquad y(t) = 0\]
จะได้
\[dx = 3\, dt, \qquad dy = 0 \, dt\]
ฉะนั้น
\begin{eq*}
\int_{**C_1**} xy \, dx + x^2 \, dy &=& \int_0^1 (3t)(0) (3\,dt) + (3t)^2 (0\, dt)= 0
\end{eq*}

:::





:::solution
(ต่อ)
เส้นโค้ง $**C_2**$ มีสมการพารามิเตอร์เป็น $ \vrt = (1-t)\langle 3,0 \rangle + t \langle 3, 2 \rangle = \langle 3, 2t \rangle$ นั่นคือ
\[x(t) = 3, \qquad y(t) = 2t\]
จะได้
\[dx = 0 \, dt, \qquad dy = 2 \, dt\]
ฉะนั้น
\begin{eq*}
\int_{**C_2**} xy \, dx + x^2 \, dy &=& \int_0^1 (3)(2t) (0\,dt) + (3)^2 (2 \, dt) 

&=& \int_0^1 18 \, dt = 18t \Big|_0^1 = 18 
\end{eq*}

:::





:::solution
(ต่อ)
เส้นโค้ง $**C_3**$ มีสมการพารามิเตอร์เป็น $ \vrt = (1-t)\langle 3,2 \rangle + t \langle 0, 0 \rangle = \langle 3-3t, 2-2t \rangle$ นั่นคือ
\[x(t) = 3-3t, \qquad y(t) = 2-2t\]
จะได้
\[dx = -3 \, dt, \qquad dy = -2 \, dt\]
ฉะนั้น
\begin{eq*}
\int_{**C_3**} xy \, dx + x^2 \, dy &=& \int_0^1 (3-3t)(2-2t) (-3\,dt) + (3-3t)^2 (-2 \, dt) 

&=& \int_0^1 -18(1-t)^2 - 18(1-t)^2 \, dt 

&=&-36 \int_0^1 (1-t)^2 \, dt 

&=& -36 \left(-\frac{(1-t)^3}{3}\right)\Big|_{0}^1 = 36\left(-\frac{(-1)^3}{3}\right) = 12
\end{eq*}

:::





:::solution
(ต่อ)
ฉะนั้น เมื่อนำปริพันธ์ตามเส้นทั้ง 3 เส้นมาบวกกันจะได้
\begin{eq*}
&\int_C xy \, dx + x^2\,dy 

&=& \int_{**C_1**} xy \, dx + x^2\,dy + \int_{**C_2**} xy \, dx + x^2\,dy + \int_{**C_3**} xy \, dx + x^2\,dy 

&=& 0 + 18 +12 = 30
\end{eq*}

:::
