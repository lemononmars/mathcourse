:::remark วิธีการหาผลเฉลยเฉพาะเมื่อ f(x) เป็นพหุนาม

กำหนดสมการเชิงอนุพันธ์
\[y^{(n)} + a_{n-1} y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x)\] 
โดยที่ $f(x)$ เป็นพหุนามดีกรี $n$ **และไม่เป็นผลเฉลยเติมเต็ม** แล้วผลเฉลยเฉพาะจะอยู่ในรูป 
\begin{equation} y_p = A_nx^n + A_{n-1}x^{n-1} + \cdots + A_1x + A_0 \end{equation} 
เมื่อ $A_n, A_{n-1}, \ldots, A_0$ เป็นค่าคงตัว ที่สามารถหาได้จากการแทนค่า $y_p$ ลงไปในสมการเชิงอนุพันธ์

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' + y' + y = 3x+1\] 

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = 3x+1$ ซึ่งเป็นพหุนามดีกรี 1 ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป 
\[y_p = A x + B\] 
ซึ่งมีอนุพันธ์เป็น $y_p' = A$ และ $y_p'' = 0$ ฉะนั้น เราสามารถแทนค่า $y_p, y_p'$ และ $y_p''$ ลงในสมการด้านบน จะได้
\begin{eq*}
y'' + y' + y = (0) + (A) + (Ax + B) &=& 3x + 1 

Ax + (A+B) &=& 3x + 1
\end{eq*}

:::




\[**y_p = A x + B**\]

:::solution
(ต่อ)
\[ Ax + (A+B) = 3x + 1 \] 

เมื่อเทียบสัมประสิทธิ์ของ $x$ และค่าคงตัวทั้งสองข้างของสมการให้เท่ากัน จะได้
\begin{eq*}
A &=& 3 

A + B &=& 1
\end{eq*} 
นั่นคือ $A = 3$ และ $B = -2$ 
ฉะนั้น ผลเฉลยเฉพาะคือ 
\[ y_p = 3x-2 \]

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' - 2y' + y = x^2 + 2x\]

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = x^2 + 2x$ ซึ่งเป็นพหุนามดีกรี 2 ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป
\[y_p = A x^2 + B x + C\] 
ซึ่งมีอนุพันธ์เป็น $y_p' = 2A x + B$ และ $y_p'' = 2A$ ฉะนั้น เราสามารถแทนค่า $y_p, y_p'$ และ $y_p''$ ลงในสมการด้านซ้ายมือ จะได้
\begin{eq*}
y'' - 2y' + y = (2A) - 2(2Ax+B) + (Ax^2 + Bx + C) &=& x^2+2x 

Ax^2 + (-4A+B)x + (2A-2B+C) &=& x^2+2x
\end{eq*}

:::




\[**y_p = A x^2 + B x + C**\]

:::slide


:::solution
(ต่อ)
\[ **Ax^2** + **(-4A+B)x** + **(2A-2B+C)** = **x^2**+**2x** \] 

เมื่อเทียบสัมประสิทธิ์ของ $x^2, x$ และค่าคงตัวทั้งสองข้างของสมการให้เท่ากัน จะได้
\begin{eq*}
A &=& 1 

-4A+B &=& 2 

2A-2B+C &=& 0
\end{eq*} 
นั่นคือ $A = 1, B=6$ และ $C =10$ 
ฉะนั้น ผลเฉลยเฉพาะคือ 
\[ y_p = x^2+6x-10 \]

:::
