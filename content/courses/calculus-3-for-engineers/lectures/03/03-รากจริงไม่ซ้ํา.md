## กรณีที่ 1: รากจริงไม่ซ้ำกัน

ถ้า $m_1$ และ $m_2$ เป็นรากจริงที่ไม่ซ้ำกัน (นั่นคือ $m_1 \neq m_2$) 
:::slide

แล้วเราทราบว่า
\[ y = e^{m_1x}, \quad y = e^{m_2x}\] 
เป็นผลเฉลยของสมการ $ay'' + by' + cy = 0$ และเนื่องจากเรารู้ว่าผลบวกเชิงเส้นของผลเฉลยก็เป็นผลเฉลยด้วย ฉะนั้น เราจึงสรุปได้ว่าผลเฉลยทั่วไปของสมการคือ 

:::note

\[ y = Ae^{m_1x} + Be^{m_2x}\] 

:::

เมื่อ $A$ และ $B$ เป็นค่าคงตัวใด ๆ 

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' - 5y' + 6y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 - 5m +6 = 0$ ถ้าให้ $m_1, m_2$ เป็นรากของสมการนี้ จะได้ว่า
\begin{eq*}
m_1 + m_2 &=& 5 

m_1m_2 &=& 6
\end{eq*} 
นั่นคือ $m_1 = 2$ และ $m_2 = 3$ ทำให้เราทราบว่า $y= e^{2x}$ และ $y = e^{3x}$ เป็นผลเฉลยของสมการเชิงอนุพันธ์ และเนื่องจากผลบวกเชิงเส้นก็เป็นผลเฉลยเช่นกัน ฉะนั้น ผลเฉลยทั่วไปคือ 
\[y = Ae^{2x} + Be^{3x}\]

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' - 2y' - 8y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 -2 m - 8 = 0$ ถ้าให้ $m_1, m_2$ เป็นรากของสมการนี้ จะได้ว่า 
\begin{eq*}
m_1 + m_2 &=& 2 

m_1m_2 &=& -8
\end{eq*} 
นั่นคือ $m_1 = -2$ และ $m_2 = 4$ ทำให้เราทราบว่า $y= e^{-2x}$ และ $y = e^{4x}$ เป็นผลเฉลยของสมการเชิงอนุพันธ์ และเนื่องจากผลบวกเชิงเส้นก็เป็นผลเฉลยเช่นกัน ฉะนั้น ผลเฉลยทั่วไปคือ 
\[y = Ae^{-2x} + Be^{4x}\]

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' - y = 0, \quad y(0) = 0, y'(0) = 2\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 -1 = 0$ ถ้าให้ $m_1, m_2$ เป็นรากของสมการนี้ จะได้ว่า
\begin{eq*}
m_1 + m_2 &=& 0 

m_1m_2 &=& -1
\end{eq*} 
นั่นคือ $m_1 = -1$ และ $m_2 = 1$ ทำให้เราทราบว่า $y= e^{-x}$ และ $y = e^{x}$ เป็นผลเฉลยของสมการเชิงอนุพันธ์ และเนื่องจากผลบวกเชิงเส้นก็เป็นผลเฉลยเช่นกัน ฉะนั้น ผลเฉลยทั่วไปคือ 
\[y = Ae^{-x} + Be^{x}\]

:::





:::solution

(ต่อ) เมื่อได้ผลเฉลยทั่วไปแล้ว เราต้องหาผลเฉลย**เฉพาะ** นั่นคือต้องหาค่าคงตัว $A,B$ ที่ตรงกับเงื่อนไขที่กำหนดไว้ว่า 
\[ y(0) = 0, \quad y'(0) = 2\] 
แทนค่าลงในสมการได้ดังนี้ 
\begin{eq*}
0 = y(0) &=& Ae^{-0} + Be^{0} = A + B 

2 = y'(0) &=& -Ae^{-0} + Be^{0} = -A+B 
\end{eq*}
เมื่อแก้สมการ $A+B = 0, -A+B=2$ ออกมา จะได้คำตอบเป็น $A = -1, B=1$ ดังนั้นผลเฉลย**เฉพาะ**คือ
\[ y = -e^{-x} + e^x\]

:::
