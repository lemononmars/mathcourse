## สมการเอกพันธ์อันดับตั้งแต่ 3 ขึ้นไป

สำหรับสมการเชิงเส้นอันดับ $n$ ระดับขึ้น 1 ที่มีสัมประสิทธิ์เป็นค่าคงตัว 

:::note

\[y^{(n)} + a_{n-1}y^{(n-1)}+ \cdots + a_1y'+ a_0y = 0\]

:::

โดยที่ $n$ มากกว่า 2 
:::slide
เรายังสามารถสร้างสมการลักษณะเฉพาะเป็น

:::note

\[m^n + a_{n-1}m^{n-1} + \cdots + a_1m + a_0 = 0\]

:::

และหารากของพหุนามดีกรี $n$ ได้เช่นเคย โดยผลเฉลยจะอยู่ในรูป $y = e^{mx}, y= e^{rx}\cos sx$ และ $y = e^{rx}\sin sx$ เช่นเดิม ยกเว้นกรณีที่มีรากซ้ำที่ต้องการทฤษฎีบทเพิ่มดังนี้

:::





:::theorem

กำหนดสมการเชิงอนุพันธ์
\[y^{(n)} + a_{n-1}y^{(n-1)}+ \cdots + a_1y'+ a_0y = f(x)\] 
ซึ่งมีสมการลักษณะเฉพาะเป็น
\[m^n + a_{n-1}m^{n-1} + \cdots + a_1m + a_0 = 0\] 
ถ้า $m = m_1$ เป็นรากซ้ำ $k$ ตัว แล้ว 
\begin{eq*}
y &=& A_0e^{m_1x} + A_1xe^{m_1x} + A_2x^2e^{m_1x} + \cdots + A_{k-1}x^{k-1}e^{m_1x} 

&=& e^{m_1x} \left( A_0 + A_1x + A_2x^2 + \cdots + A_{k-1}x^{k-1} \right)
\end{eq*} 
เป็นผลเฉลยของสมการ

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y''' - 3y'' + 3y' - y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^3 -3m^2+3m-1 = 0$ แยกตัวประกอบได้เป็น $(m-1)^3 = 0$ ฉะนั้นจึงมีราก $m=1$ ซึ่งเป็นรากซ้ำ 3 ตัว 

เมื่อใช้ทฤษฎีบท จะได้ผลเฉลยทั่วไปเป็น 
\[y = e^x(A_0 + A_1x + A_2x^2)\]

:::
