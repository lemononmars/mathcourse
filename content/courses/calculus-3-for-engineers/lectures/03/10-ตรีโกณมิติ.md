:::remark วิธีการหาผลเฉลยเฉพาะเมื่อ f(x) เป็นฟังก์ชัน \sin หรือ \cos

กำหนดสมการเชิงอนุพันธ์
\[ y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x)\] 
โดยที่ $f(x) = a\sin kx + b\cos kx$ **และไม่เป็นผลเฉลยเติมเต็ม** แล้ว ผลเฉลยเฉพาะจะอยู่ในรูป
\begin{equation} y_p = A\sin kx + B\cos kx \end{equation} 
เมื่อ $A,B$ เป็นค่าคงตัว ที่สามารถหาได้จากการแทนค่า $y_p$ ลงไปในสมการเชิงอนุพันธ์

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' - y' + 2y = 4\sin 2x\]

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = 4\sin 2x$ ซึ่งเป็นฟังก์ชันตรีโกณมิติ ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป
\[y_p = A \sin 2x + B\cos 2x\] 
ซึ่งมีอนุพันธ์เป็น 
\begin{eq*}
y_p' &=& 2A\cos 2x - 2B\sin 2x 

y_p'' &=& -4A\sin 2x - 4B\cos 2x
\end{eq*}

:::





:::solution
(ต่อ) ฉะนั้น เราสามารถแทนค่า $y_p, y_p'$ และ $y_p''$ ลงในสมการด้านบน ได้เป็น
\begin{eq*}
& & y'' - y' + 2y 

&=& (4A\sin 2x - 4B\cos 2x) - (2A\cos 2x - 2B\sin 2x) + 2( A \sin 2x + B\cos 2x) 

&=&(6A +2B) \sin 2x + (-2B-2A)\cos 2x
\end{eq*} 
นั่นคือ
\[ (6A +2B) \sin 2x + (-2B-2A) \cos 2x = 4\sin 2x\] 
เมื่อเทียบสัมประสิทธิ์ของ $x$ และค่าคงตัวทั้งสองข้างของสมการให้เท่ากัน จะได้
\begin{eq*}
6A+2B &=& 4 

-2A-2B &=& 0
\end{eq*} 
นั่นคือ $A = 1$ และ $B = -1$ 
ฉะนั้น ผลเฉลยเฉพาะคือ
\[ y_p = \sin 2x - \cos 2x \]

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' + 2y' = 12\sin (-3x) -18\cos (-3x) \]

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = 12\sin (-3x) -18\cos (-3x)$ ซึ่งเป็นฟังก์ชันตรีโกณมิติที่ฟังก์ชันด้านในเป็น $-3x$ เหมือนกัน ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป
\[y_p = A\sin (-3x)+ B\cos (-3x)\] 
ซึ่งมีอนุพันธ์เป็น 
\begin{eq*}
y_p' &=& -3A\cos (-3x) + 3B\sin (-3x) 

y_p'' &=& -9A\sin (-3x) - 9B\cos (-3x)
\end{eq*} 
ฉะนั้น เราสามารถแทนค่า $y_p'$ และ $y_p''$ ลงในสมการด้านบน จะได้

:::





:::solution
(ต่อ)
\begin{eq*}
& & y'' +2y' 

&=& (-9A\sin (-3x) - 9B\cos (-3x)) + 2(-3A\cos (-3x) + 3B\sin (-3x)) 

&=&(-9A+6B) \sin (-3x) + (-9B-6A)\cos (-3x)
\end{eq*} 
นั่นคือ 
\[**(-9A+6B) \sin (-3x)** + **(-9B-6A)\cos (-3x)** = **12\sin (-3x)** **-18\cos (-3x)**\] 
เมื่อเทียบสัมประสิทธิ์ของ $x$ และค่าคงตัวทั้งสองข้างของสมการให้เท่ากัน จะได้
\begin{eq*}
-9A+6B &=& 12 

-9B-6A &=& -18
\end{eq*} 
นั่นคือ $A = 0$ และ $B = 2$ 
ฉะนั้น ผลเฉลยเฉพาะคือ 
\[ y_p = 0 \sin (-3x) + 2\cos(-3x) = 2\cos (-3x) \]

:::
