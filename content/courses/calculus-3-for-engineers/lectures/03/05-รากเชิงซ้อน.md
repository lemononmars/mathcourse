## กรณีที่ 3: รากเชิงซ้อน

ถ้า $m_1$ และ $m_2$ เป็นรากเชิงซ้อน 
:::slide
จะสามารถเขียนรากอยู่ในรูป
\[ m_1 = r+si, \quad m_2= r-si\] 
โดยเราเรียก $r$ ว่า **ส่วนจริง** และ $s$ ว่า **ส่วนจินตภาพ** 

เราสามารถใช้กรณีที่ 1 ได้เช่นกัน ซึ่งจะออกมาเป็น
\[ y = A_0 e^{m_1x} + B_0 e^{m_2x}\] 
เมื่อ $A_0, B_0$ เป็นค่าคงตัวใด ๆ แต่เนื่องจาก $m_1$ และ $m_2$ เป็นจำนวนเชิงซ้อน เราสามารถใช้สมบัติของออยเลอร์ 

:::note

\[e^{i\theta} = \cos \theta + i \sin \theta\]

:::


:::





:::slide

\begin{eq*}
y &=& A_0 e^{(r+si)x} + B_0 e^{(r-si)x} 

&=& A_0 e^{rx} e^{isx} + B_0 e^{rx} e^{-isx} 

&=& e^{rx} \left( A_0 ( \cos sx + i \sin sx) + B_0 (\cos (-sx) + i \sin (-sx)) \right) 

&=& e^{rx} \left( A_0 (\cos sx + i \sin sx) + B_0 (\cos sx - i \sin sx) \right) 

&=& e^{rx} \left( (A_0 + B_0) \cos sx + (A_0i - B_0i) \sin sx \right) 

&=& e^{rx} (A\cos sx + B \sin sx)
\end{eq*} 
เมื่อ $A,B$ เป็นค่าคงตัวใด ๆ 

สรุปว่า ผลเฉลยทั่วไปของสมการคือ

:::note

\[ y = e^{rx}(A\sin sx + B\cos sx)\]

:::

เมื่อ $r$ คือส่วนจริงของราก และ $s$ คือส่วนจินตภาพของราก 

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' -4 y' + 8y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 -4 m +8 = 0$ หาผลเฉลยโดยใช้สูตรได้
\begin{eq*}
m = \frac{-(-4) \pm \sqrt{(-4)^2 - 4(8)}}{2} &=& \frac{4 \pm \sqrt{-16}}{2} 

&=& \frac{4 \pm 4i}{2} = 2 \pm 2i
\end{eq*} 
นั่นคือ $m_1 = 2+2i$ และ $m_2 = 2-2i$ ซึ่งมีส่วนจริงเป็น $r=2$ และส่วนจินตภาพเป็น $s=2$ ทำให้ได้ผลเฉลยทั่วไปเป็น
\[y = e^{2x}(A \cos 2x + B \sin 2x)\]

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' - 2y' + 17y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 - 2m +17 = 0$ หาผลเฉลยโดยใช้สูตรได้
\begin{eq*}
m = \frac{-(-2) \pm \sqrt{(-2)^2 - 4(17)}}{2} &=& \frac{2 \pm \sqrt{-64}}{2} 

&=& \frac{2 \pm 8i}{2} = 1 \pm 4i
\end{eq*} 
นั่นคือ $m_1 = 1+4i$ และ $m_2 = 1-4i$ ซึ่งมีส่วนจริงเป็น $r=1$ และส่วนจินตภาพเป็น $s=4$ ทำให้ได้ผลเฉลยทั่วไปเป็น
\[y = e^{x}(A \cos 4x + B \sin 4x)\]

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' + 25y = 0, \quad y(0) = 2, y'(0) = 5\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 + 25 = 0$ หาผลเฉลยโดยใช้สูตรได้
\begin{eq*}
m = \frac{-(0) \pm \sqrt{(0)^2 - 4(25)}}{2} &=& \frac{\pm \sqrt{-100}}{2} 

&=& \frac{\pm 10i}{2} = \pm 5i
\end{eq*} 
นั่นคือ $m_1 = 5i$ และ $m_2 = -5i$ ซึ่งมีส่วนจริงเป็น $r=0$ และส่วนจินตภาพเป็น $s=5$ ทำให้ได้ผลเฉลยทั่วไปเป็น
\[y = e^{0x}(A \cos 5x + B \sin 5x) = A\cos 5x + B\sin 5x\]

:::





:::slide


:::example
[ (ต่อ)]
\[ y'' + 25y = 0, \quad y(0) = 2, y'(0) = 5\]
\[y = e^{0x}(A \cos 5x + B \sin 5x) = A\cos 5x + B\sin 5x\]

:::


:::solution

โจทย์นี้ต้องการผลเฉลยเฉพาะ นั่นคือเราต้องหาค่า $A,B$ ที่ทำให้ $y(0) = 2$ และ $y'(0) = 4$ เมื่อแทนค่า $x=0$ ลงไปในผลเฉลยทั่วไป จะได้
\begin{eq*}
2 = y(0) &=& A\cos 0 + B \sin 0 = A 

5 = y'(0) &=& -5A\sin 0 + 5B\cos 0 = 5B 
\end{eq*} 
นั่นคือ $A = 2$ และ $B= 1$ ฉะนั้นผลเฉลยเฉพาะคือ
\[ y = 2\cos 5x + \sin 5x\]

:::


:::





## สรุปขั้นตอนการแก้สมการเชิงเส้นเอกพันธ์อันดับ 2 ระดับขั้น 2


:::note



- สร้างสมการลักษณะเฉพาะ $am^2 + bm + c = 0$ 

- หาราก $m_1$ และ $m_2$ ของสมการลักษณะเฉพาะ 


- ถ้าได้รากเป็นจำนวนจริงไม่ซ้ำกัน และ $m_1 \neq m_2$ ผลเฉลยคือ 
\[y = Ae^{m_1x} + Be^{m_2x}\] 

- ถ้าได้รากเป็นจำนวนจริงที่ซ้ำกัน ($m_1 = m_2$) ผลเฉลยคือ 
\[y = Ae^{m_1x} + Bxe^{m_1x}\]

- ถ้าได้รากเป็นจำนวนเชิงซ้อน $m_1 = r+si, m_2 = r-si$ ผลเฉลยคือ 
\[y = e^{rx}(A\sin sx + B\cos sx)\]




:::
