ในคาบเรียนนี้ เราจะศึกษาสมการเอกพันธ์ (นั่นคือ ฟังก์ชันด้านขวามือของสมการ $f(x)$ เท่ากับ 0) 

:::definition

สมการเชิงเส้นเอกพันธุ์ อันดับ 2 ระดับขั้น 1 ที่มีสัมประสิทธิ์เป็นค่าคงตัว คือสมการที่อยู่ในรูป
\begin{equation}
ay'' + by' + cy = 0
\end{equation} 
โดยที่ $a,b,c$ เป็นค่าคงตัว

:::



:::example



- $y'' + y' + y = 0$

- $3y'' - 2y' + 2y = 0$

- $-y'' - 8y'= 0$ 

- $y'' - 4y = 0$


:::





## ที่มาของวิธีการหาผลเฉลย 1/3

เรายังไม่ทราบวิธีหรือเทคนิคการหาผลเฉลยสมการเชิงอนุพันธ์อันดับสอง (นั่นคือ มีพจน์ $y''$) แต่เราสามารถทดสอบฟังก์ชันทั่วไปที่เรารู้จักได้ 

:::slide



\def\arraystretch{1.5}

| y | y' | y'' |
| --- | --- | --- |
| x^n | nx^{n-1} | n(n-1)x^{n-2} |
| e^{mx} | me^{mx} | m^2e^{mx} |
| \ln x | \frac{1}{x} | -\frac{1}{x^2} |
| \sin ax | a\cos ax | -a^2 \sin ax |
| \cos ax | -a\sin ax | -a^2\cos ax |



:::





## ที่มาของวิธีการหาผลเฉลย 2/3


:::slide

เราต้องการให้ $y, y'$ และ $y''$ มีหน้าตาคล้าย ๆ กัน ฉะนั้น ถ้าเราลองให้ $y = e^{mx}$ ดู จะได้
\[ y' = \dx e^{mx} = me^{mx} , \quad y'' = \dx me^{mx} = m^2e^{mx}\] 
เมื่อนำ $y, y', y''$ ไปแทนในสมการแรก จะได้
\[ am^2e^{mx} + bme^{mx} + ce^{mx} = 0\] 
เนื่องจากเราทราบว่า $e^{mx} \neq 0$ สำหรับทุกค่า $m,x$ เราจึงสามารถนำ $e^{mx}$ หารตลอดทั้งสมการได้ จึงได้ออกมาเป็นสมการ

:::note

\[ am^2 + bm + c = 0\]

:::

สมการนี้มีชื่อเรียกว่า **สมการลักษณะเฉพาะ** (characteristic equation)

:::





## สมการลักษณะเฉพาะ


:::definition

กำหนดสมการเชิงเส้นเอกพันธุ์ อันดับ 2 ระดับขั้น 1 ที่มีสัมประสิทธิ์เป็นค่าคงตัว ในรูป
\begin{equation}
ay'' + by' + cy = 0 \nonumber
\end{equation} 
โดยที่ $a,b,c$ เป็นค่าคงตัว แล้วนิยาม **สมการลักษณะเฉพาะ** เป็นสมการกำลังสอง
\begin{equation}
am^2+bm+c = 0
\end{equation}
โดยที่ $m$ เป็นตัวแปร

:::





## ที่มาของวิธีการหาผลเฉลย 3/3


:::slide

ซึ่งสมการ $am^2 + bm + c = 0$ เป็นสมการกำลังสอง สามารถแก้ได้ด้วยเทคนิคต่าง ๆ เช่น การจัดรูปให้เป็นกำลังสองสมบูรณ์ การแยกตัวประกอบด้วยการแก้สมการ

:::note

\[m_1+m_2 = -\frac{b}{a} \]
\[m_1m_2 = \frac{c}{a}\]

:::

หรือการใช้สูตร

:::note

\[ m = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

:::

เราทราบแล้วว่าสมการกำลังสองมีราก 2 ราก ที่อาจจะเป็นจำนวนจริงหรือจำนวนเชิงซ้อน และอาจจะเป็นรากซ้ำกันได้ เราจึงต้องพิจารณาแต่ละวิธีแยกกัน

:::
