## กรณีที่ 2: รากจริงซ้ำกัน

ถ้า $m_1$ และ $m_2$ เป็นรากจริงที่ซ้ำกัน (นั่นคือ $m_1 = m_2$) 

:::slide

เราทราบเพียงผลเฉลยเดียวคือ $y = e^{m_1x}$ ถ้าเราเลียนแบบกรณีที่ 1 และสร้างผลเฉลย
\[ y = Ae^{m_1x} + Be^{m_1x}\] 
จะสังเกตว่าที่จริงแล้ว $Ae^{m_1x} + Be^{m_1x} = (A+B)e^{m_1x} = Ce^{m_1x}$ 

นั่นคือ เราได้เพียงผลเฉลยเดียว แต่มีหลักการหาผลเฉลย (ศึกษาเพิ่มได้ในหนังสือ) ว่า ถ้าพบผลเฉลยที่ซ้ำกัน ให้''เพิ่ม''ผลเฉลยด้วยการคูณ $x$ เข้าไป ในที่นี้คือ เราเพิ่มผลเฉลย
\[ y = xe^{m_1x}\] 

:::




เราลองทดสอบดูได้ว่า $y=xe^{m_1x}$ เป็นผลเฉลยของสมการจริง 

:::slide

\begin{eq*}
y &=& xe^{m_1x} 

y' &=& m_1xe^{m_1x} + e^{m_1x} 

y'' &=& m_1^2xe^{m_1x} + m_1e^{m_1x} + m_1e^{m_1x} 

&=& m_1^2xe^{m_1x} + 2m_1e^{m_1x} 

y'' + a_1y' + a_0y &=& \left(m_1^2xe^{m_1x} + 2m_1e^{m_1x}\right) + a_1\left( m_1xe^{m_1x} + e^{m_1x} \right) + a_0 xe^{m_1x} 

&=& (m_1^2+a_1m_1 + a_0)xe^{m_1x} + (2m_1+a_1)e^{m_1x} 

&=& 0 + 0 = 0
\end{eq*}
ฉะนั้น ผลเฉลยทั่วไปของสมการคือ 

:::note

\[ y = Ae^{m_1x} + Bxe^{m_1x} = e^{m_1x}(A + Bx)\]

:::

เมื่อ $A,B$ เป็นค่าคงตัวใด ๆ 

:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' - 2y' + y = 0\]

:::


:::slide


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 -2 m +1 = 0$ ถ้าให้ $m_1, m_2$ เป็นรากของสมการนี้ จะได้ว่า
\begin{eq*}
m_1 + m_2 &=& 2 

m_1m_2 &=& 1
\end{eq*} 
นั่นคือ $m_1 = 1$ และ $m_2 = 1$ ซึ่งเป็นรากซ้ำ ทำให้เราได้ผลเฉลย $y=e^x$ และสร้างผลเฉลยเพิ่มขึ้นมาเป็น $y=xe^{x}$ ทำให้ได้ผลเฉลยทั่วไปเป็น
\[y = Ae^x + xBe^x = e^x(A+Bx)\]

:::


:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ y'' + 4y' +4 y = 0\]

:::


:::solution

สร้างสมการลักษณะเฉพาะได้เป็น $m^2 +4 m +4 = 0$ ถ้าให้ $m_1, m_2$ เป็นรากของสมการนี้ จะได้ว่า
\begin{eq*}
m_1 + m_2 &=& -4 

m_1m_2 &=& 4
\end{eq*} 
นั่นคือ $m_1 = -2$ และ $m_2 = -2$ ซึ่งเป็นรากซ้ำ ทำให้เราได้ผลเฉลย $y=e^{-2x}$ และสร้างผลเฉลยเพิ่มขึ้นมาเป็น $y=xe^{-2x}$ ทำให้ได้ผลเฉลยทั่วไปเป็น
\[y = Ae^{-2x} + Bxe^{-2x} = e^{-2x}(A + Bx)\]

:::
