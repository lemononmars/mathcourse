## ที่มาของการหาผลเฉลยสมการไม่เอกพันธ์

พิจารณาสมการ
\begin{equation} 
\dyx = \cos x
\end{equation}
เราสามารถหาผลเฉลยได้ทันทีด้วยการหาปริพันธ์ได้เป็น
\[ y = \sin x + C\]
ซึ่งมีอยู่สองส่วนด้วยกัน ได้แก่ $\sin x$ ที่เป็นปฏิยานุพันธ์ของ $\cos x$ และค่าตัว $C$ คำถามคือค่า $C$ มาจากไหน? 




:::slide

ที่จริงแล้วมีค่าคงตัวที่ซ่อนอยู่ในสมการดังนี้
\[ \dyx = \cos x + 0 \]
ทำให้เราสามารถหาผลเฉลยแยกเป็นสองส่วน ได้แก่
\begin{align*}
\dyx &= \cos x &\longrightarrow && **y_p** &= **\sin x** 

\dyx &= 0 &\longrightarrow && **y_c** &= **C**
\end{align*}
ดังนั้นถ้าเรากำหนดให้
\[ y = **y_p** + **y_c** = **\sin x** + **C**\]
เราสามารถใช้สมบัติเชิงเส้นของอนุพันธ์เพื่อตรวจสอบผลเฉลยได้เป็น
\[ \dyx = \dx (**y_p** + **y_c**) = \dx **y_p** + \dx **y_c** = \cos x + 0 = \cos x\]
ซึ่งเป็นผลเฉลยทั้งหมดของสมการ \eqref{eq:yc_yp_example} จริง

:::





## นิยามของผลเฉลยบริบูรณ์


:::definition

สมาการเชิงเส้นแบบไม่เอกพันธ์อันดับ $n$ ที่มีสัมประสิทธิ์เป็นค่าคงตัว
\begin{equation} 
y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x) 
\end{equation}
มี**ผลเฉลยบริบูรณ์**ในรูป 
\[y = y_p + y_c\]
โดยที่ $y_p$ เป็น **ผลเฉลยเฉพาะ** (particular solution) ที่ได้จากการแก้สมการไม่เอกพันธ์ \eqref{eq:complete_solution} และ $y_c$ เป็น **ผลเฉลยเติมเต็ม** (complementary solution) ที่ได้จากการแก้สมการเอกพันธ์
\[y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1 y' + a_0 y = 0 \]

:::






:::example

กำหนดสมการ 
\[y'' + y = 2e^x\]


- จงตรวจสอบว่า $y_p = e^x$ เป็นผลเฉลยเฉพาะ

- จงตรวจสอบว่า $y_c = C_1 \sin x + C_2 \cos x$ เป็นผลเฉลยเติมเต็ม

- จงหาผลเฉลยบริบูรณ์ พร้อมตรวจคำตอบ


:::


:::solution



- นำ $y_p = **e^x**$ ไปแทนค่าในฝั่งซ้ายของสมการ จะได้
\[y_p'' + y_p' = e^x + e^x = 2e^x\]
ซึ่งเท่ากับฟังก์ชันฝั่งขวาของสมการ ฉะนั้น $y_p$ เป็นผลเฉลยเฉพาะ


:::





:::solution
(ต่อ)


- นำ $y_c = **C_1\sin x +C_2\cos x** $ ไปแทนค่าในฝั่งซ้ายของสมการ จะได้
\[y_c'' + y_c' = (-C_1\sin x - C_2\cos x) + (C_1\sin x +C_2\cos x)=0\]
ฉะนั้น $y_c$ เป็นผลเฉลยเติมเต็ม*

*(ในทางปฏิบัติ เราต้องหาผลเฉลยจากสมการ $y''+y=0$ โดยตรง)*

- ผลเฉลยบริบูรณ์คือ
\[y = **y_p** + **y_c** = **e^x** + **C_1 \sin x + C_2 \cos x**\]
เราตรวจคำตอบได้ดังนี้
\begin{eq*}
y'' + y'&=& (e^x + C_1 \sin x +C_2 \cos x)'' + (e^x + C_1\sin x +C_2\cos x) 

&=& (e^x - C_1\sin x -C_2\cos x) + (e^x + C_1 \sin x + C_2 \cos x) 

&=& 2e^x
\end{eq*}


:::






## วิธีเทียบสัมประสิทธิ์ (Method of undetermined coefficient)

เป้าหมายของเราคือ หาฟังก์ชัน $y_p$ ที่ทำให้
\[ y_p^{(n)} + a_{n-1} y_p^{(n-1)} + \cdots + a_1y_p' + a_0y_p = f(x)\] 

ซึ่งจะมีทั้งหมด 3 วิธีได้แก่


- วิธีการใช้ตัวดำเนินการดี (D-operator)

- วิธีเทียบสัมประสิทธิ์ (Method of undetermined coefficient)

- วิธีแปรตัวพารามิเตอร์ (Parameter variable)


สำหรับในวิชานี้ เราจะศึกษาเพียงวิธีเดียวคือ วิธีเทียบสัมประสิทธิ์




ถ้าฟังก์ชัน $f(x)$ เป็นฟังก์ชันพื้นฐาน เราก็สามารถ''เดา''ผลเฉลยได้ไม่ยาก 

:::example

กำหนดสมการเชิงอนุพันธ์ 
\[ y' + y = 2x+6\] 
จงหาผลเฉลยเฉพาะ ด้วยการคาดเดาฟังก์ชัน $y$

:::


:::solution

เราต้องการหาฟังก์ชัน $y$ ที่ทั้ง $y$ และ $y'$ ต่างก็เป็นพหุนามดีกรี 1 หรือเป็นค่าคงตัว นั่นคือ น่าจะเป็นฟังก์ชัน
\[y = Ax + B\]
ในที่นี้ถ้าเราลองแทนค่า $y = 2x+4$ ดู จะได้ $y'=2$ ดังนั้น
\[ y' + y = 2 + (2x+4) = 2x+6\] 
แสดงว่า ผลเฉลยเฉพาะของสมการ $y' + y = 2x+6$ คือ 
\[y_p = 2x+4\]

:::




สำหรับฟังก์ชันที่ไม่ซับซ้อนมาก จะมีรูปแบบดังต่อไปนี้


\def\arraystretch{1.5}

| f(x) | y_p |
| --- | --- |
| e^{rx} | Ae^{rx} |
| x^n | A_nx^n + A_{n-1}x^{n-1} + \cdots + A_1x + A_0 |
| x^n e^{rx} | e^{rx}(A_nx^n + A_{n-1}x^{n-1} + \cdots + A_1x + A_0) |
| \sin (bx) | A_1\sin (bx) + A_2\cos(bx) |
| \cos (bx) | A_1\sin (bx) + A_2\cos(bx) |
| \sin (bx) e^{rx} | e^{rx} (A_1\sin (bx) + A_2\cos(bx)) |
| \cos (bx) e^{rx} | e^{rx} (A_1\sin (bx) + A_2\cos(bx)) |

*รูปแบบการกำหนดผลเฉลยเฉพาะ $y_p$ จากฟังก์ชัน $f(x)$*
