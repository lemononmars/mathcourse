## เมื่อผลเฉลยเติมเต็ม ปรากฎใน f(x)

สังเกตว่า วิธีการที่เราบอกไว้ กำหนดว่า $f(x)$ ต้องไม่เป็นผลเฉลยเติมเต็ม พิจารณา
\[y' - y = 5e^x\]

:::slide

ผลเฉลยเติมเต็มที่ได้จากสมการ $y'-y=0$ คือ 
\[y_c = Ae^x\] 
เมื่อ $A$ เป็นค่าคงตัว สังเกตว่ารูปแบบผลเฉลยตรงกับ $f(x)$ แสดงว่าถ้าเราพยายามหาผลเฉลยเฉพาะ $y_p$ ด้วยการแทน $y_p = Ce^x$ จะได้
\[y_p' - y_p = Ce^x - Ce^x = 0\]
นั่นคือ เราไม่สามารถหาค่าคงตัว $C$ ที่ทำให้ $y_p' - y_p = 5e^x$ ได้!!!


:::




อย่างไรก็ตาม เรายังสามารถหาผลเฉลยเฉพาะได้ ด้วยหลักการที่เราเคยใช้ นั่นคือคูณด้วย $x$ เข้าไป เพื่อสร้างผลเฉลยใหม่ ทำให้ได้ว่า
\[**y_p = Cxe^x**\]
จากนั้นถึงจะนำ $y_p$ นี้ ไปแทนค่าในสมการเพื่อหาค่าคงตัว $C$

:::slide

\begin{eq*}
y_p' - y_p &=& 5e^x 

(Cxe^x)' - (Cxe^x) &=& 5e^x

Cxe^x + Ce^x - (Cxe^x) &=& 5e^x

Ce^x &=& 5e^x

C &=& 5
\end{eq*}
ฉะนั้น ผลเฉลยบริบูรณ์คือ
\[y = y_c + y_p = Ae^x + 5xe^x\]

:::





## หลักการหาผลเฉลย เมื่อผลเฉลยเติมเต็มมีพจน์ใน f(x)

กำหนดให้ $s$ เป็นจำนวนเต็มบวกที่น้อยที่สุด ที่ทำให้ $x^{s-1}f(x)$ **ไม่เป็น**ผลเฉลยทั่วไปของสมการ 
\[y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x)\]
แล้วเราสามารถคาดเดาผลเฉลยเฉพาะ $y_p$ ได้ตามนี้


\def\arraystretch{1.5}

| \text{ฟังก์ชัน } f(x) | \text{ผลเฉลยเฉพาะ } y_p |
| --- | --- |
| a_nx^n + a_{n-1}x^{n-1} + \cdots +a_0 | **x^s**(A_nx^n+A_{n-1}x^{n-1}+\cdots+A_0) |
| ae^{kx} | A**x^s**e^{kx} |
| x^nce^{kx} | **x^s**(A_n x^n + A_{n-1}x^{n-1} + \cdots + A_1x+A_0)e^{kx} |
| a\sin {kx} + b\cos{kx} | **x^s**(A\sin{kx} + B\cos{kx}) |
| e^{rx} (a\sin {kx} + b\cos{kx}) | **x^s**e^{rx}(A\sin{kx} + B\cos{kx}) |






:::remark การหาผลเฉลยบริบูรณ์โดยวิธีเทียบสัมประสิทธิ์

กำหนดสมการเชิงเส้นไม่เอกพันธ์ที่มีสัมประสิทธิ์เป็นค่าคงตัว
\[ y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x) \]


- หาผลเฉลยเติมเต็ม $y_c$ ด้วยสมการลักษณะเฉพาะ

- หาผลเฉลยเฉพาะ $y_p$ ด้วยการเทียบสัมประสิทธิ์ (ในตาราง)

- ถ้าผลเฉลยเติมเต็ม $y_p$ มีพจน์ที่ซ้ำกับรูปแบบผลเฉลยเฉพาะ $y_c$ ให้นำผลเฉลยเฉพาะส่วนนั้นที่ซ้ำไปคูณด้วย $x^n$ เมื่อ $n$ เป็นจำนวนที่ทำให้พจน์ใน $y_p$ แตกต่างกับ $y_c$ ทั้งหมด

- สรุปเป็นผลเฉลยบริบูรณ์ $y = y_p+y_c$


:::
