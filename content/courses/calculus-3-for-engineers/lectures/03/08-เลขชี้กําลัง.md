:::remark วิธีการหาผลเฉลยเฉพาะเมื่อ f(x) เป็นฟังก์ชันเลขชี้กำลัง

ถ้ากำหนดสมการเชิงอนุพันธ์
\[ y^{(n)} + a_{n-1} y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x)\] 
โดยที่ $f(x) = Ce^{kx}$ เป็นฟังก์ชันเลขชี้กำลัง **และไม่เป็นผลเฉลยเติมเต็ม** แล้วผลเฉลยเฉพาะจะอยู่ในรูป 
\begin{equation} y_p = Ae^{kx} \end{equation} 
เมื่อ $A$ เป็นค่าคงตัว ที่สามารถหาได้จากการแทนค่า $y_p$ ลงไปในสมการเชิงอนุพันธ์

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' - y' + y = 12e^{2x}\]

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = 12e^{2x}$ ซึ่งเป็นฟังก์ชันเลขชี้กำลัง ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป
\[y_p = Ae^{2x}\] 
ซึ่งมีอนุพันธ์เป็น $y_p' = 2Ae^{2x}$ และ $y_p'' = 4Ae^{2x}$ ฉะนั้น เราสามารถแทนค่า $y_p, y_p'$ และ $y_p''$ ลงในสมการด้านซ้ายมือ จะได้
\begin{eq*}
y'' - y' + y = (4Ae^{2x}) - (2Ae^{2x}) + (Ae^{2x}) &=& 12e^{2x} 

3Ae^{2x} &=& 12e^{2x}
\end{eq*} 
นั่นคือ $A=4$ ฉะนั้น ผลเฉลยเฉพาะคือ 
\[ y_p = 4e^{2x} \]

:::






:::example

จงหาผลเฉลยเฉพาะของสมการเชิงอนุพันธ์
\[ y'' - 5y = 2e^{-3x}\]

:::


:::solution

เนื่องจากฟังก์ชันด้านขวาเป็น $f(x) = 2e^{-3x}$ ซึ่งเป็นฟังก์ชันเลขขี้กำลัง ฉะนั้นเราจะได้ผลเฉลยเฉพาะในรูป 
\[y_p = Ae^{-3x}\] 
ซึ่งมีอนุพันธ์เป็น $y_p' = -3Ae^{-3x}$ และ $y_p'' = 9Ae^{-3x}$ ฉะนั้น เราสามารถแทนค่า $y_p, y_p'$ และ $y_p''$ ลงในสมการด้านบน จะได้
\begin{eq*}
y'' - 5y = (9Ae^{-3x}) - 5(Ae^{-3x}) &=& 2e^{-3x} 

4Ae^{-3x} &=& 2e^{-3x}
\end{eq*} 
นั่นคือ $A=\tfrac{1}{2}$ ฉะนั้น ผลเฉลยเฉพาะคือ 
\[ y_p = \tfrac{1}{2}e^{-3x} \]

:::
