## การเปลี่ยนตัวแปร

ถ้าสมการมีรูปแบบที่ซับซ้อน เราอาจลองเปลี่ยนตัวแปรเพื่อลดรูปสมการให้ง่ายขึ้น เช่น
\[x^4 - 3x^2 + 2 = 0\] 
เป็นสมการกำลังสี่แต่ถ้าเราเปลี่ยนตัวแปรโดยกำหนดให้ $t = x^2$ จะได้
\[t^2 - 3t + 2 = 0\] 
ซึ่งกลายเป็นสมการกำลังสอง ที่เราหาคำตอบได้เป็น
\[t = 1 \text{ และ } t = 2\] 
จากนั้นเราจึงแทนกลับไปเป็นค่า $x$ ได้เป็น
\[x^2 = 1 \text{ และ } x^2 = 2\] 
\[x = -1, 1, -\sqrt{2}, \sqrt{2}\]



ในทำนองเดียวกับ เราสามารถแก้สมการเชิงอนุพันธ์ได้ด้วยการเปลี่ยนตัวแปร โดยเราจะศึกษาการเปลี่ยนตัวแปร
\[v =\frac{y}{x}\] 

:::definition

สมการเชิงอนุพันธ์แบบเอกพันธ์ คือสมการที่สามารถเขียนอยู่ในรูป
\begin{equation}
\dyx = F\left(\frac{y}{x}\right)
\end{equation}
โดยที่ $F$ เป็นฟังก์ชันตัวแปรเดียว

:::






:::example

สมการต่อไปนี้ เป็นสมการเชิงอนุพันธ์แบบเอกพันธ์
\begin{align*}
\dyx &= 2 - 3\frac{y}{x} \qquad &\longrightarrow && F(v) &= 2-3v

\dyx &= \frac{x^2}{y^2}\qquad &\longrightarrow && F(v) &= \frac{1}{v^2} 

\dyx &= \frac{x+y}{x} = 1 + \frac{y}{x} \qquad &\longrightarrow && F(v) &= 1 + v
\end{align*}

:::




คำถามก็คือ เราจะตรวจสอบได้อย่างไรว่าสมการเชิงอนุพันธ์ที่ให้มานั้น เป็นสมการแบบเอกพันธุ์หรือไม่? 

คำตอบคือ เราสามารถใช้นิยามอีกนิยามหนึ่งได้ 


:::definition

ฟังก์ชัน $f(x,y)$ เป็น**ฟังก์ชันเอกพันธ์ระดับขั้น** $n$ ถ้าสำหรับทุกค่าคงตัว $\lambda$ แล้ว
\[f(\lambda x, \lambda y) = \lambda^n f(x,y)\]
สำหรับทุกค่า $x,y$

:::






:::example

จงพิจารณาว่าฟังก์ชันต่อไปนี้เป็นฟังก์ชันเชิงอนุพันธ์เอกพันธ์หรือไม่
\[f(x,y) = 2x + 5y\]

:::


:::solution

กำหนดให้ $\lambda$ เป็นค่าคงตัวใด ๆ หาค่าของ $f(\lambda x,\lambda y)$ ได้เป็น 
\begin{align*}
f(\lambda x, \lambda y) &= 2(\lambda x) + 5(\lambda y) 

&= \lambda (2x + 5y) 

&= \lambda f(x,y) 
\end{align*}
ฉะนั้น $f(x,y) = 2x+5y$ เป็นฟังก์ชันเอกพันธ์ระดับขั้น 1

:::






:::example

จงพิจารณาว่าฟังก์ชันต่อไปนี้เป็นฟังก์ชันเชิงอนุพันธ์เอกพันธ์หรือไม่
\[f(x,y) = x^2 + xy + y^2\]

:::


:::solution

กำหนดให้ $\lambda$ เป็นค่าคงตัวใด ๆ หาค่าของ $f(\lambda x,\lambda y)$ ได้เป็น 
\begin{align*}
f(\lambda x, \lambda y) &= (\lambda x)^2 + (\lambda x)(\lambda y) + (\lambda y)^2 

&= \lambda^2 (x^2 + xy + y^2) 

&= \lambda f(x,y) 
\end{align*}
ฉะนั้น $f(x,y) = x^2 + xy + y^2$ เป็นฟังก์ชันเอกพันธ์ระดับขั้น 2

:::





:::theorem

สมการ $\dyx = f(x,y)$ เป็นสมการเชิงอนุพันธ์แบบเอกพันธ์ก็ต่อเมื่อ $f(x,y)$ เป็นฟังก์ชันเอกพันธ์ระดับขั้น 0 (นั่นคือ $f(x,y) = f(\lambda x, \lambda y)$)

:::

เมื่อเราทราบว่าเป็นสมการเชิงอนุพันธ์แบบเอกพันธ์แล้ว เราจึงสามารถหาผลเฉลยได้ด้วยการกำหนดตัวแปร $v = \frac{y}{x}$ โดยมีขั้นตอนดังนี้




:::remark วิธีการหาผลเฉลยของสมการเชิงอนุพันธ์แบบเอกพันธ์ (1/2)



- กำหนดตัวแปร $v = \frac{y}{x}$ ซึ่งก็คือ $y = vx$ และแทนค่า $y = vx$ ลงไปในฟังก์ชัน $f(x,y)$ จะได้
\[ f(x,y) = f(x,vx) = x^0 f(1,v) = F(v)\]

- หาปริพันธ์ $\frac{dv}{dx}$ โดยใช้สูตรผลหารของฟังก์ชัน จะได้
\[ \frac{dv}{dx} = \frac{xy' - y}{x^2} = \frac{F(v)-v}{x} \]


:::





:::remark วิธีการหาผลเฉลยของสมการเชิงอนุพันธ์แบบเอกพันธ์ (2/2)


\setcounter{enumi}{2}

- เนื่องจากสมการ $\frac{dv}{dx} = \frac{F(v)-v}{x}$ เป็นสมการแบบแยกตัวแปรได้ จึงสามารถหาผลเฉลยของสมการได้เป็น 
\[ Q(v) = P(x) + C\] 
เมื่อ $Q$ และ $P$ เป็นฟังก์ชันตัวแปรเดียว 

- แทนค่า $v=\frac{y}{x}$ เพื่อให้กลับมาเป็นสมการที่มีตัวแปร $x$ กับ $y$


:::







:::example

จงหาผลเฉลยทั่วไปของสมการ 
\[\dyx = \frac{x+y}{x}\]

:::


:::solution

กำหนดให้ $v = \frac{y}{x}$ และแทนค่า $y = vx$ ลงไปใน $f(x,y) = \frac{x+y}{x}$ จะไดั
\[ \frac{x+y}{x} = \frac{x+vx}{x} = \frac{x(1+v)}{x} = 1+v = F(v)\] 
จากนั้นคำนวณ $\frac{dv}{dx}$ ได้เป็น
\[\frac{dv}{dx} = \frac{F(v)-v}{x} = \frac{1+v-v}{x} = \frac{1}{x}\]

:::





:::solution
(ต่อ)
สมการนี้สามารถแยกตัวแปรได้ จึงหาผลเฉลยของสมการแบบแยกตัวแปรได้เป็น 
\begin{align*}
dv &= \frac{1}{x} \, dx 

\int 1 \, dv &=\int \frac{1}{x} \, dx 

v &= \ln | x | + C 
\end{align*}
เมื่อแทนค่า $v = \frac{y}{x}$ จะได้ 
\begin{align*}
\frac{y}{x} &= \ln |x | + C 

y &= x\ln |x| + Cx 
\end{align*}
ฉะนั้น $y = x\ln |x| + Cx$ เป็นผลเฉลยทั่วไปของสมการ $\dyx = \frac{x+y}{x}$

:::






:::example

จงหาผลเฉลยทั่วไปของสมการ 
\[\dyx = \frac{x^2+xy+y^2}{x^2}\]

:::


:::solution

กำหนดให้ $v = \frac{y}{x}$ และแทนค่า $y = vx$ ลงในไป $f(x,y)$ จะได้
\[ \frac{x^2+xy+y^2}{x^2} = \frac{x^2 + x(vx) + (vx)^2}{x^2} = \frac{x^2(1+v+v^2}{x^2} = 1+v+v^2 = F(v)\]
จากนั้นคำนวณ $\frac{dv}{dx}$ ได้เป็น 
\[ \frac{dv}{dx} = \frac{F(v)-v}{x} = \frac{(1+v+v^2)-v}{x} = \frac{1+v^2}{x}\]

:::





:::solution
(ต่อ)
สมการนี้สามารถแยกตัวแปรได้ จึงหาผลเฉลยของสมการแบบแยกตัวแปรได้เป็น 
\begin{align*}
\frac{1}{1+v^2}\,dv &= \frac{1}{x} \, dx 

\int \frac{1}{1+v^2} \, dv &=\int \frac{1}{x} \, dx 

\arctan v &= \ln | x | + C 
\end{align*}
เมื่อแทนค่า $v = \frac{y}{x}$ จะได้ 
\begin{align*}
\arctan \left( \frac{y}{x} \right) &= \ln |x | + C 

\frac{y}{x} &= \tan( \ln |x| + C ) 

y &= x \tan (\ln |x| + C) 
\end{align*}
ฉะนั้น $y = x \tan (\ln |x| + C)$ เป็นผลเฉลยทั่วไปของสมการ $\dyx = \frac{x^2+xy+y^2}{x^2}$

:::
