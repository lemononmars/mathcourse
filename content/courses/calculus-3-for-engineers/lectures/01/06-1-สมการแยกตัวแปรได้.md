สมมติว่าเรามีสมการ

:::note

\[2x - 1 = x + 5\]

:::

ขั้นตอนแรกในการแก้สมการนี้คือการจัดรูปสมการด้วยการ **ย้ายข้าง** เพื่อให้ตัวแปรอยู่ฝั่งเดียวกัน ดังนี้ 
\[2x - x = 5 + 1\] 
\[x = 6\] 
ในทำนองเดียวกัน สมมติว่าเราต้องการหาผลเฉลยของสมการเชิงอนุพันธ์ 
\[\dyx = \frac{x}{y}\] 
เราสามารถจัดรูปสมการด้วยการ ย้ายข้าง ได้เช่นกัน เนื่องจากเรามีตัวแปร $x$ และ $y$ เรา
สามารถย้ายข้างได้ดังนี้
\[y \, dy = x \, dx\]




## นิยามสมการแยกตัวแปรได้


:::definition

สมการแยกตัวแปรได้คือสมการที่สามารถเขียนอยู่ในรูป
\begin{equation}
\dyx= p(x)q(y) 
\end{equation}
โดยที่ $p$ เป็นฟังก์ชันตัวแปรเดียวซึ่งมี $x$ เป็นตัวแปรอิสระ และ $q$ เป็นฟังก์ชันตัวแปรเดียวซึ่งมี $y$ เป็นตัวแปรอิสระ

:::






:::example

สมการต่อไปนี้เป็นสมการเชิงอนุพันธ์แบบแยกตัวแปรได้ 
\begin{eq*}
\dyx &=& xy 

\dyx &=& \frac{x^2}{y+1} 

\dyx &=& xy+y
\end{eq*}

:::slide

สมการล่างสุด อาจดูเหมือนจะแยกตัวแปรไม่ได้ แต่เราจัดรูปเป็น $xy+y = y(x+1)$ ทำให้ตัวแปรแยกกันได้แล้ว

:::


:::






:::example

จงหาผลเฉลยทั่วไปของสมการเชิงอนุพันธ์
\[ \dyx = \frac{x}{y} \]

:::


:::solution

ขั้นแรก เราจัดรูปสมการให้ตัวแปร $x$ อยู่ฝั่งหนึ่ง และตัวแปร $y$ อยู่อีกฝั่งหนึ่ง 
\[y dy = x dx\] 
จากนั้น เราสามารถหาปริพันธ์ทั้งสองข้างของสมการ ได้เป็น
\[\int y \, dy = \int x \, dx \] 
ซึ่งคำนวณได้เป็น 
\[\frac{y^2}{2} + C_1 = \frac{x^2}{2} + C_2 \]

:::






:::solution
(ต่อ) ท้ายสุด เรารวมค่าคงตัว $C_1$ และ $C_2$ เข้าด้วยกันและจัดรูปสมการได้ดังนี้ 
\begin{eq*}
\frac{y^2}{2} &=& \frac{x^2}{2} + C_3 \qquad \text{กำหนด } C_3 = C_2 - C_1 

y^2 &=& x^2 + 2C_3 

y &=& \pm \sqrt{x^2 + C} \qquad \text{กำหนด } C = 2C_3 
\end{eq*}
ฉะนั้น ผลเฉลยทั่วไปของสมการเชิงอนุพันธ์คือ 
\[y =\sqrt{x^2 + C} \qquad \text{ และ } y = - \sqrt{x^2+C}\]
เมื่อ $C$ เป็นค่าคงตัว

:::





## 

เราสามารถสรุปตัวอย่างก่อนหน้านี้ ออกมาเป็นขั้นตอนการหาผลเฉลยได้ดังนี้ 

:::remark



- จัดรูปสมการ $\dyx = p(x)q(y)$ ใหม่ให้อยู่ในรูป
\[ \frac{1}{q(y)} d y= p(x) dx\] 

- อินทิเกรตทั้งสองข้างของสมการ จะได้
\[ \int \frac{1}{q(y)} \, dy = \int p(x) \, dx\]


:::





:::remark


\setcounter{enumi}{3}

- เราจะได้ $Q(y) = P(x) + C$ เป็นผลเฉลยของสมการ โดยที่ 


- $Q(y) = \int \frac{1}{q(y)} \, dy$ 

- $P(x) = \int p(x) \, dx$ 

- $C$ เป็นค่าคงตัว



:::






:::example

จงหาผลเฉลยของสมการเชิงอนุพันธ์ 
\[\dyx = \frac{x^4}{y^3}\]

:::


:::solution

ขั้นแรก เราจัดรูปสมการให้ตัวแปร $x$ อยู่ฝั่งหนึ่ง และตัวแปร $y$ อยู่อีกฝั่งหนึ่ง 
\[ y^3 \, dy = x^4 \, dx \] 
เมื่ออินทิเกรตทั้งสองข้างแล้วจะได้
\[ \int y^3 \, dy = \int x^4 \, dx\] 
ซึ่งคำนวนได้เป็น
\[\frac{y^4}{4} + C_1 = \frac{x^5}{5} + C_2\] 

:::





:::solution
(ต่อ) ท้ายสุด เรารวมค่าคงตัว $C_1$ และ $C_2$ เข้าด้วยกันและจัดรูปสมการได้ดังนี้ 
\begin{eq*}
\frac{y^4}{4} &=& \frac{x^5}{5} + C_3 \qquad \text{กำหนด } C_3 = C_2 - C_1 

y^4 &=& \frac{4}{5}x^5 + 4C_3 

y &=& \pm \sqrt[4]{\frac{4}{5}x^5 + C} \qquad \text{กำหนด } C = 4C_3 
\end{eq*}
ฉะนั้น ผลเฉลยทั่วไปของสมการเชิงอนุพันธ์คือ $y = \sqrt[4]{\frac{4}{5}x^5 + C}$ เมื่อ $C$ เป็นค่าคงตัว 

:::

**หมายเหตุ** เราไม่จำเป็นต้องจัดผลเฉลยให้อยู่ในรูป $y = f(x)$ เสมอไป เช่น
\[y^4 = \frac{4}{5}x^5 + C\]
ก็นับเป็นผลเฉลยได้เช่นกัน





:::example

จงหาผลเฉลยของสมการเชิงอนุพันธ์ 
\[\dyx = x^2y\]

:::


:::solution

ขั้นแรก เราจัดรูปสมการให้ตัวแปร $x$ อยู่ฝั่งหนึ่ง และตัวแปร $y$ อยู่อีกฝั่งหนึ่ง
\[ \frac{1}{y} \, dy = x^2 \, dx \] 
เมื่ออินทิเกรตทั้งสองข้างแล้วจะได้
\[ \int \frac{1}{y} \, dy = \int x^2 \, dx\] 
ซึ่งคำนวนได้เป็น
\[ \ln |y| +C_1 = \frac{x^3}{3} +C_2\]

:::





:::solution
(ต่อ) ท้ายสุด เรารวมค่าคงตัว $C_1$ และ $C_2$ เข้าด้วยกันและจัดรูปสมการได้ดังนี้ 
\begin{eq*}
\ln |y| &=& \frac{x^3}{3} + C_3 \qquad \text{กำหนด } C_3 = C_2 - C_1 

|y| &=& e^{\frac{x^3}{3} + C_3} 

&=&e^{\frac{x^2}{2}} \times e^{C_3} 

&=& Ce^{x^3}{3} \qquad \text{กำหนด } C_4 = e^{C_3} 

y &=& \pm C_4e^{x^3}{3}
\end{eq*}
สังเกตว่า $C_4 = e^{C_3} > 0$ เสมอ ฉะนั้นเมื่อรวมกับเครื่องหมาย $\pm$ จะได้ว่า $ \pm C_4$ แทนค่าคงตัวใด ๆ ที่ไม่เป็น 0 นั่นคือเราให้ $C = C_4$ ได้ 

ฉะนั้น ผลเฉลยทั่วไปของสมการเชิงอนุพันธ์คือ $y = Ce^{x^3}{3}$ เมื่อ $C$ เป็นค่าคงตัวใด ๆ ที่ไม่เป็น 0

:::
