## รูปแบบของผลเฉลย

ย้อนกลับไปที่สมการเชิงอนุพันธ์

:::note

\[ \dyx = 4x^3 \]

:::



:::slide

เราทราบว่า $y=x^4$ เป็นผลเฉลยหนึ่ง แต่ที่จริงแล้วสมการนี้มีผลเฉลยอื่น ๆ อีกด้วย ได้แก่
\[ y = x^4 + C \] 
เมื่อ $C$ เป็นค่าคงตัวใด ๆ (เช่น $x^4+1, \quad x^4-5, \quad x^4+100$) 

:::




ซึ่งสามารถกำหนดได้ถ้ามีเงื่อนไขอื่น เช่น
\[ \dyx = 4x^3 \text{ โดยที่ } y(0) = 2\] 

:::slide

ในที่นี้ จะมีผลเฉลยเดียวเท่านั้น ซึ่งก็คือ
\[ y(x) = x^4 + 2\] 
เนื่องจากเมื่อแทนค่า $x=0$ จะได้ $2 = y(0) = 0^4 + C$ เราจึงได้ $C=2$ 

:::





## นิยามของผลเฉลย


:::definition

ผลเฉลยของสมการเชิงอนุพันธ์ที่มีค่าคงตัวไม่เจาะจง คือ **ผลเฉลยทั่วไป** (General solution) 


ผลเฉลยซึ่งกำหนดค่าคงตัวนั้นให้มีค่าที่แน่นอน คือ **ผลเฉลยเฉพาะ** (Particular solution) 

:::


:::slide

จากสมการอนุพันธ์ $\dyx = 4x^3$ ผลเฉลย 
\[ y = x^4+C \] 
คือผลเฉลยทั่วไป ถ้าเราแทนค่า $C=2$ แล้วจะได้ผลเฉลยเฉพาะ
\[ y=x^4+2 \]

:::





## การตรวจสอบผลเฉลยของสมการเชิงอนุพันธ์

ก่อนที่จะทำการศึกษาวิธีการหาผลเฉลยในบทถัด ๆ ไป เราจะเริ่มจากการตรวจสอบผลเฉลยเสียก่อน พิจารณาสมการ
\[ x^2 - 5x + 4 = 0\]

:::slide

เราสามารถหาคำตอบของสมการได้เป็น $x = 1,4$ โดยเราสามารถตรวจสอบว่าคำตอบที่ได้มาถูกต้องเนื่องจาก
\[1^2 - (5)(1) + 4 = 0 \qquad \text{และ} \qquad 4^2 - (5)(4) + 4 = 0\]
ในทำนองเดียวกัน ถ้ากำหนดสมการเชิงอนุพันธ์มาให้ พร้อมกับฟังก์ชัน $y=f(x)$ เราสามารถตรวจสอบได้ว่า $y$ เป็นผลเฉลยของสมการนั้นหรือไม่ ได้ด้วยการนำไปแทนค่าเพื่อตรวจสอบว่าเป็นจริงหรือไม่

:::





:::example

จงแสดงว่า $y = Ce^{2x}$ เป็นผลเฉลยทั่วไปของสมการเชิงอนุพันธ์ 
\[\dyx= 2y \]

:::


:::solution

ถ้า $y =C e^{2x}$ แล้ว $\dyx = 2Ce^{2x}$ ดังนั้นเมื่อนำไปแทนในสมการจะได้
\[ \dyx = 2y \qquad \longrightarrow \qquad 2Ce^{2x} = 2y = 2Ce^{2x} \]
ฉะนั้น $y = Ce^{2x}$ เป็นผลเฉลยทั่วไปของสมการเชิงอนุพันธ์ $\dyx = 2y$

:::





:::example

จงแสดงว่า $y = C\sin 2x$ เป็นผลเฉลยทั่วไปของสมการเชิงอนุพันธ์ 
\[\dyx[2] + 4y = 0\]

:::


:::solution

ถ้า $y = C\sin 2x$ แล้ว $\dyx = 2C\cos 2x$ และ $\dyx[2] = -4C\sin 2x$ ดังนั้นเมื่อนำไปแทนในสมการจะได้
\[ \dyx[2] + 4y = 0 \qquad \longrightarrow \qquad -4C\sin 2x + 4C\sin 2x = 0\]
ฉะนั้น $y = C\sin 2x$ เป็นผลเฉลยทั่วไปของสมการเชิงอนุพันธ์ $\dyx[2] + 4y = 0$

:::





:::example

จงแสดงว่า $y = x^2 - 3x$ เป็นผลเฉลยเฉพาะของสมการเชิงอนุพันธ์ 
\[\dyx[2] - \dyx + 1 = 2x, \qquad y(0) = 0, y(3) = 0\]

:::


:::solution

ถ้า $y = x^2 - 3x$ แล้ว $\dyx = 2x-3$ และ $\dyx[2] = 2$ ดังนั้นเมื่อนำไปแทนในสมการจะได้
\[\dyx[2] + \dyx + 1 = 2x \qquad \longrightarrow \qquad (2) + (2x-3) + 1 = 2x\]
ซึ่งเป็นจริง นอกจากนี้เราต้องตรวจสอบว่าเงื่อนไขเป็นจริง ซึ่ง
\[y(0) = 0^2 - (3)(0) = 0 \qquad y(3) = 3^2-(3)(3) = 0\]
ฉะนั้น $y = x^2 - 3x$ เป็นผลเฉลยเฉพาะของสมการเชิงอนุพันธ์

:::
