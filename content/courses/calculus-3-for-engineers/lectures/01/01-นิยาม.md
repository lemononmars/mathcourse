## อะไรคือสมการ?

**สมการ** หมายถึงประโยคสัญลักษณ์ทางคณิตศาสตร์ที่ใช้แสดงว่าสองสิ่งเท่ากับ 

:::slide

\begin{eq*}
2+4 &=& 6 

\sqrt{9} &=& 3 

e^{i \pi} + 1 &=& 0 
\end{eq*}
ถ้ามีตัวแปรอยู่ในสมการนั้นแล้ว เราจะอยากหาผลเฉลยของสมการเพื่อหาคำตอบว่าตัวแปรนั้นมีค่าเท่าไหร่

:::






## เครื่องมืออะไร ใช้แก้สมการได้?


:::slide

เราได้ศึกษาเครื่องมือหาผลเฉลยของสมการมากมาย เช่น


- บวก-ลบ 

- คูณ-หาร 

- ยกกำลัง-ถอดราก 

- $e^x - \ln x$ 

- ฟังก์ชันผกผัน 


:::example

\begin{eq*}
x + 3 = 5 &\to& x = 2 

x^2 + 3x + 2 = 0 &\to& x = -1, -2 
\end{eq*}

:::

ซึ่งคำตอบที่ได้จะเป็นจำนวนเต็ม, จำนวนจริง, จำนวนเชิงซ้อน หรืออะไรก็ได้แล้วแต่เงื่อนไขที่กำหนด

:::
