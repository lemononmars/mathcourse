## การเขียนเวกเตอร์


:::definition



- เวกเตอร์ 2 มิติ: $\vec{v} = \langle v_1, v_2 \rangle$ โดยที่ $v_1, v_2$ เป็นจำนวนจริง 

- เวกเตอร์ 3 มิติ: $\vec{v} = \langle v_1, v_2, v_3 \rangle$ โดยที่ $v_1, v_2, v_3$ เป็นจำนวนจริง

## เวกเตอร์เชิงเรขาคณิต


:::definition พีชคณิตของเวกเตอร์ในปริภูมิสองมิติ

ถ้า $\vec{u} = \langle u_1, u_2 \rangle, \vec{v} = \langle v_1, v_2 \rangle$ เป็นเวกเตอร์ และ $k$ เป็นจำนวนจริงแล้ว 


- $\vec{u} + \vec{v} = \left\langle u_1+v_1, u_2+v_2 \right\rangle$ 

- $\vec{u} - \vec{v} = \left\langle u_1 - v_1, u_2 - v_2 \right\rangle $ 

- $k \vec{u} = \left\langle ku_1, ku_2 \right\rangle$


:::

*ผลบวกคูณเวกเตอร์ $k\vec{u*$ เมื่อ $k$ เท่ากับ $-3,-2,-1,1,2$ และ $3$}






:::example

กำหนดให้ $\vec{u} = \langle 1,3 \rangle$ และ $\vec{v} = \langle 4,2 \rangle$ จงหา


- $\vec{u} + \vec{v}$

- $\vec{u} - \vec{v} $

- $5\vec{u}$


:::


:::solution



- $\vec{u} + \vec{v} = \left\langle 1+4, 3+2 \right\rangle = \left\langle 5,5 \right\rangle$ 

- $\vec{u} - \vec{v} = \left\langle 1-4, 3-2 \right\rangle = \left\langle -3, 1 \right\rangle$ 

- $5 \vec{u} = \left\langle (5)(1), (5)(3) \right\rangle = \left\langle 5, 15 \right\rangle$


:::






:::example

กำหนดให้ $\vec{u} = \left\langle 6,8 \right\rangle$ และ $\vec{v} = \left\langle 3,4 \right\rangle$ จงหา


- $2\vec{u} + \vec{v}$

- $\vec{u} - 2\vec{v}$


:::


:::solution



- $2\vec{u} = \left\langle (2)(6), (2)(8) \right\rangle = \left\langle 12, 16 \right\rangle$ 

ฉะนั้น $2\vec{u} + \vec{v} = \left\langle 12, 16 \right\rangle + \left\langle 3,4 \right\rangle = \left\langle 12+3, 16+4 \right\rangle = \left\langle 15, 20 \right\rangle$ 

- $2\vec{v} = \left\langle (2)(3), (2)(4) \right\rangle = \left\langle 6, 8 \right\rangle$ 

ฉะนั้น $\vec{u} - 2\vec{v} = \left\langle 6,8 \right\rangle - \left\langle 6,8 \right\rangle = \left\langle 6-6, 8-8 \right\rangle = \left\langle 0,0 \right\rangle$


:::





## เวกเตอร์เชิงเรขาคณิต


:::definition

ถ้า $\vec{u} = \langle u_1, u_2, u_3 \rangle, \vec{v} = \langle v_1, v_2, v_3 \rangle$ เป็นเวกเตอร์ และ $k$ เป็นจำนวนจริงแล้ว 


- $\vec{u} + \vec{v} = \langle u_1 + v_1, u_2 + v_2, u_3 + v_3 \rangle$ 

- $\vec{u} - \vec{v} = \langle u_1 - v_1, u_2 - v_2, u_3 - v_3 \rangle$ 

- $k \vec{u} = \langle ku_1, ku_2, ku_3 \rangle$


:::





:::example

กำหนดให้ $\vec{u} = \langle 1,2,3 \rangle$ และ $\vec{v} = \langle 4,5,6 \rangle$ จงหา


- $\vec{u} + \vec{v}$

- $\vec{u} - \vec{v}$

- $-2\vec{u}$


:::


:::solution



- $\vec{u} + \vec{v} = \left\langle 1+4, 2+5, 3+6 \right\rangle = \left\langle 5,7,9 \right\rangle$ 

- $\vec{u} - \vec{v} = \left\langle 1-4, 2-5, 3-6 \right\rangle = \left\langle -3, -3, -3 \right\rangle$

- $-2 \vec{u} = \left\langle (-2)(1), (-2)(2), (-2)(3) \right\rangle = \left\langle -2, -4, -6 \right\rangle$


:::






:::example

กำหนดให้ $\vec{u} = \langle 0,1,2 \rangle$ และ $\vec{v} = \langle 3,2,1 \rangle$ จงหา


- $4\vec{u} + \vec{v}$

- $3\vec{u} - 2\vec{v}$


:::


:::solution



- $4\vec{u} = \left\langle (4)(0), (4)(1), (4)(2) \right\rangle = \left\langle 0,4,8 \right\rangle$ 

ฉะนั้น $4\vec{u} + \vec{v} = \left\langle 0,4,8 \right\rangle + \left\langle 3,2,1 \right\rangle = \left\langle 0+3, 4+2, 8+1 \right\rangle = \left\langle 3,6,9 \right\rangle$ 

- $3\vec{u} = \left\langle (3)(0), (3)(1), (3)(2) \right\rangle = \left\langle 0,3,6 \right\rangle$ 

$2\vec{v} = \left\langle (2)(3), (2)(2), (2)(1) \right\rangle = \left\langle 6,4,2 \right\rangle$ 

ฉะนั้น $3\vec{v} - 2\vec{u} = \left\langle 0,3,6 \right\rangle - \left\langle 6,4,2 \right\rangle = \left\langle 0-6, 3-4, 6-2 \right\rangle = \left\langle -6,-1,4 \right\rangle$


:::






## หลักเกณฑ์ทางเลขคณิตของเวกเตอร์


:::property

กำหนดเวกเตอร์ $\vec{u}, \vec{v}$ และค่าคงตัว $k,l$ แล้ว


- $\vec{u} + \vec{v} = \vec{v} + \vec{u}$ (สมบัติการสลับที่) 

- $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$ (สมบัติการเปลี่ยนกลุม่) 

- $\vec{u} + \vec{0} = \vec{0} + \vec{u} = \vec{u}$ เมื่อ $\vec{0} = \left\langle 0,0 \right\rangle$ ในปริภูมิสองมิติ และ $\vec{0} = \left\langle 0,0,0 \right\rangle$ ในปริภูมิสามมิติ

- $\vec{u} + (-\vec{u}) = \vec{0}$ 

- $k(l \vec{u}) = (kl) \vec{u}$ 

- $k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}$ (สมบัติการกระจาย)


:::
