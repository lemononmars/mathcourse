## เวกเตอร์หน่วยทิศทางขนานกับแกน


:::definition

ในปริภูมิสองมิติ นิยามเวกเตอร์หนึ่งหน่วยในทิศทางขนานกับแกน $x$ และแกน $y$ ดังนี้
\[\mathbf{i} = \vec{i} = \left\langle 1,0 \right\rangle , \qquad \mathbf{j} = \vec{j} = \left\langle 0,1 \right\rangle\]
ในปริภูมิสามมิติ นิยามเวกเตอร์หนึ่งหน่วยในทิศทางขนานกับแกน $x$ แกน $y$ และแกน $z$ ดังนี้
\[\mathbf{i} = \vec{i} = \left\langle 1,0,0 \right\rangle \qquad \mathbf{j} = \vec{j} = \left\langle 0,1,0 \right\rangle \qquad \mathbf{k} = \vec{k} = \left\langle 0,0,1 \right\rangle \]

:::

ในเอกสารนี้ เราจะใช้ $\vec{i}, \vec{j}$ และ $\vec{k}$ 






:::tikz TikZ diagram
\begin{tikzpicture}
\draw[very thin,color=gray] (-0.5,-0.5) grid (2.5,2.5);
\draw[<->, thick] (-0.5,0) -- (3,0) node[right] {$x$};
\draw[<->, thick] (0,-0.5) -- (0,3) node[above] {$y$};
\draw[->, blue, very thick] (0,0) -- (1,0) node[below right, scale = 1.5, fill = white, fill opacity = 0.8] {$\vec{i} = \left\langle 1,0 \right\rangle$};
\draw[->, red, very thick] (0,0) -- (0,1) node[right, scale = 1.5, fill = white, fill opacity = 0.8] {$\vec{j} = \left\langle 0,1 \right\rangle$};
\end{tikzpicture}
:::


*เวกเตอร์หน่วย $\vec{i*$ และ $\vec{j}$}



:::slide

เราสามารถเขียน $\vec{v}$ ในปริภูมิสองมิติ ในรูปของเวกเตอร์หนึ่งหน่วย $\vec{i}$ และ $\vec{j}$ ได้ดังนี้
\[ \vec{v} = \left\langle v_1, v_2 \right\rangle = \leftlangle v_1, + v_2 \rightangle\]

:::






:::tikz TikZ diagram
\begin{tikzpicture}[scale = 1.5]
\draw[->, thick] (0,0) -- (2,0) node[right] {$x$};
\draw[->, thick] (0,0) -- (-1,-1) node[left, below] {$y$};
\draw[->, thick] (0,0) -- (0,2) node[above] {$z$};
\draw[->, blue, very thick] (0,0) -- (1,0) node[above right, scale = 1.5] {$\vec{i} = \left\langle 1,0,0 \right\rangle$};
\draw[->, red, very thick] (0,0) -- (-0.5,-0.5) node[below right, scale = 1.5] {$\vec{j} = \left\langle 0,1,0 \right\rangle$};
\draw[->, teal, very thick] (0,0) -- (0,1) node[left, scale = 1.5] {$\vec{k} = \left\langle 0,0,1 \right\rangle$};
\end{tikzpicture}
:::


*เวกเตอร์หน่วย $\vec{i*, \vec{j}$ และ $\vec{k}$}



:::slide

เราสามารถเขียน $\vec{v}$ ในปริภูมิสามมิติ ในรูปของเวกเตอร์หน่วย $\vec{i}, \vec{j}$ และ $\vec{k}$ ได้ดังนี้
\[ \vec{v} = \left\langle v_1, v_2, v_3 \right\rangle = \vvv{v_1}{+ v_2}{+ v_3}\]

:::






:::example

จงแปลงเวกเตอร์ต่อไปนี้ให้เป็นรูปของเวกเตอร์หนึ่งหน่วย $\vec{i}$ และ $\vec{j}$ 


- $\left\langle 2,5 \right\rangle $

- $\left\langle -2,2 \right\rangle$

- $\left\langle 2,-2,1 \right\rangle$

- $\left\langle 0,0,1 \right\rangle$


:::


:::solution



- $\left\langle 2,5 \right\rangle = \leftlangle 2, +5 \rightangle$ 

- $\left\langle -2,2 \right\rangle = \leftlangle -2, +2 \rightangle$ 

- $\left\langle 2,-2,1 \right\rangle = \vvv{2}{-2}{+}$ 

- $\left\langle 0,0,3 \right\rangle = \vvv{0}{+0}{+3} = 3\mathbf{k}$


:::






:::example

จงแปลงเวกเตอร์ต่อไปนี้ให้เป็นรูปของเวกเตอร์ $\langle , \rangle$


- $\leftlangle 2, -5 \rightangle $

- $3\mathbf{i}$

- $\vvv{}{-4}{-}$

- $\mathbf{k} - 2\mathbf{j}$


:::


:::solution



- $\leftlangle 2, -5 \rightangle = \left\langle 2,-5 \right\rangle$ 

- $3\mathbf{i} = 3\mathbf{i} + 0\mathbf{j} = \left\langle 3,0 \right\rangle$ 

- $\vvv{}{-4}{-} = \left\langle 1,-4,-1 \right\rangle$ 

- $\mathbf{k} - 2\mathbf{j} = 0\mathbf{i} + (-2)\mathbf{j} + \mathbf{k} = \left\langle 0,-2,1 \right\rangle$


:::





## เวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันกับ \vec{u
$}

:::definition

กำหนดเวกเตอร์ $\vec{u}$ แล้ว\alert{เวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันกับ $\vec{u}$} คือ $\frac{1}{\| \vec{u} \|} \vec{u} $

:::





:::tikz TikZ diagram
\begin{tikzpicture}[scale=0.8]
\draw[gray, very thin] (-0.5,-0.5) grid (3.5,2.5);
\draw[<->] (-0.5,0) -- (3.5,0) node [pos=1, right] {$x$};
\draw[<->] (0,-0.5) -- (0,2.5) node [pos=1, above] {$y$};
\draw[->, teal] (0,0) -- (2,1) node [pos=1, above] {$\vec{u}$};
\draw[->, very thick, red] (0,0) -- (0.894,0.447) node [pos = 0.5, above left, fill = white, fill opacity = 0.5] {$\frac{1}{\| \vec{u} \|} \vec{u}$};
\end{tikzpicture}
:::


*เวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันกับ $\vec{u*$}






:::example

จงหาเวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันกับเวกเตอร์ $\left\langle 4,-3 \right\rangle$

:::


:::solution

$$\| \left\langle 4,-3 \right\rangle \| = \sqrt{4^2+(-3)^2} = 5$$ 
ดังนั้นเวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันคือ 
\begin{eq*}
\frac{1}{5} \left\langle 4,-3 \right\rangle &=& \bv{ \frac{1}{5} \times 4, \frac{1}{5} \times (-3) } 

&=& \bv{\frac{4}{5}, -\frac{3}{5}}
\end{eq*}

:::






:::example

จงหาเวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันกับเวกเตอร์ $\left\langle 2,-2,1 \right\rangle$

:::


:::solution

$$\| \left\langle 2,-2,1 \right\rangle \| = \sqrt{2^2+(-2)^2+1^2} = 3$$ 
ดังนั้นเวกเตอร์หนึ่งหน่วยที่มีทิศทางเดียวกันคือ 
\begin{eq*}
\frac{1}{3} \left\langle 2,-2,1 \right\rangle &=& \bv{ \frac{1}{3} \times 2, \frac{1}{3} \times (-2), \frac{1}{3} \times 1 } 

&=& \bv{\frac{2}{3}, \frac{-2}{3}, \frac{1}{3}}
\end{eq*}

:::
