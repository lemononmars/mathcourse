## ทบทวนฟังก์ชันประกอบ


:::theorem

กำหนดให้ $f(x)$ และ $g(x)$ เป็นฟังก์ชัน แล้วเรานิยามฟังก์ชันประกอบเป็น
\[ (f\circ g)(x) = f(g(x))\]

:::





:::example

ให้ $f(x) = x^2$ และ $g(x) = 3x$ จงหา 


- $(f \circ g)(x)$ 

- $(g \circ f)(x)$


:::


:::solution



- \begin{eqnarray*}
(f \circ g)(x) &=& f(g(x)) 

&=& (g(x))^2 

&=& (3x)^2 = 9x^2
\end{eqnarray*} 

- \begin{eqnarray*}
(g \circ f)(x) &=& g(f(x)) 

&=& 3f(x) 

&=& 3x^2
\end{eqnarray*}


:::





ในทางปฏิบัติ เราจะเปลี่ยนฟังก์ชันให้เป็นฟังก์ชันประกอบ 

:::example

จงแปลงฟังก์ชัน $f(x) = (x+2)^4$ ให้อยู่ในรูปของฟังก์ชันประกอบ $(u \circ v)(x)$

:::


:::solution

ให้ $f(x) = (x+2)^4$ 


- ถ้าเรากำหนดให้ $v(x) = x +2$ จะได้ $f(x) = (v(x))^4$ 

- ถ้าเรากำหนดให้ $u(x) = x^4$ จะได้ 
\[ f(x) = (v(x))^4 = u(v(x)) = (u \circ v)(x)\]


:::






:::example

จงแปลงฟังก์ชัน $f(x) = (x^2+3x)^3$ ให้อยู่ในรูปของฟังก์ชันประกอบ $(u \circ v)(x)$

:::


:::solution

ให้ $f(x) = (x^2+3x)^3$ 


- ถ้าเรากำหนดให้ $v(x) = x^2+3x$ จะได้ $f(x) = (v(x))^3$ 

- ถ้าเรากำหนดให้ $u(x) = x^3$ จะได้ 
\[ f(x) = (v(x))^3 = u(v(x)) = (u \circ v)(x)\]


:::






:::example

จงแปลงฟังก์ชัน $f(x) = \frac{1}{(x^3+1)^2}$ ให้อยู่ในรูปของฟังก์ชันประกอบ $(u \circ v)(x)$

:::


:::solution

ให้ $f(x) = \frac{1}{(x^3+1)^2}$ 


- ถ้าเรากำหนดให้ $v(x) = x^3 +1$ จะได้ $f(x) = \frac{1}{(v(x))^2}$ 

- ถ้าเรากำหนดให้ $u(x) = \frac{1}{x^2} = x^{-2}$ จะได้ 
\[ f(x) = \frac{1}{(u(x))^2} = (u(x))^{-2} = v(u(x)) = (v \circ u)(x)\]


:::






:::example

จงเขียนฟังก์ชัน $f(x) = \sqrt[3]{x^5+5}$ ให้อยู่ในรูปของฟังก์ชันประกอบ $(u \circ v)(x)$

:::


:::solution

ให้ $f(x) = \sqrt[3]{x^5+5}$ 


- ถ้าเรากำหนดให้ $v(x) = x^5+5$ จะได้ $f(x) = \sqrt[3]{v(x)}$ 

- ถ้าเรากำหนดให้ $u(x) = \sqrt[3]{x} = x^{\frac{1}{3}}$ จะได้ 
\[ f(x) = \sqrt[3]{v(x)} = u(v(x)) = (u \circ v)(x)\]


:::





## สูตรอนุพันธ์ของฟังก์ชันประกอบ (กฎลูกโซ่)


:::theorem

ถ้า $f(x) = (u \circ v)(x)$ เป็นฟังก์ชันประกอบแล้ว 
\begin{eqnarray}
\dx f(x) = \dx (u \circ v)(x) &=& \left(\frac{d}{d v(x)} u(v(x))\right)\left( \dx v(x)\right)
\end{eqnarray}

:::

โดยที่ความหมายของ $\frac{d}{d v(x)} u(v(x))$ คือ การหาอนุพันธ์ $\frac{d}{dx} u(x)$ แล้วเปลี่ยนตัวแปร $x$ ให้กลายเป็นฟังก์ชัน $v(x)$





:::example

จงหา $\dx (x+2)^4$

:::


:::solution

กำหนดให้ $f(x) = (x+2)^4$ เมื่อเขียนให้เป็นรูปของฟังก์ชันประกอบจะได้ 
\[ v(x) = x+2, \quad u(x) = x^4 \]
\[ \dx v(x) = 1, \quad \dx u(x) = 4x^3 \rightarrow \frac{d}{d**v(x)**} u(**v(x)**) = 4(**v(x)**)^3\]
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx (u \circ v)(x) &=& \left(\frac{d}{d v(x)} u(v(x))\right)\left( \dx v(x)\right) 

&=& 4(v(x))^3 (1) 

&=& 4(x+2)^3
\end{eqnarray*}

:::






:::example

จงหา $\dx (x^2+1)^3$

:::


:::solution

กำหนดให้ $f(x) = (x^2+1)^3$ เมื่อเขียนให้เป็นรูปของฟังก์ชันประกอบจะได้ 
\[ v(x) = x^2+1 , \quad u(x) = x^3\]
\[\dx v(x) = 2x, \quad \dx u(x) = 3x^2 \rightarrow \frac{d}{d**v(x)**} u(**v(x)**) = 3(**v(x)**)^2\] 
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx (u \circ v)(x) &=& \left(\frac{d}{d v(x)} u(v(x))\right)\left( \dx v(x)\right) 

&=& 3(v(x))^2 (2x) 

&=& 3(x^2+1)^2 (2x) = 6x(x^2+1)^2
\end{eqnarray*}

:::






:::example

จงหา $\dx \frac{1}{(x^3+3x)^4}$

:::


:::solution

กำหนดให้ $f(x) = \tfrac{1}{(x^3+3x)^4}$ เมื่อเขียนให้เป็นรูปของฟังก์ชันประกอบจะได้ 
\[ v(x) = x^3+3x, \quad u(x) = \tfrac{1}{x^4} = x^{-4}\]
\[ \dx v(x) = 3x^2+3, \quad \dx u(x) = -4x^{-5} \rightarrow \frac{d}{dv(x)} u(v(x)) = -4(v(x))^{-5}\]
ฉะนั้น
\begin{eqnarray*}
\dx (u \circ v)(x) &=& \left(\frac{d}{d v(x)} u(v(x))\right)\left( \dx v(x)\right) 

&=&= -4(v(x))^{-5} \cdot (3x^2+3) 

&=& (-4(x^3+3x)^{-5} \cdot (3x^2+3) = -4(3x^2+3)(x^3+3x)^{-5}
\end{eqnarray*}

:::





## สูตรอนุพันธ์ของฟังก์ชันประกอบแบบย่อ


:::theorem

ถ้า $f(x) = (u \circ v)(x)$ เป็นฟังก์ชันประกอบแล้ว 
\begin{eqnarray*}
\dx f(x) = \dx (u \circ v)(x) &=& u'(v(x)) \cdot v'(x) 

&=& (u'(v) \cdot v' )(x) \nonumber
\end{eqnarray*}

:::





## อนุพันธ์ฟังก์ชันยกกำลัง

เนื่องจากอนุพันธ์ของฟังก์ชันประกอบในรูปแบบฟังก์ชันยกกำลังใช้บ่อย เราจึงสรุปเป็นสูตรได้ตามนี้

:::theorem

กำหนดฟังก์ชัน $u(x)$ ที่หาอนุพันธ์ได้ และ $n$ เป็นจำนวนจริงที่ไม่เท่ากับ 0 แล้ว
\begin{equation} 
\dx (u(x))^n = nu(x)^{n-1} \dx u(x)
\end{equation}

:::





:::example

จงหา $\dx (3x+1)^4$

:::


:::solution

\begin{eq*}
\dx (3x+1)^4 &=& 4(3x+1)^3 \dx (3x+1) 

&=& 4 (3x+1)^3 (3) 

&=& 12 (3x+1)^3
\end{eq*}

:::






:::example

จงหา $\dx (x^2-1)^5$

:::


:::solution

\begin{eq*}
\dx (x^2-1)^5 &=& 5(x^2-1)^4 \dx (x^2-1) 

&=& 5 (x^2-1)^4 (2x) 

&=& 10x (x^2-1)^4
\end{eq*}

:::






:::example

จงหา $\dx \sqrt{6x+5}$

:::


:::solution

\begin{eq*}
\dx \sqrt{6x+5} &=& \dx (6x+5)^{1/2} 

&=& \frac{1}{2} (6x+5)^{-1/2} \dx (6x+5) 

&=& \frac{1}{2 \sqrt{ 6x+5}} (6) 

&=& \frac{3}{\sqrt{6x+5}}
\end{eq*}

:::
