## อนุพันธ์ฟังก์ชัน f(x) = \sin x


:::theorem

กำหนดให้ $f(x) = \sin x$ จะได้ว่า
\begin{equation} 
\dx \sin x = \cos x
\end{equation}
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า 
\[ \dx \sin (u(x)) = \cos u(x) \left( \dx u(x)\right)\]

:::






:::example

จงหา


- $\dx \sin (4x)$

- $\dx \sin (5x+1)$ 

- $\dx \sin (e^x)$


:::


:::solution

\begin{eqnarray*}
\dx \sin (4x) &=& \cos (4x) \dx 4x 

&=& (\cos (4x))(4) = 4 \cos (4x) 

\dx \sin (5x+1) &=& \cos (5x+1) \dx (5x+1) 

&=& 5 \cos (5x+1) 

\dx \sin (e^x) &=& \cos (e^x) \dx (e^x) 

&=& e^x \cos (e^x)
\end{eqnarray*}

:::





## อนุพันธ์ฟังก์ชัน f(x) = \cos x


:::theorem

กำหนดให้ $f(x) = \cos x$ จะได้ว่า
\begin{equation}
\dx \cos x = -\sin x
\end{equation} 
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า
\[ \dx \cos (u(x)) = -\sin u(x) \left( \dx u(x) \right)\]

:::






:::example

จงหา


- $\dx \cos (-2x)$

- $\dx \cos (x^2+2)$ 

- $\dx \cos (\ln x)$


:::


:::solution

\begin{eqnarray*}
\dx \cos (-2x) &=& -\sin (-2x) \left(\dx (-2x)\right) 

&=& (-\sin(-2x)) (-2) = 2 \sin (-2x) 

\dx \cos (x^2+2) &=& -\sin (x^2+2) \left(\dx (x^2+2) \right) 

&=& (-\sin(x^2+2))(2x) = -2x\sin(x^2+2) 

\dx \cos (\ln x) &=& -\sin (\ln x) \left(\dx \ln x\right) = (-\sin (\ln x))\left( \frac{1}{x} \right) 

&=& \tfrac{-\sin (\ln x)}{x}
\end{eqnarray*}

:::





## อนุพันธ์ฟังก์ชัน f(x) = \tan x


:::theorem

กำหนดให้ $f(x) = \tan x$ จะได้ว่า
\begin{equation}
\dx \tan x = (\sec x)^2
\end{equation}
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า
\[ \dx \tan (u(x)) = ( \sec u(x) )^2 \left( \dx u(x) \right)\]

:::





## อนุพันธ์ฟังก์ชันตรีโกณมิติอื่น

สำหรับฟังก์ชันตรีโกณมิติส่วนกลับ ได้แก่
\[ \sec x = \frac{1}{\cos x}, \qquad \csc x = \frac{1}{\sin x}, \qquad \cot x = \frac{1}{\tan x}\]
เราสามารถหาสูตรได้โดยใช้อนุพันธ์ฟังก์ชันผลหาร ซึ่งจะได้ผลลัพธ์ดังนี้

:::theorem

\begin{eq}
\dx \sec u(x) &=& \sec u(x) \tan u(x) \dx u(x) 

\dx \csc u(x) &=& -\csc u(x) \cot u(x) \dx u(x) 

\dx \cot u(x) &=& -(\csc u(x))^2 \dx u(x)
\end{eq}

:::






:::example

จงหา


- $\dx \tan (3x+2)$

- $\dx \sec (x^3)$ 

- $\dx \cot (\cos x)$


:::


:::solution

\begin{eqnarray*}
\dx \tan(3x+2) &=& (\sec (3x+2))^2 \left( \dx (3x+2) \right) = 3(\sec (3x+2)^2) 

\dx \sec (x^3) &=& \sec (x^3) \tan (x^3) \left( \dx (x^3) \right) 

&=& 3x^2 \sec (x^3) \tan (x^3) 

\dx \cot (\cos x) &=& -(\csc (\cos x))^2 \left( \dx \cos x\right) 

&=& - (\csc (\sin x))^2 (- \sin x) = (\csc (\cos x))^2 (\sin x)
\end{eqnarray*}

:::
