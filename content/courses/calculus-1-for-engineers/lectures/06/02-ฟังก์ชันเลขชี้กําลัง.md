## ฟังก์ชันเลขชี้กำลัง

ฟังก์ชันนึงที่มีความสำคัญมากในการสร้างแบบจำลองทางคณิตศาสตร์ คือฟังก์ชันเลขชี้กำลัง
\[ f(x) = a^x\]
โดยที่ $a$ เป็นจำนวนจริงบวก


:::remark ข้อควรระวัง

ฟังก์ชันยกกำลัง $f(x) = x^n$ และฟังก์ชันเลขชี้กำลัง $g(x) = n^x$ เป็นฟังก์ชันที่แตกต่างกัน โดยสังเกตได้จากตำแหน่งของตัวแปร เช่น
\begin{eq*}
f(x) = x^4 &\longrightarrow& f(3) = 3^4 = (3)(3)(3)(3) = 81 

g(x) = 4^x &\longrightarrow& g(3) = 4^3 = (4)(4)(4) = 64
\end{eq*}

:::





## ฟังก์ชันลอการิทึม

ฟังก์ชันที่ต้องพิจารณาคู่กับฟังก์ชันเลขชี้กำลังเสมอ คือฟังก์ชันลอการิทึม ซึ่งเป็นฟังก์ชันผกผันของฟังก์ชันเลขชี้กำลัง และมีนิยามดังนี้

:::definition

นิยามฟังก์ชันลอการิทึมฐานธรรมชาติ 
\[f(x) = \ln x\]
เป็นฟังก์ชันผกผันของ $e^x$ นั่นคือ
\[ y = \ln x \text{ ก็ต่อเมื่อ } e^y = x\]

:::

เช่น ถ้ากำหนดให้ $a = \ln (e^7)$ แล้วจะได้ว่า $e^a = e^7$ นั่นคือ $a=7$ นั่นเอง




## อนุพันธ์ฟังก์ชันชี้กำลัง


:::theorem

นิยามฟังก์ชัน $f(x) = e^x$ เมื่อ $e$ เป็นค่าคงตัว $e \approx 2.71827$ 
แล้วจะได้ว่า
\begin{equation} 
\dx e^x = e^x\
\end{equation}
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า 
\[ \dx e^{u(x)} = e^{u(x)} \dx u(x)\]

:::






:::example

จงหา


- $\dx e^{2x}$

- $\dx e^{3x+4}$

- $\dx e^{x^2}$


:::


:::solution

\begin{eqnarray*}
\dx e^{2x} = e^{2x} \dx 2x &=& e^{2x} (2) 

&=& 2e^{2x} 

\dx e^{3x+4} = e^{3x+4} \dx (3x+4) &=& e^{3x+4} (3) 

&=& 3e^{3x+4} 

\dx e^{x^2} = e^{x^2} \dx x^2 &=& e^{x^2} (2x) 

&=& 2xe^{x^2}
\end{eqnarray*}

:::






:::example

จงหา


- $\dx xe^x$

- $\dx e^{e^x}$


:::


:::solution

\begin{eqnarray*}
\dx xe^x &=& x \dx e^x + e^x \dx x \boxed{\text{อนุพันธ์ของผลคูณฟังก์ชัน}} 

&=& x(e^x) + e^x(1) 

&=& xe^x + e^x 

\dx e^{e^x} &=& e^{e^x} \dx e^x 

&=& e^{e^x} (e^{x}) 

&=& e^{(e^x + x)} \boxed{\text{สมบัติของฟังก์ชันเลขชี้กำลัง}}
\end{eqnarray*}

:::





## ฟังก์ชันเลขชี้กำลัง สำหรับฐานใด ๆ

เราศึกษาอนุพันธ์ของฟังก์ชัน $f(x) = e^x$ เนื่องจากมีสมบัติที่จำได้ง่ายว่า
\[ \dx e^x = e^x\]
ถ้าฟังก์ชันเลขชี้กำลังมีฐานอื่นที่ไม่ใช่ $e$ เราสามารถใช้สมบัติของฟังก์ชันเลขชี้กำลังเพื่อแปลงได้ดังนี้ กำหนดฟังก์ชัน $f(x) = a^x$ แล้วจะได้ว่า
\[a^x = (e^{(\ln a)})^x = e^{ (\ln a) x} \]
โดยที่ $\ln a$ เป็นค่าคงที่ ถ้าเรามองเลขชี้กำลังเป็นฟังก์ชัน $u(x) = (\ln a)x$ และใช้กฎลูกโซ่จะได้
\begin{eq*}
\dx a^x = \dx \left(e^{(\ln a)x}\right) &=& e^{(\ln a)x} \left( \dx (\ln a) x\right) 

&=& e^{(\ln a)x} (\ln a) = (\ln a) a^x
\end{eq*}




## อนุพันธ์ฟังก์ชันเลขชี้กำลัง สำหรับฐานใด ๆ


:::theorem

กำหนดฟังก์ชัน $f(x) = a^x$ แล้วจะได้ว่า
\begin{equation} 
\dx a^x = (\ln a)a^x
\end{equation}
เมื่อ $\ln a$ เป็นค่าคงตัว
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า 
\[ \dx a^{u(x)} = (\ln a)a^{u(x)} \dx u(x)\]

:::






:::example

จงหา


- $\dx 2^{x}$

- $\dx \left(\frac{1}{3^x}\right)$

- $\dx 4^{x^2}$


:::


:::solution

\begin{eqnarray*}
\dx 2^x &=& (\ln 2)2^x 

\dx \left(\frac{1}{3^x}\right) &=& \dx (3^{-x}) = (\ln 3)3^{-x} \left( \dx (-x) \right) 

&=& -(\ln 3)3^{-x} 

\dx 4^{x^2} &=& (\ln 4) 4^{x^2} \left( \dx x^2\right) 

&=& (2 \ln 4)(x)4^{x^2}
\end{eqnarray*}

:::
