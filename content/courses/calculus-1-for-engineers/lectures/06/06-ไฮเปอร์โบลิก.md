## นิยามฟังก์ชันไฮเปอร์โบลิก

แม้ว่าจะดูคล้ายกับเส้นโค้งของฟังก์ชันพาราโบลา $f(x) = x^2$ แต่ที่จริงแล้วเส้นโค้งนี้ขึ้นอยู่กับฟังก์ชันเลขชี้กำลัง $f(x) = e^x$ ตามนิยามดังนี้

:::definition

\begin{eq}
\sinh x &=& \frac{e^x - e^{-x}}{2} 

\cosh x &=& \frac{e^x + e^{-x}}{2} 

\tanh x &=& \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}} 
\end{eq}

:::





## นิยามฟังก์ชันไฮเปอร์โบลิกส่วนกลับ

เราสามารถนิยามฟังก์ชันตรีไฮเปอร์โบลิกส่วนกลับ ได้ในทำนองเดียวกันกับฟังก์ชันตรีโกณมิติส่วนกลับได้ดังนี้

:::definition

\begin{eq}
\csch x &=& \frac{1}{\sinh x} = \frac{2}{e^x - e^{-x}} 

\sech x &=& \frac{1}{\cosh x} = \frac{2}{e^x + e^{-x}} 

\coth x &=& \frac{1}{\tanh x} = \frac{e^x + e^{-x}}{e^x - e^{-x}}
\end{eq}

:::

## อนุพันธ์ฟังก์ชันไฮเปอร์โบลิก

เนื่องจากฟังก์ชันไฮเปอร์โบลิก สร้างขึ้นมาจากฟังก์ชันเลขชี้กำลัง เราจึงหาอนุพันธ์ได้โดยตรงดังนี้

:::theorem





- $\dx \sinh x = \cosh x$

- $\dx \cosh x = \sinh x$

- $\dx \tanh x = (\sech x)^2$	





- $\dx \coth x = (\csch x)^2$

- $\dx \sech x = -\sech x \tanh x$

- $\dx \csch x = -\csch x \coth x$




:::

การพิสูจน์อนุพันธ์ของ $\sinh x$ อยู่ในบทพิสูจน์ G)




## อนุพันธ์ฟังก์ชันไฮเปอร์โบลิก

เมื่อใช้ร่วมกับกฎลูกโซ่แล้วจะได้สูตรดังต่อไปนี้

:::theorem





- $\dx \sinh u = \cosh u \dux$

- $\dx \cosh u = \sinh u \dux$

- $\dx \tanh u = (\sech u)^2 \dux$	





- $\dx \coth u = -(\csch u)^2 \dux$

- $\dx \sech u = -\sech u \tanh u \dux$

- $\dx \csch u = -\csch u \coth u \dux$




:::






:::example

จงหา


- $\dx \sinh (5x)$

- $\dx \cosh (x^3)$ 

- $\dx \tanh (\sqrt[3]{x})$


:::


:::solution

\begin{eqnarray*}
\dx \sinh (**5x**) &=& \cosh (**5x**) \dx (**5x**) 

&=& 5\cosh (5x)

\dx \cosh (**x^3**) &=& \sinh (**x^3**) \dx (**x^3**) 

&=& 3x^2\sinh (x^3) 

\dx \tanh (\red{\sqrt[3]{x}}) &=& (\sech^2 (\red{\sqrt[3]{x}})) \dx (\red{\sqrt[3]{x}}) 

&=& (\sech^2 (\sqrt[3]{x})) \frac{1}{3}x^{-\frac{2}{3}}
\end{eqnarray*}

:::
