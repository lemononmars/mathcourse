## อนุพันธ์ฟังก์ชันลอการิทึม


:::theorem

กำหนดให้ $f(x) = \ln x$ แล้วจะได้ว่า 
\begin{equation} 
\dx \ln x = \frac{1}{x}
\end{equation}
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า 
\[ \dx \ln (u(x)) = \frac{1}{u(x)} \left( \dx u(x) \right)\]

:::







:::example

จงหา


- $\dx \ln (3x)$

- $\dx \ln (4x-2)$

- $\dx \ln(x^3+2x)$


:::


:::solution

\begin{eqnarray*}
\dx \ln (3x) &=& \frac{1}{3x} \left(\dx 3x\right) = \left(\frac{1}{3x} \right)( 3 )= \frac{1}{x} 

\dx \ln (4x-2) &=& \frac{1}{4x-2} \left(\dx (4x-2)\right) = \left(\frac{1}{4x-2}\right) (4) = \frac{4}{4x-2} 

\dx \ln (x^3+2x) &=& \frac{1}{x^3+2x} \left(\dx (x^3+2x)\right) = \left(\frac{1}{x^3+2x}\right) (3x^2+2) 

&=& \frac{3x^2+2}{x^3+2x}
\end{eqnarray*}

:::






:::example

จงหา $\dx \ln(e^x + x^e)$

:::


:::solution

\begin{eqnarray*}
\dx \ln (e^x + x^e) &=& \frac{1}{e^x+x^e} \left( \dx (e^x + x^e) \right) 

&=& \left( \frac{1}{e^x+x^e} \right) (e^x + ex^{e-1}) 

&=& \frac{e^x + ex^{e-1}}{e^x + x^e} 

\end{eqnarray*}

:::






:::example

จงหา $\dx \ln (\ln x)$

:::


:::solution

\begin{eqnarray*}
\dx \ln (\ln x) &=& \frac{1}{\ln x} \left( \dx \ln x\right) 

&=& \frac{1}{\ln x} \left( \frac{1}{x}\right) 

&=& \frac{1}{x\ln x}
\end{eqnarray*}

:::





## ข้อควรระวัง 1


:::remark

การเขียนฟังก์ชันลอการิทึมต้องระวังเรื่องการใส่วงเล็บ พิจารณา
\[ f(x) = \ln x + 1\]
ฟังก์ชันนี้สามารถตีความได้สองอย่างคือ $(\ln x) + 1$ หรือ $\ln (x+1)$ ดังนั้น เพื่อหลีกเลี่ยงความกำกวม จึงควรจะใส่วงเล็บทุกครั้ง**ถ้า**ตัวแปรในฟังก์ชันลอการิทึมไม่ใช่ $x$ โดด ๆ เช่น
\[ \ln (2x), \quad \ln(x^4), \quad \ln (x^2+1), \quad \ln\left( \tfrac{1}{x} \right) \]
และถ้ามีการบวกลบหรือคูณฟังก์ชันอื่น ควรจะวางไว้หน้าฟังก์ชัน $\ln$ เช่น
\[ 2 \ln x, \quad x^3 + \ln x, \quad x\ln (x^2)\]

:::





## ข้อควรระวัง 2


:::remark

ฟังก์ชัน $f(x) =(\ln x)^2$ และ $g(x) = \ln (x^2)$ เป็นคนละฟังก์ชันกัน


- $(\ln x)^2$ หมายความว่าให้หาค่าของ $\ln x$ ก่อน จากนั้นนำค่าที่ได้ไปยกกำลังสอง

- $\ln (x^2)$ หมายความว่าให้นำ $x$ ไปยกกำลังสองก่อน จากนั้นนำค่าที่ได้ไปใส่ในฟังก์ชันลอการิทึม

ฉะนั้น เวลาใช้กฎลูกโซ่จึงต้องเรียงลำดับให้ถูกต้อง ดังตัวอย่างต่อไปนี้


:::






:::example

จงหา 


- $\dx (\ln x)^2$

- $\dx \ln (x^2)$


:::



:::solution



กำหนดให้ $u = \ln x$ จะได้ 
\begin{eq*}
\dx (\ln x)^2 &=& \dx (u^2) 

&=& 2u \dx (u) 

&=& 2\ln x \left( \dx \ln x \right) 

&=& 2 \ln x \left( \frac{1}{x} \right) = \frac{2\ln x}{x}
\end{eq*}


กำหนดให้ $u = x^2$ จะได้ 
\begin{eq*}
\dx \ln (x^2) &=& \dx \ln u 

&=& \frac{1}{u} \dx (u) 

&=& \frac{1}{x^2} \left( \dx x^2\right) 

&=& \frac{1}{x^2} (2x) = \frac{2x}{x^2} = \frac{2}{x}
\end{eq*}



:::






## ฟังก์ชันลอการิทึม สำหรับฐานใด ๆ

เราได้ศึกษาอนุพันธ์ฟังก์ชันลอการิทึมฐานธรรมชาติ
\[ \dx \ln x = \frac{1}{x}\]
ซึ่งที่จริงแล้วเราสามารถหาอนุพันธ์ของฟังก์ชันลอการิทึมฐานใดก็ได้ โดยใช้สมบัติของฟังก์ชันลอการิทึมที่ว่า
\[\log_a x = \frac{\ln x}{\ln a}\]
ฉะนั้น 
\begin{eq*}
\dx (\log_a) x = \dx \left(\frac{\ln x}{\ln a}\right) &=& \frac{1}{\ln a} \left( \dx \ln x \right) \boxed{\text{$\ln a$ เป็นค่าคงตัว}} 

&=& \frac{1}{\ln a} \left( \frac{1}{x} \right) = \frac{1}{(\ln a)x}
\end{eq*}




## อนุพันธ์ฟังก์ชันลอการิทึม สำหรับฐานใด ๆ


:::theorem

กำหนดให้ $f(x) = \log_a x$ แล้วจะได้ว่า 
\begin{equation} 
\dx (\log_a) x = \frac{1}{(\ln a)x}
\end{equation}
กำหนดให้ $u = u(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ จากกฎลูกโซ่ของฟังก์ชันประกอบจะได้ว่า 
\[ \dx \log_a (u(x)) = \frac{1}{(\ln a)u(x)} \left(\dx u(x)\right)\]

:::
