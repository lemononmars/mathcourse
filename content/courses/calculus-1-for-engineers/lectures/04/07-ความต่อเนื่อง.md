## ที่มาของความต่อเนื่อง

ถ้าฟังก์ชัน $f(x)$ ไม่มีลิมิตที่จุด $x=a$ เมื่อเราวาดกราฟเราจะเห็นว่ากราฟทางซ้ายและทางขวาของจุด $x=a$ จะไม่เชื่อมกัน เราจะเรียกฟังก์ชันประเภทนี้ว่าฟังก์ชันที่**ไม่ต่อเนื่อง** ที่จุด $x=a$



:::tikz TikZ diagram
\begin{tikzpicture}[scale = 0.8]

\draw (-2,3) .. controls (-0.5,0) .. (1,2);
\draw (1,3) .. controls (1.5,4) .. (2,1);
\filldraw[fill = white] (1, 2) circle [radius = 0.1cm];
\filldraw[fill = black] (1, 3) circle [radius = 0.1cm];
\draw[dotted] (1,2) -- (1,0) node[below = 0.1cm] {$1$};
\end{tikzpicture}
:::


*ตัวอย่างกราฟของฟังก์ชัน $f(x)$ ที่ไม่มีลิมิตที่ $x=1$*




แต่ฟังก์ชันที่มีลิมิตที่จุด $x=a$ ก็อาจจะไม่ต่อเนื่องที่จุดนั้นก็ได้ ดังตัวอย่างในภาพต่อไปนี้



:::tikz TikZ diagram

\end{tikzpicture}
:::


*ตัวอย่างกราฟของฟังก์ชัน $f(x)$ ที่มีลิมิตที่ $x=-1$ และ $x=1$ แต่ไม่ต่อเนื่อง*

ฟังก์ชัน $f(x)$ ไม่นิยามค่าที่จุด $x=-1$ ส่วนจุด $x=1$ ฟังก์ชันนิยามค่า แต่ค่าของฟังก์ชันไม่เท่ากับค่าของลิมิต เรานับว่าทั้งสองกรณีนี้ฟังก์ชันไม่ต่อเนื่องที่จุดนั้น ๆ




## นิยามความต่อเนื่อง


:::definition

ฟังก์ชัน $f$ มีความต่อเนื่องที่จุด $x=a$ ก็ต่อเมื่อเงื่อนไขต่อไปนี้ทั้งหมดเป็นจริง 


- $f(a)$ หาค่าได้ 

- $\limx{a} f(x)$ หาค่าได้ 

- $\limx{a} f(x) = f(a)$ 

แต่ถ้าขาดสมบัติข้อใดข้อหนึ่งไป ในสามข้อที่กล่าวมา จะกล่าวว่า $f$ ไม่มีความต่อเนื่องที่จุด $x=c$ 

:::






:::example

จงพิจารณาว่าฟังก์ชัน 
\[f(x) = x+5\]
มีความต่อเนื่องที่จุด $x = 3$ หรือไม่

:::


:::solution

เราใช้นิยามตรวจสอบได้ดังนี้ 


- $f(3) = 8$ นั่นคือ $f(3)$ หาค่าได้ 

- $\limx{a} f(x) = \limx{3} (x+5) 3+5 = 8$ หาค่าได้

- $\limx{3} f(x) = f(3)$ 

เนื่องจากสมบัติทั้งสามข้อเป็นจริง ฉะนั้นฟังก์ชัน $f(x) = x+5$ **มีความต่อเนื่อง** ที่จุด $x = 3$

:::






:::example

จงพิจารณาว่าฟังก์ชัน 
\[f(x) = \frac{x^2+x}{x}\]
มีความต่อเนื่องที่จุด $x = 0$ หรือไม่

:::


:::solution

เราใช้นิยามตรวจสอบได้ดังนี้ 


- $f(0)$ หาค่าไม่ได้ เนื่องจาก $\frac{x^2+x}{x}$ หาค่าไม่ได้เมื่อแทนค่า $x=0$ 

เนื่องจากสมบัติข้อแรกเป็นเท็จ ฉะนั้นฟังก์ชัน $f(x)$ **ไม่มีความต่อเนื่อง** ที่จุด $x = 0$

:::






:::example

จงพิจารณาว่าฟังก์ชัน 
\[f(x) = \begin{cases} \frac{x^2+x}{x} &\mbox{เมื่อ } x \neq 0 
1 &\mbox{เมื่อ } x = 0\end{cases}\]
มีความต่อเนื่องที่จุด $x = 0$ หรือไม่

:::


:::solution

เราใช้นิยามตรวจสอบได้ดังนี้ 


- $f(0)$ หาค่าได้ เนื่องจากนิยามไว้ว่า $f(0) = 1$ 

- $\limx{a} f(x) = \limx{0} \frac{x^2+x}{x} = \limx{0} = x+1 = 1$ หาค่าได้ 

- $\limx{0} f(x) = f(0)$ 

เนื่องจากสมบัติทั้งสามข้อเป็นจริง ฉะนั้นฟังก์ชัน $f(x)$ **มีความต่อเนื่อง** ที่จุด $x = 0$

:::





## ฟังก์ชันต่อเนื่อง

เมื่อเรานิยามความต่อเนื่อง ณ จุดหนึ่งได้แล้ว เราก็จะสามารถขยายนิยามออกไปได้อีก ดังนี้

:::definition



- ถ้า $f$ มีความต่อเนื่องทุกจุดบนช่วงเปิด $(a,b)$ แล้วเราจะกล่าวว่า $f$ มีความต่อเนื่องบนช่วง $(a,b)$ 

- ถ้าฟังก์ชัน $f$ ที่มีความต่อเนื่องทุกจุดบนช่วง $(-\infty, +\infty)$ (นั่นคือ ต่อเนื่องสำหรับทุกจำนวนจริง) เราจะกล่าวว่า $f$ เป็นฟังก์ชันต่อเนื่อง 


:::

ซึ่งฟังก์ชันต่อเนื่อง ไม่ว่าจะเป็นช่วง $(a,b)$ หรือต่อเนื่องสำหรับทุกจำนวนจริง เป็นเงื่อนไขสำคัญสำหรับทฤษฎีบทในอนุพันธ์และปริพันธ์ ที่เราจะได้เรียนในภาคเรียนนี้





:::example

จงพิจารณาว่าฟังก์ชัน $f(x) = \frac{1}{x^2-x+2}$ มีความต่อเนื่องบนช่วงต่อไปนี้หรือไม่


- $(-6,-4)$

- $(-3, 0)$

- $(0,1)$

- $(3,5)$


:::


:::solution

เราสามารถตรวจสอบได้ไม่ยากว่าฟังก์ชัน $f(x)$ หาค่าไม่ได้ (นั่นคือไม่ต่อเนื่อง) ที่จุด $x = -2$ และ $x=1$ จากนั้นตรวจสอบว่าช่วงใดมีจุด $x=-2$ และ $x=1$


- $f$ ต่อเนื่องบน $(-6,-4)$ 

- $f$ ไม่ต่อเนื่องบน $(-3,0)$ เนื่องจากไม่ต่อเนื่องที่จุด $x=-2$ 

- $f$ ต่อเนื่องบน $(0,1)$ เนื่องจากจุด $x=1$ ไม่อยู่บนช่วงเปิด $(0,1)$ 

- $f$ ต่อเนื่องบน $(3,5)$


:::
