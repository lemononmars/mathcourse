## ลิมิตของฟังก์ชันในรูป \tfrac{0
{0}$}
บางครั้งเราแทนค่า $a$ ในฟังก์ชัน $f(x)$ แล้วได้ตัวส่วนเป็น 0 

:::note



- $f(x) = \frac{1}{x}$ แทนค่า $x=0$ 

- $f(x) = \frac{x^2-1}{x-1}$ แทนค่า $x=1$ 

- $f(x) = \frac{x}{\sin x}$ แทนค่า $x = \pi$ 


:::

ในกรณีเหล่านี้ เรายังไม่สามารถสรุปโดยทันทีว่าลิมิตเป็นอนันต์ หรือหาลิมิตไม่ได้ ต้องวิเคราะห์ต่อว่าเป็นลิมิตประเภทใด โดยอาศัยการวาดกราฟเข้ามาช่วย และถ้าทราบว่ามีลิมิตแล้วถึงจะทดลองหาลิมิตโดยใช้การจัดรูปพหุนามต่าง ๆ





## สมบัติพหุนาม


:::property



- $x^2 - y^2 = (x-y)(x+y)$

- $x^3 - y^3 = (x-y)(x^2 + xy + y^2)$

- $(x+y)^2 = x^2 + 2xy + y^2$

- $(x+a)(x+b) = x^2 + (a+b)x + ab$ 


:::





:::example

จงแยกตัวประกอบพหุนามต่อไปนี้


- $x^3+x^2$

- $2x^4 - 4x^3 + 6x^2$

- $x^2 - 16$

- $x^2 + 3x + 2$


:::


:::solution



- $x^3+x^2 = x^2(x+1)$

- $2x^4-4x^3+6x^2 = 2x^2(x^2-2x+3)$

- $x^2-16 = (x-4)(x+4)$

- $x^2+3x+2 = (x+1)(x+2)$


:::





:::example

จงหาค่าของ $ \limx{0}\left( \frac{x^2+2x}{x} \right)$ 

:::


:::solution

กำหนดให้ $f(x) = \frac{x^2+2x}{x}$ เมื่อลองแทนค่า $x=0$ ดูจะได้ $\frac{0^2 + 2\cdot 0}{0} = \frac{0}{0}$ 

นั่นคือ ฟังก์ชัน $f(x)$ หาค่าไม่ได้เมื่อ $x=0$

แต่เราสามารถจัดรูปใหม่ เป็น 
\[f(x) = \frac{x^2+2x}{x} = \frac{x(x+2)}{x} = x+2 \text{ โดยที่ } x \neq 0\] 

ฉะนั้น 
\[\limx{0} f(x) = \limx{0} (x+2) = 0+2 = 2\]

:::






:::example

จงหาค่าของ $\limx{1} \frac{x^2-1}{x-1}$

:::


:::solution

กำหนดให้ $f(x) = \frac{x^2-1}{x-1}$ เมื่อลองแทนค่า $x=1$ ดูจะได้ $\frac{1^2-1}{1-1} = \frac{0}{0}$ 

นั่นคือ ฟังก์ชัน $f(x)$ หาค่าไม่ได้เมื่อ $x=1$

แต่เราสามารถจัดรูปใหม่เป็น 
\[f(x) = \frac{x^2-1}{x-1} = \frac{(x-1)(x+1)}{x-1} = x+1 \text{ โดยที่ } x \neq 1\] 

ฉะนั้น 
\[\limx{1} f(x) = \limx{1} x+1 = 1+1 = 2\]

:::
