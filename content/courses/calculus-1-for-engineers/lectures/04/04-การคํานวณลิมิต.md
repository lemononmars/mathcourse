## ความสำคัญของการคำนวณลิมิต

ถึงแม้เราจะใช้กราฟหรือสร้างตารางค่าของฟังก์ชันมาช่วยวิเคราะห์ แต่เราก็ยังไม่ได้พิสูจน์อย่างชัดเจนว่าลิมิตหาค่าได้จริงหรือไม่ เราจึงต้องหาวิธีการคำนวณที่ได้ผลลัพธ์แน่นอน เช่น



สำหรับฟังก์ชันพื้นฐานที่ใช้งานบ่อยและคำนวณได้ง่าย เราสามารถสร้างทฤษฎีบทต่อยอดกันได้ 

พิจารณา 
\[\limx{a} f(x)\]
เมื่อ $f(x)$ เป็นค่าคงตัว และเมื่อ $f(x) = x$

:::remark

## ทฤษฎีบทสำหรับลิมิตของฟังก์ชันพื้นฐาน


:::theorem สมบัติของลิมิต

ให้ $a$ และ $c$ เป็นจำนวนจริง จะได้ว่า 



- $\limx{a} c = c$ 

- $\limx{a} x = a$ 


:::







:::example

จงหาค่าของลิมิตต่อไปนี้


- $\limx{2} 5 $

- $\limx{0} -4 $

- $\limx{2} x $

- $\limx{\pi} x$ 


:::


:::solution



- เนื่องจากฟังก์ชัน $f(x) = 5$ เป็นฟังก์ชันค่าคงตัว ฉะนั้น $\limx{2} 5 = 5$ 

- เนื่องจากฟังก์ชัน $f(x) = -4$ เป็นฟังก์ชันค่าคงตัว ฉะนั้น $\limx{0} -4 = -4$ 

- เนื่องจากกำหนดฟังก์ชัน $f(x) = x$ มาให้ ฉะนั้น $\limx{2} x = 2$ 

- เนื่องจากกำหนดฟังก์ชน $f(x) = x$ มาให้ ฉะนั้น $\limx{\pi} x = \pi$ 


:::





## ลิมิตของผลบวกและผลลบฟังก์ชัน และการคูณด้วยค่าคงตัว

ในการหาลิมิตของฟังก์ชันพีชคณิต หรือฟังก์ชันประกอบ เราสามารถหาลิมิตของฟังก์ชันทีละฟังก์ชัน แล้วค่อยนำมาคำนวณทีหลังได้

:::property พีชคณิตของลิมิต

ถ้า $\limx{a} f(x) = L$ และ $\limx{a} g(x) = M$ จะได้ว่า 


- $\limx{a}[f(x) **+** g(x)] = \limx{a} f(x) **+** \limx{a} g(x) = L**+**M$ 

- $\limx{a} [f(x) **-** g(x)] = \limx{a} f(x) **-** \limx{a} g(x) = L **-** M$ 

- $\limx{a} **c** (f(x)) = **c** \limx{a} f(x) = **c** L$ เมื่อ $c$ เป็นค่าคงตัว 


:::






:::example

จงหาค่าของ 


- $\limx{3} (x+ 5)$

- $\limx{2} (3x-1 )$


:::


:::solution

\begin{eqnarray*}
\limx{3} (x+ 5) &=& \limx{3} x + \limx{3} 5 

&=& 3+5 

&=& 8 

\limx{2} (3x-1 ) &=& \limx{2} 3x - \limx{2} 1 

&=& 3\limx{2} x - \limx{2} 1 

&=& 3(2) - 1 = 5
\end{eqnarray*}

:::





## ลิมิตของผลคูณและผลหารฟังก์ชัน

เราสามารถหาลิมิตของฟังก์ชันที่อยู่ในรูปผลคูณ หรือผลหารของฟังก์ชันได้เช่นกัน ที่ต้องระวังคือ ถ้าเป็นเป็นรูปผลหารแล้ว ตัวส่วนต้องไม่เท่ากับ 0 ถ้าตัวส่วนเท่ากับ 0 ต้องใช้วิธีอื่น ซึ่งดูได้ในหน้าถัดไป

:::property พีชคณิตของลิมิต

ถ้า $\limx{a} f(x) = L$ และ $\limx{a} g(x) = M$ จะได้ว่า 


- $\limx{a} f(x) g(x) = \left(\limx{a} f(x)\right)\left( \limx{a} g(x)\right) = LM$ 

- $\limx{a} \frac{f(x)}{g(x)} = \frac{ \limx{a} f(x)}{ \limx{a} g(x)} = \frac{L}{M}$ เมื่อ $m \neq 0$ 


:::






:::example

จงหาค่าของ $\limx{1} 2x(x+3)$

:::


:::solution

\begin{eqnarray*}
\limx{1} 2x(x+3) = 2 \limx{1} x(x+3) &=& 2 (\limx{1} x)(\limx{1} x+3) 

&=& 2(\limx{1} x)(\limx{1} x + \limx{1} 3) 

&=& 2(1)(1+3) 

&=& 8 

\end{eqnarray*}

:::





:::example

จงหาค่าของ $\limx{-1} \left(\frac{x-3}{x-1}\right) $

:::


:::solution

\begin{eqnarray*}
\limx{-1} \left(\frac{x-3}{x-1}\right) = \frac{\limx{-1} (x-3)}{\limx{-1} (x-1)} &=& \frac{\left(\limx{-1} x\right) - \left(\limx{-1}3\right)}{\left(\limx{-1} x\right) - \left(\limx{-1} 1\right)} 

&=& \frac{-1-3}{-1-1} = \frac{-4}{-2} = 2
\end{eqnarray*}

:::





## ลิมิตของฟังก์ชันอื่น ๆ


:::property พีชคณิตของลิมิต (ต่อ)

ถ้า $\limx{a} f(x) = L$ และ $\limx{a} g(x) = M$ จะได้ว่า 

\setcounter{enumi}{5}

- $\limx{a} [f(x)]^{g(x)} = \left[\limx{a} f(x)\right]^{\left[\limx{a} g(x)\right]} =L^M$ เมื่อ $L > 0$

- ถ้า $n$ เป็นจำนวนคี่แล้ว $\limx{a} \sqrt[n]{f(x)} = \sqrt[n]{\limx{a} f(x)} = \sqrt[n]{L}$

- ถ้า $n$ เป็นจำนวนคู่และ $L>0$ แล้ว $\limx{a} \sqrt[n]{f(x)} = \sqrt[n]{\limx{a} f(x)} = \sqrt[n]{L}$


:::






:::example

จงหาค่าของ 


- $\limx{-3} x^2 $

- $\limx{5} \sqrt{x+4}$

- $\limx{2} (x+2)^{x+1}$


:::


:::solution

\begin{eqnarray*}
\limx{-3} x^2 &=& \left(\limx{-3} x\right)^2 = (-3)^2 = 9 

\limx{5} \sqrt{x+4} &=& \sqrt{\limx{5} (x+4)} = \sqrt{5+4} = \sqrt{9} = 3 

\limx{2} (x+2)^{x+1} &=& (\limx{2} (x+2))^{(\limx{2} (x+1))} 

&=& (2+2)^{(2+1)} = 4^3 = 64
\end{eqnarray*}

:::





## ข้อสรุป

หลังจากที่เราเห็นตัวอย่างแล้ว สังเกตว่าเราสามารถตั้งสมมติฐานได้ดังนี้

:::remark


ถ้า $f(a)$ หาค่าได้ แล้ว $\limx{a} f(x) = f(a)$


:::

ซึ่งเป็นจริงสำหรับฟังก์ชันพื้นฐาน แต่ภายใต้เงื่อนไขบางอย่างฟังก์ชันของ $f(x)$ อาจทำให้ลิมิตหาค่าไม่ได้ก็ได้ เราจึงไม่สามารถสรุปเป็นทฤษฎีแบบแน่นอนได้
