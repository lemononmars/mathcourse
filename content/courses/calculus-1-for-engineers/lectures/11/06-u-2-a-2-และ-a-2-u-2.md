:::theorem สูตรปริพันธ์ของฟังก์ชันในรูป u^2 \pm a^2 และ a^2 \pm u^2

ให้ $a$ เป็นค่าคงที่ และ $u$ เป็นฟังก์ชันที่หาปริพันธ์ได้ 
\begin{eqnarray*}
\int \frac{1}{a^2+u^2} \, du &=& \frac{1}{a} \arctan \frac{u}{a} + C 

\int \frac{1}{a^2 - u^2} \, du &=& \frac{1}{2a} \ln \left| \frac{a+u}{a-u} \right| + C \qquad \text{เมื่อ } u^2 < a^2

\int \frac{1}{u^2 - a^2} \, du &=& \frac{1}{2a} \ln \left| \frac{u-a}{u+a} \right| + C \qquad \text{เมื่อ } u^2 > a^2

\int \frac{1}{\sqrt{a^2-u^2}} \, du &=& \arcsin \frac{u}{a} + C 

\int \frac{1}{\sqrt{u^2 \pm a^2}} \, du &=& \ln | u + \sqrt{u^2 \pm a^2} | + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์ $\int \frac{dx}{4 + 9x^2}$

:::


:::solution

$4 + 9x^2 = 2^2 + (3x)^2$ ฉะนั้นเราให้ $a = 2$ และ $u=3x$ 

โดยเราต้องเปลี่ยน $dx$ เป็น $du$ ด้วย จาก $\frac{du}{dx} = 3$ ได้ $dx = \frac{du}{3}$ และแทนค่าในสูตรที่ 1 
\begin{eqnarray*}
\int \frac{dx}{4+9x^2} = \int \frac{1}{a^2 + u^2} \frac{du}{3} &=& \frac{1}{3} \int \frac{1}{a^2 + u^2} \, du 

&=& \frac{1}{3} \left( \frac{1}{a} \arctan \frac{u}{a} + C \right)

&=& \frac{1}{3} \left( \frac{1}{2} \arctan \frac{3x}{2} + C \right) 

&=& \frac{1}{6} \arctan \frac{3x}{2} + C
\end{eqnarray*}

:::







:::example

จงหาปริพันธ์ $\int \frac{dx}{\sqrt{25 - x^2}}$

:::


:::solution

$25 - x^2 = 5^2 - x^2$ ฉะนั้นเราให้ $a = 5$ และ $u=x$ 

โดยเราต้องเปลี่ยน $dx$ เป็น $du$ ด้วย จาก $\frac{du}{dx} = 1$ ได้ $dx =du$ และแทนค่าในสูตรที่ 4 
\begin{eqnarray*}
\int \frac{dx}{\sqrt{25 - x^2}} &=& \int \frac{1}{\sqrt{a^2 - u^2}} \, du 

&=& \arcsin \frac{u}{a} + C 

&=& \arcsin \frac{x}{5} + C
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์ $\int \frac{1}{\sqrt{16-9x^2}} \, dx$

:::


:::solution

เมื่อเทียบกับสูตร จะได้ $a^2 = 16$ และ $u^2 = 9x^2$ นั่นคือ $a = 4$ และ $u = 3x$ และ
\[ \frac{du}{dx} = \dx 3x = 3 \rightarrow dx = \frac{1}{3} du\]
ฉะนั้น
\begin{eqnarray*}
\int \frac{1}{\sqrt{16-9x^2}} \, dx = \int \frac{1}{\sqrt{a^2-u^2}} \left(\frac{du}{3}\right) &=& \frac{1}{3} \int \frac{1}{\sqrt{a^2-u^2}} \, du 

&=& \frac{1}{3} \left( \arcsin \frac{u}{a} + C \right)

&=& \frac{1}{3} \arcsin \left(\frac{3x}{4}\right) + C
\end{eqnarray*}

:::
