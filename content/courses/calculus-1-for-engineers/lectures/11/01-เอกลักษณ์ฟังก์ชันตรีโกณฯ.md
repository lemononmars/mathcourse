เราทราบว่า
\begin{eq*}
\int \sin x \, dx &=& 
:::slide
-\cos x + C
:::


\int \cos x \, dx &=& 
:::slide
\sin x + C
:::

\end{eq*}
ในที่นี้ เราจะศึกษาการหาปริพันธ์ของฟังก์ชันตรีโกณมิติที่มีเลขชี้กำลังสูงขึ้น และปริพันธ์ของผลคูณฟังก์ชันตรีโกณมิติ

:::definition

เรานิยามให้ $\sin^n x = (\sin x)^n$ และ $\cos^n x = (\cos x)^n$ เพื่อให้เขียนได้กระชับขึ้น

:::





## ทบทวนเอกลักษณ์ตรีโกณมิติ (1/3)

จากนิยามของฟังก์ชัน $\sin x$ และ $\cos x$ โดยใช้รูปสามเหลี่ยม ทำให้เราสามารถหาเอกลักษณ์ต่าง ๆ ได้ดังต่อไปนี้

:::property

\begin{eqnarray*}
\sin^2 x + \cos ^2 x &=& 1 

\sin 2x &=& 2\sin x \cos x 

\cos 2x &=& \cos^2 x - \sin^2 x 

&=& 1 - 2\sin^2 x = 2\cos^2 x - 1

\sin^2 x &=& \frac{1-\cos 2x}{2} 

\cos^2 x &=& \frac{1+\cos 2x}{2} 
\end{eqnarray*}

:::





## ทบทวนเอกลักษณ์ตรีโกณมิติ (2/3)


:::property เอกลักษณ์ตรีโกณมิติ: ผลบวกมุม

\begin{eqnarray*}
\sin (x+y) &=& \sin x \cos y + \sin y \cos x 

\sin (x-y) &=& \sin x \cos y - \sin y \cos x 

\cos (x+y) &=& \cos x \cos y - \sin x \sin y

\cos (x-y) &=& \cos x \cos y + \sin x \sin y 

\end{eqnarray*}

:::





## ทบทวนเอกลักษณ์ตรีโกณมิติ (3/3)


:::property เอกลักษณ์ตรีโกณมิติ: ผลคูณฟังก์ชัน

\begin{eqnarray*}
\sin x \sin y &=& \frac{1}{2} \left( \cos (x-y) - \cos (x+y) \right) 

\cos x \cos y &=& \frac{1}{2} \left( \cos (x-y) + \cos (x+y) \right) 

\sin x \cos y &=& \frac{1}{2} \left( \sin (x+y) + \sin (x-y) \right) 

\cos x \sin y &=& \frac{1}{2} \left( \sin (x+y) - \sin (x-y) \right) 
\end{eqnarray*}

:::






:::example

จงใช้เอกลักษณ์ตรีโกณมิติเพื่อหาปริพันธ์ $\int \sin^2 x\, dx$

:::


:::solution

ใช้เอกลักษณ์ $\sin^2 x = \frac{1-\cos 2x}{2}$ ฉะนั้น
\begin{eqnarray*}
\int \sin^2 x \, dx &=& \int \frac{1-\cos 2x}{2} \, dx 

&=& \frac{1}{2} \left( \int 1 \, dx - \int \cos 2x \, dx \right) 

&=& \frac{1}{2}\left(x - \int \cos u \frac{du}{2} + C\right) \boxed{\text{แทนค่า $u = 2x$}}

&=& \frac{1}{2}\left(x - \frac{1}{2}\sin 2x + C\right) = \frac{1}{2}x - \frac{1}{4}\sin 2x + C
\end{eqnarray*}

:::






:::example

จงใช้เอกลักษณ์ตรีโกณมิติเพื่อหาปริพันธ์ $ \int \sin x \cos x \, dx$

:::


:::solution

ใช้เอกลักษณ์ $\sin 2x = 2\sin x \cos x$ เมื่อจัดรูปจะได้ $\sin x \cos x = \frac{1}{2} \sin 2x$ ฉะนั้น 
\begin{eqnarray*}
\int \sin x \cos x \, dx &=& \int \frac{1}{2} \sin 2x \, dx 

&=& \frac{1}{2} \int \sin u \frac{du}{2} \boxed{\text{แทนค่า $u = 2x$}} 

&=& \frac{1}{4} \int \sin u \, du 

&=& \frac{1}{4} (-\cos u + C) = -\frac{1}{4}\cos 2x + C
\end{eqnarray*}

:::






:::example

จงใช้เอกลักษณ์ตรีโกณมิติเพื่อหาปริพันธ์ $\int \sin 2x \cos 3x \, dx$

:::


:::solution

ใช้เอกลักษณ์ผลคูณ 
\[ \sin 2x \cos 3x = \frac{1}{2}(\sin (2x+3x) + \sin(2x-3x)) = \frac{1}{2}(\sin 5x + \sin (-x)) \]
\begin{eqnarray*}
\int \sin 2x \cos 3x \, dx &=& \int \frac{1}{2}(\sin 5x + \sin (-x)) \, dx 

&=& \frac{1}{2} \left( \int \sin 5x \, dx + \int \sin (-x) \, dx \right) 

&=& \frac{1}{2}\left( -\frac{1}{5} \cos 5x - \frac{1}{-1} \cos (-x) + C\right) 

&=& -\frac{1}{10} \cos 5x + \frac{1}{5} \cos (-x) + C
\end{eqnarray*}

:::
