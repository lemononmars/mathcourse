:::theorem



- ให้ $c$ เป็นค่าคงตัว แล้ว $\dx c = 0$

- ให้ $n$ เป็นจำนวน**จริง** ที่ไม่เป็นศูนย์ แล้วจะได้ว่า $\dx x^n = nx^{n-1}$


:::

ในบางครั้งเราต้องใช้ทักษะการเปลี่ยนรูปเลขชี้กำลัง เพื่อให้เป็นรูป $x^n$ โดยมีสมบัติพื้นฐานต่อไปนี้

:::property



- $\frac{1}{x^a} = x^{-a} $ เมื่อ $a$ เป็นจำนวนจริงที่ไม่เป็นศูนย์

- $\sqrt[n]{x} = x^{\frac{1}{n}}$ เมื่อ $n$ เป็นจำนวนจริงบวก


:::





:::example

จงแปลงพจน์ต่อไปนี้ ให้อยู่ในรูปของ $x^n$ เมื่อ $n$ เป็นจำนวนจริง


- $\frac{1}{x^2}$

- $\frac{1}{x^5}$

- $\frac{1}{x^{3.5}}$

- $\frac{1}{x^{-4}}$


:::


:::solution



- $\frac{1}{x^2} = x^{-2}$

- $\frac{1}{x^5} = x^{-5}$

- $\frac{1}{x^{3.5}} = x^{-3.5}$

- $\frac{1}{x^{-4}} = x^{-(-4)} = x^4$


:::





:::example

จงแปลงพจน์ต่อไปนี้ ให้อยู่ในรูปของ $x^n$ เมื่อ $n$ เป็นจำนวนจริง


- $\sqrt{x}$

- $\sqrt[3]{x}$

- $\sqrt[5]{x}$

- $\sqrt[4]{x^3}$


:::


:::solution



- $\sqrt{x} = x^{\frac{1}{2}}$

- $\sqrt[3]{x} = x^{\frac{1}{3}}$

- $\sqrt[5]{x} = x^{\frac{1}{5}}$

- $\sqrt[4]{x^3} = (x^3)^{\frac{1}{4}} = x^{\frac{3}{4}}$


:::





:::example

จงแปลงพจน์ต่อไปนี้ ให้อยู่ในรูปของ $x^n$ เมื่อ $n$ เป็นจำนวนจริง


- $\frac{1}{\sqrt{x}}$

- $\frac{1}{\sqrt[3]{x}}$

- $\frac{\sqrt{x}}{x^2}$

- $\frac{\sqrt[3]{x}}{\sqrt[4]{x}}$


:::


:::solution



- $\frac{1}{\sqrt{x}} = \frac{1}{x^{\frac{1}{2}}} = x^{-\frac{1}{2}}$

- $\frac{1}{\sqrt[3]{x}} = \frac{1}{x^{\frac{1}{3}}} = x^{-\frac{1}{3}}$

- $\frac{\sqrt{x}}{x^2} = \frac{x^{\frac{1}{2}}}{x^2} = x^{\frac{1}{2} - 2} = x^{-\frac{3}{2}}$

- $\frac{\sqrt[3]{x}}{\sqrt[4]{x}} = \frac{x^{\frac{1}{3}}}{x^{\frac{1}{4}}} = x^{\frac{1}{3} - \frac{1}{4}} = x^{\frac{1}{12}}$


:::





:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx 4$

- $\dx \frac{1}{2}$

- $\dx (-5)$


:::


:::solution



- เนื่องจาก $f(x) = 4$ เป็นฟังก์ชันค่าคงตัว ฉะนั้น $\dx 4 = 0$

- เนื่องจาก $f(x) = \frac{1}{2}$ เป็นฟังก์ชันค่าคงตัว ฉะนั้น $\dx \frac{1}{2} = 0$

- เนื่องจาก $f(x) = -5$ เป็นฟังก์ชันค่าคงตัว ฉะนั้น $\dx (-5) = 0$


:::






:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx x^2$

- $\dx x^3$

- $\dx x^4$


:::


:::solution



- $\dx x^{**2**} = **2** x^{**2**-1} = 2x^1 = 2x$

- $\dx x^{**3**} = **3** x^{**3**-1} = 3x^2 $

- $\dx x^{**4**} = **4** x^{**4**-1} = 4x^3$


:::





:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx x^{1.5}$

- $\dx x^{\frac{4}{3}}$

- $\dx x^{-5}$


:::


:::solution



- $\dx x^{1.5} = 1.5 x^{1.5 - 1} = 1.5 x^{0.5}$

- $\dx x^{\frac{4}{3}} = \frac{4}{3} x^{\frac{4}{3} - 1} = \frac{4}{3} x^{\frac{1}{3}}$

- $\dx x^{-5} = -5 x^{-5-1} = -5x^{-6}$


:::





:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx \left(\frac{1}{x}\right)$

- $\dx \left(\frac{1}{x^3}\right)$

- $\dx \left(\frac{1}{x^5}\right)$

- $\dx \left(\frac{1}{x^{2.5}}\right)$


:::


:::solution



- $\dx \left(\frac{1}{x}\right) = \dx x^{-1} = -1x^{-1-1} = -x^{-2}$

- $\dx \left(\frac{1}{x^3}\right) = \dx x^{-3} = -3x^{-3-1} = -3x^{-4}$

- $\dx \left(\frac{1}{x^5}\right) = \dx x^{-5} = -5x^{-5-1} = -5x^{-6}$

- $\dx \left(\frac{1}{x^{2.5}}\right) = \dx x^{-2.5} = -2.5x^{-2.5-1} = -2.5x^{-3.5}$


:::





:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx \sqrt{x}$

- $\dx \sqrt[3]{x}$

- $\dx \sqrt[4]{x}$

- $\dx \sqrt[5]{x^3}$


:::


:::solution



- $\dx \sqrt{x} = \dx x^{\frac{1}{2}} = \frac{1}{2} x^{\frac{1}{2} -1 } = \frac{1}{2} x^{-\frac{1}{2}}$

- $\dx \sqrt[3]{x} = \dx x^{\frac{1}{3}} = \frac{1}{3} x^{\frac{1}{3} -1 } = \frac{1}{3} x^{-\frac{2}{3}}$

- $\dx \sqrt[4]{x} = \dx x^{\frac{1}{4}} = \frac{1}{4} x^{\frac{1}{4} -1 } = \frac{1}{4} x^{-\frac{3}{4}}$

- $\dx \sqrt[5]{x^3} = \dx x^{\frac{3}{5}} = \frac{3}{5} x^{\frac{3}{5} -1 } = \frac{3}{5} x^{-\frac{2}{5}}$


:::






:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx \left(\frac{1}{x^2}\right)$

- $\dx \left(\frac{1}{\sqrt{x}}\right)$

- $\dx x$


:::


:::solution



- $\dx \frac{1}{x^2} = \dx x^{-2} = -2x^{-2-1} = -2x^{-3} = -\frac{2}{x^3}$

- $\dx \frac{1}{\sqrt{x}} = \dx x^{-\frac{1}{2}} = -\frac{1}{2} x^{-\frac{1}{2} - 1} = - \frac{1}{2} x^{-\frac{3}{2}}$

- $\dx x = \dx x^1 = 1(x^0) = 1$


:::





:::remark

สังเกตว่า $\dx x = 1$ มีที่มาจากสูตร $\dx x^n = nx^{n-1}$ ฉะนั้นจึงใช้สูตรได้ แต่ถ้าต้องการแยกออกมาเป็นอีกสูตรหนึ่งก็ได้ จะได้เป็นสูตรพื้นฐานดังนี้


- $\dx c = 0$ เมื่อ $c$ เป็นค่าคงตัว

- $\dx x = 1$

- $\dx x^n = nx^{n-1}$


:::
