## โจทย์การหาความเปลี่ยนแปลง

เราสามารถเขียนโจทย์เป็นภาษาคณิตศาสตร์ได้ดังนี้

:::slide


:::remark

กำหนดสิ่งต่อไปนี้ให้


- ฟังก์ชัน $f(x)$ 

- กราฟของฟังก์ชัน $y=f(x)$

- จุด $P = (x_0, f(x_0))$ ซึ่งอยู่บนกราฟ


จงหาความชันของเส้นสัมผัสเส้นโค้ง ณ จุด $P$

:::


:::

*ภาพแสดงฟังก์ชัน $y=\frac{x^2*{4}$ และเส้นสัมผัส (เส้นประ) ที่จุด $(x,y) = (2,1)$}




เนื่องจากเรายังไม่ทราบวิธีการสร้างเส้นสัมผัส เราจึงเริ่มจากสร้างเส้นตรงโดยการเลือกจุด $Q$ อีกจุดที่อยู่บนกราฟเช่นกัน และสร้างส่วนของเส้นตรง $PQ$ ขึ้นมา

:::


*ภาพแสดงการหาความชันของเส้นตรงที่เชื่อมจุด $(x,y)$ และ $(x_1,y_1)$*





:::slide

จากรูป จะเห็นว่า ความชันของเส้นตรงที่ผ่านจุด $P$ และ $Q$ คือ
\[ \frac{\Delta y}{\Delta x} = \frac{f(x+h) - f(x)}{h}\] 
ถ้าให้ $h$ เข้าใกล้ 0 (ทางซ้ายและทางขวา) จะได้ว่า จุด $Q$ เคลื่อนที่เข้าหาจุด $P$ จนทำให้ส่วนของเส้นตรง $PQ$ เข้าใกล้เส้นสัมผัสเส้นโค้ง $y=f(x)$ ที่จุด $P$ 


ดังนั้นความชันของเส้นสัมผัสเส้นโค้ง $y=f(x)$ ที่จุด $x$ ใดๆ คือ
\[ \limh \frac{f(x+h) - f(x)}{h}\]

:::






## นิยามของอนุพันธ์


:::definition

ให้ $f$ เป็นฟังก์ชันของตัวแปร $x$ โดยที่ $y = f(x)$ แล้ว ฟังก์ชัน $f$ จะเรียกว่า **หาอนุพันธ์ได้ที่จุด** $\mathbf{x}$ ก็ต่อเมื่อ 
\begin{equation}
\limh \frac{f(x+h) - f(x)}{h}
\end{equation}
หาค่าได้ ถ้าลิมิตหาค่าได้ เราเรียกว่า อนุพันธ์ของ $f$ ที่ $x$ และเขียนแทนด้วยสัญลักษณ์ใดสัญลักษณ์หนึ่งต่อไปนี้
\[ \dx f(x) = \limh \frac{f(x+h) - f(x)}{h}\]

:::






:::example

จงหาอนุพันธ์ของฟังก์ชัน $f(x) = 2x+3$

:::


:::solution

หาลิมิตจากสมการ เมื่อแทนค่า $f(x) = 2x+3$ จะได้
\begin{eqnarray*}
\limh \frac{f(x+h) - f(x)}{h} &=& \limh \frac{(2(x+h) + 3)) - (2x+3)}{h} 

&=& \limh \frac{2x+2h+3-2x-3}{h} 

&=& \limh \frac{2h}{h} 

&=& \limh 2 =2 
\end{eqnarray*}
ฉะนั้น $\dx f(x) = 2$

:::






:::example

จงหาอนุพันธ์ของฟังก์ชัน $f(x) = x^2$

:::


:::solution

หาลิมิตจากสมการ เมื่อแทนค่า $f(x) = x^2$ จะได้
\begin{eqnarray*}
\limh \frac{f(x+h) - f(x)}{h} &=& \limh \frac{(x+h)^2 - x^2}{h} 

&=& \limh \frac{(x^2+2xh+h^2) - x^2}{h} 

&=& \limh \frac{2xh + h^2}{h} = \limh 2x+h = 2x
\end{eqnarray*} 
ฉะนั้น $\dx f(x) = 2x$

:::






:::example

จงหาอนุพันธ์ของฟังก์ชัน $f(x) = \frac{1}{x}$

:::


:::solution

หาลิมิตจากสมการ เมื่อแทนค่า $f(x) =\frac{1}{x}$ จะได้
\begin{eqnarray*}
\limh \frac{f(x+h) - f(x)}{h} &=& \limh \frac{\left(\frac{1}{x+h}\right) - \left(\frac{1}{x}\right)}{h} 

&=& \limh \frac{\frac{x - (x+h)}{(x+h)x}}{h} = \limh \frac{-h}{h(x+h)x} 

&=& \limh \frac{-1}{(x+h)x} = -\frac{1}{x^2} 
\end{eqnarray*} 
ฉะนั้น $\dx f(x) = -\frac{1}{x^2}$

:::





## การเขียนอนุพันธ์ในรูปแบบอื่น ๆ

นอกจากรูปแบบ $\dx f(x)$ ในนิยามแล้ว เราสามารถเขียนในรูปแบบอื่นได้ดังต่อไปนี้


- $\dyx$ - การเขียนในรูปแบบนี้ สอดคล้องกับนิยามของความชัน $\frac{\Delta y}{\Delta x}$

- $\frac{df}{dx}$ - ความหมายเดียวกันกับ $\dyx$ โดยที่เรากำหนดให้ $y = f(x)$ 

- $f\,'(x)$ - แม้ว่าการเขียนแบบนี้จะกระชับ แต่จะติดปัญหาเวลาศึกษาสมบัติต่าง ๆ เช่น เราจะ\textbf{**ไม่**}เขียนเป็น $(3x-1)' = 3$ 





## การหาค่าของอนุพันธ์

ผลลัพธ์จากการหาอนุพันธ์เป็นฟังก์ชัน ถ้าเราต้องการหาค่าของอนุพันธ์ที่จุด $x=x_0$ จะเขียนแทนด้วยสัญลักษณ์ต่อไปนี้

:::remark

กำหนดฟังก์ชัน $f(x)$ ที่หาอนุพันธ์ ณ จุด $x = x_0$ ได้ แล้วค่าของอนุพันธ์ที่จุด $x=x_0$ จะเขียนแทนด้วย
\[ \dx f(x) \Big|_{x=x_0} \]
หรือ
\[ f\,'(x_0) \]

:::






:::example

จงหาอนุพันธ์ของฟังก์ชัน $f(x) = \frac{1}{x}$ ที่จุด 


- $x = 2$

- $x = -\frac{1}{3}$


:::


:::solution



- เราทราบว่า $\dx \frac{1}{x} = -\frac{1}{x^2}$ ฉะนั้น $\dx \frac{1}{x} \Big|_{x = 1} = -\frac{1}{2^2} = -\frac{1}{4}$

โดยสามารถเขียนในอีกรูปแบบหนึ่งคือ $f\,'(2) = -\frac{1}{4}$

- เราทราบว่า $\dx \frac{1}{x} = -\frac{1}{x^2}$ ฉะนั้น $\dx \frac{1}{x} \Big|_{x = -\frac{1}{3}} = -\frac{1}{\left(-\frac{1}{3}\right)^2} = -9$

โดยสามารถเขียนในอีกรูปแบบหนึ่งคือ $f\,'\left(-\frac{1}{3}\right) = -9$


:::





## ความสัมพันธ์ระหว่างอนุพันธ์และความต่อเนื่อง


\begin{cor}{}{}
ถ้า $f$ เป็นฟังก์ชันที่มีอนุพันธ์ที่จุด $x = x_0$ แล้ว $f$ จะมีความต่อเนื่องที่จุด $x = x_0$
\end{cor}
