## สมบัติพื้นฐานของอนุพันธ์


:::property

กำหนดให้ $f$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ทุกค่า $x$ ใน $D_f$ (โดเมนของ $f$) และ $c$ เป็นค่าคงตัว แล้ว 
\begin{equation}
\dx cf(x) = c \left( \dx f(x)\right)
\end{equation}

:::






:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx 3x^2$

- $\dx 4x^3$

- $\dx (-2x^5)$


:::


:::solution



- $\dx 3x^2 = 3 \dx x^2 = 3 (2x) = 6x$

- $\dx 4x^3 = 4 \dx x^3 = 4(3x^2) = 12x^2$

- $\dx (-2x^5) = -2 \dx x^5 = -2(5x^4) = -10x^4$


:::





:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx \left(\frac{2}{x^3}\right)$

- $\dx \left(\frac{1}{4x^5}\right)$

- $\dx 3 \sqrt[6]{x}$


:::


:::solution



- $\dx \left(\frac{2}{x^3}\right) = 2 \dx x^{-3} = 2 (-3x^{-3-1}) = -6x^{-4}$

- $\dx \left(\frac{1}{4x^5}\right) = \frac{1}{4} \dx x^{-5} = \frac{1}{4} (-5x^{-5-1}) = -\frac{5}{4} x^{-6}$

- $\dx 3 \sqrt[6]{x} = 3 \dx x^{\frac{1}{6}} = 3 \left( \frac{1}{6} x^{\frac{1}{6} - 1} \right) = \frac{1}{2} x^{-\frac{5}{6}}$


:::





## สมบัติพื้นฐานของอนุพันธ์


:::property

กำหนดให้ $f$ และ $g$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ทุกค่า $x$ ใน $D_f$ และ $D_g$ (โดเมนของ $f$ และ $g$) แล้ว 

\begin{equation}
\dx (f + g)(x) = \dx f(x) + \dx g(x) 

\dx (f - g)(x) = \dx f(x) - \dx g(x)
\end{equation}


:::






:::example

จงหาอนุพันธ์ต่อไปนี้


- $\dx (x^2 -2x)$ 

- $ \dx (x^5+x^4)$


:::


:::solution

\begin{eqnarray*}
\dx (x^2 - 2x) &=& \dx x^2 - \dx 2x 

&=& 2x - 2 

\dx (x^5 + x^4) &=& \dx x^5 + \dx x^4 

&=& 5x^4 + 4x^3
\end{eqnarray*}

:::
