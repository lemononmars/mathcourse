## อนุพันธ์ผลคูณ

ในบางครั้ง ฟังก์ชันอยู่ในรูปของผลคูณที่ไม่สามารถแยกได้ เช่น
\[ f(x) = x^2 \sin x\]
เราจึงต้องมีทฤษฎีบทสำหรับหาค่าของอนุพันธ์ของฟังก์ชันผลคูณ

:::theorem

กำหนดให้ $u$ และ $v$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ใน $D_u$ และ $D_v$ (โดเมนของ $u$ และ $v$) 

แล้ว $uv$ เป็นฟังก์ชันที่หาอนุพันธ์ได้และ 
\begin{eqnarray}
\dx (uv)(x) &=& u(x) \dx v(x) + v(x) \dx u(x) 
\end{eqnarray}

:::






:::example

จงหาอนุพันธ์ของ $f(x) = x^3(x+2)$

:::


:::solution

เขียน $f(x) = u(x) v(x)$ โดยที่ 
\[u(x) = x^3, \qquad v(x) = x+2\]
จะได้ 
\[\dx u(x) = 3x^2, \qquad \dx v(x) = 1\] 
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx (u\cdot v)(x) &=& u(x) \dx v(x) + v(x) \dx u(x) 

&=& (x^3)(1) + (x+2)(3x^2) 

&=& x^3 + 3x^3 + 6x^2 

&=& 4x^3 + 6x^2
\end{eqnarray*}

:::






:::example

จงหาอนุพันธ์ของ $f(x) =(2x+5)(5x-2)$

:::


:::solution

เขียน $f(x) = u(x) v(x)$ โดยที่ 
\[u(x) = 2x+5, \qquad v(x) = 5x-2\] 
จะได้ 
\[\dx u(x) = 2, \qquad \dx v(x) = 5\] 
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx (uv)(x) &=& u(x)\dx v(x) + v(x)\dx u(x) 

&=& (2x+5)(5) + (5x-2)(2) 

&=& 10x+25 + 10x-4 

&=& 20x+21
\end{eqnarray*}

:::






:::example

จงหาอนุพันธ์ของ $f(x) =(x^5+x)\left(\frac{1}{x^3} + 2\frac{1}{x^2}\right)$

:::


:::solution

เขียน $f(x) = u(x) v(x)$ โดยที่ 
\[u(x) = x^5+x, \qquad v(x) = x^{-3} + 2x^{-2}\] 
จะได้ 
\[\dx u(x) = 5x^4+1, \qquad \dx v(x) = -3x^{-4} - 4x^{-3}\] 
ฉะนั้น
\begin{eqnarray*}
\dx (uv)(x) &=& u(x)\dx v(x) + v(x)\dx u(x) 

&=& (x^5+x)(-3x^{-4} - 4x^{-3}) + (x^{-3} + 2x^{-2})(5x^4+1) 

&=& (-3x-4x^2-3x^{-3}-4x^{-2})+(5x+x^{-3}+10x^2+2x^{-2}) 

&=& 6x^2+2x-2x^{-2}-2x^{-3}
\end{eqnarray*}

:::





## สูตรอนุพันธ์ผลคูณแบบย่อ

ถ้าเราเข้าใจหลักการหาอนุพันธ์ของผลคูณฟังก์ชันแล้ว เราสามารถเขียนย่อในรูปแบบดังต่อไปนี้ได้

:::remark

\begin{eqnarray*}
\dx (u\cdot v)(x) &=& u(x)v'(x) + v(x)u'(x) 

&=& (uv' + vu')(x) 
\end{eqnarray*}

:::
