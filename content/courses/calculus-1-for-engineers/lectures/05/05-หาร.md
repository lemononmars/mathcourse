## อนุพันธ์ผลหาร

ในทำนองเดียวกัน ฟังก์ชันที่อยู่ในรูปผลหาร เช่น $f(x) = \frac{x^2}{x+1}$
ก็สามารถหาอนุพันธ์ได้เช่นกัน โดยที่ไม่จำเป็นต้องจัดรูปใหม่

:::theorem

กำหนดให้ $u$ และ $v$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ใน $D_u$ และ $D_v$ (โดเมนของ $u$ และ $v$) 

แล้ว $\frac{u}{v}$ เป็นฟังก์ชันที่หาอนุพันธ์ได้และ 
\begin{eqnarray}
\dx \left(\frac{u}{v} \right)(x) &=& \frac{v(x) \dx u(x) - u(x) \dx v(x)}{(v(x))^2}
\end{eqnarray}

:::






:::example

จงหาอนุพันธ์ของ $f(x) =\frac{1}{2x+3}$

:::


:::solution

เขียน $f(x) = \frac{u(x)}{v(x)}$ โดยที่ $u(x) = 1$ และ $v(x) = 2x+3$ จะได้ 
\[\dx u(x) = 0, \qquad \dx v(x) = 2\] 
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx \left( \frac{u}{v}\right)(x) &=& \frac{v(x)\dx u(x) - u(x)\dx v(x)}{(v(x))^2} 

&=& \frac{(2x+3)(0) - (1)(2)}{(2x+3)^2} 

&=& \frac{-2}{(2x+3)^2}
\end{eqnarray*}

:::






:::example

จงหาอนุพันธ์ของ $f(x) =\frac{3x+2}{4x-5}$

:::


:::solution

เขียน $f(x) = \frac{u(x)}{v(x)}$ โดยที่ $u(x) = 3x+2$ และ $v(x) = 4x-5$ จะได้ 
\[\dx u(x) = 3, \qquad \dx v(x) = 4\]
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx \left( \frac{u}{v}\right)(x) &=& \frac{v(x)\dx u(x) - u(x)\dx v(x)}{(v(x))^2} 

&=& \frac{(4x-5)(3) - (3x+2)(4)}{(4x-5)^2} 

&=& \frac{(12x-15)-(12x+8)}{(4x-5)^2} = \frac{-23}{(4x-5)^2}
\end{eqnarray*}

:::






:::example

จงหาอนุพันธ์ของ $f(x) =\frac{x+1}{x^2+1}$

:::


:::solution

เขียน $f(x) = \frac{u(x)}{v(x)}$ โดยที่ $u(x) = x+1$ และ $v(x) = x^2+1$ จะได้ 
\[\dx u(x) = 1, \qquad \dx v(x) = 2x\]
ฉะนั้น
\begin{eqnarray*}
\dx f(x) = \dx \left( \frac{u}{v}\right)(x) &=& \frac{v(x)\dx u(x) - u(x) \dx v(x)}{(v(x))^2} 

&=& \frac{(x^2+1)(1) - (x+1)(2x)}{(x^2+1)^2} 

&=& \frac{(x^2+1) - (2x^2+2x)}{(x^2+1)^2} = \frac{-x^2-2x+1}{(x^2+1)^2}
\end{eqnarray*}

:::





## สูตรอนุพันธ์ผลหารแบบย่อ

ในทำนองเดียวกัน เราสามารถเขียนสูตรอนุพันธ์ผลหารแบบย่อได้ดังนี้

:::remark

\begin{eqnarray*}
\dx \left(\frac{u}{v} \right)(x) &=& \frac{v(x)u'(x) - u(x)v'(x)}{(v(x))^2} 

&=& \left( \frac{vu'-uv'}{v^2}\right) (x)
\end{eqnarray*}

:::
