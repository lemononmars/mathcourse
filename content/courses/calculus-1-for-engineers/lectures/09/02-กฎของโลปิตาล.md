:::theorem

ให้ $f,g$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ที่ $c$


- ถ้า $\limx{c} f(x) = 0 = \limx{c} g(x)$ แล้ว
\begin{equation} 
\limx{c} \frac{f(x)}{g(x)} = \limx{c} \frac{f\,'(x)}{g\,'(x)}
\end{equation}

- ถ้า $\limx{c} f(x) = \pm\infty$ และ $\limx{c} g(x) = \pm \infty$ แล้ว
\begin{equation} 
\limx{c} \frac{f(x)}{g(x)} = \limx{c} \frac{f\,'(x)}{g\,'(x)}
\end{equation}


:::






:::example

จงหา $\limx{0} \frac{x^2+3x}{x}$ โดยกฎของโลปิตาล

:::


:::solution

สังเกตว่าถ้าให้ $f(x) = x^2+3x$ และ $g(x) = x$ แล้ว $\limx{0} f(x) = 0 = \limx{0} g(x)$ ฉะนั้นเราจึงไม่สามารถแทนค่า $x=0$ ได้ทันที 

จากกฎของโลปิตาล จะได้ว่า
\begin{eqnarray*}
\limx{0} \frac{x^2+3x}{x} &=& \limx{0} \frac{\dx (x^2+3x)}{\dx (x)} 

&=& \limx{0} \frac{2x+3}{1} 

&=& (2)(0) + 3 = 3
\end{eqnarray*}

:::






:::example

จงหา $\limx{1} \frac{x^3-x}{x^2-3x+2}$ โดยกฎของโลปิตาล

:::


:::solution

สังเกตว่าถ้าให้ $f(x) = x^3-x$ และ $g(x) = x^2-3x+2$ แล้ว $\limx{1} f(x) = 0 = \limx{1} g(x)$ ฉะนั้นเราจึงไม่สามารถแทนค่า $x=1$ ได้ทันที 

จากกฎของโลปิตาล จะได้ว่า
\begin{eqnarray*}
\limx{1} \frac{x^3-x}{x^2-3x+2} = \limx{1} \frac{\dx (x^3-x)}{\dx (x^2-3x+2)} &=& \limx{1} \frac{3x^2-1}{2x-3} 

&=& \frac{3(1)^2 - 1}{2(1) - 3} 

&=& \frac{2}{-1} = -2
\end{eqnarray*}

:::






:::example

จงหา $\limx{\infty} \frac{5x^2+12}{-x^2+56}$ โดยกฎของโลปิตาล

:::


:::solution

สังเกตว่าถ้าให้ $f(x) = 5x^2+12$ และ $g(x) = -x^2+56$ แล้ว $\limx{\infty} f(x) = \infty$ และ $ \limx{\infty} g(x) = -\infty$ เราจึงไม่สามารถหาลิมิตของตัวเศษและส่วนแยกกันได้

จากกฎของโลปิตาล จะได้ว่า
\begin{eqnarray*}
\limx{\infty} \frac{5x^2+12}{-x^2+56} &=& \limx{\infty} \frac{\dx(5x^2+12)}{\dx (-x^2+56)} 

&=& \limx{\infty} \frac{10x}{-2x} 

&=& \limx{\infty} -5 

&=& -5
\end{eqnarray*}

:::






:::example

จงหา $\limx{0} \frac{e^x-1-x}{x^2}$ โดยกฎของโลปิตาล

:::


:::solution

สังเกตว่าถ้าให้ $f(x) = e^x-1-x$ และ $g(x) = x^2$ แล้ว $\limx{0} f(x) = 0 = \limx{0} g(x)$ ฉะนั้นเราจึงไม่สามารถแทนค่า $x=0$ ได้ทันที 

จากกฎของโลปิตาล จะได้ว่า 
\[ \limx{0} \frac{e^x-1-x}{x^2} = \limx{0} \frac{e^x-1}{2x} \] 
แต่ว่า! เรายังหาค่าของลิมิตไม่ได้อยู่ดี เพราะว่า $\frac{e^0 - 1}{2\cdot 0} = \frac{0}{0}$ ถึงกระนั้น เราสามารถใช้กฎของโลปิตาลกับลิมิต $\limx{0} \frac{e^x-1}{2x}$ ได้อีกรอบ

:::





:::solution
(ต่อ)
ถ้าให้ $f_2(x) = e^x-1$ และ $g_2(x) = 2x$ แล้ว $\limx{0} f_2(x) = 0 = \limx{0} g_2(x)$
\begin{eqnarray*}
\limx{0} \frac{e^x-1}{2x} &=& \limx{0} \frac{e^x}{2} 

&=& \frac{e^0}{2} = \frac{1}{2} 
\end{eqnarray*}
ฉะนั้น 
\[ \limx{0} \frac{e^x-1-x}{x^2} = \limx{0} \frac{e^x-1}{2x} = \frac{1}{2} \]

:::
