เราสามารถเปลี่ยนสูตรของอนุพันธ์ $\dyx$ ที่เรามี นั่นคือ
\[ \dx c = 0 \qquad \dx x = 1 \qquad \dx x^n = nx^{n-1}\]
เป็นสูตรของปริพันธ์ได้ทันทีดังนี้ 

:::property

\begin{eq*}
\int 0 \, dx &=& C 

\int 1 \, dx &=& x + C 

\int x^n \, dx &=& \left(\frac{1}{n+1}\right)x^{n+1} + C \text{ เมื่อ $n \neq -1$}
\end{eq*}

:::






:::example

จงหาปริพันธ์ต่อไปนี้


- $\int x^3 \,dx$ 

- $\int x^6 \, dx$ 

- $\int \frac{1}{x^3} \, dx $ 

- $ \int \sqrt{x} \, dx$


:::


:::solution



- $ \int x^3 \, dx = \frac{1}{4} x^4 + C$ 

- $ \int x^6 \, dx = \frac{1}{7} x^7 + C$ 

- $ \int \frac{1}{x^3} \, dx = \int x^{-3} \, dx = \frac{1}{-2} x^{-2} + C = \frac{-1}{2x^2} + C$ 

- $ \int \sqrt{x} \, dx = \int x^{\frac{1}{2}} \, dx = \frac{1}{\left(\frac{1}{2} + 1\right)} x^{\left( \frac{1}{2} + 1 \right)} + C = \frac{1}{\left(\frac{3}{2}\right)} x^{\frac{3}{2}} + C = \frac{2}{3} x^{\frac{3}{2}} + C$


:::





## สมบัติของปริพันธ์

สมบัติการคูณด้วยค่าคงตัวของฟังก์ชัน การบวก และการลบฟังก์ชันที่มีในอนุพันธ์ สามารถใช้กับอนุพันธ์ได้ทันที ดังนี้

:::property

ดึงค่าคงตัว 
\[ \int **c** f(x) \, dx = **c** \int f(x) \, dx \]
ผลบวกและผลลบฟังก์ชัน
\[ \int \left( f(x) **+** g(x) \right)\, dx = \int f(x) \, dx **+** \int g(x) \, dx\]
\[ \int \left( f(x) **-** g(x)\right) \, dx = \int f(x) \, dx **-** \int g(x) \, dx\] 

:::





:::example

จงหาปริพันธ์
\[\int 6x\,dx\]

:::


:::solution

\begin{eqnarray*}
\int 6x \, dx &=& 6 \int x \, dx 

&=& 6 \left(\frac{1}{2}x^2+C\right) 

&=& 3x^2 + 6C 

&=& 3x^2 + C'
\end{eqnarray*}
สังเกตว่า $C$ เป็นสัญลักษณ์พิเศษที่แทนจำนวนจริงใดก็ได้ ดังนั้น $6C$ จึงแทนจำนวนจริงใดก็ได้เช่นกัน เราเลยเปลี่ยน $6C$ เป็น $C'$ ได้ ในที่นี้ $C'$ ยังนับว่าเป็นจำนวนจริงก็ได้ เช่นเดียวกันกับสัญลักษณ์ $C$

:::






:::example

จงหาปริพันธ์
\[\int 4x^7\,dx\]

:::


:::solution

\begin{eqnarray*}
\int 4x^7 \, dx &=& 4 \int x^7 \, dx 

&=& 4\left( \frac{1}{8}x^8 + C \right) 

&=& \frac{1}{2}x^8 + 4C 

&=& \frac{1}{2}x^8 + C'
\end{eqnarray*}
เราสร้างสัญลักษณ์ใหม่เป็น $C'$ โดยเขียน $C' = 4C$

:::






:::example

จงหาปริพันธ์
\[\int (x^2 + 1 )\,dx\]

:::


:::solution

\begin{eqnarray*}
\int x^2 + 1 \, dx &=& \int x^2 \, dx + \int 1 \, dx 

&=& \left(\frac{1}{3}x^3 + C_1\right) + (x + C_2) 

&=& \frac{1}{3}x^3 + x + C
\end{eqnarray*}
ในที่นี้ เนื่องจาก $C_1$ และ $C_2$ ต่างก็เป็นจำนวนจริงใดก็ได้ เราจึงสามารถสร้างสัญลักษณ์ใหม่ $C = C_1 + C_2$ ที่เป็นจำนวนจริงใดก็ได้เหมือนกัน

:::
