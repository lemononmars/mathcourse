## ตัวดำเนินการผกผัน

สมมติกำหนดฟังก์ชัน 
\[y = f(x)\]
แล้วเราสามารถนิยามฟังก์ชันผกผันเป็น
\[f^{-1}(y) = x\]

เช่น

:::slide

\begin{eq*}
y = 2x &\Rightarrow& \frac{y}{2} = x 

y = \sin x &\Rightarrow& \sin^{-1}(y) = x 

y = \cos x &\Rightarrow& \cos^{-1}(y) = x 

y = e^x &\Rightarrow& \ln y = x
\end{eq*}

:::





## นิยาม

ในทำนองเดียวกัน เราสามารถนิยามตัวดำเนินการผกผันให้กับอนุพันธ์ได้ เช่น
\[ \dx x^4 = 4x^3 \]
เราเลยคิดว่า น่าจะมีการนิยาม
\[x^4 = ? (4x^3)\]
โดยที่ $?$ เป็นตัวดำเนินการที่เราสร้างขึ้นมาใหม่ 


:::definition

ฟังก์ชัน $F(x)$ เป็นปฏิยานุพันธ์ของฟังก์ชัน $f(x)$ ถ้า $\dx F(x) = f(x)$ 

:::






:::example

จงหาปฏิยานุพันธ์ $F(x)$ ของฟังก์ชัน $f(x)$ ที่กำหนดให้ต่อไปนี้


- $f(x) = 3$ 

- $f(x) = 2x$ 

- $f(x) = \cos x$


:::


:::solution



- $F(x) = 3x$ เป็นปฏิยานุพันธ์ของ $f(x) = 3$ เพราะว่า $\dx 3x = 3$ 

- $F(x) = x^2+1$ เป็นปฏิยานุพันธ์ของ $f(x) = 2x$ เพราะว่า $\dx (x^2+1) = 2x$ 

- $F(x) = \sin x$ เป็นปฏิยานุพันธ์ของ $f(x) = \cos x$ เพราะว่า $\dx \sin x = \cos x$ 


:::




อย่างไรก็ตาม ปฏิยานุพันธ์ไม่ได้มีแค่ฟังก์ชันเดียวเท่านั้น 

พิจารณาฟังก์ชัน $f(x) = 2x$ 

:::slide



- $F_1(x) = x^2$ เป็นปฏิยานุพันธ์ของ $f(x) $ เพราะว่า $\dx x^2 = 2x$ 

- $F_2(x) = x^2 + 2$ เป็นปฏิยานุพันธ์ของ $f(x)$ เพราะว่า $\dx (x^2+2) = 2x$ 

- $F_2(x) = x^2 -1 $ เป็นปฏิยานุพันธ์ของ $f(x)$ เพราะว่า $\dx (x^2-1) = 2x$ 

- $F_2(x) = x^2 + 1234$ เป็นปฏิยานุพันธ์ของ $f(x)$ เพราะว่า $\dx (x^2+1234) = 2x$ 


:::


:::theorem

ถ้า $F(x)$ เป็นปฏิยานุพันธ์ของ $f(x)$ และ $C$ เป็นค่าคงตัว แล้ว $F(x) + C$ ก็เป็นปฏิยานุพันธ์ของ $f(x)$ เช่นกัน 

:::





## นิยามของปริพันธ์

ฉะนั้นเราจึงเรียกคำตอบ $F(x) + C$ ทั้งหมดว่า **ปริพันธ์** 

:::definition

กำหนดให้ $f(x)$ เป็นฟังก์ชันที่มีปฏิยานุพันธ์ $F(x)$ นั่นคือ $\dx F(x) = f(x)$ แล้ว **ปริพันธ์ของ f** คือ $F(x) +C$ โดยจะเขียนแทนด้วย
\[ \int f(x) \, dx = F(x) + C\] 
อ่านว่า **ปริพันธ์ไม่จำกัดเขตของ $f(x)$ เทียบกับ $x$**

:::

ในที่นี้ ตัว $C$ ไม่ใช่ทั้งค่าคงตัวและตัวแปร แต่เป็นสัญลักษณ์ใหม่ที่สร้างขึ้นมาใช้กับปริพันธ์





:::example

จงหาปริพันธ์ต่อไปนี้ ด้วยการทดลองแทนค่าปฏิยานุพันธ์ $F(x)$ 


- $ \int 1 \, dx $ 

- $\int 2x \, dx$ 

- $\int 5x^4 \, dx$ 

- $\int 2e^{2x} \, dx$


:::


:::solution



- เนื่องจาก $\dx x = 1$ ฉะนั้น $ \int 1 \, dx = x + C$ 

- เนื่องจาก $\dx x^2 = 2x$ ฉะนั้น $ \int 2x \, dx = x^2 + C$ 

- เนื่องจาก $\dx x^5 = 5x^4$ ฉะนั้น $ \int 5x^4 \, dx = x^5 + C$ 

- เนื่องจาก $\dx e^{2x} = 2e^{2x}$ ฉะนั้น $ \int 2e^{2x} \, dx = e^{2x} + C$ 


:::





## หมายเหตุ 1/3


:::remark

ถ้าให้ $c$ เป็นค่าคงตัวแล้วจะได้ว่า $\dx c = 0$ ฉะนั้น $ \int 0 \, dx = c + C$ 

แต่เนื่องจาก $C$ แทนค่าคงตัวใด ๆ ก็ได้ ฉะนั้น $c + C$ ก็เป็นค่าคงตัวใด ๆ ก็ได้เช่นกัน นั่นคือเราจะเขียนแค่ 
\[ \int 0 \, dx = C\] 

ในทำนองเดียวกัน ถ้าเราพบค่า $C$ หลายค่า เราจะสามารถรวมเป็น $C$ ตัวเดียวได้

:::





## หมายเหตุ 2/3


:::remark

บางครั้งเราจะเห็นการเขียน $\int \, dx$ โดยไม่มีการกำหนดฟังก์ชันในเครื่องหมาย $ \int$ ในที่นี้เราจะกำหนดว่า
\[ \int \, dx = \int 1 \, dx\] 

:::





## หมายเหตุ 3/3


:::remark

เราอาจใช้ตัวแปรอื่นแทน $x$ ก็ได้ แต่การจะหาปริพันธ์ได้นั้น ตัวแปรทั้งหมดหลัง $\int$ ก็ต้องเป็นตัวแปรเดียวกันกับหลัง $d$ 

:::slide

\begin{eq*}
\int 3 \, du &=& 3u + C 

\int -2 \, dr &=& -2r + C 

\int 2\alpha \, d\alpha &=& \alpha^2 + C 

\int e^{z} \, dz &=& e^z + C
\end{eq*}

:::
