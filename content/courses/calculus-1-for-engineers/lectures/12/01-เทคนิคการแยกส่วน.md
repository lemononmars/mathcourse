ถ้ายังจำกันได้ เรามีสมบัติอนุพันธ์ของผลคูณ 
\[\dx (u\cdot v) = u \dx v + v \dx u \] 
ซึ่งเขียนในอีกรูปหนึ่งได้เป็น
\[ d (u \cdot v) = u \, dv + v \, du\] 
เราสามารถหาปริพันธ์ทั้งสองข้างได้เป็น
\begin{eqnarray*}
\int d(u\cdot v) &=& \int (u \, dv + v \, du) 

&=& \left(\int u \,dv\right) + \left(\int v \,du\right) 
\end{eqnarray*}
ถ้าเรามอง $u \cdot v$ เป็นฟังก์ชันหนึ่ง จะได้ $\displaystyle \int d(u\cdot v) = \int 1 \, d(u \cdot v) = u\cdot v + C$



ฉะนั้น
\begin{eqnarray*}
uv + C &=& \left(\int u \, dv\right) + \left(\int v\, du\right) 

\int u dv &=& uv + C - \left(\int v\, du\right) 
\end{eqnarray*}
แต่เนื่องจากค่า $C$ นี้จะไปรวมกับค่า $C$ จาก $\int v du$ อยู่แล้ว จึงไม่จำเป็นต้องเขียนตอนนี้ 

:::definition

กำหนดให้ $u, v$ เป็นฟังก์ชันที่หาปริพันธ์ได้ แล้ว
\begin{eq} 
\int u \, dv = uv - \int v\, du
\end{eq}

:::





:::remark ขั้นตอนการหาปริพันธ์แยกส่วน



- สังเกตว่า $f$ จะเป็นฟังก์ชันหลายฟังก์ชันคูณกัน (หรือหารกัน) แยกเป็นสองส่วนได้ $f = u\cdot v'$ โดยที่ $v'$ เป็นฟังก์ชันที่หาปริพันธ์ได้ง่าย 

- เขียน $f \, dx = u \cdot v' \, dx = u \, dv$ โดยที่ $v' \, dx = dv$ นั่นคือ $v = \int v' \, dx$ โดยละพจน์ $C$ ไว้ 

- แทนค่า $u$ และ $v$ ที่ได้ลงในสูตร 
\[ \int u \, dv = uv - \int v\, du\]


:::






:::example

จงหาปริพันธ์ $\int x \sin x \, dx$

:::


:::solution



- ให้ $f(x) = x \sin x$ สังเกตว่าเป็นฟังก์ชันที่คูณกัน เราจึงให้ $u = x$ และ $v' = \sin x$ 

- เมื่อ $v' = \sin x$ จะได้ $v = \int \sin x \, dx = -\cos x + C$ 

- แทนค่า $u = x$ และ $v = -\cos x$ ลงในสูตร 
\begin{eqnarray*}
\int u \, dv &=& uv - \int v\, du 

\int x \sin x \, dx &=& (x) \cdot (-\cos x) - \int (-\cos x) \, dx 

&=& -x\cos x + \sin x + C
\end{eqnarray*}


:::






:::example

จงหาปริพันธ์ $\int x e^x \, dx$

:::


:::solution



- ให้ $f(x) = x e^x$ สังเกตว่าเป็นฟังก์ชันที่คูณกัน เราจึงให้ $u = x$ และ $v' = e^x$ 

- เมื่อ $v' = e^x$ จะได้ $v = \int e^x \, dx = e^x + C$ 

- แทนค่า $u = x$ และ $v = e^x$ ลงในสูตร 
\begin{eqnarray*}
\int u \, dv &=& uv - \int v\, du 

\int x e^x \, dx &=& (x) \cdot (e^x) - \int (e^x) \, d (x) 

&=& xe^x - e^x + C
\end{eqnarray*}


:::






:::example

จงหาปริพันธ์ $\int x^2 \ln x \, dx$

:::


:::solution



- ให้ $f(x) = x^2 \ln x$ สังเกตว่าเป็นฟังก์ชันที่คูณกัน เราจึงให้ $u = x^2$ และ $v' = \ln x$ 

- เมื่อ $v' = \ln x$ จะได้ $v = \int \ln x \, dx = ........$ 

- เนื่องจากเรายังไม่รู้ค่าของ $\int \ln x \, dx$ แปลว่าเราต้องลองเปลี่ยน $u, v'$ เป็นตัวอื่น 


:::





\[\int x^2 \ln x \, dx\]

:::solution
(ต่อ)


- ลองใหม่ ให้ $u = \ln x$ และ $v' = x^2$ 

- เมื่อ $v' = x^2$ จะได้ $v = \int x^2 \, dx = \frac{1}{3}x^3 + C$ 

- แทนค่า $u = \ln x$ และ $v = \frac{1}{3}x^3$ ลงในสูตร 
\begin{eqnarray*}
\int u \, dv &=& uv - \int v\, du 

\int x^2 \ln x \, dx &=& (\ln x) \cdot \left( \frac{1}{3}x^3\right) - \int \frac{1}{3}x^3\, d (\ln x)

\end{eqnarray*}


:::





:::solution
(ต่อ)
\begin{eqnarray*}
\int x^2 \ln x \, dx &=& (\ln x) \cdot \left( \frac{1}{3}x^3\right) - \int \frac{1}{3}x^3\, d (\ln x)

&=& \frac{1}{3} x^3 \ln x - \int \frac{1}{3}x^3 \cdot \frac{1}{x}\, dx

&=& \frac{1}{3} x^3 \ln x - \frac{1}{3} \int x^2\, dx

&=& \frac{1}{3} x^3 \ln x - \frac{1}{3}\left( \frac{1}{3}x^3 + C \right)

&=& \frac{1}{3} x^3 \ln x - \frac{1}{9}x^3 + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์ $\int x^4 \ln x \, dx$

:::


:::solution

กำหนดให้ $u = \ln x$ และ $v' = x^4$ จะได้ 
\[v = \int x^4 \, dx = \frac{1}{5}x^5 + C\]
ฉะนั้นแทนค่า $u = \ln x$ และ $v = \frac{1}{5}x^5$ ลงในสูตรจะได้
\begin{eqnarray*}
\int x^4 \ln x \, dx &=& (\ln x) \cdot \left( \frac{1}{5}x^5\right) - \int \frac{1}{5}x^5\, d (\ln x)

&=& \frac{1}{5} x^5 \ln x - \frac{1}{5} \int x^5 \cdot \frac{1}{x}\, dx

&=& \frac{1}{5} x^5 \ln x - \frac{1}{5} \int x^4\, dx = \frac{1}{5} x^5 \ln x - \frac{1}{25}x^5 + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์ $\int x^2 e^x \, dx$

:::


:::solution



- ลองให้ $u = x^2$ และ $v' = e^x$ 

- เมื่อ $v' = e^x$ จะได้ $v = \int e^x \, dx = e^x + C$ 

- แทนค่า $u = x^2$ และ $v = e^x$ ลงในสูตร จะได้
\begin{eqnarray*}
\int x^2 e^x \, dx &=& (x^2) \cdot (e^x) - \int e^x \, d (x^2)

&=& x^2 e^x - \int e^x \cdot 2x \, dx = x^2 e^x - 2 \int xe^x \, dx
\end{eqnarray*}

แต่! เราไม่มีสูตรของ $\int xe^x \, dx$ 

:::





:::solution
(ต่อ)
อย่างไรก็ตามสังเกตว่าเลขชี้กำลังของ $x$ ลดลงจาก $x^2$ เหลือ $x^1 = x$ 

ฉะนั้น ถ้าเราใช้เทคนิคนี้อีกรอบน่าจะทำให้เลขชี้กำลังหายไป 

เราสามารถหา $\int xe^x \, dx$ ได้โดยแทนค่า $u = x$ และ $v = e^x$ ลงในสูตร 
\begin{eqnarray*}
\int u \, dv &=& uv - \int v\, du 

\int x e^x \, dx &=& (x) \cdot (e^x) - \int (e^x) \, d (x) 

&=& xe^x - e^x + C
\end{eqnarray*}

:::





:::solution
(ต่อ)
ฉะนั้น เราแทนค่า $\int x e^x \, dx = xe^x - e^x + C$ ในสมการ จะได้
\begin{eqnarray*} 
\int x^2 e^x &=& x^2 e^x - 2 \int xe^x \, dx 

&=& x^2 e^x - 2 \left( xe^x - e^x + C \right) 

&=& x^2 e^x - 2xe^x + 2e^x + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์ $\int x^2 \sin x \, dx$

:::


:::solution



- ลองให้ $u = x^2$ และ $v' = \sin x$ 

- เมื่อ $v' = \sin x$ จะได้ $v = \int \sin x\, dx = -\cos x + C$ โดยละ $C$ ไว้เหลือ $v = -\cos x$ 

- แทนค่า $u = x^2$ และ $v = -\cos x$ ลงในสูตร จะได้
\begin{eqnarray*}
\int x^2 \sin x\, dx &=& (x^2) \cdot (-\cos x) - \int (-\cos x) \, d (x^2)

&=& -x^2 \cos x + \int \cos x \cdot 2x \, dx 

&=& -x^2 \cos x+ 2 \int x \cos x\, dx
\end{eqnarray*}

สังเกตว่า แม้จะหาปริพันธ์ไม่ได้ในทันที แต่เลขชี้กำลังก็ลดลงมาจาก $x^2$ เหลือ $x$

:::





:::solution
(ต่อ)
ใช้เทคนิคปริพันธ์แยกส่วนอีกรอบ กับ $\int x \cos x \, dx$ โดยแทน $u = x$ และ $dv = \cos x \, dx$ นั่นคือ $v = \sin x$ ลงไปในสูตร 
\begin{eqnarray*}
\int u \, dv &=& uv - \int v\, du 

\int x \cos x\, dx &=& (x) \cdot (\sin x) - \int (\sin x) \, d (x) 

&=& x\sin x + \cos x + C
\end{eqnarray*}

:::





:::solution
(ต่อ)
ฉะนั้น เราแทนค่า $\int x \cos x \, dx = x\sin x + \cos x + C$ ในสมการ จะได้
\begin{eqnarray*} 
\int x^2 \sin x &=& -x^2 \cos x + 2 \int x \cos x \, dx 

&=& -x^2 \cos x + 2(x\sin x + \cos x + C)

&=& -x^2 \cos x + 2x\sin x + 2\cos x + C
\end{eqnarray*}

:::
