เราได้ศึกษานิยามของอนุพันธ์ ซึ่งเท่ากับ
\[\dyx = \limh \frac{f(x+h)-f(x)}{h}\]
โดยเราให้ความหมายว่าเป็นอัตราความเปลี่ยนแปลงของตัวแปรตาม $y$ เทียบกับตัวแปรอิสระ $x$




## ทบทวนเส้นตรง

เราได้เคยศึกษาสมการเส้นตรงมาแล้ว ดังนี้

:::theorem

สมการเส้นตรงที่ผ่านจุด $(x_0, y_0)$ และมีความชันเท่ากับ $m$ คือ
\begin{equation} 
y-y_0 = m(x-x_0) 
\end{equation} 

:::


:::figure diff_applied_line — สมการเส้นตรงที่ผ่านจุด $(x_0, y_0)$ และมีค่าชันเท่ากับ $m$
:::





## สมการเส้นสัมผัสเส้นโค้ง

กำหนดกราฟ $y=f(x)$ และเราต้องการหาสมการเส้นสัมผัสเส้นโค้งเมื่อกำหนด $x=x_0$ เราจะหาค่า $y_0$ และ $m$ ได้ดังนี้


- จากกราฟที่กำหนดให้ เราทราบว่า $y_0 = f(x_0)$ นั่นคือจุด $(x_0, f(x_0))$ เป็นจุดที่เส้นสัมผัสผ่าน

- จากนิยามของอนุพันธ์ เราทราบว่าความชันของเส้นสัมผัสเส้นโค้งเมื่อ $x=x_0$ คือ $m = f\,'(x_0)$


:::figure diff_applied_tangent_line — เส้นสัมผัสเส้นโค้ง $y=f(x)$ เมื่อ $x = x_0$
:::




ฉะนั้น เมื่อนำจุด $(x_0, f(x_0))$ และความชัน $m = f\,'(x_0)$ ไปใส่ในสมการ \eqref{eq:applied_basic_line} จะสามารถสรุปเป็นทฤษฎีบทได้ดังนี้

:::theorem

กำหนดฟังก์ชัน $f(x)$ ที่หาอนุพันธ์ได้ที่จุด $x=x_0$ แล้วสมการเส้นสัมผัสเส้นโค้ง $y = f(x)$ ที่จุด $(x_0, f(x_0))$ คือ
\begin{equation} 
y - f(x_0) = f\,'(x_0)(x-x_0)
\end{equation}

:::






:::example

จงหาสมการเส้นสัมผัสเส้นโค้ง $y = x^3$ เมื่อ $x=2$

:::


:::solution
กำหนดให้ $f(x) = x^3$


- เนื่องจาก $f(**2**) = **2**^3 = **8**$ ดังนั้นจุด $(**2**, f(**2**)) = (**2**,**8**)$ อยู่บนเส้นโค้ง $y = f(x)$ 

- ความชันของเส้นสัมผัสเส้นโค้งที่จุด $(2, 8)$ คืออนุพันธ์ของฟังก์ชัน ซึ่งเราหาอนุพันธ์ได้เป็น $f\,'(x) = 3x^2$ ฉะนัั้นเมื่อแทนค่า $**x=2**$ ลงไปจะได้ $f\,'(**2**) = 3(**2**)^2 = **12**$ 

ฉะนั้น จากสมการ \eqref{eq:applied_line} สมการเส้นสัมผัสเส้นโค้ง $y = f(x)$ ที่จุด $(1,2)$ คือ 
\begin{eqnarray*}
y - f(x_0) &=& f\,'(x_0) (x-x_0) 

y - **8** &=& **12**(x - **2**) 

y &=& 12x-16
\end{eqnarray*}

:::





:::figure diff_applied_tangent_ex1 — ตัวอย่างที่ \theex: สมการเส้นสัมผัส $y=12x-16$
:::






:::example

จงหาสมการเส้นสัมผัสเส้นโค้ง $y = 5x^2 - 3$ เมื่อ $x=1$

:::


:::solution
กำหนดให้ $f(x) = 5x^2-3$


- เนื่องจาก $f(1) = 5(1^2) - 3 = 2$ ดังนั้นจุด $(1, f(1)) = (1,2)$ อยู่บนเส้นโค้ง $y = f(x)$ 

- ความชันของเส้นสัมผัสเส้นโค้งที่จุด $(1, 2)$ คืออนุพันธ์ของฟังก์ชัน ซึ่งเรารู้ว่า $f\,'(x) = 10x$ ฉะนัั้น $f\,'(1) = 10(1) = 10$ 

ฉะนั้น จากสมการ \eqref{eq:applied_line} สมการเส้นสัมผัสเส้นโค้ง $y = f(x)$ ที่จุด $(1,2)$ คือ 
\begin{eqnarray*}
y - f(x_0) &=& f\,'(x_0) (x-x_0) 

y - 2 &=& 10(x-1) 

y &=& 10x-8
\end{eqnarray*}

:::





:::figure diff_applied_tangent_ex2 — ตัวอย่างที่ \theex: สมการเส้นสัมผัส $y=12x-16$
:::






:::example

จงหาสมการเส้นสัมผัสเส้นโค้ง $y = \ln (x+3)$ เมื่อ $x=5$

:::


:::solution
กำหนดให้ $f(x) = \ln (x+3)$


- เนื่องจาก $f(5) = \ln (5+3) = \ln 8$ ดังนั้นจุด $(5, f(5)) = (5, \ln 8)$ อยู่บนเส้นโค้ง $y = f(x)$ 

- ความชันของเส้นสัมผัสเส้นโค้งที่จุด $(5,\ln 8)$ คืออนุพันธ์ของฟังก์ชัน ซึ่งเราหาอนุพันธ์ได้เป็น $f\,'(x) = \tfrac{1}{x+3}$ ฉะนัั้นเมื่อแทนค่า $x=5$ ลงไปจะได้ $f\,'(5) = \tfrac{1}{5+3} = \tfrac{1}{8}$ 

ฉะนั้น จากสมการ \eqref{eq:applied_line} สมการเส้นสัมผัสเส้นโค้ง $y = f(x)$ ที่จุด $(5, \ln 8)$ คือ 
\begin{eqnarray*}
y - f(x_0) &=& f\,'(x_0) (x-x_0) 

y - \ln 8 &=& \tfrac{1}{8}(x - 5) 

y &=& \tfrac{x}{8} - \tfrac{5}{8} + \ln 8
\end{eqnarray*}

:::





:::figure diff_applied_tangent_ex3 — ตัวอย่างที่ \theex: สมการเส้นสัมผัส $y=10x-8$
:::






:::example

ถ้าเส้นโค้ง $y = x^2+4$ สัมผัสกับเส้นตรง $y = mx$ เมื่อ $m$ เป็นจำนวนจริงที่ยังไม่ทราบค่า แล้วจงหาจุดสัมผัสและค่า $m$

:::


:::solution

กำหนด $f_1(x) = x^2+4$ และ $f_2(x) = mx$ และให้เส้นตรงสัมผัสกับเส้นโค้งที่จุด $(x_0, y_0)$ แล้วเราทราบว่า


- จุดที่สัมผัสต้องอยู่บนเส้นโค้งและเส้นตรง นั่นคือ
\[ f_1(x_0) = f_2(x_0) \]

- ความชันของเส้นโค้ง ณ จุดนั้น ต้องเท่ากับความชันของเส้นตรง ณ จุดนั้น นั่นคือ
\[ f_1\,'(x_0) = f_2\,'(x_0) \]

เราสามารถใช้สองสมการนี้ในการหาค่า $m$ และ $(x_0, y_0)$ ได้ดังนี้

:::





:::solution
(ต่อ)
จากสมการที่สอง จะได้
\begin{eq*}
f_1\,'(x_0) &=& f_2\,'(x_0) 

2x_0 &=& m
\end{eq*}
เมื่อได้ค่า $m$ แล้ว ให้นำจุดนี้ไปแทนในสมการแรก จะได้
\begin{eq*}
f_1(x_0) &=& f_2(x_0) 

x_0^2 +4 &=& mx_0 

&=& (2x_0)x_0 

x_0^2 &=& 4 

x_0 &=& -2, 2
\end{eq*}
ฉะนั้น เราได้สองคำตอบดังนี้


- จุดสัมผัสคือจุด $(-2, f_1(-2)) = (2, 8)$ โดยมีค่าชันเท่ากับ $m = 2(-2) = -4$

- จุดสัมผัสคือจุด $(2, f_1(2)) = (2, 8)$ โดยมีค่าชันเท่ากับ $m = 2(2) = 4$


:::
