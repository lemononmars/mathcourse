## อนุพันธ์อันดับสอง

เราสามารถหาอนุพันธ์ต่อเนื่องได้ ซึ่งจะมีความหมายแตกต่างกันไปแล้วแต่หัวข้อที่ใช้ศึกษา ในขั้นนี้เราเพียงให้คำนิยามและแสดงตัวอย่างเท่านั้น

:::definition

กำหนด $y = f(x)$ ถ้า $f\,'(x)$ เป็นฟังก์ชันที่หาอนุพันธ์ได้ เราจะเรียก **อนุพันธ์อันดับสอง** ของ $f$ เทียบกับ $x$ ว่า

\[ \dx[2] f(x) = \dx \left( \dx f(x) \right) = \dx \left( f\,'(x) \right)\]

โดยเราสามารถเขียนในรูปแบบอื่นได้ดังนี้
\[\dx[2] f(x) = f\,''(x) = f^{\,(2)}(x)\]

:::






:::example

กำหนดให้ $f(x) = x^3$ จงหาอนุพันธ์อันดับสอง $f\,''(x)$ 

:::


:::solution

\begin{eqnarray*}
f\,''(x) = \dx[2] f(x) &=& \dx \left( \dx x^3 \right) 

&=& \dx (3x^2) 

&=& 3 \dx x^2 

&=& 3(2x) = 6x
\end{eqnarray*}

:::






:::example

กำหนดให้ $f(x) = \frac{1}{x^2}$ จงหา $f\,''(x)$ 

:::


:::solution

\begin{eqnarray*}
f\,''(x) = \dx[2] f(x) &=& \dx \left( \dx x^{-2} \right) 

&=& \dx \left( -2(x^{-3}) \right) 

&=& (-2) \dx x^{-3} 

&=& (-2)(-3x^{-4}) = 6x^{-4} 
\end{eqnarray*}

:::






:::example

กำหนดให้ $f(x) = xe^x$ จงหา $f\,''(x)$ 

:::


:::solution

\begin{eqnarray*}
f\'(x) &=& \dx xe^x 

&=& x \dx e^x + e^x \dx x 

&=& xe^x+e^x 

f\,''(x) &=& \dx \left( xe^x + e^x \right) 

&=& \left(\dx xe^x\right) + \left(\dx e^x\right) 

&=& (xe^x + e^x) + e^x 

&=& xe^x + 2e^x
\end{eqnarray*}

:::





:::example

กำหนดให้ $f(x) = \sin x + \cos x$ จงหา $f\,''(x)$ 

:::


:::solution

\begin{eqnarray*}
f\,'(x) &=& \dx (\sin x + \cos x) 

&=& \left(\dx \sin x\right) + \left(\dx \cos x \right) \boxed{\text{สมบัติอนุพันธ์ของผลบวกฟังก์ชัน}} 

&=& \cos x - \sin x 

f\,''(x) = \dx f\,'(x) &=& \dx \left( \cos x - \sin x \right) 

&=& \left(\dx \cos x\right) - \left(\dx \sin x\right) 

&=& -\sin x -\cos x
\end{eqnarray*}

:::





## อนุพันธ์ของฟังก์ชันอันดับสูง


:::definition

**อนุพันธ์อันดับ** $n$ ของ $f$ เทียบ $x$ นิยามโดย
\begin{eq}
\dx[n] f(x) &=& \dx \left( f^{\,(n-1)(x)} \right) 

&=& \dx \left( \dx \left( \cdots \left( \dx f(x) \right) \cdots \right) \right) \nonumber
\end{eq}
โดยมีพจน์ $\dx$ ทั้งหมด $n$ พจน์ ซึ่งหมายถึงการหาอนุพันธ์ต่อเนื่อง รวมทั้งหมด $n$ ครั้ง ซึ่งเราสามารถเขียนแบบย่อได้เป็น 
\[ \dx[n] f(x) = f^{\,(n)}(x)\]

:::






:::example

กำหนดให้ $f(x) = x^4$ จงหาอนุพันธ์อันดับ 4 (นั่นคือ $f\,^{(4)}(x)$)

:::


:::solution
เราหาอนุพันธ์อันดับ 1,2,3 และ 4 ไล่ขึ้นไปทีละอันดับได้ดังนี้
\begin{eqnarray*}
**f\,'(x)** &=& \dx (x^4) = 4x^3 

**f\,''(x)** = \dx **f\,'(x)** &=& \dx (4x^3) = 4(3x^2) = 12x^2 

**f\,'''(x)** = \dx **f\,''(x)** &=& \dx (12x^2) = 12(2x) = 24x 

f\,^{(4)} = \dx **f\,'''(x)** &=& \dx (24x) = 24
\end{eqnarray*}
ฉะนั้น $f\,^{(4)}(x) = 24$

:::






:::example

กำหนดให้ $f(x) = x^5+x^2$ จงหา $f\,'''(x)$

:::


:::solution
เราหาอนุพันธ์อันดับ 1,2 และ 3 ไล่ขึ้นไปทีละอันดับได้ดังนี้
\begin{eqnarray*}
**f\,'(x)** &=& \dx (x^5 + x^2) = \left( \dx x^5 \right) + \left( \dx x^2 \right) 

&=& 5x^4 + 2x 

**f\,''(x)** = \dx **f\,'(x)** &=& \dx (5x^4 + 2x) = \left( \dx 5x^4 \right) + \left( \dx 2x \right) 

&=& 5(4x^3) + 2(1) = 20x^3 + 2 

f\,'''(x) = \dx **f\,''(x)** &=& \dx (20x^3 + 2) = \left( \dx 20x^3 \right) + \left( \dx 2 \right)

&=& 20(3x^2) + 0 = 60x^2
\end{eqnarray*}
ฉะนั้น $f\,'''(x) = 60x^2$

:::






:::example

กำหนดให้ $f(x) = e^{2x}$ จงหาอนุพันธ์อันดับ 3 (นั่นคือ $f\,^{(3)}(x)$)

:::


:::solution
เราหาอนุพันธ์อันดับ 1,2 และ 3 ไล่ขึ้นไปทีละอันดับได้ดังนี้
\begin{eqnarray*}
**f\,'(x)** &=& \dx (e^{2x})= e^{2x} \dx (2x) \boxed{\text{จากสูตร $\dx e^u = e^u \dx u$}}

&=& 2e^{2x} 

**f\,''(x)** &=& \dx **f\,'(x)** = \dx (2e^{2x}) = 2e^{2x} \dx (2x) = 4e^{2x} 

f\,'''(x) &=& \dx **f\,''(x)** = \dx (4e^{2x}) = 4e^{2x} \dx 2x = 8e^{2x}
\end{eqnarray*}
ฉะนั้น $f\,^{(3)}(x) = 8e^{2x}$

:::





## หมายเหตุ


:::remark

การหาอนุพันธ์อันดับสูง แนะนำให้ใช้สัญลักษณ์ $\dx[n] f(x)$ แทน $f\,^{(n)}$ แต่ถ้าต้องการใช้ตัวย่อ ให้ระวังการใช้ดังนี้


- เราสามารถใชัตัวย่อ $f\,', f\,''$ และ $f\,'''$ แทน $f\,^{(1)}, f\,^{(2)}$ และ $f\,^{(3)}$ ได้ 

- สำหรับอนุพันธ์อันดับที่ 4 เป็นต้นไป เราจะใช้สัญลักษณ์ $f\,^{(n)}(x)$ ตามนิยามเสมอ ไม่ใช้ $'$ เนื่องจากสามารถนับได้ยากว่ามีสัญลักษณ์นั้นทั้งหมดกี่ตัว (เช่น $f\,'''''(x)$ มีสัญลักษณ์ $'$ อยู่กี่ตัว?)

- เราจำเป็นจะต้องใส่วงเล็บรอบตัวเลข $(n)$ เพราะถ้าไม่ใส่แล้วจะกลายเป็น $f\,^{n}(x)$ ซึ่งอาจจะหมายความว่านำฟังก์ชันไปยกกำลัง $f\,^n(x) = (f (x))^n$ ก็ได้


:::
