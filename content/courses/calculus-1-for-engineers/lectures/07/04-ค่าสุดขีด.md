## การประยุกต์การหาค่าสุดขีดสัมพัทธ์ของฟังก์ชัน

ในการแก้ปัญหาทางวิศวกรรมหรือธุรกิจ เรามักจะเจอโจทย์ปัญหาต่อไปนี้


- หาตำแหน่งสูงสุดของลูกบอลที่เราโยนขึ้นฟ้า

- หาระยะทางที่ไกลที่สุด ที่เกิดจากการดีดสปริง

- หาจำนวนสินค้าที่ต้องผลิต ถ้าต้องการให้ได้กำไรมากที่สุด

ซึ่งแปลงเป็นโจทย์ทางคณิตศาสตร์ได้เป็น

:::note

กำหนดฟังก์ชัน $f(x)$ ในช่วง $[a,b]$ จงหาค่า $x$ ที่ทำให้ $f(x)$ มากที่สุด หรือ น้อยที่สุด

:::

ถ้าฟังก์ชัน $f(x)$ ไม่ซับซ้อนนัก เราสามารถใช้อนุพันธ์ในการหาค่าที่ดีที่สุดได้

## ค่าสุดขีดสัมบูรณ์และสัมพัทธ์


:::definition

กำหนดให้ $f$ เป็นฟังก์ชันนิยามบนช่วงปิด $[a,b]$ และ $c \in [a,b]$


- $f$ มี**ค่าสูงสุดสัมบูรณ์** ที่ $x=c$ ก็ต่อเมื่อ $f(c)$ เป็นค่ามากที่สุดในช่วง $[a,b]$ (นั่นคือ $f(c) \geq f(x)$ สำหรับทุกค่า $x \in [a,b]$) 

- $f$ มี**ค่าต่ำสุดสัมบูรณ์** ที่ $x=c$ ก็ต่อเมื่อ $f(c)$ เป็นค่าน้อยที่สุดในช่วง $[a,b]$ (นั่นคือ $f(c) \leq f(x)$ สำหรับทุกค่า $x \in [a,b]$)

- $f$ มีค่าสูงสุด**สัมพัทธ์** ที่ $x=c$ ก็ต่อเมื่อ $f(c)$ เป็นค่ามากที่สุดในช่วง $[a_0,b_0]$ สำหรับค่า $a_0, b_0$ บางค่าที่ $a_0 < c < b_0$ 

- $f$ มีค่าต่ำสุด**สัมพัทธ์** ที่ $x=c$ ก็ต่อเมื่อ $f(c)$ เป็นค่าน้อยที่สุดในช่วง $[a_0,b_0]$ สำหรับค่า $a_0, b_0$ บางค่าที่ $a_0 < c < b_0$ 


:::






:::example



จงหาว่าจุดต่าง ๆ ในกราฟต่อไปนี้ เป็นจุดประเภทใด ถ้ากำหนดให้ $f$ เป็นฟังก์ชันที่นิยามในช่วงของกราฟ



:::figure diff_applied_extrema_ex1 — กราฟ $y = f(x)$
:::




:::


:::solution



- จุด $C$ เป็นจุดต่ำสุดสัมบูรณ์

- จุด $D$ เป็นจุดสูงสุดสัมบูรณ์

- จุด $B$ และ $D$ เป็นจุดสูงสุดสัมพัทธ์

- จุด $A$ และ $C$ เป็นจุดต่ำสุดสัมพัทธ์


:::





## หมายเหตุ


:::remark



- $f$ มี**ค่า**สูงสุดสัมบูรณ์มีได้ค่าเดียว หรืออาจจะไม่มีเลยก็ได้

- $f$ มี**ค่า**ต่ำสุดสัมบูรณ์มีได้ค่าเดียว หรืออาจจะไม่มีเลยก็ได้

- $f$ มี**จุด**สูงสุดสัมบูรณ์และจุดต่ำสุดสัมบูรณ์ได้หลายจุด เช่น ฟังก์ชัน $f(x) = \cos x$ มีค่าสูงสุดสัมพัทธ์เท่ากับ $1$ แต่มีจุดสูงสุดสัมพัทธ์เมื่อ $x = n \pi$ สำหรับทุกจำนวนเต็ม $n$


:::

:::





## จุดวิกฤต

คำถามต่อไปคือ เราจะทราบได้อย่างไรว่าฟังก์ชัน $f$ มีค่าสูงสุดสัมพัทธ์และต่ำสุดสัมพัทธ์ที่ใด

:::definition

**ค่าวิกฤต** ของฟังก์ชัน $f(x)$ คือค่า $c$ ที่ทำให้


- $f\,'(c) = 0$ หรือ 

- $f\,'(c)$ หาค่าไม่ได้

ถ้า $c$ เป็นค่าวิกฤตของฟังก์ชัน แล้วเราเรียกจุด $(c,f(c))$ บนกราฟว่า**จุดวิกฤต**

:::






:::example

จงหาค่าวิกฤตทั้งหมดของฟังก์ชันต่อไปนี้


- $f(x) = 3x$

- $f(x) = x^2-4x$


:::


:::solution



- ฟังก์ชัน $f(x) = 3x$ หาอนุพันธ์ได้ 
\[f\,'(x) = 3\]
แสดงว่าเราหาค่า $c$ ที่ทำให้ $f\,'(c)=0$ ไม่ได้ นั่นคือ $f(x)$ ไม่มีค่าวิกฤต 

- ฟังก์ชัน $f(x) = x^2-4x$ หาอนุพันธ์ได้ 
\[f\,'(x) = 2x-4\] 
ซึ่งมีค่าเท่ากับ $0$ เมื่อ $x=2$ ฉะนั้น $f(x)$ มีค่าวิกฤต $x=2$ 


:::







:::example

จงหาค่าวิกฤตทั้งหมดของฟังก์ชันต่อไปนี้


- $f(x) = x^3-3x$

- $f(x) = |x|$


:::


:::solution



- ฟังก์ชัน $f(x) = x^3-3x$ หาอนุพันธ์ได้ 
\[f\,'(x) = 3x^2-3\] 
ซึ่งมีค่าเท่ากับ $0$ เมื่อ $x =-1, 1$ ฉะนั้นเ $f(x)$ มีค่าวิกฤตสองค่า คือเมื่อ $x = -1$ และ $x=1$ 

- ฟังก์ชัน $f(x) = |x|$ หาอนุพันธ์ได้ $f\,'(x) = -1$ เมื่อ $x<0$, $f\,'(x) = 1$ เมื่อ $x> 0$ และหาค่าไม่ได้เมื่อ $x=0$ ฉะนั้น $f(x)$ มีค่าวิกฤต $x=0$ 


:::





## การทดสอบจุดวิกฤต

เมื่อได้ค่าวิกฤตและจุดวิกฤตแล้ว เราต้องพิจารณาต่อว่าจุดนั้นเป็นจุดประเภทใด สังเกตว่าถ้า $f\,'(c) = 0$ แล้วเรายังไม่สามารถสรุปได้ทันทีว่าเป็นจุดประเภทใด แต่เราสามารถใช้ความเว้าของกราฟมาวิเคราะห์ได้ทันทีดังนี้


- จุดสูงสุดสัมพัทธ์ จะมีรูปเว้าบน นั่นคือค่าของ $f\,'(x)$ จะเปลี่ยนจากค่าบวก เป็นศูนย์ และเป็นค่าลบ นั่นคือ $f\,''(x)$ เป็นลบ

- จุดต่ำสุดสัมพัทธ์ จะมีรูปเว้าล่าง นั่นคือค่าของ $f\,'(x)$ จะเปลี่ยนจากค่าลบ เป็นศูนย์ และเป็นค่าบวก นั่นคือ $f\,''(x)$ เป็นบวก





## การทดสอบจุดวิกฤต


:::theorem

ให้ $f(x)$ เป็นฟังก์ชันที่หาอนุพันธ์และอนุพันธ์อันดับสองได้บนช่วง $[a,b]$ และ $c$ เป็นค่าวิกฤตแล้ว


- ถ้า $f\,''(c) < 0$ แล้ว $f(c)$ เป็นค่าสูงสุดสัมพัทธ์

- ถ้า $f\,''(c) > 0$ แล้ว $f(c)$ เป็นค่าต่ำสุดสัมพัทธ์

- ถ้า $f\,''(c) = 0$ แล้วเรายังไม่สามารถให้ข้อสรุปได้ ต้องพิจารณาจาก $f\,'(x)$ อีกที


:::






:::example

จงหาจุดวิกฤตทั้งหมดของฟังก์ชัน $f(x) = x^2-4x$ พร้อมทดสอบว่าเป็นจุดประเภทใด 

:::


:::solution

อนุพันธ์ของฟังก์ชันมีค่าเท่ากับ 
\[f\,'(x) = 2x-4\] 
ซึ่งมีจุดวิกฤตเมื่อ $2x-4 = 0$ นั่นคือ $x_0 = 2$ อนุพันธ์อันดับสองคือ 
\[f\,''(x) = 2\] 
ทำให้ $f\,''(x_0) = 2 > 0$ ดังนั้นจุดวิกฤต $x_0 = 2$ คือจุดต่ำสุดสัมพัทธ์

:::






:::example

จงหาจุดวิกฤตทั้งหมดของฟังก์ชัน $f(x) = -2x^2-8x+10$ พร้อมทดสอบว่าเป็นจุดประเภทใด 

:::


:::solution

อนุพันธ์ของฟังก์ชันมีค่าเท่ากับ 
\[f\,'(x) = -4x-8\] 
ซึ่งมีจุดวิกฤตเมื่อ $-4x-8 = 0$ นั่นคือ $x_0 = -2$ อนุพันธ์อันดับสองคือ 
\[f\,''(x) = -4\] 
ทำให้ $f\,''(x_0) = -4 < 0$ ดังนั้นจุดวิกฤต $x_0 = -2$ คือจุดสูงสุดสัมพัทธ์

:::






:::example

จงหาจุดวิกฤตทั้งหมดของฟังก์ชัน $f(x) = x^3-3x$ พร้อมทดสอบว่าเป็นจุดประเภทใด 

:::


:::solution

อนุพันธ์ของฟังก์ชันมีค่าเท่ากับ 
\[f\,'(x) = 3x^2-3\] 
ซึ่งมีจุดวิกฤตเมื่อ $3x^2-3 = 0$ นั่นคือ $x_0 = -1, 1$ รวม 2 จุด โดยเราต้องวิเคราะห์แต่ละจุดแยกกัน

อนุพันธ์อันดับสองคือ 
\[f\,''(x) = 6x\] 


- สำหรับจุดวิกฤต $x_0 = -1$ เราทราบว่า $f\,''(-1) = -6 < 0$ ดังนั้นจุดวิกฤต $x_0 = -1$ คือจุดสูงสุดสัมพัทธ์ 

- สำหรับจุดวิกฤต $x_0 = 1$ เราทราบว่า $f\,''(-1) = 6 > 0$ ดังนั้นจุดวิกฤต $x_0 = 1$ คือจุดต่ำสุดสัมพัทธ์


:::






:::example

จงหาจุดวิกฤตทั้งหมดของฟังก์ชัน $f(x) = x^6$ พร้อมทดสอบว่าเป็นจุดประเภทใด 

:::


:::solution

อนุพันธ์ของฟังก์ชันมีค่าเท่ากับ 
\[f\,'(x) = 6x^5\] 
ซึ่งมีจุดวิกฤตเมื่อ $x_0 = 0$ อนุพันธ์อันดับสองคือ 
\[f\,''(x) = 30x^4\] 
ทำให้ $f\,''(x_0) = 0$ ดังนั้นเราไม่สามารถสรุปได้ว่าจุดวิกฤต $c = 0$ เป็นจุดประเภทใด

:::
