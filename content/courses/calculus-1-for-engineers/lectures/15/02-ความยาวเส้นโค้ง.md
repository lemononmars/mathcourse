## ที่มาของสูตร

กำหนดเส้นโค้ง $y=f(x)$ จาก $x=a$ ถึง $x=b$ แล้วเราสามารถหาความยาวส่วนโค้งได้ ด้วยการกำหนดจุดบนเส้นโค้งและลากเส้นตรงเชื่อมจุดเข้าด้วยกัน

*การประมาณความส่วนโค้ง ด้วยเส้นตรงที่แบ่งเป็นช่วง ๆ*




พิจารณาเส้นตรงที่เชื่อมจุดสองจุด ได้แก่ จุด $(x_0, f(x_0))$ และจุด $(x_1, f(x_1))$ 




:::tikz TikZ diagram
\begin{tikzpicture}
\axes{-0.5}{2.5}{-0.5}{2}
\draw[teal, domain = 0:2] plot (\x, {1+sin(\x r)});
\draw[red] (0, {1+sin(0 r)}) -- (2, {1+sin(2 r)});
\draw[blue, dashed] (0, {1+sin(0 r)}) --+ (2,0);
\draw[<->] (0, {0.5+sin(0 r)}) --+ (2,0) node[below, pos = 0.5] {$\Delta x$};
\draw[blue, dashed] (2, {1+sin(2 r)}) -- (2,{1+sin(0 r)});
\draw[<->] (2.5, {1+sin(2 r)}) -- (2.5,{1+sin(0 r)}) node[right, pos = 0.5] {$\Delta y$};
\end{tikzpicture}
:::


*ความสัมพันธ์ระหว่างส่วนของเส้นตรงระหว่างสองจุด และค่า $\Delta x$ และ $\Delta y$*



เส้นตรงนี้ คือเส้นตรงข้ามมุมฉากในสามเหลี่ยมที่มีความกว้าง $x_1 - x_0 = dx$ และความสูง $f(x_1) - f(x_0) = dy$ 



จากนั้นเราสามารถใช้ทฤษฎีบทปิทากอรัส เพื่อหาความยาวเส้นตรงได้เป็น 
\[\sqrt{(dx)^2 + (dy)^2}\]
ซึ่งสามารถเขียนใหม่ได้ดังนี้
\[\sqrt{(dx)^2 + (dy)^2} = \sqrt{(dx)^2 + (dx)^2\left( \frac{dy}{dx} \right)^2} = \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx\]
ดังนั้น ความยาวเส้นตรงรวมกันมีค่าเท่ากับ
\[\sum \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx \]



และเมื่อเราแบ่งช่วงย่อยให้มากขึ้นเรื่อย ๆ จนจำนวนช่วงย่อยเข้าใกล้อนันต์ จึงได้สูตร
\[L = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx \]

## สูตรหาความยาวเส้นโค้ง


:::theorem

กำหนดฟังก์ชัน $f(x)$ เป็นฟังก์ชันต่อเนื่องและหาอนุพันธ์ได้บนช่วง $[a,b]$ แล้วความยาวส่วนโค้งของกราฟ $y = f(x)$ จาก $x =a$ ถึง $x=b$ มีค่าเท่ากับ
\begin{equation} 
L= \int_a^b \sqrt{1 + \left(\dyx\right)^2} \, dx
\end{equation}

:::

เราสามารถย่อเป็น $\int_a^b \sqrt{1 + (f\,')^2} \, dx$ ก็ได้ 





:::example

จงหาความยาวเส้นโค้งของกราฟ $y = 2x+1$ บนช่วง $[0,4]$ 

:::


:::solution

อนุพันธ์ของฟังก์ชันคือ $\dyx = 2$ ฉะนั้น ความยาวส่วนโค้งบนช่วง $[0,4]$ มีค่าเท่ากับ 
\begin{eq*}
\int_a^b \sqrt{1 + \left(\dyx\right)^2} \, dx &=& \int_0^4 \sqrt{1 + (2)^2} \, dx 

&=& \int_0^4 \sqrt{5} \, dx 

&=& \sqrt{5} x \Big|_0^4 

&=& 4\sqrt{5}
\end{eq*}

:::







:::example

จงหาความยาวเส้นโค้งของกราฟ $y = \frac{2}{3}x^{3/2}$ บนช่วง $[0,1]$ 

:::


:::solution

อนุพันธ์ของฟังก์ชันคือ $\dyx = \sqrt{x}$ ฉะนั้น ความยาวส่วนโค้งบนช่วง $[0,1]$ มีค่าเท่ากับ 
\begin{eq*}
\int_a^b \sqrt{1 + \left(\dyx\right)^2} \, dx &=& \int_0^1 \sqrt{1 + \left( \sqrt{x}\right)^2} \, dx 

&=& \int_0^1 \sqrt{1 + x } \, dx
\end{eq*}
เราต้องใช้เทคนิคการแทนค่า $u$ ในการหาปริพันธ์นี้

:::





:::solution
(ต่อ)
กำหนดให้ $ u =1 + x$ จะได้ $du = dx$ ดังนั้น
\begin{eq*}
\int \sqrt{1 + x} \, dx &=& \int \sqrt{u} \, du 

&=& \frac{2}{3}u^{3/2} + C 

&=& \frac{2}{3} \left(1 + x \right)^{3/2} + C
\end{eq*}
ฉะนั้น ความยาวส่วนโค้งมีค่าเท่ากับ
\begin{eq*}
\int_0^1 \sqrt{1 + x } \, dx &=& \left( \frac{2}{3} \left(1 + x \right)^{3/2} \right) \Big|_0^1 

&=& \frac{2}{3} \left(1 + 1 \right)^{3/2} - \frac{2}{3} \left(1 + 0 \right)^{3/2} 

&=& \frac{2}{3} ( 2^{3/2} - 1 ) = \frac{2}{3} (2\sqrt{2} - 1) 
\end{eq*}

:::
