:::theorem สูตรปริพันธ์ฟังก์ชันตรีโกณมิติ

\begin{eqnarray*}
\int \sin u \, du &=& - \cos u + C 

\int \cos u \, du &=& \sin u + C 

\int \tan u \, du &=& - \ln | \cos u| + C = \ln | \sec u| + C

\int \cot u \, du &=& \ln | \sin u | + C

\int \sec u \, du &=& \ln | \sec u + \tan u | + C 

\int \csc u \, du &=& \ln | \csc u - \cot u| + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int \sin(3x) \,dx\]

:::


:::solution

แทนค่า $u = 3x$ จะได้ $\frac{du}{dx} = 3$ นั่นคือ $du = 3\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \sin(3x) \, dx = \int \sin(u) \left( \frac{1}{3} \, du \right) &=& \frac{1}{3} \int \sin(u) \, du 

&=& \frac{1}{3} \left( -\cos (u) + C \right) 

&=& -\frac{1}{3} \cos(u) + C = -\frac{1}{3} \cos(3x) + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int \cos(4x-3) \,dx\]

:::


:::solution

แทนค่า $u = 4x-3$ จะได้ $\frac{du}{dx} = 4$ นั่นคือ $du = 4\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \cos(4x-3) \, dx &=& \int \cos(u) \left( \frac{1}{4} \, du \right) = \frac{1}{4} \int \cos(u) \, du 

&=& \frac{1}{4} \left( \sin (u) + C \right) 

&=& \frac{1}{4} \sin(u) + C = \frac{1}{4} \sin(4x-3) + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int \sin x (\cos x)^8 \,dx\]

:::


:::solution

แทนค่า $u = \cos x$ จะได้ $\frac{du}{dx} = - \sin x$ นั่นคือ $du = - \sin x\, dx$

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \sin x (\cos x)^8 \, dx = \int (\sin x) (u^8) \left( \frac{du}{- \sin x} \right) &=& - \int u^8 \, du 

&=& \frac{1}{9}u^9 + C

&=& \frac{1}{9}(\cos x)^9 + C 
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์ 
\[\int x\tan (x^2) \, dx\]

:::


:::solution

ใช้การแทนค่า $u$ โดยกำหนดให้ $u(x) = x^2$ จะได้ $du = 2x \, dx$ ฉะนั้น
\begin{eq*}
\int x \tan (x^2) \, dx &=& \int x \tan u \frac{du}{2x} 

&=& \frac{1}{2} \int \tan u \, du 

&=& \frac{1}{2} (\ln | \sec u| + C) 

&=& \frac{1}{2} \ln |\sec (x^2)| + C
\end{eq*}

:::
