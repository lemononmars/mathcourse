## วิธีการหาปริพันธ์โดยใช้เทคนิคการแทนค่า u

เราสามารถสรุปการหาปริพันธ์ $\int (2x+1 )^5\,dx$ ออกมาเป็นขั้นตอนได้ดังนี้

:::remark ขั้นตอนการใช้เทคนิคการแทนค่า u



- หาพจน์ที่ดูซับซ้อนก่อน และลองแทนค่าพจน์นั้นเป็นฟังก์ชัน $u$ 

- หาอนุพันธ์ $du = u' dx$ จะได้ว่า $dx = \frac{du}{u'}$ 

- แทนค่า $dx$ และจัดรูปพจน์อื่นในปริพันธ์ให้เป็น $u$ เท่าที่ทำได้ 


- ถ้าผลลัพธ์เป็นปริพันธ์ที่เหลือแต่ตัวแปร $u$ ให้ทำการหาปริพันธ์ได้ 

- ถ้ายังติดทั้งตัวแปร $u$ และ $x$ ให้ลองแทนค่า $u$ ใหม่ หรือให้ลองวิธีอื่น



:::





:::example

จงหาปริพันธ์ $\int (5-4x)^3\,dx$ โดยการแทนค่า $u$

:::


:::solution

แทนค่า $u = 5-4x$ จะได้ $\frac{du}{dx} = -4$ นั่นคือ $du = -4\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int (5-4x)^3 \, dx = \int u^3 \left( \frac{du}{-4} \right) &=& -\frac{1}{4} \int u^3 \, du 

&=& -\frac{1}{4} \left( \frac{1}{4} u^4 + C \right) 

&=& -\frac{1}{16}u^4 + C = \frac{-1}{16}(5-4x)^4 + C
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์ต่อไปนี้ โดยการแทนค่า $u$
\[\int \frac{x}{(x^2+1)^2}\,dx\]

:::


:::solution

แทนค่า $u = x^2+1$ จะได้ $\frac{du}{dx} = 2x$ นั่นคือ $du = 2x\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \frac{x}{(x^2+1)^2} \, dx = \int \frac{x}{u^2} \left(\frac{du}{2x} \right) &=& \frac{1}{2} \int \frac{1}{u^2} \, du = \frac{1}{2} \int u^{-2} \, du 

&=& \frac{1}{2} \left( - u^{-1} + C \right) 

&=& \frac{1}{2}u^{-1} + C = \frac{1}{2}(x^2+1)^{-1} + C
\end{eqnarray*}

:::







:::example

จงหาปริพันธ์ต่อไปนี้ โดยการแทนค่า $u$
\[\int x^2 \sqrt{x^3-5} \, dx\]

:::


:::solution

แทนค่า $u = x^3-5$ จะได้ $\frac{du}{dx} = 3x^2$ นั่นคือ $du = 3x^2\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int x^2 \sqrt{x^3-5}\, dx = \int x^2 \sqrt{u} \left(\frac{du}{3x^2} \right) &=& \frac{1}{3} \int \sqrt{u}\, du = \frac{1}{3} \int u^{\frac{1}{2}}\, du 

&=& \frac{1}{3} \left( \frac{2}{3} u^{\frac{3}{2}} + C \right) 

&=& \frac{2}{9} u^{\frac{3}{2}} + C = \frac{2}{9}(x^3-5)^{\frac{3}{2}} + C
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์ต่อไปนี้ โดยการแทนค่า $u$
\[\int x^2 \sqrt{x-1} \, dx\]

:::


:::solution

แทนค่า $u = x-1$ จะได้ $\frac{du}{dx} = 1$ นั่นคือ $du = dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ จะได้ $\int x^2 \sqrt{x-1}\, dx = \int x^2 \sqrt{u} \, du$ แต่สังเกตว่าเรายังคำนวณต่อไม่ได้ทันทีเนื่องจากมีพจน์ $x^2$ หลงเหลืออยู่

อย่างไรก็ตาม เราสามารถเปลี่ยนตัวแปร $x$ ให้เป็นตัวแปร $u$ ได้ดังนี้
\[ u = x-1 \qquad \rightarrow \qquad x = u+1 \]

:::





:::solution
(ต่อ)
ฉะนั้น
\begin{eqnarray*}
\int x^2 \sqrt{x-1}\, dx &=& \int (u+1)^2 \sqrt{u} \, du 

&=& \int (u^2+2u+1) u^{\frac{1}{2}} \, du 

&=& \int u^{\frac{5}{2}} + 2u^{\frac{3}{2}} + u^{\frac{1}{2}} \, du 

&=& \frac{1}{7/2} u^{\frac{7}{2}} + 2 \left(\frac{1}{5/2} u^{\frac{5}{2}}\right) + \frac{1}{3/2} u^{\frac{3}{2}} + C 

&=& \frac{2}{7} u^{\frac{7}{2}} + \frac{4}{5} u^{\frac{5}{2}} + \frac{2}{3} u^{\frac{3}{2}} + C 

\end{eqnarray*}

:::





## การใช้สูตรร่วมกับการหาปริพันธ์โดยการแทนค่า

เราได้ศึกษาสูตรปริพันธ์ต่าง ๆ เช่น

:::remark

\begin{eqnarray*}
\int x^n \, dx &=& \frac{1}{n+1}x^{n+1} + C 

\end{eqnarray*}

:::

เมื่อใช้ร่วมกับการหาปริพันธ์ด้วยการแทนค่า เราจะเปลี่ยนไปใช้ตัวแปร $u$ แทน ซึ่งเราจะเขียนสูตรใหม่ และมีวิธีการใช้งานดังต่อไปนี้

:::remark

\begin{eqnarray*}
\int u^n \, du &=& \frac{1}{n+1}u^{n+1} + C 

\end{eqnarray*}

:::
