:::theorem ปริพันธ์ของฟังก์ชันเลขชี้กำลัง และฟังก์ชันที่ให้ผลลัพธ์เป็นฟังก์ชันลอการิทึม

\begin{eqnarray*}
\int e^u \, du &=& e^u + C 


\int \frac{1}{u} \, du &=& \ln |u| + C
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์
\[\int e^{2x} \,dx\]

:::


:::solution

แทนค่า $u = 2x$ จะได้ $\frac{du}{dx} = 2$ นั่นคือ $du = 2\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int e^{2x} \, dx = \int e^u \left( \frac{1}{2} \, du \right) &=& \frac{1}{2} \int e^u \, du 

&=& \frac{1}{2} (e^u + C) 

&=& \frac{1}{2} e^u + C = \frac{1}{2} e^{2x} + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int 3e^{4x+5} \,dx\]

:::


:::solution

แทนค่า $u = 4x+5$ จะได้ $\frac{du}{dx} = 4$ นั่นคือ $du = 4\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int 3e^{4x+5} \, dx = 3\int e^u \left( \frac{1}{4} \, du \right) &=& \frac{3}{4} \int e^u \, du 

&=& \frac{3}{4} (e^u + C) 

&=& \frac{3}{4} e^u + C = \frac{3}{4} e^{4x+5} + C
\end{eqnarray*}

:::





:::example

จงหาปริพันธ์
\[\int \frac{1}{2x+1} \,dx\]

:::


:::solution

แทนค่า $u = 2x+1$ จะได้ $\frac{du}{dx} = 2$ นั่นคือ $du = 2\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \frac{1}{2x+1} \, dx = \int \frac{1}{u} \left( \frac{1}{2} \, du \right) &=& \frac{1}{2} \int \frac{1}{u} \, du 

&=& \frac{1}{2} (\ln |u| + C) 

&=& \frac{1}{2} \ln |u| + C = \frac{1}{2} \ln|2x+1| + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int \frac{2}{3-4x} \,dx\]

:::


:::solution

แทนค่า $u = 3-4x$ จะได้ $\frac{du}{dx} = -4$ นั่นคือ $du = -4\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int \frac{2}{3-4x} \, dx = 2\int \frac{1}{u} \left( \frac{1}{-4} \, du \right) &=& -\frac{2}{4} \int \frac{1}{u} \, du 

&=& -\frac{1}{2} (\ln |u| + C) 

&=& -\frac{1}{2} \ln |u| + C = -\frac{1}{2} \ln|3-4x| + C
\end{eqnarray*}

:::






:::example

จงหาปริพันธ์
\[\int x^2e^{x^3} \,dx\]

:::


:::solution

แทนค่า $u = x^3$ จะได้ $\frac{du}{dx} = 3x^2$ นั่นคือ $du = 3x^2\, dx$ 

เมื่อเปลี่ยนพจน์ในปริพันธ์ให้กลายเป็น $u$ 
\begin{eqnarray*}
\int x^2e^{x^3} \, dx = \int x^2 e^u \left( \frac{du}{3x^2} \right) &=& \frac{1}{3} \int e^u \, du 

&=& \frac{1}{3} \left( e^u + C \right) 

&=& \frac{1}{3} e^u + C = \frac{1}{3}e^{x^3} + C
\end{eqnarray*}

:::
