## ที่มาของการแยกเศษส่วนย่อย

ถ้าปริพันธ์อยู่ในรูปเศษส่วนพหุนาม $\int \frac{P(x)}{Q(x)} \, dx$ **แต่**ดีกรี ของ $P(x)$ น้อยกว่า $Q(x)$ และไม่มีอยู่ในรูปแบบของสูตรที่เคยศึกษามาแล้ว ต้องใช้ทฤษฎีบทต่อไปนี้

:::theorem

ถ้าแยกตัวประกอบ $Q(x)$ ได้เป็น $Q(x) = (x-a_1)(x-a_2)\ldots(x-a_n)$ เมื่อ $a_1,a_2,\ldots,a_n$ ไม่ซ้ำกัน แล้ว 
\[ \frac{P(x)}{Q(x)} = \frac{A_1}{x-a_1} + \frac{A_2}{x-a_2} + \cdots + \frac{A_n}{x-a_n}\] 
เมื่อ $A_1, A_2, \ldots, A_n$ เป็นค่าคงตัว 

:::




ในกรณีที่ $Q(x)$ เป็นพหุนามอันดับ 2 นั่นคือ เราสามารถแยกตัวประกอบได้เป็น $Q(x) = (x-a)(x-b)$ จะได้ว่า 

:::slide

\[ \frac{P(x)}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}\] 
ซึ่งเมื่อคูณทั้งสองฝั่งของสมการด้วย $(x-a)(x-b)$ จะได้ 
\[ P(x) = A(x-b) + B(x-a)\] 
ถ้าเราแทนค่า $**x=a**$ ในสมการจะได้ 
\[ P(**a**) = A(**a**-b) + B(**a**-a) = A(**a**-b)\] 
ฉะนั้น เราจะได้ $A = \frac{P(a)}{a-b}$ ในทำนองเดียวกัน ถ้าแทนค่า $**x=b**$ จะได้ 
\[P(**b**) = A(**b**-b) + B(**b**-a) = B(**b**-a)\] 
นั่นคือ $B = \frac{P(b)}{b-a}$ 

:::






:::example

จงแปลง $\frac{1}{x(x-1)}$ ให้เป็นเศษส่วนย่อย 

:::


:::solution

กำหนดให้ $\frac{1}{x(x-1)} = \frac{A}{x} + \frac{B}{x-1}$ 
เมื่อคูณทั้งสองฝั่งของสมการด้วย $x(x-1)$ จะได้ 
\[1 = A(x-1) + Bx \] 
เมื่อแทนค่า $**x=0**$ และ $**x=1**$ ดังต่อไปนี้ 
\[ 1 = A(**0**-1) + B (**0**)= -A \qquad \Longrightarrow \qquad A = -1\] 
\[1 = A(**1**-1) + B(** 1**) = B \qquad \Longrightarrow \qquad B = 1\] 
ดังนั้น $ \frac{1}{x(x-1)} = \frac{-1}{x} + \frac{1}{x-1}$

:::






:::example

จงแปลง $\frac{3x}{(x-2)(x+4)}$ ให้เป็นเศษส่วนย่อย 

:::


:::solution

ถ้าเราต้องการเปลี่ยน $\frac{3x}{(x-2)(x+4)}$ เป็นเศษส่วนย่อย นั่นคือ $\frac{x}{(x-2)(x+4)} = \frac{A}{x-2} + \frac{B}{x+4}$ 
เมื่อคูณทั้งสองฝั่งของสมการด้วย $(x-2)(x+4)$ จะได้ 
\[3x = A(x+4) + B(x-2) \] 
เมื่อแทนค่า $**x=2**$ และ $**x=-4**$ (เพื่อทำให้พจน์ $B$ หายไป) จะได้ 
\[6 = A(**2**+4) + B(**2**-2) = 6A \qquad \Longrightarrow \qquad A = 1\] 
\[-12 = A(**-4**+4) + B(**-4**-2) = -6B \qquad \Longrightarrow \qquad B = 2\] 
ดังนั้น $ \frac{x}{(x-2)(x+4)} = \frac{1}{x-2} + \frac{2}{x+4}$

:::
