## การหาปริพันธ์เมื่อแยกเป็นเศษส่วนย่อยได้แล้ว

เมื่อเราแยกเป็นเศษส่วนย่อยได้สำเร็จแล้ว เราก็จะสามารถหาปริพันธ์ได้ด้วยสูตร
\[ \int \frac{1}{x} \, dx = 
:::slide
\ln |x| + C
:::
\] 
ซึ่งเราสามารถใช้การแทนค่า $u$ เพื่อขยายเป็นสูตรทั่วไปได้ดังนี้ 

:::theorem

ให้ $r,s$ เป็นจำนวนจริง โดยที่ $r \neq 0$ จะได้ว่า
\begin{equation} 
\int \frac{1}{rx + s} \, dx = \frac{1}{r} \ln |rx+s| + C
\end{equation}

:::





:::solution

ให้เทคนิคการแทนค่า $u$ โดยให้ $u = rx + s$ จะได้ $du = r \, dx$ ดังนั้น
\begin{eqnarray*}
\int \frac{1}{rx+s} \, dx &=& \int \frac{1}{u} \left(\frac{du}{r}\right) 

&=& \frac{1}{r} \int \frac{1}{u} \, du 

&=& \frac{1}{r} \ln |u| + C = \frac{1}{r} \ln |rx+s| + C
\end{eqnarray*}

:::






:::example

จงใช้สมการ \eqref{eq:integral_fraction} เพื่อหาปริพันธ์ต่อไปนี้


- $\int \frac{1}{x-4} \, dx$

- $\int \frac{1}{2x+3} \, dx $

- $\int \frac{1}{-5x+4} \, dx $


:::


:::solution



- $\int \frac{1}{x-4} \, dx = \ln |x-4| + C$

- $\int \frac{1}{2x+3} \, dx = \frac{1}{2} \ln | 2x+3 | + C$

- $\int \frac{1}{-5x+4} \, dx = \frac{1}{-5} \ln | - 5x + 4| + C$


:::







:::example

จงหา $\int \frac{1}{x(x-1)} \, dx$

:::


:::solution

จากตัวอย่างในหน้าที่ \ref{ex:partial_fraction1} เราสามารถแยกเป็นเศษส่วนย่อยดังนี้
\[\frac{1}{x(x-1)} = -\frac{1}{x} + \frac{1}{x-1}\] 
ฉะนั้น
\begin{eqnarray*}
\int \frac{1}{x(x-1)} \, dx &=& \int \left(- \frac{1}{x} + \frac{1}{x-1} \right)\, dx 

&=& - \int \frac{1}{x} \, dx + \int \frac{1}{x-1} \, dx 

&=& - \ln |x| + \ln |x-1| + C
\end{eqnarray*}

:::






:::example

จงหา $\int \frac{3x}{(x-2)(x+4)} \, dx$

:::


:::solution

จากตัวอย่างในหน้าที่ \ref{ex:partial_fraction2} เราสามารถแยกเป็นเศษส่วนย่อยดังนี้
\[\frac{3x}{(x-2)(x+4)} = \frac{1}{x-2} + \frac{2}{x+4}\] 
ฉะนั้น
\begin{eqnarray*}
\int \frac{x}{(x-2)(x+4)} \, dx &=& \int \left( \frac{1}{x-2} + \frac{2}{x+4} \right)\, dx 

&=& - \int \frac{1}{x-2} \, dx + 2\int \frac{1}{x+4} \, dx 

&=& \ln |x-2| + 2\ln |x+4| + C
\end{eqnarray*}

:::






:::example

จงหา $\int \frac{2x+4}{(2x-1)(3x+1)} \, dx$

:::


:::solution

เนื่องจากข้อนี้เป็นโจทย์ใหม่ ฉะนั้นขั้นตอนแรก เราต้องแยกเป็นเศษส่วนย่อยก่อน กำหนดให้
\begin{eq*}
\frac{2x+4}{(2x-1)(3x+1)} &=& \frac{A}{2x-1} + \frac{B}{3x+1} 

2x+4 &=& A(3x+1) + B(2x-1) 
\end{eq*}
จากนั้น แทนค่า $\red{x= -\frac{1}{3}}$ เพื่อหาค่า $B$ และแทนค่า $\blue{x= \frac{1}{2}}$ เพื่อหาค่า $A$

:::





:::solution
(ต่อ)
เมื่อแทนค่า $\red{x= -\frac{1}{3}}$ จะได้
\begin{eq*}
2\red{\left(-\frac{1}{3}\right)} + 4 &=& A\left( 3 \red{\left(-\frac{1}{3}\right)} + 1 \right) + B\left(2 \red{\left(- \frac{1}{3}\right)} -1 \right) 

\frac{10}{3} &=&0 + B\left(-\frac{5}{3} \right) 

B &=& -2
\end{eq*}
เมื่อแทนค่า $\blue{x= \frac{1}{2}}$ จะได้
\begin{eq*} 
2\blue{\left(\frac{1}{2}\right)} +4 &=& A\left( 3 \blue{\left(\frac{1}{2}\right)} + 1 \right) + B\left(2 \blue{\left( \frac{1}{2}\right)} -1 \right) 

5 &=& A\left( \frac{5}{2} \right) + 0 

A &=& 2
\end{eq*}

:::





:::solution
(ต่อ)
ฉะนั้น
\[\frac{2x+4}{(2x-1)(3x+1)} = \frac{2}{2x-1} + \frac{-2}{3x+1} \]
จะได้ว่า
\begin{eqnarray*}
\int \frac{2x+4}{(2x-1)(3x+1)} \, dx &=& \int \frac{2}{2x-1} + \frac{-2}{3x+1} \, dx 

&=& 2 \int \frac{1}{2x-1} \, dx - 2\int \frac{1}{3x+1} \, dx 

&=& 2\left( \frac{1}{2} \ln |2x-1|\right) - 2\left( \frac{1}{3} \ln |3x+1| \right) + C 

&=& \ln|2x-1| -\frac{2}{3} \ln |3x+1| + C
\end{eqnarray*}

:::
