## ตัวอย่างที่ 2

กำหนดให้ราคาเริ่มต้นของสิ้นค้าคือ $x$ บาท


ให้ฟังก์ชันราคาหลังจากคิดส่วนลดจากร้านค้า เป็น $f(x) = 0.5 x$


ให้ฟังก์ชันราคาหลังจากคิดส่วนลดจากคูปอง เป็น $g(x) = 0.9 x$


ถ้าเรานำส่วนลดที่ได้จากร้านค้า ไปใช้เป็นราคาในการคำนวณส่วนลดจากคูปอง จะได้ว่า

:::slide

\[g(f(x) = g(0.5 x) = 0.9 (0.5 x) = 0.45 x \]

ซึ่งสังเกตว่า แทนที่จะคำนวณแยกกันสองรอบ เราสามารถคำนวณได้ทีเดียว โดยกำหนดฟังก์ชันใหม่คือ
\[ (g \circ f)(x) = 0.45 x\]

:::





## ฟังก์ชันประกอบ (composite function)

นอกจากที่เราจะสามารถนำฟังก์ชันมาบวก ลบ คูณ หาร ได้ตามปกติแล้ว เรายังสามารถนำมาประกอบกันเพื่อสร้างเป็นฟังก์ชันใหม่ได้ด้วย

:::definition

ฟังก์ชันประกอบ หรือ ฟังก์ชันคอมโพสิต ให้ $f(x)$ และ $g(x)$ เป็นฟังก์ชันใดๆ ฟังก์ชันคอมโพสิท คือ $f \circ g$ โดยที่ 
\[ (f \circ g)(x)= f(g(x))\]
นั่นคือ เราแทนค่า $x$ เป็น $g(x)$ ในฟังก์ชัน $f(x)$

:::

*การสร้างฟังก์ชันประกอบในรูปของการทำงานเครื่องจักรแบบต่อเนื่อง*





:::figure function_composite_meme1 — ความแตกต่างระหว่าง $f \circ g$ และ $g \circ f$
:::






:::example

กำหนดให้ $f(x) = x+1$ และ $g(x) = x^2$ จงหา 


- $(f \circ g)(x)$

- $(g \circ f)(x)$

- $(f \circ f)(x)$

- $(g \circ g)(x)$


:::


:::solution

\begin{eqnarray*}
(f \circ g)(x) &=& f(**g(x)**) = **g(x)** + 1 = x^2 + 1 

(g \circ f)(x) &=& g(**f(x)**) = **f(x)**^2 = **(x+1)**^2
\end{eqnarray*}
สังเกตว่า $(f \circ g)(x) \neq (g \circ f)(x)$ นั่นคือลำดับการเขียนมีผลต่อผลลัพธ์
\begin{eqnarray*}
(f \circ f)(x) &=& f(**f(x)**) = **f(x)** + 1 = **x+1** + 1 = x+2 

(g \circ g)(x) &=& g(**g(x)**) = (**g(x)**)^2 = (**x^2**)^2 = x^4
\end{eqnarray*}

:::






:::example

กำหนดให้ $f(x) = \sqrt{x} $ และ $g(x) = 2x+1$ จงหา 


- $(f \circ g)(x)$

- $(f \circ g)(4)$

- $(g \circ f)(x)$

- $(g \circ f)(4)$


:::


:::solution

\begin{eqnarray*}
(f \circ g)(x) &=& f(**g(x)**) = \sqrt{**g(x)**} = \sqrt{2x+1} 

(f \circ g)(4) &=& \sqrt{2(4) + 1 } = \sqrt{9} = 3 

(g \circ f)(x) &=& g(**f(x)**) = 2**f(x)**+1 = 2\green{\sqrt{x}} + 1 

(g \circ f)(4) &=& 2\sqrt{4} + 1 = 2(2) + 1 = 5
\end{eqnarray*}

:::
